## 证候名称：瘀热发黄证（急黄·瘀热型）
### 辨证体系
- 所属体系：脏腑辨证、八纲辨证、卫气营血辨证
- 涉及脏腑：肝、胆、心、胃、脾

### 主症（必备症状）
- 身目俱黄，黄色鲜明如金（急黄特征）
- 尿色深黄如浓茶
- 大便干结，2–3日一行
- 肝区胀痛、腹满胀感
- 鼻衄、肌肤瘀斑（热迫血行）

### 兼症（常见伴随症状）
- 纳差、恶心、乏力
- 口干口苦、烦躁
- 精神萎靡、懒言少语
- 低热或身热不扬

### 舌象
- 舌质：偏红或红绛
- 舌苔：黄薄腻或黄燥

### 脉象
- 弦滑数

### 病因
- 外感湿热疫毒（主因）
- 素有痰火、气郁（旧病精神分裂症）
- 久病入络，湿热瘀阻血分
- 饮食不节、嗜酒（诱因）

### 病机
- 湿热疫毒 → 蕴结肝胆脾胃 → 深入营血 → 瘀热互结 → 胆汁外溢发黄
- 瘀热阻滞胆道 → 胆液不循常道 → 身目尿黄
- 热迫血行 → 鼻衄、出血倾向
- 核心病机：**湿热瘀毒深结血分，肝胆失疏，瘀热发黄**

### 鉴别要点
- 与**湿热发黄（气分）**鉴别：瘀热发黄病在**血分**，见出血、舌绛、脉弦滑数；湿热发黄多在**气分**，无明显出血、舌偏红苔黄腻、脉弦数
- 与**疫毒发黄（急黄·热毒型）**鉴别：瘀热发黄以**瘀、黄、出血、神呆**为主；疫毒发黄以**高热、神昏谵语、烦躁抽搐**更突出
- 与**寒湿阴黄**鉴别：阴黄黄色晦暗、畏寒、便溏、舌淡苔白腻、脉濡缓；本证黄色鲜明、热象显著

### 辨证逻辑规则
- 若见**身目黄如金 + 尿深黄 + 大便干结 + 肝区胀痛 + 鼻衄/瘀斑 + 舌红苔黄腻 + 脉弦滑数** → 可确诊瘀热发黄证
- 若黄疸进行性加深 + 出血倾向 + 神志迟钝 → 提示**瘀热深入营血、病情危重**
- 若兼见**精神异常、懒言少语、反应迟钝** → 提示**瘀热兼夹痰浊、阻闭心窍**
