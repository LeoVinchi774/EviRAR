## 证候名称：饮阻肝胃，清阳不升证

### 辨证体系
- 所属体系：脏腑辨证、气血津液辨证
- 涉及脏腑：肝、胃、脾

### 主症（必备症状）
- 眩晕，视物旋转
- 恶心呕吐，嗳气
- 肝区胀痛，牵及肩臂

### 兼症（常见伴随症状）
- 心悸
- 口干不喜饮
- 胸胁苦满
- 食少纳呆

### 舌象
- 舌质：暗红
- 舌苔：薄黄或白滑

### 脉象
- 沉弦，或弦数

### 病因
- 情志不遂，肝气郁结
- 饮食伤脾，水湿内停
- 肝脾失调，痰饮内生，阻滞肝胃

### 病机
- 肝气郁滞 → 横逆犯胃 → 脾胃失运 → 水饮内停 → 阻滞肝胃 → 清阳不升 → 眩晕；胃失和降 → 恶心呕吐；肝络不和 → 肝区痛牵肩臂；饮邪扰心 → 心悸；饮郁化热 → 苔薄黄、脉弦
- 核心病机：**肝脾失调，痰饮内停，肝胃不和，清阳不升**

### 鉴别要点
- 与**痰饮内停阻滞清阳证**鉴别：本证**肝区痛、肩臂牵痛、胁胀**更突出；前者病位更广泛
- 与**肝气郁结证**鉴别：本证有水饮征象（眩晕、呕逆、苔滑、脉弦）；肝气郁结以胁胀、善太息、脉弦为主
- 与**肝火上炎证**鉴别：本证无面红目赤、口苦、舌红苔黄、脉弦数等纯热象

### 辨证逻辑规则
- 若有"**眩晕+肝区痛+肩臂牵痛+恶心呕吐**" → 提示饮阻肝胃，清阳不升证
- 若**舌暗红、苔薄黄、脉沉弦** → 支持本证（饮阻气滞化热）
- 若"**眩晕与情绪波动相关**" → 提示肝失疏泄，肝脾同病
- 本证属**里、虚实夹杂、寒热错杂**，不应出现"纯寒（苔白滑、脉沉迟）或纯热（舌红苔黄燥、脉弦数）"极端表现
