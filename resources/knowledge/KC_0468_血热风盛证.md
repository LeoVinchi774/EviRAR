## 证候名称：血热风盛证

### 辨证体系
- 所属体系：气血辨证、卫气营血辨证
- 涉及脏腑：心、肝、肺

### 主症（必备症状）
- 皮肤紫癜，色鲜红或紫红，略高出皮面，对称分布于下肢
- 瘙痒剧烈，伴抓痕、血痂
- 起病急骤，发展迅速

### 兼症（常见伴随症状）
- 发热，微恶风寒，咽痛
- 关节肿痛，腹痛，便血
- 口干口苦，心烦易怒
- 小便短赤，大便干结

### 舌象
- 舌质：红或绛
- 舌苔：薄黄或黄腻

### 脉象
- 浮数或弦数

### 病因
- 外感风热之邪（主因）——侵袭肌表，入于营血
- 情志失调，肝郁化火（诱因）——火热内生，灼伤血络
- 饮食不节，嗜食辛辣（诱因）——酿生湿热，迫血妄行

### 病机
- 外感风热/肝郁化火/饮食不节 → 火热内生 → 侵入营血 → 迫血妄行 → 血溢脉外 → 渗于肌肤 → 发为紫癜 → 风热之邪侵袭肌表 → 瘙痒剧烈 → 热盛伤津 → 口干口苦、小便短赤
- 核心病机概括：血热风盛，迫血妄行，血溢脉外，肌肤失养

### 鉴别要点
- 与"血瘀内阻，滋于外络证"鉴别：血瘀内阻证起病缓，紫癜色紫暗，无明显热象，舌质暗红有瘀点，脉弦；本证起病急，紫癜色鲜红，伴发热咽痛，舌红苔黄，脉浮数
- 与"湿热蕴结证"鉴别：湿热蕴结证伴关节肿痛、腹胀腹痛、大便黏滞，舌苔黄腻，脉滑数；本证以风热表证为主，关节症状较轻，舌苔薄黄，脉浮数
- 与"热毒入血证"鉴别：热毒入血证病情重，瘀斑成片，色紫暗，伴高热、神昏，舌红绛，脉滑数；本证病情较轻，以风热表证为主，无明显神昏表现

### 辨证逻辑规则
- 若有"急性起病+皮肤鲜红紫癜+发热咽痛+瘙痒" → 高度提示本证
- 若舌红苔黄，脉浮数 → 支持本证；若舌质暗红有瘀点，脉弦或涩 → 排除本证
- 若出现"关节肿痛、腹痛、便血" → 需考虑热毒内蕴之变证
- 本证属"热证、实证"，不应出现"皮肤紫暗、面色晦暗、畏寒肢冷"等寒象表现
- 若抗过敏治疗有效，皮损分布对称 → 支持本证，符合过敏性紫癜特点
