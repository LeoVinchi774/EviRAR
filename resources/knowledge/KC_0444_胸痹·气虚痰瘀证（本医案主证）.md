## 证候名称：胸痹·气虚痰瘀证（本医案主证）
### 辨证体系
- 所属体系：脏腑辨证、八纲辨证、病性辨证
- 涉及脏腑：心、脾、肺、肾

### 主症（必备症状）
- 反复胸闷痛，劳累诱发，休息或服药可缓解
- 神疲体倦，气短气促，动则尤甚
- 咳嗽，痰白量不多
- 双下肢浮肿，不能平卧

### 兼症（常见伴随症状）
- 口干，纳差，睡眠欠佳
- 心悸，脉律不整（早搏）
- 面色少华或晦暗

### 舌象
- 舌质：淡暗
- 舌苔：白微浊

### 脉象
- 细数

### 病因
- 年老体虚（主因）：年高脏腑机能衰退，心气亏虚
- 久病耗伤（主因）：心梗后心脉受损，气血耗伤
- 饮食失节（诱因）：脾胃损伤，痰湿内生
- 劳逸失调（诱因）：劳累耗气，加重心脾亏虚

### 病机
- 心气亏虚 → 血行无力 → 瘀血阻滞心脉
- 脾气虚弱 → 运化失司 → 水湿内停 → 聚为痰浊
- 痰瘀互结 → 痹阻心脉 → 胸阳不展 → 发为胸痹
- 心肺同病 → 肺气不宣 → 咳嗽气促，不能平卧
- 气虚及阳 → 水湿不化 → 泛溢肌肤 → 下肢浮肿
- 核心病机：**气虚为本，痰瘀为标，虚实夹杂，心脉痹阻**

### 鉴别要点
- 与"气虚血瘀证"鉴别：本证兼痰浊（咳嗽、白痰、苔浊），血瘀证无明显痰象，舌紫暗、脉涩更著
- 与"痰浊闭阻证"鉴别：本证以气虚为基础（神倦、气短、动则甚），痰浊证以痰盛（痰多、苔厚腻、脉滑）为主，气虚不显
- 与"气阴两虚证"鉴别：本证痰瘀并见（舌暗、苔浊），气阴两虚证以口干、舌红少苔、脉细弱为主，无痰浊瘀阻之象
- 与"阳虚水泛证"鉴别：本证无明显寒象（畏寒、肢冷），阳虚水泛证见舌淡胖、苔白滑、脉沉细、畏寒肢冷

### 辨证逻辑规则
1. 必备条件：**胸闷痛 + 气虚（神倦、气短、动则甚） + 痰浊（咳嗽、白痰、苔浊） + 血瘀（舌淡暗）** 四者同时存在
2. 核心规则：**气虚是前提，痰瘀是关键，心脉痹阻是结果**
3. 舌脉规则：**舌淡暗、苔白微浊、脉细数** 为特征性组合
4. 排除规则：无明显寒象（畏寒、肢冷）、无明显热象（口苦、苔黄）、无阴虚（舌红少津）表现
5. 合并症规则：可兼心悸、脉律不整、下肢浮肿、不能平卧
