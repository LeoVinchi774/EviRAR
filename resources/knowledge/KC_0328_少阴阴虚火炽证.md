## 证候名称：少阴阴虚火炽证

### 辨证体系
- 所属体系：**六经辨证（少阴病）**、**脏腑辨证（心肾）**
- 涉及脏腑：**心、肾**

### 主症（必备症状）
- 心中烦热不得卧（彻夜不寐）
- 舌红质红（舌尖红赤尤著）
- 脉象细数
- 病邪犯表后，经发表、肃肺等治法后，余邪未净

### 兼症（常见伴随症状）
- 精神萎顿
- 胸痞未除
- 口燥咽干（可选）
- 手足心热（可选）

### 舌象
- 舌质：红（舌尖红赤尤著）
- 舌苔：薄腻、苔黄

### 脉象
- 浮（初诊时表邪未解）→ 后转为**细数**（核心脉象）

### 病因
- 外感风寒之邪（主因），太阳表证未解
- 发表、肃肺等治法不当（诱因），致邪热内传少阴
- 素体阴液不足（潜在因素），邪从热化，灼伤真阴

### 病机
- 太阳表邪未解 → 经发表治疗后寒热退，但余邪内陷少阴 → 肾阴亏于下，不能上济心火 → 心火亢于上，神不安舍 → 心中烦热不得卧；阴液耗伤 → 舌红质红、脉细数；余邪阻滞气机 → 胸痞未除；正气受损 → 精神萎顿
- 核心病机：**心肾不交，水火失济，阴虚火旺，神不守舍**

### 鉴别要点
- 与**少阴寒化证**鉴别：寒化证见畏寒肢冷、下利清谷、脉微细、舌淡苔白；本证为虚热，见心烦不寐、舌红质红、脉细数
- 与**栀子豉汤证（虚烦证）**鉴别：虚烦证为余热郁于胸膈，无阴虚之象（舌不红少苔、脉不细数），病位较浅；本证为少阴阴虚火旺，病位在里，伴肾阴虚见症
- 与**心火亢盛证**鉴别：心火亢盛证仅见心烦失寐等心火偏亢症状，无肾阴虚见症（如口燥咽干、脉细数）；本证兼具心火偏亢与肾阴虚表现
- 与**猪苓汤证（阴虚水热互结）**鉴别：猪苓汤证伴口渴喜凉、小便不利、水肿等水热互结见症；本证以心肾不交、神不守舍为核心，无水湿内停表现

### 辨证逻辑规则
- 若有**“心中烦热不得卧 + 舌红质红 + 脉细数”**症状组合 → 高度提示本证
- 若**舌象为红、苔黄**，脉象**细数** → 支持本证（阴虚火旺）；舌淡苔白、脉沉微则排除本证
- 若出现**“精神萎顿 + 胸痞未除”** → 为余邪未净、正气受损之象，需考虑本证兼余邪阻滞
- 本证属**虚热证（阴虚火旺）**，不应出现**畏寒肢冷、下利清谷、脉微细**等寒化证表现
- 本证为**少阴病热化**范畴，病位在里，属**里虚热证**，与太阳表证（恶寒无汗、头痛骨楚）有别
