### 一、 模拟问诊路径（针对水肿/慢性肾炎急性发作场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“您这次主要是因为哪里不舒服来看病？”（引导患者说出“咽喉疼痛”或“浮肿”等主诉）；“这个浮肿/不舒服的情况有多久了？是第一次出现还是反复发作？”
- 医案特征提取：病程长达4年，为慢性病程；浮肿反复发作，呈顽固性；本次因“劳累过度，复感外邪”急性加重。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望神**：观察患者精神是否萎靡（神疲乏力）。
    - **望形态与浮肿**：重点观察颜面、眼睑有无浮肿，其程度如何（颜面浮肿）。观察有无咳嗽、咳痰，痰的性状（咳嗽黄痰）。
    - **望咽喉**：检查咽喉部是否红肿、疼痛（咽喉疼痛）。
- **触觉焦点**：
    - **切脉**：重点体会脉象是否濡软无力，或兼有浮、滑、数等象（脉濡）。
    - **测量**：测量血压（血压150/100mmHg）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - 舌诊：舌质颜色（红），舌苔颜色与厚薄（苔薄黄）。
    - 脉诊：脉象的力度、形态（濡）。
- **关联病史与症状追问**：
    1.  **外感与卫表**：“最近有没有怕风、怕冷的感觉？”（畏风怕冷）；“有没有发烧、头痛、鼻塞？”（确认表证）。
    2.  **脾肾功能与水液代谢**：“胃口怎么样？有没有腹胀？”（食欲不振）；“感觉腰酸、腿软吗？”（腰膝酸软）；“小便颜色、量怎么样？有没有尿频、尿急、尿痛？”（小溲短赤，结合尿检脓球提示下焦湿热）。
    3.  **既往史与治疗史**：“以前有没有得过急性肾炎或肾脏方面的疾病？什么时候？”（1992年急性肾炎史）；“这4年来浮肿和尿蛋白的情况，用过哪些药？效果怎么样？”（顽固性蛋白尿，中西药治疗史）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发病前有没有特别劳累或者感冒？”（明确诱因：劳累、外感）；“这次发病后，自己用过什么药吗？感觉有没有缓解？”（了解当前治疗反应及外邪是否仍在表）。
- **检查印证**：必须结合实验室检查，追问或查看“尿常规”结果，重点关注蛋白、红细胞、脓细胞、管型等指标（蛋白(+++)，红细胞(+)，脓球(+)），这是辨证“湿热蕴结下焦”和判断病情严重程度的关键客观依据。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肺、脾、肾**三脏同病，以**肾**为本，**肺**为标，涉及**下焦**（膀胱）。
    - **肺**：主宣发肃降，通调水道。风热犯肺，宣降失司，故见咽喉疼痛、咳嗽。
    - **脾**：主运化水湿。脾虚失运，水湿内停，故见浮肿、食欲不振、神疲乏力。
    - **肾**：主水，藏精。肾气虚，气化失司，固摄无权，故水湿泛滥（浮肿、腰膝酸软），精微下泄（蛋白尿）。
    - **下焦**：湿热之邪蕴结膀胱，气化不利，故见小溲短赤，尿检见脓球、红细胞。

- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**气虚**（肺肾气虚，脾虚）。
    - **标实**：**热**（风热、湿热）、**湿**（水湿、湿热）。

- **推理公式**：
    - **[主症：反复浮肿、顽固性蛋白尿]** + **[诱因：劳累后复感外邪]** → 提示 **肺肾气虚，卫外不固** 的慢性虚弱病机。
    - **[新发症：咽喉疼痛、咳嗽黄痰、畏风怕冷]** + **[舌脉：舌红苔薄黄]** → 推导 **风热犯肺，表证未解**（急性发作诱因）。
    - **[全身症：食欲不振、神疲乏力]** → 推导 **脾虚失运**。
    - **[局部症：腰膝酸软]** + **[核心症：浮肿、蛋白尿]** → 推导 **肾虚气化失司，固摄无权**。
    - **[下焦症：小溲短赤]** + **[客观指标：尿检红细胞(+)、脓球(+)]** + **[舌脉：舌红苔黄]** → 推导 **湿热蕴结下焦**。
    - **综合**：**肺肾气虚（本）** + **脾运失健（本）** + **风热犯肺（标）** + **湿热蕴结下焦（标）** → **辨证结论：水肿（肺肾气虚，湿热蕴结，脾运失健）**。

- **鉴别要点**：
    1.  **单纯风水泛滥证**：多见于急性起病，浮肿以眼睑、头面为主，伴恶寒发热、脉浮等表证突出，但无长期腰酸、蛋白尿等肾虚之本。**本案**为慢性基础上有急性表证，需鉴别表证是风寒还是风热（本案为黄痰、舌红苔黄，属风热）。
    2.  **脾肾阳虚水泛证**：浮肿常更甚，可至全身，伴畏寒肢冷、小便清长或夜尿多、舌淡胖苔白滑、脉沉迟等一派虚寒之象。**本案**有小便短赤、舌红苔黄、尿检有脓球，热象明显，故非纯阳虚，而是气虚夹湿热。
    3.  **下焦湿热与血淋鉴别**：两者均可见小便短赤、尿检有红细胞/脓球。但血淋以小便涩痛、尿血鲜红为主症；**本案**以浮肿、蛋白尿为主症，小便短赤为伴随症状，病机核心在肾虚不固与湿热下注，而非淋证。
