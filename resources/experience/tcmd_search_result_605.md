### 一、 模拟问诊路径（针对重症肌无力危象合并真菌感染场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：请详细描述您目前最难受、最紧急的症状是什么？（例如：是喘不上气，还是吞咽困难，还是全身没力气？）这种情况是什么时候开始加重的？加重前有没有感冒、发烧？
- **医案特征提取**：病程长（6年基础病史），急性加重（因感冒发热诱发），危重状态（呼吸困难、吞咽不下、全身瘫软）。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉焦点**：
    - **望神**：精神是否萎靡、倦怠？（神倦）
    - **望形态**：眼睑是否下垂？颈部能否自行抬起？（颈软无力抬起）
    - **望口腔**：口唇、上颚、咽部黏膜有无白色膜状物、糜烂或溃疡？（鹅口疮体征）
    - **望分泌物**：痰涎的多少、颜色、质地？（痰涎壅盛、色白）
    - **望二便**：大便的性状、次数？（频频腹泻水样便）
- **触觉/听觉焦点**：
    - **听声音**：语言是否清晰？有无痰鸣音？（语言不清）
    - **听呼吸**：呼吸是否短促？有无啰音？（呼吸气短，双下肺干湿啰音）
    - **问感觉**：吞咽食物或水时是否费力或呛咳？（吞咽困难）

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌体胖瘦、颜色？舌苔厚薄、颜色、润燥？（舌质淡胖，舌苔白腻）
    - **脉诊**：脉象的力度、粗细、频率？（脉微细弱）
- **关联病史追问**：
    - 重症肌无力确诊多久？平时如何维持治疗？（长期口服强的松、溴吡斯的明及中药）
    - 近期是否使用过抗生素、免疫抑制剂（如环磷酰胺）？使用多久？（长期及近期大量使用激素、抗生素史，是诱发真菌感染的关键）
    - 有无发热、咳嗽？（感冒发热诱发）

**第四层：治疗经过与转归判断**
- **关键提问**：这次加重后，在西医院用过哪些药物（特别是抗生素、激素、免疫球蛋白等）？效果如何？（使用高级抗生素、免疫抑制剂后病情“急转直下”、“无好转”，提示治疗反应异常，需考虑特殊感染）
- **关键检查追问**：最近的痰培养、大便涂片结果是什么？（实验室检查提示真菌感染）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、胃**（为病变之本），涉及**肺**（呼吸、痰涎）、**大肠**（腹泻）。
- **核心病性**：**本虚标实**。
    - **本虚**：极度**气虚**（脾胃虚损，元气大伤），进而**气陷**（大气下陷）。
    - **标实**：**湿浊、痰饮、热毒**（真菌感染表现为鹅口疮、痰多、腹泻）。
- **推理公式**：
    1.  **【长期病史+危象主症】**：长期重症肌无力（痿证）病史 + 急性出现的**呼吸困难、吞咽不下、颈软、脉微细弱** → 推导为 **“大气下陷”**（气虚至极，升举无力，脏腑功能垂危）。
    2.  **【体质基础+用药史】**：脾胃虚损（痿证）体质 + **长期大量使用激素、抗生素**（损伤脾胃元气） → 强化 **“脾胃虚损，元气大伤”** 的病机判断。
    3.  **【感染体征+舌脉】**：**口腔白色薄膜（鹅口疮）、痰多、腹泻、舌苔白腻** + 在极度虚损基础上出现 → 推导为 **“湿浊（真菌）蕴结”** 的标实证，此乃正虚邪乘。
    4.  **【综合诊断】**：**脾胃虚损、大气下陷（本）** + **湿浊蕴肺与大肠（标）** → 中医诊断：**痿证（脾胃虚损、大气下陷），鹅口疮**。
- **鉴别要点**：
    - **鉴别单纯湿热与虚损夹湿**：本例虽有白腻苔、湿浊表现，但根本在于**舌质淡胖、脉微细弱、全身功能衰竭**，此为**虚损至极，湿浊内停**，与实热或单纯湿热证（舌红、苔黄腻、脉滑数）的病性根本不同。治疗需以**大补元气、升阳举陷为主**，佐以化湿祛浊，不可过用苦寒清利。
    - **鉴别感染性质**：在常规抗细菌感染治疗无效且加重时，需高度警惕**特殊病原体（如真菌）感染**，此乃长期免疫抑制治疗的常见并发症，中医视为“虚处留邪”。问诊和检查需针对性追溯抗生素、免疫抑制剂使用史及病原学结果。
