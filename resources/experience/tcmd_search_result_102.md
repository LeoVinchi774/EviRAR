### 一、 模拟问诊路径（针对“精中带血/血精”场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最不舒服、最担心的问题是什么？”（引导主诉）→ “发现精液带血有多久了？是每次都有，还是偶尔出现？是在什么情况下发现的？”
- **医案特征提取**：患者主诉为“入房后精液带血”，属突发性事件（“近来忽发现”），且与“房事过于频繁”的诱因直接相关。问诊需重点锁定血精的出现时间、频率、与性活动的关系。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：无需直接望诊局部，但需通过问诊了解“精液带血”的具体性状（如颜色鲜红或暗红、血量多少、是否夹有血块）。
- **触觉/自觉症状焦点**：询问有无“强中”（阴茎异常勃起，久举不衰）现象及其持续时间。询问房事前后或平素有无会阴、小腹、睾丸等部位的坠胀、疼痛或灼热感。
- **医案特征提取**：本医案关键局部特征为“强中现象”与“精液带血”并存，提示“相火炽盛”与“精道出血”的关联。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**必须查看舌象（舌色、苔色、苔质）与脉象**。本医案提示：舌苔黄腻，脉细弱而数。
- **全身症状与体质追问**：
    1.  **精力与神志**：“最近感觉精神、体力怎么样？有没有觉得特别疲劳、困倦、提不起劲？”（对应：一身困倦、四肢无力、神态萎靡）
    2.  **饮食与消化**：“胃口怎么样？吃东西有味道吗？有没有口干、口苦的感觉？”（对应：饮食无味，兼夹湿热）
    3.  **形体与面色**：观察患者**形体是否消瘦**，**面色是否苍白或萎黄、缺乏光泽**。（对应：形体消瘦，面白不泽）
    4.  **体质与病史**：“您平时身体底子怎么样？是不是比较怕热、容易上火？或者以前医生说过您是阴虚体质吗？”（对应：素禀阴亏体质）
    5.  **情志**：“发现这个问题后，情绪、睡眠怎么样？”（对应：思想异常紧张）

**第四层：治疗经过与转归判断**
- **关键提问**：“发现这个问题后，有没有去医院做过检查？（如精液常规、细菌培养）结果如何？”“之前有没有用过什么药（特别是抗生素或止血药）？效果怎么样？”
- **医案特征提取**：医案中已进行“精液检查示红细胞（++），白细胞少许，可见革兰阴性杆菌”，西医诊断为“精囊炎”。问诊需确认检查结果，并了解前期治疗史，以判断病情阶段及对中药治疗的反应性。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肾**（主藏精）、**精室/精窍**。涉及肝经（肝经绕阴器）与相火。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**肾阴亏虚**（根本）。
    - **标实**：**相火炽盛**（虚火上炎）、**兼夹湿热**。

- **推理公式**：
    1.  **[主症：精液带血 + 强中现象] + [体质与诱因：素禀阴亏 + 房事频繁]** → 推导病机起点：肾阴亏虚，阴不制阳，导致**相火偏亢**（强中）。虚火扰动精室，迫血妄行，故见血精。
    2.  **[全身症状：形体消瘦、神疲乏力、面白不泽] + [脉象：细弱]** → 印证并深化“本虚”判断。“壮火食气”，相火过亢（壮火）耗伤人体正气（气），故出现一系列气虚症状（困倦、乏力）；阴精与气血耗伤，机体失养，故见形体消瘦、面白不泽、脉细弱。此为**阴亏及气，气阴两伤**之象。
    3.  **[舌象：苔黄腻] + [症状：饮食无味] + [检查：可见革兰阴性杆菌]** → 提示兼夹**湿热**为患。湿热蕴结于下焦，上泛于舌，故苔黄腻；困阻脾胃，故饮食无味。细菌检查结果从微观层面佐证了湿热（炎症）的存在。
    4.  **[脉象：数]** → 是**邪火**（包括虚火与湿热之热）存在的直接征象。

- **综合辨证结论**：**肾阴亏极，相火炽盛，兼夹湿热**。其中，肾阴亏虚是病本，相火亢盛是核心病机，湿热是兼夹邪气，气虚是火盛耗气的病理结果。

- **鉴别要点**：
    1.  **单纯湿热下注证 vs 本证（阴虚火旺兼湿热）**：
        - **单纯湿热下注**：多以实证为主。血精颜色可能更鲜红或暗红，伴明显的会阴、小腹灼热胀痛，小便黄赤，舌红苔黄腻，脉滑数或弦数。但**通常无长期阴虚体质背景，无明显的形体消瘦、脉细等阴伤之象，强中现象不突出或无**。
        - **本证**：具备明显的阴虚火旺体质与症状（如素体阴亏、强中、脉细），湿热是兼夹表现。治疗需**滋阴降火为主，清利湿热为辅**，切忌过用苦寒燥湿而重伤阴液。
    2.  **气虚不摄证 vs 本证**：
        - **气虚不摄**：血精可能色淡，伴有明显的气短、乏力、自汗、舌淡苔白、脉弱无力等气虚症状，**但无阴虚火旺（如强中、五心烦热）和湿热（如苔黄腻）的表现**。
        - **本证**：虽有气虚症状（神疲乏力），但其根源在于“壮火散气”，本质是阴虚火旺耗气所致。若误辨为单纯气虚而滥用补气（如人参、黄芪），恐助长火热，加重病情（“无异火上加油”）。治疗关键在于“养阴为主，使水生火降，少火自能生气”。
