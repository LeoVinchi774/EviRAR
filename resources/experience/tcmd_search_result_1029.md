### 一、 模拟问诊路径（针对粉刺/痤疮伴色斑场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“面部粉刺（痘痘）出现多久了？有什么明显的原因吗？在什么情况下会加重？”
- **医案特征提取**：病程半年，无明显诱因，但**经行前期明显加重**。此点提示病情与月经周期、血分变化密切相关，是问诊关键。

**第二层：局部体征细查（望诊/触诊导向）**
- **视觉焦点**：
    - **形态与大小**：粉刺大小不一，大者如豆，小者如粟。
    - **颜色与性质**：皮损**红褐相间**，部分有**黑色脓头**。注意观察是否有**色斑沉着**（医案中为治疗后出现的转归，但初诊时需关注色素沉着倾向）。
    - **分布**：此起彼伏，持续存在。
- **触觉与感觉焦点**：
    - **患者自觉症状**：询问是否伴有**瘙痒**或疼痛。
- **医案特征提取**：**红褐相间**（红为热，褐为瘀）、**黑色脓头**（热毒瘀结）、**瘙痒**（风热或血热）、**色斑沉着**（血瘀或络阻）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡红/红/绛）、舌苔（薄白/黄/腻）、脉象（细/数/弦）。医案中为“舌淡红，苔薄白，脉细”，提示阴虚血热但热象未完全外露于舌，脉细则主阴血不足。
- **全身症状追问**：
    1.  **二便**：“平时大便情况如何？干不干？”（医案：大便干，提示津亏或热结）。
    2.  **月经**：“月经的量、色、质怎么样？有没有血块？经期前后身体有什么特别感觉？”（医案：经量少色黄，此为关键辨证信息，量少为阴血不足，色黄为有热）。
    3.  **睡眠与情志**：“睡眠怎么样？容不容易做梦？平时情绪、压力大不大？”（医案：夜寐多梦，结合“操劳谋虑”，提示心肝血虚、虚火扰神）。
    4.  **治疗史与体质**：“之前用过什么药？效果怎么样？”（医案：曾用牛黄解毒丸等苦寒清热药无效，反增色斑，提示病机非单纯实火，可能涉及阴虚或血瘀，苦寒更伤阴血）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前治疗（如内服清热解毒药、外治）后，粉刺是减轻了、没变化，还是出现了其他新问题（如色斑）？”此问旨在验证“苦寒伤阴，血热凝瘀”的病机推断，并评估病势转归。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、肝**。心主血脉，其华在面；肝藏血，主疏泄。病在面部**血分孙络**（细小血脉）。
- **核心病性**：**本虚标实**。**本虚**为**心肝阴血亏虚**；**标实**为**血热、血瘀**。热属**虚热**（相火、君火妄动）与**郁热**并存。
- **推理公式**：
    - **[主症：面部粉刺经前加重] + [体征：粉刺红褐相间、有黑色脓头、伴色斑] + [全身症：经量少色黄、大便干、夜寐多梦] + [舌脉：脉细（舌淡红苔薄白为热未完全浮越之象）] + [治疗史：苦寒清热无效反增色斑]**
    - **→ 辨证结论：阴虚血热，面部孙络闭阻证。**
    - **推导链**：
        1.  **经前加重、经少色黄、夜梦多** → 指向**肝血（阴）不足，相火内动；心血（阴）不足，虚火扰神**（心肝阴虚血热）。
        2.  **粉刺红褐、有黑头、色斑** → 血热煎灼为“红”，血行不畅成“褐”、“黑”，瘀滞于络为“斑”（**血热瘀阻**）。
        3.  **大便干** → 阴津不足，肠道失润。
        4.  **脉细** → 主阴血亏虚。
        5.  **苦寒药无效反加重** → 证实非单纯实热火毒，过用苦寒更伤阴血，使血热凝涩，瘀阻加重（**“寒则凝涩”**），故色斑显现。
- **鉴别要点**：
    - **与单纯肺经风热/肠胃湿热证鉴别**：后者多见于青少年，粉刺鲜红、疼痛，多有皮脂溢出，常伴口干、便秘、苔黄腻等实热证，对清热解毒法（如枇杷清肺饮）反应较好。本案为中年女性，有经期关联、阴血不足体征（经少、梦多、脉细），且苦寒无效，可资鉴别。
    - **与单纯气滞血瘀证鉴别**：后者色斑或暗疮结节为主，疼痛固定，可能伴胁胀、舌紫暗、脉涩，但阴虚内热之象（如经色黄、夜梦）不显。本案热象（经色黄、粉刺红）与阴虚象（经少、脉细）并见，病机更为复杂。
