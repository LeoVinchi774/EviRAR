### 一、 模拟问诊路径（针对冠心病PCI术后/胸痹场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最不舒服的是什么？是在什么情况下出现或加重？（如活动后）”
- **医案特征提取**：主诉为“活动后气短，伴喘息，时有心前区疼痛”，病程为“久病”（PCI术后3年），加重因素为“活动后”。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者精神面貌（神疲）、面色、口唇颜色（暗紫倾向）、四肢末梢颜色及有无痉挛。
- **触觉焦点**：触摸患者四肢温度（逆冷畏寒），切诊脉象（沉细）。
- **医案特征提取**：四肢逆冷、畏寒、偶有痉挛；舌暗紫；脉沉细。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（色暗紫）、舌苔（薄白）；脉象（沉、细）。
- **关联病史追问**：
    1.  “心前区疼痛的具体性质、部位、持续时间？服用硝酸甘油后能否完全缓解？”（确认胸痹主症）
    2.  “除了心慌气短，平时体力如何？是否容易疲劳？”（探查气虚）
    3.  “胃口怎么样？肚子胀不胀？大便情况如何？”（探查脾胃功能）
    4.  “睡眠怎么样？容易醒吗？是否需要药物帮助？”（探查心神状况）
    5.  “平时怕冷吗？手脚凉不凉？”（探查阳虚）
    6.  “口干想喝水吗？口苦是持续的还是阵发的？”（探查津液与热象）
    7.  “既往有什么其他慢性病史？（如高血压）目前在服用哪些药物？”（明确病史与用药史）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次来就诊，主要是因为之前的症状控制不理想，还是有新的不舒服？”（明确就诊动因，结合医案为PCI术后长期调治）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：心（主血脉）、脾（主运化）、肾（主纳气、温煦）。病位在心，其本在脾肾。
- **核心病性**：本虚标实。**本虚**：气虚（心、脾、肾）、阳虚（肾）、阴虚（心肾）；**标实**：血瘀、痰阻、气滞。
- **推理公式**：
    1.  **[主症：活动后气短、喘息、心前区痛] + [全身症：神疲乏力] + [舌脉：脉沉细]** → 推导出 **心气亏虚，肾不纳气**（气虚推动无力，肾虚摄纳无权）。
    2.  **[全身症：四肢逆冷畏寒] + [舌象：舌暗]** → 推导出 **脾肾阳虚，温煦失职**（阳虚生寒，寒凝血滞）。
    3.  **[舌象：舌暗紫] + [病史：PCI术后，久病]** → 推导出 **气虚血瘀，脉络不通**（气为血帅，气虚则血行涩滞成瘀）。
    4.  **[伴随症：口干口苦、纳差、胃胀腹胀满、大便困难] + [舌苔：薄白（后期见腻）]** → 推导出 **脾虚运化失司，津液不布，气机壅滞**（脾虚生湿，气滞生胀，津亏肠燥）。
    5.  **综合**：将以上1-4点整合，形成完整病机链条：患者年高久病 → **脾肾虚衰（本）** → 导致水液不运生痰、气虚推动无力致瘀、阳虚温煦失职致寒 → **痰、瘀、寒互结，痹阻心脉（标）** → 发为胸痹。证属 **脾肾虚衰，气虚血瘀**（兼夹痰、气滞）。
- **鉴别要点**：
    1.  **区分单纯气虚血瘀与兼夹阳虚**：单纯气虚血瘀多见乏力、舌暗、脉弱，但畏寒、四肢逆冷不明显。本案脉沉细、肢冷畏寒，是**气虚及阳**的明确指征。
    2.  **区分胸痹与胃脘痛**：患者有胃胀、腹胀，需问清疼痛部位（心前区 vs 上腹部）、与饮食和活动的关系（活动后诱发 vs 食后加重），本案心前区痛与活动相关，且PCI术后病史明确，病位在心。
    3.  **辨口干口苦之寒热**：口干口苦常提示热象，但本案舌苔薄白、脉沉细、畏寒肢冷，整体偏寒，此口干口苦可能为**气虚津液不布**或**虚阳浮越、气机郁而化热**所致，属寒热错杂，治疗需温补为主，佐以清热滋阴（如用知母、麦冬）。
