### 一、 模拟问诊路径（针对长期便秘伴情志不畅场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您便秘多久了？具体是怎么个困难法？（比如几天一次、大便干不干、费力吗、有没有排不干净的感觉？）最近有没有加重？”
- **医案特征提取**：病程长达3年余，近2周加重。核心症状为“大便干燥，数日1行，排便困难，排便不尽”。此为功能性便秘的典型主诉框架。

**第二层：症状细节与伴随体征挖掘（问诊/望诊导向）**
- **排便细节追问**：“除了干，大便是什么形状（如羊屎状）？排便时肚子胀不胀？有没有口干想喝水？小便情况怎么样？”（挖掘“腹胀”、“口干欲饮”）
- **全身伴随症状追问**：“睡眠怎么样？容易入睡吗？睡得好吗？”（挖掘“失眠”）
- **视觉焦点（望诊）**：注意观察患者“面色少华”（面色苍白或萎黄，缺乏光泽），这是气血亏虚的重要外象。
- **医案特征提取**：便秘伴随的全身症状群为“腹胀、口干欲饮、失眠、面色少华”，提示病位不局限于肠，已涉及气机、津液、心神。

**第三层：体质、病史与情志状态深挖（全身与舌脉）**
- **必查舌脉**：“请伸出舌头我看一下。” “我给您把把脉。” （医案明确：舌淡苔薄白，脉细弦。此为辨证关键客观依据）
- **体质与病史追问**：“平时身体怎么样？有没有其他慢性病？月经情况如何？（针对女性患者，了解冲任及阴血状态）”
- **情志状态追问（关键）**：“最近心情怎么样？是不是容易心烦、紧张或者情绪低落？有没有因为什么事长期心情不好？”（直接关联“有抑郁症病史”，此为本案核心病机之一“心肝气郁”的切入点）
- **医案特征提取**：“年近5旬”（提示天癸将竭，肾精、阴血易亏的生理阶段）与“抑郁症病史”（明确的情志致病因素）是构建完整病机链条的基石。

**第四层：生活习惯与治疗经过**
- **关键提问**：“平时饮食偏好吗？（如喜辛辣、油炸？）喝水多吗？吃蔬菜水果多吗？有没有定时上厕所的习惯？”（为治疗医嘱提供依据）
- **治疗转归**：“以前因为便秘看过医生或吃过药吗？效果怎么样？”（了解既往治疗史，评估病情顽固程度）

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肠腑（标）**， **心、肝、肾（本）**。病变涉及肠腑传导失司；心主神明、肝主疏泄、肾主五液的功能失调。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：阴血亏虚（肾阴、心肝之血不足）。
    - **实**：气机郁滞（心肝气郁）。
    - **病性要素**：津亏、血虚、气郁。

- **推理公式**：
    1.  **[长期便秘（大便干结、数日一行）] + [口干欲饮] + [舌淡苔薄白] → 推导出“阴血津液亏虚，肠腑失于濡润”**（增液汤证基础）。
    2.  **[有抑郁症病史] + [失眠] + [脉弦] → 推导出“心肝气郁，气机不畅，心神被扰”**（气郁致津液布散失常，加重便秘；郁热扰心则失眠）。
    3.  **[面色少华] + [舌淡] + [脉细] + [年近五旬] → 佐证并强化“阴血亏虚”的病机**，且与生理阶段（肾元渐亏）相符。
    4.  **[腹胀、排便困难、不尽感] + [脉弦] → 提示“腑气不通”，为气机郁滞在肠道的具体表现**（四磨汤、麻子仁丸中行气导滞药的运用依据）。
    **最终整合**：**阴血亏虚（本） + 心肝气郁（枢机不利） → 共同导致肠腑失濡、传导无力（标），兼心神不宁**。证型概括为：**心肝气郁，阴血亏虚，肠腑失濡，心神不宁**。

- **鉴别要点**：
    1.  **与单纯“热结便秘”鉴别**：单纯热结常伴舌红苔黄、口干口臭、腹痛拒按、脉数有力等实热之象。本案舌淡、脉细弦，无典型热象，故非单纯实热。
    2.  **与单纯“气虚便秘”鉴别**：气虚便秘多见排便无力、便后疲乏、气短懒言、舌淡胖有齿痕、脉弱。本案虽有虚象，但突出“气郁”（脉弦、有情志病史）和“阴血虚”（口干、面色少华、脉细），而非单纯气虚。
    3.  **与单纯“血虚便秘”鉴别**：血虚便秘可伴面色萎黄、头晕心悸、唇甲色淡，但常无明显气郁和失眠等心神症状。本案气郁与心神不宁症状突出，病机更复杂。
    **提示模型**：本案的关键在于识别 **“情志因素（郁）”** 与 **“阴血不足（虚）”** 并存，且相互影响，形成了“因郁致虚，因虚难运”的复杂局面。治疗上需 **“行气”与“滋阴养血”并举，“通腑”与“安神”同施**，不可偏废。
