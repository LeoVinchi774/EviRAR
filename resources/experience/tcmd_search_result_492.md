### 一、 模拟问诊路径（针对慢性胃脘痛/痞满场景）
**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“您最不舒服的感觉是什么？持续多久了？”（引导患者描述主症：如胃胀、胃痛、烧心、纳差等）
- 医案特征提取：病程日久（“慢性”）、症状反复（“有时”午夜烧灼感）、得食稍安（虚性疼痛特点）。

**第二层：局部体征细查（望诊/切诊导向）**
- 视觉焦点：观察患者**面色**（是否少华、萎黄）、**神态**（是否倦怠）。
- 触觉焦点：**按压胃脘部**（询问是否喜按、拒按，有无固定压痛点或包块）。
- 医案特征提取：面色少华、脘部按之较舒（喜按，提示虚或气滞）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：**舌质**（是否暗、有瘀点）、**舌苔**（色、质、厚薄）、**脉象**（弦、细、涩等）。
- 关联病史追问：
    1.  **情绪与饮食**：“平时情绪、压力如何？是否易怒、思虑多？饮食是否规律，有无偏好？”
    2.  **疼痛细节**：“胃痛是胀痛、刺痛还是隐痛？有无规律（如与情绪、饮食、昼夜的关系）？”
    3.  **全身症状**：“是否常感疲劳乏力？有无口干、口苦、反酸、烧心？大小便情况如何？”
    4.  **既往诊断**：“是否做过胃镜？结果如何？”（明确“萎缩性胃炎伴肠化”的现代医学诊断背景）

**第四层：治疗经过与转归判断**
- 关键提问：“之前用过哪些药（中药或西药）？效果怎么样？症状是持续存在还是时好时坏？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、胃**。病在胃腑，与肝之疏泄、脾之运化功能失常密切相关。
- **核心病性**：**本虚标实，虚实夹杂**。**虚**在脾气虚；**实**在肝气郁结、气滞血瘀、郁而化热。
- **推理公式**：
    1.  **[脘胀、隐痛、按之较舒] + [情绪因素/脉弦] → 推导出“肝郁气滞，横逆犯胃”**。
    2.  **[倦怠、面色少华、纳呆] + [得食稍安] → 推导出“脾气虚弱，运化失职”**。
    3.  **[病程日久（慢性）] + [隐隐作痛（固定痛）] + [舌质暗] → 推导出“久病入络，气虚血瘀”**。
    4.  **[午夜胃内烧灼感、口苦] → 推导出“气郁日久，化热伤津”**。
    5.  综合以上：**肝脾气郁（气滞、脾虚） + 血瘀 + 郁热 → 辨证结论：肝脾气郁兼血瘀证**。
- **鉴别要点**：
    1.  **与单纯肝胃不和证鉴别**：单纯肝胃不和以脘胁胀痛、嗳气吞酸、情绪诱发为主，**气虚（倦怠、面色少华）和血瘀（隐痛固定）的征象不显**。
    2.  **与脾胃虚寒证鉴别**：脾胃虚寒证见胃脘冷痛、喜温喜按、食冷加重、四肢不温，**无口苦、烧灼感等郁热之象，亦无气滞血瘀之胀痛、刺痛**。
    3.  **与胃阴不足证鉴别**：胃阴不足证见胃脘灼痛、饥不欲食、口干舌燥、舌红少苔，**无明显的脾虚倦怠和气滞血瘀之胀、痛并见的特点**。
