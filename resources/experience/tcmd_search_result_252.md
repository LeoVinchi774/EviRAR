### 一、 模拟问诊路径（针对带下异常/绝经前后诸证场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的不舒服是什么？持续多久了？是第一次出现还是反复发作？”
- **医案特征提取**：主诉为“阴痒、带下量多反复半年”。问诊需明确：①带下量、色、质、气味（本案为量多、色黄）；②瘙痒的具体部位、性质、发作规律（本案为外阴瘙痒反复）；③阴道干涩感的有无及程度（本案为刻下症状）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：带下颜色（黄、白、赤、青、黑）、质地（清稀、粘稠、如豆渣、如泡沫）、有无异味。外阴、阴道局部望诊（有无红肿、萎缩、抓痕、破溃）。
- **触觉焦点**：非必须，但可询问患者自我感觉，如局部有无灼热感、疼痛感。
- **医案特征提取**：带下色黄（提示有热），阴道干涩（提示阴精不足），瘙痒反复（提示风邪或湿热扰动）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌体形态（胖大、瘦薄）、舌边（有无齿痕）、舌色（淡、红、暗）、苔色（白、黄、灰黑）、苔质（厚、薄、腻、燥）。**医案特征**：舌体胖大、边有齿痕（脾虚湿盛）、舌淡（气血不足或阳虚）、苔黄（有热）。
    - **脉诊**：脉象（细、弦、滑、数、沉）。**医案特征**：脉细弦（细主气血虚，弦主肝郁或痛证）。
- **关联病史与全身症状追问**：
    1.  **月经与生育史**：“您什么时候绝经的？生育过几次？”（本案：45岁绝经，足月产1子，提示天癸早竭，肝肾基础可能不足）。
    2.  **全身机能状态**：“平时容易累吗？胃口怎么样？睡眠如何？大小便情况？”（本案：平素易乏力（气虚），胃纳欠（脾虚运化无力），大便稀溏（脾虚湿盛），夜寐可（心神未受明显扰动），小便调（下焦气化尚可））。
    3.  **既往检查**：“最近有没有查过血常规或其他检查？”（本案：血常规示白细胞偏低3.97×10⁹/L，提示可能存在气血生化不足或免疫功能偏低）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这半年来看过医生吗？用过什么药（中药或西药）？效果怎么样？”（本案原文未提及前序治疗，但问诊时应常规询问，以评估病情顽固程度和治疗反应）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、肾、肝，病在带脉、下焦（前阴）**。
    - 脾：主运化水湿，脾虚则湿浊内生。
    - 肾：主生殖，为先天之本，绝经后肾气渐衰，阴阳失衡。
    - 肝：肝经循阴器，阴虚相火或湿热可循经下扰。
    - 带脉：约束诸经，固摄带下，失约则带下量多。

- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：脾肾气虚（乏力、纳差、便溏、舌胖齿痕、脉细），兼有肝肾阴虚（阴道干涩、绝经日久）。
    - **标实**：湿热下注（带下色黄、苔黄），兼有虚风内动（阴痒反复）。

- **推理公式**：
    1.  **[主症：带下色黄 + 阴痒反复] + [舌象：苔黄] → 推导出“湿热下注”或“相火扰动”的标实证。**
    2.  **[全身症状：乏力、纳差、便溏] + [舌象：舌体胖大、边有齿痕、舌淡] + [辅助检查：白细胞偏低] → 推导出“脾虚气弱，运化失职，气血生化不足”的本虚证。**
    3.  **[病史：绝经15年] + [局部症状：阴道干涩] → 推导出“肝肾阴虚，天癸竭，阴精不足”的体质基础。**
    4.  **综合①②③，结合“阴损及阳”理论，脾阳亦虚，水湿失运，流注下焦，蕴久化热，形成“脾肾气虚，带脉失约，湿热下注”的复合病机。** 脉细弦佐证了气血亏虚兼有气机不畅或肝郁。

- **鉴别要点**：
    - **与单纯湿热下注证鉴别**：单纯湿热下注常见带下黄稠臭秽、阴部灼热、口苦、苔黄腻、脉滑数，全身虚象不明显。本案虽有湿热（黄带、苔黄），但伴随明显的脾虚（乏力、纳差、便溏、舌淡胖）和阴虚（阴道干涩）之象，属虚实夹杂。
    - **与单纯脾虚湿盛证鉴别**：脾虚湿盛多见带下色白或淡黄、质稀、无臭，伴神疲、纳少、便溏、舌淡苔白腻。本案带下色黄、苔黄，提示湿已化热，病性偏热。
    - **与单纯肝肾阴虚证鉴别**：肝肾阴虚多见潮热盗汗、五心烦热、腰膝酸软、舌红少苔，带下量可能不多甚至干涩。本案虽有阴虚之基，但以带下量多、色黄等湿热带下的标实症状为主诉。
