### 一、 模拟问诊路径（针对大偻/强直性脊柱炎场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要哪里不舒服？疼痛有多久了？是持续性的还是间断性的？最近是加重了还是减轻了？”
- **医案特征提取**：病程长（2年，加重半年），有反复发作史（“诸症复萌”），疼痛部位在腰背及双侧髋部，伴有明显的“晨僵”（晨起僵硬）和“夜间痛”。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者站立、行走、弯腰、转侧时的姿态与活动度。重点看脊柱生理曲度（有无变直、后凸）、腰部肌肉状态（有无僵硬、萎缩）、髋关节活动范围。
- **触觉焦点**：触诊腰骶部、双侧骶髂关节、髋关节有无固定压痛点。评估脊柱及关节的僵硬程度和活动受限范围（如弯腰、后伸、侧屈、旋转）。
- **医案特征提取**：“腰背疼痛，弯腰受限，髋部僵硬疼痛，转侧不利”提示中轴关节（脊柱、骶髂）及外周关节（髋）活动功能障碍。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡/暗/红）、舌苔（薄白/腻/黄）、脉象（弦细/滑/沉）。本医案为“舌淡苔薄白，脉弦细”。
- **关联病史追问**：
    1.  **疼痛性质**：“疼痛是酸痛、刺痛还是胀痛？有没有怕冷或者怕热的感觉？”
    2.  **全身状况**：“平时怕冷还是怕热？体力精力怎么样？睡眠、吃饭、大小便情况如何？”（医案中“纳眠可，二便尚调”提示全身一般状况尚可，但需确认）
    3.  **既往诊疗史**：“之前做过哪些检查？（如HLA-B27、血沉、C反应蛋白）用过什么药（中药或西药）？效果怎么样？”
    4.  **家族史**：“家里直系亲属有没有类似的腰背疼痛或关节炎病史？”

**第四层：治疗经过与转归判断**
- **关键提问**：“这次为什么来就诊？之前的治疗效果不理想吗？您希望通过这次治疗达到什么效果？”
- **医案特征提取**：患者因症状复发且加重就诊，既往中西药治疗“诸症稍轻”但未根治，提示病情顽固，需长期、系统治疗。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝肾**（主）、**督脉**、**筋骨**（脊柱、关节）。病在筋骨，根在肝肾。
- **核心病性**：**本虚标实**。**虚**在肝肾亏虚、气血不足；**实**在痰浊、瘀血阻滞经络。
- **推理公式**：
    1.  **定位在肝肾筋骨**：主症为“腰及两侧髋部僵硬疼痛”（腰为肾之府，肝主筋，肾主骨） + “晨僵、夜间痛”（肝肾不足，精血亏虚，筋骨失养，阳气不升，阴血凝滞） → 病位在**肝肾、筋骨、督脉**。
    2.  **定性为本虚标实**：
        - **本虚证据**：病程长（2年），年过六旬（63岁），**舌淡**（气血不足），**脉细**（阴血亏虚）。综合指向**肝肾亏虚、气血不足**。
        - **标实证据**：疼痛固定、僵硬、转侧不利（不通则痛），**脉弦**（主痛、主气滞），结合实验室指标（血沉、CRP升高提示炎症活动，中医多辨为“痰瘀热毒”内蕴）。综合指向**痰瘀阻络**（痹阻经络）。
    3.  **综合辨证**：[腰髋僵痛、晨僵夜甚]（筋骨失养，络脉不通） + [舌淡苔薄白]（气血不足，无明显热象） + [脉弦细]（正虚夹瘀，气血不充） → 辨证结论：**大偻（强直性脊柱炎），证属肝肾亏虚、痰瘀阻络型**。
- **鉴别要点**：
    1.  **与单纯寒湿痹阻鉴别**：单纯寒湿者多遇冷加重，得温痛减，舌苔多白腻，脉多沉紧。本例舌淡苔薄白，无明显寒象，且病程长，虚象明显。
    2.  **与湿热痹阻鉴别**：湿热者多见关节红肿热痛，口干苦，小便黄，舌红苔黄腻，脉滑数。本例无热象，舌脉均不支持。
    3.  **与单纯血瘀证鉴别**：单纯血瘀者疼痛如刺，位置固定，舌质紫暗或有瘀斑，脉涩。本例兼有**舌淡、脉细**等明显虚象，故为**虚实夹杂**，非纯实之瘀。
    4.  **活动期与缓解期鉴别**：本例实验室指标（血沉61，CRP 13.5）提示疾病处于**活动期**，但全身热象不显（舌淡苔白），属“痰瘀化热”未透或热毒内伏之象，治疗需在补益肝肾、化痰逐瘀基础上，兼顾清解（如方中用忍冬藤、蒲公英）。若进入缓解期，指标正常，则治疗重点更偏向补益肝肾，强筋健骨。
