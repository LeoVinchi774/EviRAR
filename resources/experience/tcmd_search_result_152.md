### 一、 模拟问诊路径（针对带下异常伴痛经/不孕场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的不舒服是什么？这种情况持续多久了？”
- **医案特征提取**：
    - **主诉与病程**：带下量多、色黄、质稠、有臭味，持续1年。痛经（经行第2天右下腹痛），已婚未孕1年。
    - **关键特征**：带下增多在月经中期（排卵期）尤为明显，提示与冲任气血周期变化相关。痛经性质为“按之痛减”，属虚中夹实或气滞血瘀。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉/嗅觉焦点（问诊）**：
    - **带下**：颜色（黄/白/赤）、质地（清稀/黏稠/如豆渣）、气味（腥/臭/秽）、量（多少，是否浸湿内裤）。
    - **经血**：颜色（暗红/鲜红）、质地（有无血块、血块大小及颜色）、经量（中等/多/少）。
- **触觉/感觉焦点（问诊）**：
    - **腹痛**：部位（固定/游走）、性质（刺痛/胀痛/隐痛/冷痛）、放射（是否放射至腰背）、与按压关系（喜按/拒按）、与月经关系（经前/经期/经后）。
    - **医案特征提取**：带下“色黄，质黏稠，臭秽”；经行“右下腹疼痛，放射腰背，按之痛减，经血夹块”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌色（淡/红/暗/紫）、舌边（有无齿痕、是否偏红）、苔色（白/黄）、苔质（薄/厚/腻/滑）。
    - **脉象**：脉位（浮/沉）、脉率（数/迟）、脉力（有力/无力）、脉形（细/弦/滑）。
- **关联病史与全身症状追问**：
    - **婚育史**：结婚年限、避孕情况、既往孕产史、有无流产史。
    - **月经史**：周期、经期、经量、经色、有无痛经及其规律。
    - **全身状况**：有无腰酸腰痛、小腹坠胀、神疲乏力、口干口苦、纳食、二便、睡眠情况。
    - **医案特征提取**：已婚1年未避孕未孕；偶有腰痛；纳食二便正常；**刻下舌脉**：舌尖边红，苔薄黄，脉细弦。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个情况看过医生或吃过药吗？效果怎么样？”（本医案为初诊，此问为常规流程，用于评估病情顽固程度及既往治疗反应）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**下焦、胞宫、任脉、带脉、肝、肾**。
    - 带下、痛经、不孕，病位主要在下焦胞宫。
    - 任主胞胎，带脉约束诸经，带下异常责之任带二脉失约。
    - 经行腹痛、脉弦，与肝气疏泄相关；腰痛、不孕，与肾气相关。

- **核心病性**：**实证为主，属湿热、血瘀、气滞夹杂**。
    - **热**：带下色黄、臭秽，舌尖边红，苔黄。
    - **湿**：带下量多、质黏稠。
    - **瘀**：经行腹痛（固定右下腹）、经血夹块。
    - **气滞**：腹痛放射、脉弦。
    - **虚实夹杂**：病程1年，按之痛减，脉细，提示有正虚（如肾虚）基础，但当前以邪实（湿、热、瘀）为主要矛盾。

- **推理公式**：
    1.  **[主症：带下量多色黄质稠臭秽] + [舌脉：舌尖边红，苔薄黄] → 推导出“湿热蕴结下焦”**。
    2.  **[主症：经行固定右下腹痛、经血夹块] + [体征：按之痛减（虚实夹杂）、脉弦] → 推导出“瘀血内阻，气机不畅”**。
    3.  **[病史：经期腹痛 + 带下异常 + 不孕1年] + [病机：湿热瘀互结] → 推导出“湿瘀阻滞胞脉，气机不畅，难以摄精成孕”**。
    4.  **综合**：**湿热 + 血瘀 + 气滞 → 辨证结论：湿瘀下注，气机不畅**。

- **鉴别要点**：
    - **与单纯湿热下注鉴别**：单纯湿热下注带下亦色黄臭秽，但痛经可能不明显或为胀痛，经血多不夹块，舌苔多黄腻。**本案关键鉴别点在于“经血夹块”和“固定部位刺痛”，这是血瘀证的明确指征**。
    - **与单纯气滞血瘀鉴别**：单纯气滞血瘀痛经明显，但带下多无异常或仅量稍多、色质正常。**本案关键鉴别点在于“带下量多、色黄、臭秽”，这是湿热证的明确指征**。
    - **与脾肾两虚带下鉴别**：脾肾两虚带下多色白、质清稀、无臭或腥，常伴神疲乏力、腰膝酸冷，舌淡苔白，脉沉细。**本案带下色黄臭秽、舌红苔黄、脉弦，均不支持虚寒**。
