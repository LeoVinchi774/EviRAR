### 一、 模拟问诊路径（针对月经后期/多囊卵巢综合征场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请详细描述一下您月经不调的具体情况，比如多久来一次？持续多少天？量、色、质地如何？这种情况持续多久了？”
- **医案特征提取**：主诉为“月经延期4-5年”，周期长达“4-5月一行”，经期“5-7天”，需依赖“激素类药”方能来潮。此为病程长、周期严重延后的核心特征。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望面与眼睑**：观察面部有无色斑、痤疮；重点查看下眼睑颜色（如本案左鲜红、右淡红），以判断气血与水饮分布。
    - **望舌**：仔细察看舌色（淡）、舌形（齿痕）、苔质与苔色（厚腻/薄黄腻），此为辨证关键。
    - **望腹部与下肢**：观察腹部形态（膨隆）；查看下肢皮肤有无血络（毛细血管）显露、肌肤甲错（干燥如鳞甲）或袜痕（按压后痕迹不易消退，提示水饮）。
- **触觉焦点**：
    - **触手足**：触摸患者手足温度与湿度（本案“手潮凉”）。
    - **切脉**：仔细体会脉象的浮沉、力度、速度（本案“脉浮软”）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌淡主虚、主寒；齿痕主脾虚湿盛；苔厚腻主湿浊内蕴；苔黄提示化热。
    - **脉象**：脉浮提示病位在表或有外邪；脉软（濡）主虚、主湿。
- **关联病史与症状追问**：
    1.  **寒热与表证**：“平时怕冷还是怕热？是否容易出汗？遇冷风会不会打喷嚏、流清鼻涕？”（挖掘“表束”证据：怕冷、遇冷流涕喷嚏）
    2.  **经期伴随症状**：“来月经时有没有乳房胀痛、小腹疼痛？经血里血块多不多？颜色是暗是淡？”（判断气滞、血瘀、寒凝）
    3.  **消化与水液代谢**：“胃口怎么样？有没有嗳气、腹胀、肠鸣？大便性状如何（黏腻/干结）？小便颜色？”（挖掘“里虚”、“水饮”、“里热”证据：肠鸣矢气、大便黏、尿黄）
    4.  **全身状况**：“有没有口干、口黏的感觉？平时容易疲劳、心慌吗？有没有耳鸣？”（综合判断津液、水饮与气血状态）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前是否在其他医院明确诊断过（如多囊卵巢综合征）？用过哪些药物（特别是激素类）？效果如何？这次希望中医主要在哪些方面进行调理？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**表（太阳经）** 与 **里（太阴脾、少腹血室）**。病涉肌表营卫、脾胃中焦及胞宫血分。
- **核心病性**：**本虚标实，寒热错杂**。本质为**里虚**（脾虚）、**伤血**（血寒/血滞）；标实为**表束**（风寒外袭未解）、**水饮**内停、兼有**里热**。
- **推理公式**：
    **[月经后期（4-5月一行）+ 痛经血块 + 手足潮凉]** → 提示 **血分受病，寒凝血滞（伤血）**。
    **[遇冷流涕喷嚏 + 怕冷 + 脉浮]** → 提示 **风寒束表，营卫不和（表束）**。
    **[舌淡齿痕 + 肠鸣矢气 + 大便偏黏]** → 提示 **脾虚失运，湿浊内停（里虚兼湿）**。
    **[口干口黏 + 尿黄 + 苔黄腻]** → 提示 **湿郁化热（里热）**。
    **[心悸 + 下肢袜痕 + 舌苔腻]** → 提示 **水饮内停**。
    **综合推导**：表证（风寒）未解，内传入里，损伤脾阳，导致运化失司，水湿内停，寒湿凝滞于血分，影响冲任，故月经后期；湿郁日久，部分化热，形成**表里同病（表束、里虚、水饮、里热）** 之复杂证候。
- **鉴别要点**：
    1.  **单纯肝郁血瘀证**：多以经前乳胀、胁痛、情绪烦躁、经色紫暗有块为主，舌质偏暗或有瘀点，脉弦。**本案虽有血瘀（血块），但核心病机起点在“表寒入里”和“脾虚水停”，且伴有明显的表证与脾虚湿蕴体征（舌淡齿痕苔腻、肠鸣），非单纯肝郁**。
    2.  **单纯肾阳虚证**：多以月经后期、量少色淡、腰膝酸冷、畏寒肢冷、夜尿频多为主，舌淡苔白，脉沉迟。**本案虽有怕冷，但同时有怕热、尿黄、口干等热象，且脉浮提示病位在表，非纯里虚寒**。
    3.  **单纯湿热下注证**：多见带下量多色黄、阴痒、小便短赤、舌红苔黄腻。**本案热象不重（尿黄、口干黏），且以寒象（怕冷、血块、舌淡）、表证和水饮征象更为突出，湿热并非主导**。
