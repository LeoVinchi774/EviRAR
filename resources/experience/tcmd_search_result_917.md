### 一、 模拟问诊路径（针对慢性、反复发作性头痛场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您头痛具体在哪个位置？是什么感觉（搏动样、针刺样、胀痛、紧箍感）？持续多久了？是持续痛还是一阵阵发作？”
- **医案特征提取**：病程长达2年，时发时止（发作性），左侧颞部搏动样疼痛。有明确的诱发/加重因素（经前期加重、劳累后加重）。

**第二层：症状特征细查（问诊导向）**
- **发作先兆与伴随症状**：“头痛发作前有没有特殊感觉（如眼前闪光、黑点、视物模糊）？发作时怕光、怕声音吗？有没有恶心、呕吐？”
- **疼痛性质与规律**：“疼痛是固定在一个地方还是到处跑？和情绪、劳累、月经周期、天气变化有关系吗？”
- **医案特征提取**：发作前有眼前黑点、波纹（视觉先兆），畏光，恶心。疼痛为搏动样，与月经周期（经前期）和劳累相关。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身状态与体质倾向**：“平时怕冷还是怕热？容易感冒吗？精力体力如何，容易累吗？睡眠、胃口、大小便怎么样？最近有没有脱发？”
- **必查舌脉**：舌质（颜色、胖瘦、瘀点瘀斑）、舌苔（颜色、厚薄、润燥）、脉象（力度、粗细、频率）。
- **医案特征提取**：畏寒怕冷，口淡，食欲欠佳，不易入睡，平日易感冒、易劳累，有脱发。舌象为“舌淡暗，苔薄白”，脉象为“脉细”。

**第四层：诊疗经过与诱发因素**
- **关键提问**：“之前做过哪些检查？结果如何？用过什么药（西药/中药）？效果怎么样？这次发作前有没有特殊诱因（如长途旅行、熬夜、情绪波动）？”
- **医案特征提取**：检查结果基本正常，曾口服布洛芬对症处理。本次再发与“旅途劳累”直接相关。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**脑窍（清窍）、经络（久病入络）**。病位在头，但根源于全身气血运行失常，久病及络，瘀血阻滞脑络。
- **核心病性**：**本虚标实**。**虚**在气虚（卫外不固、推动无力）、兼有阳虚（畏寒怕冷）；**实**在血瘀（久病、疼痛固定、舌暗）。整体为**虚实夹杂，以气虚为本，血瘀为标**。
- **推理公式**：
    1.  **[主症：久病（2年）头痛 + 疼痛固定、搏动样]** → 指向“久病入络”、“不通则痛”，**血瘀**是核心病理产物。
    2.  **[伴随体征：易感冒、易劳累、脉细]** → 指向**气虚**（卫表不固，机能减退）。
    3.  **[全身症状：畏寒怕冷、口淡、舌淡]** → 提示存在**阳气不足**（气虚及阳）。
    4.  **[舌脉佐证：舌淡暗（淡为气虚，暗为血瘀）、苔薄白、脉细（气血不足之象）]** → 完美印证“气虚血瘀”的病机。
    5.  **推导链条**：**气虚（推动无力、卫外不固）** → **血行不畅，久而成瘀** → **瘀血阻滞脑络** → **清窍失养，发为头痛**。劳累（耗气）或经前期（气血变动）时，气虚更甚，血瘀加重，故头痛发作或加剧。
- **鉴别要点**：
    1.  **与肝阳上亢头痛鉴别**：后者多伴头晕头胀、面红目赤、口苦、急躁易怒、脉弦有力。本案患者畏寒、口淡、脉细，无热象，可排除。
    2.  **与痰浊头痛鉴别**：后者多伴头重如裹、胸闷脘痞、苔腻。本案苔薄白，无痰湿内盛之象。
    3.  **与单纯血瘀头痛鉴别**：单纯血瘀证疼痛多如针刺，舌质紫暗或有瘀斑，脉涩。本案兼有明显的气虚（易感冒、劳累、脉细）和阳虚（畏寒）表现，是**气虚导致和加重的血瘀**，而非单纯实证。
    4.  **与气血亏虚头痛鉴别**：后者多为隐痛、空痛，伴面色无华、心悸乏力，但疼痛性质多非搏动样，且瘀血征象不显。本案有明确的“搏动样”疼痛和“舌暗”的瘀血指征，属于虚实夹杂，而非纯虚无实。

**总结**：本医案的辨证核心在于抓住 **“久病”** 与 **“体虚”** 两条主线。“久病”必考虑瘀血入络；“体虚”（易感、易劳、脉细）则定位为气虚。二者结合，形成“因虚致瘀，瘀阻清窍”的完整辨证链条。问诊时需系统挖掘病程、疼痛特点、全身虚弱征象及舌脉信息，以构建此逻辑。
