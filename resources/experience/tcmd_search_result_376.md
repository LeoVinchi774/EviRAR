### 一、 模拟问诊路径（针对慢性咳喘急性加重/肺胀场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次喘不上气、咳嗽加重有多久了？以前有慢性咳喘的毛病吗？持续多少年了？”
- **医案特征提取**：病程长达30余年（慢性支气管炎史），本次急性加重一周。提示问诊需重点锁定“久病”与“新发加重”的时间节点。

**第二层：局部体征细查（望诊/闻诊/切诊导向）**
- **视觉焦点**：
    - **面色与口唇**：观察面色是萎黄、晄白还是紫暗？口唇有无青紫或紫绀？
    - **咳喘形态**：观察是张口抬肩、呼吸深长，还是气短浅促？咳时是面红目赤还是声低无力？
    - **水肿**：观察双下肢有无浮肿，是凹陷性还是非凹陷性？
- **听觉/触觉焦点**：
    - **闻诊**：听咳嗽声音是高亢还是低微？呼吸时喉间有无痰鸣音？听诊双肺有无干湿性啰音？
    - **切诊**：触诊下肢水肿部位，确认是否为凹陷性。
- **医案特征提取**：面色紫暗、唇舌紫绀（血瘀、缺氧）；大口喘气但咳声低微（虚实夹杂）；双下肢凹陷性水肿（水饮内停）；双肺干湿啰音（痰浊壅肺）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡、红、紫暗）、舌体胖瘦老嫩、舌苔有无及厚薄润燥。**（本例：舌质紫暗、舌嫩少苔）**
    - **脉象**：脉位（浮沉）、脉力（有力无力）、脉率（迟数）、脉形（粗细）。**（本例：脉虚细数）**
- **关联症状追问**：
    - **汗出情况**：平时或动后是否易汗？此次发病有无出汗，是冷汗还是热汗？**（本例：身有虚汗）**
    - **痰的情况**：痰量多少？颜色质地？是否容易咳出？**（本例：喉中痰鸣、不易咯出）**
    - **津液与二便**：是否口渴？想喝热水还是冷水？小便是否通畅、量如何？大便干稀情况？**（本例：口舌干燥、不欲饮水；尿不畅；便先干后软）**
    - **全身状况**：有无心慌、胸闷？胃纳如何？腹部有无胀满不适？**（本例：胃脘不舒）**

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重前有没有受凉、劳累或者情绪波动？之前用过什么药（中药或西药）？效果怎么样？”
- **医案特征提取**：患者有明确的“肺源性心脏病”并发症史，提示问诊需关联心功能状态，并了解既往治疗反应，为判断病势深浅和制定治疗方案提供依据。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、肾**，兼及脾。肺主气司呼吸，肾主纳气，久病咳喘，肺病及肾，肾不纳气为本；痰浊阻于肺络为标。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：元气大虚（气虚为主），气阴两伤（兼有阴虚）。
    - **实**：痰浊阻肺，兼有血瘀（久病入络）。
    - **整体属性**：虽见口舌干燥，但“不欲饮水”，非实热，乃气阴亏虚，津液不能上承所致。

- **推理公式**：
    1.  **[主症：大口喘气、气短不足以息] + [体征：咳声低微、脉虚] → 推导出：气虚（肺肾气虚，肾不纳气）。**
    2.  **[症状：口舌干燥、舌嫩少苔] + [体征：脉细] → 推导出：阴虚（气阴两伤）。**
    3.  **[症状：喉中痰鸣、不易咯出] + [体征：双肺干湿啰音] → 推导出：痰浊阻肺（实证）。**
    4.  **[体征：面色紫暗、唇舌紫绀、舌质紫暗] + [病史：久病、肺心病] → 推导出：血瘀（久病入络，气虚推动无力）。**
    5.  **[体征：双下肢凹陷性水肿、尿不畅] → 推导出：水饮内停（肺脾肾运化水液功能失调）。**
    - **综合辨证结论**：**元气大虚，气阴两伤，痰浊瘀血阻于肺络。**

- **鉴别要点**：
    - **与单纯痰热壅肺证鉴别**：后者多见咳痰黄稠、口渴喜饮、舌红苔黄腻、脉滑数等实热象。本例虽有痰鸣，但咳声低微、口燥不欲饮、舌少苔、脉虚数，热象不显，虚象为主。
    - **与单纯阳虚水泛证鉴别**：后者多见畏寒肢冷、小便清长、舌淡胖苔白滑、脉沉迟等虚寒象。本例虽有水肿，但兼见口燥、脉数等阴伤之象，属气阴两虚兼水停。
    - **提示模型**：在慢性肺系疾病晚期（如肺胀），常出现**气虚、阴虚、痰浊、血瘀、水饮**多种病理因素相互胶结的复杂局面。辨证关键在于分清**本虚（气、阴、阳何者为主）与标实（痰、瘀、水何者为急）** 的轻重缓急。本例以气阴两虚为本，痰瘀水互结为标。
