### 一、 模拟问诊路径（针对慢性咳嗽/慢性咽炎场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您咳嗽多久了？这次加重有多长时间？”、“最开始是怎么引起的？（如受凉、感冒等）”、“咳嗽在什么情况下容易发作或加重？（如天气变化、接触冷空气、饮食等）”
- **医案特征提取**：病程长达7年，反复发作，近期加重1月。明确由外感风寒（受凉感冒）诱发，且遇寒（天气转凉、冷空气）即发，呈慢性、复发性特征。

**第二层：局部体征细查（望诊/闻诊/问诊导向）**
- **听觉/问诊焦点**：“咳嗽是阵发性的还是持续性的？白天重还是晚上重？”、“痰多不多？痰是什么颜色、质地？容易咳出来吗？”、“咽喉部具体有什么感觉？（如异物感、干痒、疼痛）”
- **医案特征提取**：阵发性咳嗽，痰少（提示痰热胶结或阴伤），咽部异物梗阻感（梅核气样表现，属痰气郁结或热郁于咽）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（颜色、胖瘦）、舌苔（颜色、厚薄、润燥）；脉象（部位、速率、力度、形态）。**关键**：必须获取“舌质淡红、苔薄黄，脉滑数”这一组核心体征。
- **关联症状追问**：“有没有口干、想喝水的情况？”、“食欲怎么样？大便情况如何？（干结、稀溏、次数）” 、“精神、体力感觉如何？”、“睡眠怎么样？”
- **医案特征提取**：口干、大便稍干（热灼津伤之象）；饮食不香（脾为生痰之源，肺病及脾或痰热中阻）；精神不佳（久病耗气或热扰）；睡眠尚可（提示病位主要在肺，未严重扰动心神）。

**第四层：治疗经过与转归判断**
- **关键提问**：“以前做过什么检查？（如胸片、喉镜）结果如何？”、“用过哪些药？（中药/西药）效果怎么样？能控制住吗？”、“这次发作后自己用过药吗？”
- **医案特征提取**：胸片无异常，曾诊为“慢性咽炎”，服西药可暂时缓解但反复发作。提示病在气分、在咽喉气道，非器质性肺病，符合中医“咳嗽”、“喉痹”范畴，治疗需从调整全身气机与脏腑功能入手。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺**（主症为咳嗽）、**咽喉**（咽部异物感）。涉及**大肠**（大便干，肺与大肠相表里）。
- **核心病性**：**本虚标实**。**标实**为**痰热郁肺**；**本虚**为**肺阴亏耗**。病性属**热**、属**痰**、属**阴虚**。
- **推理公式**：
    1.  **[久咳遇寒即发] + [外感风寒病史] → 推论**：初始病因为风寒袭肺，邪气留恋，肺卫不固，形成慢性病程。
    2.  **[咳嗽痰少 + 咽干异物感 + 苔薄黄 + 脉滑数] → 推论**：风寒郁而化热，热炼津成痰，形成**痰热郁肺**证。痰少因热灼津伤，痰胶难出；苔黄脉滑数为痰热典型征象；咽部不适为痰热郁结于咽喉。
    3.  **[口干 + 大便稍干] + [久咳7年] → 推论**：痰热内蕴，日久灼伤肺津，导致**肺阴亏耗**。津不上承则口干，肠腑失润则便干。
    4.  **综合**：**痰热郁肺（标、实）** + **肺阴亏耗（本、虚）** = **咳嗽（痰热郁肺、肺阴亏耗证）**。
- **鉴别要点**：
    - **与单纯风寒犯肺证鉴别**：后者咳嗽痰稀白，咽痒，恶寒重，舌苔薄白，脉浮紧。本案有化热征象（苔黄、脉数、口干），故非纯寒。
    - **与单纯肺阴虚证鉴别**：后者干咳无痰或少痰，潮热盗汗，舌红少苔，脉细数。本案有明显痰热标实证（脉滑、苔黄、咽部痰气郁结感），故非纯虚。
    - **与肝火犯肺证鉴别**：后者咳嗽阵作，咳引胁痛，面红目赤，口苦咽干，脉弦数。本案无明确肝经证候，病位核心在肺与咽喉。
    - **提示模型**：本案关键在于抓住“**寒郁化热生痰**”与“**热久灼阴**”两个病机转化环节，以及“**肺咽同病**”、“**肺肠相关**”的整体观念。问诊时，**大便情况**是国医大师李振华先生特别关注的、判断肺气通降与否的重要指征。
