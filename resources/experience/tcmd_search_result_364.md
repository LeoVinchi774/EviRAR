### 一、 模拟问诊路径（针对不寐/顽固性失眠场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？这种情况持续多久了？”
- **医案特征提取**：病程长达10余年，起因为严重精神刺激（惊吓），近期因情志与劳累（老伴患病、操劳过度）而加重。问诊需重点挖掘**发病诱因（情志创伤）**、**病程演变（症状波动与治疗史）**及**近期加重因素**。

**第二层：症状特征与伴随症细查（问诊/望诊导向）**
- **核心症状追问**：
    - **睡眠质量**：“入睡困难吗？容易醒吗？醒后还能再睡着吗？一晚总共能睡几个小时？梦多吗？是噩梦还是普通梦？”
    - **精神情志**：“平时情绪怎么样？容易着急、发脾气吗？心里会不会觉得烦乱、静不下来？”
    - **躯体伴随症**：“有没有一阵阵发热、出汗？是白天还是晚上？口干、口苦吗？吃饭胃口怎么样？肚子胀不胀？腰背感觉怎么样？”
- **医案特征提取**：失眠（多梦、易醒、睡眠时间<3小时），伴**急躁易怒、心烦、烘热汗出、咽干口苦、纳差腹胀、腰酸背痛**。问诊需系统梳理心、肝、脾、肾四脏相关症状。

**第三层：全身体征与体质挖掘（望闻问切综合）**
- **望诊焦点**：观察患者**面容（慢性病容、精神憔悴）**、**神态（焦虑、疲惫）**。
- **必查舌脉**：
    - **舌诊**：“请伸出舌头让我看看。” 重点观察**舌色（红）、舌苔（少苔、薄黄而干）**。
    - **脉诊**：切诊感知**脉象（弦细）**。
- **关联病史追问**：“以前有没有其他慢性病？长期服用什么药物？（如抗抑郁、抗焦虑药）效果和反应如何？”

**第四层：治疗经过与生活调摄**
- **关键提问**：“这次为什么来看中医？之前用过中药调理吗？对什么食物或药物有特殊反应吗？”
- **医嘱关联**：了解患者饮食偏好，为后续“少吃生冷油腻”的医嘱铺垫。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、肝、肾**，涉及脾。病机关键在**心肾不交，肝郁化火**。
- **核心病性**：**本虚标实**。**本虚**为**心肝血虚、肾阴亏虚**；**标实**为**虚火上炎、肝阳上亢、肝郁乘脾**。
- **推理公式**：
    1.  **长期失眠 + 精神刺激病史 + 急躁易怒 + 脉弦** → 提示病位在**肝**，病机为**肝气郁滞，郁久化火**。
    2.  **心烦 + 舌红少苔 + 脉细** → 提示病位在**心**，病机为**心血暗耗，心阴不足，虚热扰神**。
    3.  **腰酸背痛 + 烘热汗出 + 咽干口苦 + 舌红少苔** → 提示病位在**肾**，病机为**肾阴亏虚，阴虚阳亢，虚火上炎**。
    4.  **纳差腹胀** → 提示**肝郁乘脾**，导致脾胃升降失调。
    5.  **综合推导**：以上症状链结合**舌红少苔苔薄黄而干（阴虚内热之象）、脉弦细（阴血不足兼肝郁之象）**，形成完整证据链，辨证为 **【阴虚阳亢，虚火扰神】**。其内在逻辑是：惊吓伤肾，忧思劳倦耗伤心肝之血，久病及肾，致肾水（阴）不足，不能上济心火，亦不能涵养肝木，导致心火偏亢、肝阳上扰，共同扰动心神而致顽固性不寐。
- **鉴别要点**：
    - **与单纯心脾两虚证鉴别**：单纯心脾两虚多见心悸健忘、面色无华、倦怠乏力、舌淡苔白，**无明显的燥热、口苦、舌红苔黄等虚火征象**。本案有典型的阴虚火旺表现。
    - **与单纯痰热扰神证鉴别**：痰热扰神多见胸闷脘痞、呕恶嗳气、头重目眩、舌红苔黄腻，**脉滑数**。本案舌苔虽黄但干而薄，脉象为弦细，腹胀为肝郁乘脾所致，非痰湿壅盛之象，故可鉴别。
