### 一、 模拟问诊路径（针对老年慢性咳嗽/支气管扩张合并基础病史场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您咳嗽多久了？是持续性的还是阵发性的？什么情况下会加重或减轻？”
- **医案特征提取**：病程长达“近半年”，且“反复”发作，提示病程迁延，非急性外感。在多家医院就诊“症状缓解不明显”，提示病情顽固或既往治疗未完全对证。

**第二层：局部体征细查（望诊/问诊导向）**
- **症状性质追问**：
    - **痰**：“痰多吗？是什么颜色（白、黄、绿、灰）？质地是稀的还是稠的？容易咳出来吗？”（医案：痰量不多、色白为主）
    - **咳**：“咳嗽时喉咙或胸口有什么感觉？是干咳还是有痰才咳？”（医案：咽中不适）
    - **喘**：“咳嗽时或平时会觉得气短、喘不上气吗？活动后会不会加重？”（医案：略有气促）
    - **特殊症状排除**：“有没有咳过血？有没有发烧、怕冷或者出汗？”（医案：无咯血，无发热）
- **医案特征提取**：咳嗽、咯痰不爽（痰量不多但可能粘）、气促、咽中不适。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：观察舌质颜色（淡、红、紫暗）、舌体胖瘦、苔色（白、黄）、苔质（厚、薄、腻、干）。（医案：舌淡红苔白）
    - **脉诊**：切脉部位（寸、关、尺），感受脉的形态（浮、沉、迟、数、滑、涩、细、弦）。（医案：脉细滑）
- **关联病史与全身状况追问**：
    - **基础病史**：“您以前有没有得过肺部的慢性病（如支气管扩张、慢阻肺）？或者做过什么大手术？”（医案：支气管扩张二十余年，前列腺癌术后十余年）
    - **体质状态**：“平时容易感冒吗？精神、体力怎么样？胃口、睡眠、大小便如何？”（医案：胃纳可，大便可；结合年龄与病史推断“正气不足”）
    - **发病诱因**：“这次咳嗽发作前，有没有着凉、劳累或者情绪波动？”（医案：推断“复因感受外感寒邪”）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在其他医院都做过哪些检查（如胸片、CT）？用过哪些药（中药或西药）？效果具体怎么样？”（医案：曾在多家医院就诊症状缓解不明显）
- **转归关注点**：通过复诊信息，关注咳嗽、咳痰、气促等症状的缓解程度，以及舌脉的变化，以判断邪气是否渐退、正气是否来复。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肺**（主症为咳嗽、咯痰、气促）。兼及**脾、肾**（因患者年高、久病、术后，存在气阴两虚的根本，脾为气血生化之源，肾为气之根）。
- **核心病性**：**本虚标实，寒热错杂**。
    - **本虚**：气阴两虚（年老、久病、术后耗伤）。
    - **标实**：外邪犯肺（初期为寒，郁而化热），兼有痰浊、肺气上逆。
- **推理公式**：
    1.  **[主症：反复咳嗽半年 + 病史：高龄、支扩、癌症术后]** → 推断**正气亏虚（气阴两伤）**为发病基础。
    2.  **[症状：痰白、无发热 + 病程反复]** → 推断初期感受**外邪（寒邪）**袭肺，肺失宣降，且邪气未化火或热象不显于表。
    3.  **[症状：咯痰不爽、咽中不适 + 脉滑]** → 提示肺气壅滞，**痰浊内阻**。
    4.  **[诊断依据提示“外邪郁而化热，肺络受损” + 处方用黄芩清肺热]** → 推断存在**郁热**内伏，但热象未主导全身症状（故未见黄痰、高热）。
    5.  **[舌淡红苔白 + 脉细滑]** → “舌淡红”支持非纯实热证；“苔白”主表证、寒证或湿证，结合痰白，支持寒邪或寒痰未全化热；“脉细”为虚象（气阴不足），“脉滑”为实象（痰、邪）。
    6.  **综合推导**：**(正气亏虚之本) + (外寒袭肺，郁而化热，痰浊内阻之标)** → 辨证结论：**外邪犯肺，气阴两虚**（正虚邪恋）。
- **鉴别要点**：
    - **与单纯痰热壅肺证鉴别**：单纯痰热证多见痰黄稠、发热、舌红苔黄腻、脉数滑。本案痰白、无发热、舌淡红苔白，热象不典型，且虚象（脉细、久病、年高）明显，故非单纯实证。
    - **与单纯肺气虚或肺阴虚证鉴别**：单纯虚证咳嗽多无力，痰少或干咳，少有明显外感诱因或痰阻气逆之象。本案有痰、气促、脉滑，提示标实（邪气、痰浊）仍在，属虚实夹杂。
    - **注意“郁热”的辨识**：在老年、体弱患者中，外感后邪气易“郁而化热”，但全身热象可能不显著，需从病程迁延、用药反推（如用黄芩）及可能存在的局部热象（如咽干、痰粘难咯）中捕捉。
