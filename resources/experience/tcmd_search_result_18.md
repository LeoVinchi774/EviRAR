### 一、 模拟问诊路径（针对蛇串疮/带状疱疹场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“您身上哪个部位最不舒服？具体是什么样的感觉（是痛、是痒还是灼热）？这种情况出现多久了？什么情况下会加重或减轻？”
- 医案特征提取：病程为急性发作（疱疹初起），疼痛性质为“持续性灼热刺痛”，活动（如“左手稍抬高”）会加重疼痛。

**第二层：局部体征细查（望诊/切诊导向）**
- 视觉焦点：疱疹的形态（是丘疹、水疱还是已破溃）、颜色（鲜红、暗红）、分布范围（是否沿身体单侧分布）、皮损状态（有无糜烂、结痂）、周围皮肤情况（是否发红）。
- 触觉焦点：局部皮肤温度（是否灼热）、有无压痛、疱疹内容物性状（清亮或浑浊）。
- 医案特征提取：左肩颈部“红色瘪陷小疱疹”，大部分已破溃形成“鲜红色糜烂面”，周围“皮肤发红”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：舌质颜色（红/淡）、舌苔（色、质、厚薄）、脉象（弦、滑、数、细等）。
- 关联病史追问：“您平时情绪怎么样？最近有没有心烦、爱发脾气的情况？”“睡眠、饮食、大小便情况如何？”“您以前有没有得过糖尿病（消渴）或其他慢性病？这次发病前有没有劳累、情绪波动或感冒？”
- 医案特征提取：全身症状包括“烦躁易怒，口苦，夜不能寐，纳差，小便黄”；舌脉为“舌红，苔黄腻，脉弦滑数”；有“消渴”病史。

**第四层：治疗经过与转归判断**
- 关键提问：“这次发病后，有没有用过什么药（包括外用药）？效果怎么样？”“疼痛对您日常生活（如睡眠、活动）影响大吗？”
- 医案特征提取：患者因疼痛导致“坐卧不安”，影响睡眠与情绪，提示病情较重，需关注其心理状态与生活质量。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝经、胆经、脾经、肌肤络脉**。疱疹发于肩颈（少阳经循行区域），结合口苦、脉弦，病位主要在肝胆；苔腻、纳差，涉及脾；病邪直接外发于肌肤络脉。
- **核心病性**：**实证、热证**。以**肝火、湿热、热毒**为核心，兼有**气滞血瘀**（疼痛剧烈、病程迁延）。初诊阶段为邪实盛而正未虚。
- **推理公式**：
    1.  **[主症：沿经分布的灼热刺痛疱疹] + [体征：皮损鲜红糜烂] + [舌脉：舌红苔黄腻，脉滑数]** → 推导出 **湿热火毒蕴结肌肤** 的基本病机。
    2.  **[伴随症：烦躁易怒、口苦] + [脉象：弦] + [加重因素：情绪/活动]** → 结合病位在肝胆经，推导出 **肝气郁结，郁而化火**。
    3.  **[病史：消渴病史] + [地域：岭南湿热] + [全身症：纳差、苔腻]** → 推导出患者 **素体湿热内蕴** 的体质基础，为内外合邪提供了条件。
    4.  综合以上：**素体湿热内蕴（本） + 肝郁化火（标） + 火毒湿邪外攻肌肤（变）** → 最终辨证为 **肝郁化火、湿毒蕴肤证**。
- **鉴别要点**：
    1.  **单纯肝胆实火证**：虽有口苦、烦躁、脉弦数，但舌苔可能黄而不腻，皮损灼痛但渗出糜烂不明显，全身湿象（如纳差、苔腻）不显。本案**兼有显著的湿象（苔黄腻、纳差）**，故为火与湿合。
    2.  **脾虚湿盛证**：以纳呆、腹胀、便溏、苔白腻为主，皮损可能色淡、渗出清稀，疼痛感相对较轻，**缺乏明显的肝火证候（如口苦、烦躁、脉弦）**。本案肝火证候突出。
    3.  **气滞血瘀证（后期）**：疼痛以刺痛、固定不移为主，皮损色暗或遗留色素沉着，舌质紫暗或有瘀点。本案初诊为**灼热刺痛、皮色鲜红**，属热毒血热为主，血瘀为次；至三诊疼痛减轻但残留，皮色暗，才转为以气滞血瘀为主。
