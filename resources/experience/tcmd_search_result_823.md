### 一、 模拟问诊路径（针对眩晕/高血压病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您头晕具体是什么感觉？是昏沉不清醒，还是感觉天旋地转？这种情况持续多久了？血压最高到过多少？”
- **医案特征提取**：病程半年，反复发作，血压最高达170/102mmHg，西医常规治疗效果不佳。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者精神面貌（是否萎靡、困倦），面部及眼周有无浮肿。
- **触觉焦点**：测量血压（诊室血压、家庭自测最高血压）、心率。**（注：眩晕病在头部，局部体征以血压、心率等生命体征及神经系统检查为主，而非体表红肿热痛）**
- **医案特征提取**：精神一般，诊室血压148/96mmHg，心率68次/分。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡红/红/暗），舌苔（色黄/白，苔腻/薄），脉象（弦滑/细/沉）。
- **关联病史追问**：
    1.  **饮食与消化**：“平时饮食习惯如何？是否喜欢吃油腻、生冷的食物？有没有腹胀、反酸？大便的性状和频率怎么样？”（挖掘脾胃运化状态）
    2.  **睡眠与情绪**：“头晕时或平时睡眠怎么样？是否多梦易醒？最近情绪、压力如何？有没有急躁易怒？”（关联肝的功能）
    3.  **口渴与饮水**：“感觉口干吗？想不想喝水？喜欢喝热水还是冷水？”（辨别津液输布与热象）
    4.  **既往史**：“除了高血压，还有没有其他疾病？比如高血脂、糖尿病、颈椎病？”（鉴别诊断）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前用过哪些降压药？效果怎么样？除了降压药，有没有尝试过其他治疗（如中药、针灸）？感觉如何？”

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肝、脾、经络（清窍/巅顶）**。病本在脾（运化失司，生痰之源），病标在肝（肝风内动，风阳上扰），风痰上犯清窍（脑）及流窜经络。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾胃气虚（运化无力）；**标实**为痰（湿）、热、风（肝风）。**病势**为上逆（风阳、痰浊上扰清窍）。
- **推理公式**：
    **[主症：头晕、昏沉感]** + **[兼症：大便质烂、口干不欲饮]** + **[舌脉：舌淡红苔黄，脉弦滑]** → 辨证结论 **[风痰阻络，肝风内动]**。
    1.  **大便质烂、口干不欲饮** → 提示脾虚失运，水湿内停，津液不布（脾为生痰之源）。
    2.  **舌苔黄** → 提示湿浊蕴久化热。
    3.  **脉弦滑** → 弦主肝风、气滞，滑主痰湿。结合头晕、眠差，指向风痰上扰。
    4.  **综合推导**：脾虚生湿，湿聚成痰，痰郁化热，热极生风（肝风）。风与痰热搏结，循经上扰清窍，故发为眩晕、头重昏沉、眠差。
- **鉴别要点**：
    1.  **与“肝阳上亢证”鉴别**：两者均有头晕、血压高、眠差。肝阳上亢证常伴面红目赤、口苦、急躁易怒、舌红苔黄、脉弦数有力，而**本证关键鉴别点在于有明显的脾虚湿盛表现（大便烂、口干不欲饮）及脉象兼滑（痰湿之象）**。
    2.  **与“气血亏虚证”鉴别**：气血亏虚之眩晕常伴面色苍白或萎黄、神疲乏力、心悸、舌淡苔白、脉细弱，**本证无虚象，反见苔黄、脉弦滑之实象**。
    3.  **与“肾精不足证”鉴别**：肾精不足之眩晕常伴腰膝酸软、耳鸣健忘、遗精等，**本证病位侧重肝脾，无典型肾虚症状**。
