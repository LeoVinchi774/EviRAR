### 一、 模拟问诊路径（针对胸痹/冠心病心绞痛场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请描述一下您心口（心前区）疼痛的具体感觉（如压榨、针刺、隐痛）？疼痛会放射到别处（如肩背、手臂）吗？这种情况有多久了？一般在什么情况下容易发作或加重（如劳累、情绪激动、饱食后）？”
- **医案特征提取**：病程8年，属久病；疼痛性质为压榨性、隐痛；劳累是明确的诱发和加重因素；疼痛有牵及肩背的放射感。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者面色（是否萎黄、晦暗）、口唇颜色（是否紫暗）。**（注：胸痹局部体征重在全身望诊与舌象）**
- **触诊焦点**：**（此处非丹毒，触诊重点不同）** 主要进行脉诊，感受脉象的力度、形态、节律。
- **医案特征提取**：面色信息未直接给出，但舌象为“舌暗红，舌下青紫”，是关键的瘀血望诊体征；脉象“弦细”为切诊核心。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（红/淡/暗/紫）、舌体胖瘦、有无瘀点瘀斑；舌苔颜色（白/黄）、厚薄、润燥；**务必查看舌下络脉**（颜色、粗细、有无迂曲）。
    - **脉诊**：脉位（浮沉）、脉率（迟数）、脉力（有力无力）、脉形（弦、滑、细、涩）。
- **关联病史追问**：
    1.  “除了心痛，平时是否常感觉胸闷、心慌（心悸）、气短乏力？”
    2.  “睡眠怎么样？是否多梦易醒？”
    3.  “有没有头晕、头昏（眩晕）的感觉？是否口干想喝水？”
    4.  “饮食、大小便情况如何？（纳呆、脘腹胀满、二便调否）”
    5.  “既往是否有高血压、糖尿病、高脂血症等其他慢性病史？（医案已提示高血压、脑萎缩）”

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过哪些检查和治疗（如冠脉造影、支架等）？西医诊断是什么？服用过哪些药物（西药/中药）？效果如何，症状是持续存在还是反复发作？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症为胸痛、心悸），涉及**心络**（久病入络）、**脾**（痰浊困脾，见纳呆、腹胀、眩晕）。
- **核心病性**：**本虚标实**。**本虚**为**气虚**（乏力短气）；**标实**为**血瘀**（舌暗红、舌下青紫、久病）、**痰阻**（苔白、胸闷、眩晕）。
- **推理公式**：
    1.  **[主症：阵发性心前区隐痛/压榨痛，病程8年] + [舌脉：舌暗红，舌下青紫，脉弦细] → 推导出“久病入络，心脉瘀阻”**。
    2.  **[伴随症：乏力短气] + [脉象：细] → 推导出“气虚”**。气虚推动无力，加重血瘀。
    3.  **[伴随症：胸闷、眩晕] + [舌苔：薄白] → 推导出“痰浊内阻”**。痰阻气机则胸闷，上扰清窍则眩晕。
    4.  **[伴随症：心悸、眠差多梦] → 推导出“心神失养”**，此为气血亏虚、痰瘀扰心的共同结果。
- **综合辨证**：将以上链条整合，形成完整证型：**气虚（本）** 导致血行无力而生**瘀**，气虚运化失司而生**痰**，**痰瘀互结**，**痹阻心络**，发为胸痹。故诊断结论为：**胸痹（气虚血瘀，痰阻心络证）**。
- **鉴别要点**：
    - **与单纯气滞血瘀证鉴别**：单纯气滞血瘀常伴胁胀、善太息，疼痛部位固定如刺，舌紫暗脉涩。本案兼有**气虚**（乏力短气）和**痰阻**（胸闷、眩晕、苔白）之象。
    - **与痰浊闭阻证鉴别**：单纯痰浊闭阻以胸闷如窒、体胖痰多、苔白腻为主，瘀血体征（舌下青紫）不显。本案**瘀血**征象突出。
    - **与心肾阴虚证鉴别**：心肾阴虚常见胸痛伴心悸盗汗、腰膝酸软、舌红少苔、脉细数。本案无阴虚内热之象，反有气虚、痰湿表现。
