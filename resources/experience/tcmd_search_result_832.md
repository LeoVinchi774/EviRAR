### 一、 模拟问诊路径（针对风湿性心脏病、心功能不全场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的痛苦是什么？这种情况持续多久了？是持续存在还是反复发作？什么情况下会加重或诱发？”
- **医案特征提取**：病程长达30年，呈进行性加重（10年加重史，1个月受凉后急性加重）。主诉为“胸闷、气促”，受凉、活动（稍动）为明确诱因。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **面色与唇色**：观察面色是否萎黄、无华，唇色是否暗红或紫绀。
    - **呼吸与体位**：观察有无端坐呼吸、呼吸急促。
    - **水肿**：重点检查双下肢有无水肿，记录程度（如轻度、凹陷性）。
- **触觉焦点**：
    - **心脏触诊/听诊**：触诊心尖搏动位置与强度，听诊各瓣膜区（尤其二尖瓣、主动脉瓣、三尖瓣）有无杂音及其强度、性质。
    - **腹部触诊**：触诊肝脏大小（肋下几指），检查肝颈静脉回流征是否阳性。
    - **水肿触诊**：按压双下肢胫前或踝部，检查有无凹陷。
- **医案特征提取**：面色萎黄、唇色暗红、端坐呼吸、双下肢轻度水肿；心脏听诊有特征性多瓣膜杂音；肝大、肝颈静脉回流征阳性。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡、暗淡、红）、舌体胖瘦，苔色与质地（白、黄、腻、厚）。
    - **脉象**：脉位（浮、沉）、脉力（有力、无力）、脉率（迟、数）、脉形（细、弦），特别注意尺脉、寸脉的强弱对比。
- **关联病史与症状追问**：
    - **心系症状**：“活动后或夜间是否心悸、心慌？有无胸痛？疼痛的性质和发作时间？”
    - **全身气血状态**：“是否感觉特别疲劳、没力气？胃口怎么样？睡眠如何？”
    - **二便与津液**：“大小便情况如何？大便干不干？口干想喝水吗？喝水量多不多？”
    - **女性患者特殊问诊**：“月经情况如何？量多还是少？颜色是鲜红还是淡红？经期准不准，持续时间长不长？”
    - **既往史确认**：“是否有风湿热或风湿性心脏病病史？确诊多久了？”
- **医案特征提取**：神疲乏力、动则心悸、夜间阵发性胸痛；纳差、夜寐不安；口干不多饮、大便干结；月经量多、色淡、经期延长；舌暗淡、苔白微腻，脉沉细尺弱。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次为什么来住院？之前用过什么药（中药/西药）？效果怎么样？目前医生对下一步治疗（如手术）有什么计划？”
- **医案特征提取**：因受凉后症状急性加重、生活难以自理入院；拟行瓣膜置换术，但因一般情况差（气血两虚），故请中医会诊进行术前调理。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症为胸闷、气促、心悸，病位在心）、**脾**（纳差、面色萎黄、月经量多色淡为脾虚不运、不统血）、**肾**（脉沉细尺弱提示肾气亦亏）。病变由心及脾，涉及脾肾。
- **核心病性**：**本虚标实，以虚为主**。
    - **虚**：**气血两虚**（神疲乏力、面色萎黄、动则心悸、月经色淡、脉沉细）。
    - **实**：兼有**血瘀**（唇色暗红、舌暗淡）、**水湿**（下肢水肿、苔微腻）。
- **推理公式**：
    1.  **长期病程（30年）** + **胸闷气促、心悸（活动/夜间加重）** + **心脏瓣膜器质性病变（杂音、彩超证据）** → 病位在心，久病耗伤，心气心血亏虚。
    2.  **心气心血亏虚** + **纳差、面色萎黄、神疲乏力** → “母病及子”，心脾两虚，气血生化乏源。
    3.  **脾虚** + **月经量多、色淡、经期延长** → 脾气虚不能统摄血液，导致经血妄行，进一步加重血虚。
    4.  **气血两虚** + **唇色暗红、舌暗淡** → 气虚推动无力，血行不畅，形成**兼夹血瘀**。
    5.  **心气虚、肾气弱（脉尺弱）** + **下肢水肿、苔微腻** → 气化不利，水湿内停，形成**兼夹水湿**。
    6.  **综合**：**心脾两虚、气血不足**（主证） + **兼夹血瘀、水湿**（次证） → **辨证结论：气血两虚证**。
- **鉴别要点**：
    - **与单纯心阳虚水泛证鉴别**：两者均可有水肿、心悸、气促。**鉴别点**在于：本证以**气血两虚**的全身症状（面色萎黄、神疲乏力、月经色淡量多、舌淡）为主，水肿程度较轻；心阳虚水泛证则以**阳虚寒象**（畏寒肢冷、面白、舌淡胖苔白滑）和**水饮泛滥**（水肿严重、咳喘痰稀、心悸怔忡）为突出表现。
    - **与心血瘀阻证鉴别**：两者均可有胸痛、唇舌色暗。**鉴别点**在于：本证胸痛为阵发性，伴随明显的气血亏虚证候；心血瘀阻证则以**固定性、刺痛性胸痛**为主，气虚或阳虚症状不一定是主要矛盾，舌象多见紫暗或有瘀斑。
