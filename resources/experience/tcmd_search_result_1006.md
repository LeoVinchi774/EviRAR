### 一、 模拟问诊路径（针对“口苦”及肝脾不调相关症状场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：您感觉口苦多久了？口苦的感觉是持续的还是阵发性的？是单纯的苦，还是伴有黏腻不爽的感觉？
- **医案特征提取**：病程长达5年，呈慢性过程。症状在“心情不畅时”加重，提示情志因素是关键诱发或加重因素。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点（望诊）**：观察颜面及眼睑有无浮肿、郁胀感。观察双腿有无浮肿，按压后有无凹陷。观察口唇颜色及有无干裂、起皮。
- **触觉焦点（切诊）**：触诊两腿浮肿部位，判断是凹陷性水肿还是非凹陷性肿胀。触按胁肋部（尤其是右胁），询问有无胀痛、不适感。
- **医案特征提取**：颜面郁胀浮肿、两腿浮肿、右胁肋不适。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉（望闻问切）**：
    - **望舌**：重点观察舌质颜色（红/淡）、舌体大小（胖大/瘦小）、舌苔颜色（黄/白）与质地（腻/薄）。
    - **切脉**：重点体会脉象的弦、滑、细、数等特征。
    - **追问**：食欲如何？有无腹胀、反酸？身体有无沉重、困倦感？睡眠、大小便情况如何？近期情绪、压力状况如何？
- **关联病史追问**：有无肝胆系统疾病史（如脂肪肝、胆囊炎）？有无相关检查（如B超）？平素性格是否急躁易怒或情绪抑郁？
- **医案特征提取**：纳食不香、四肢沉重、眠可、二便尚可。舌质稍红，苔稍黄腻，舌体胖大，脉弦细。B超提示脂肪肝。平素性情急躁。

**第四层：治疗经过与转归判断**
- **关键提问**：这5年来，口苦症状是否持续存在？是否在其他地方就诊或自行服药治疗过？效果如何？近期症状加重，有无特别的诱因（如情绪波动、饮食不节、劳累等）？

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、胆**。以肝气郁结为始动病机，横逆犯脾，影响脾的运化功能，并涉及胆腑（胆汁上溢）。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾气虚弱（运化无力）；**标实**为肝气郁结、湿热内蕴。病性属**热**（口苦、舌红苔黄）、属**湿**（口黏、浮肿、苔腻、身重）。
- **推理公式**：
    1.  **[主症：长期口苦 + 诱因：情志不畅]** → 提示病位在**肝、胆**（肝失疏泄，胆汁上逆）。
    2.  **[伴随症：胁肋不适 + 脉弦]** → 支持**肝气郁结**诊断。
    3.  **[伴随症：颜面及下肢浮肿、四肢沉重、纳呆、舌体胖大]** → 提示病位在**脾**，病机为**脾虚湿盛**（脾失健运，水湿泛溢）。
    4.  **[舌脉：舌质稍红，苔黄腻]** → 提示**郁热与湿浊**并存，形成**湿热**。
    5.  **综合推导**：肝郁（气滞）→ 化热 + 横克脾土 → 脾虚生湿 → 湿热互结。故辨证为 **[肝郁脾虚，湿热内蕴]**。
- **鉴别要点**：
    1.  **与单纯肝胆湿热证鉴别**：单纯肝胆湿热证通常以胁痛、口苦、黄疸、小便黄赤、舌红苔黄腻为主，脾虚症状（如浮肿、纳呆、舌体胖大）不明显。本案兼有明显脾虚水湿内停之象，故非单纯肝胆湿热。
    2.  **与心火上炎证鉴别**：心火上炎亦可致口苦，但常伴心烦、失眠、口舌生疮、小便短赤、舌尖红赤等症，无胁肋不适及明显脾虚湿困表现。
    3.  **与痰湿中阻证鉴别**：痰湿中阻可见口黏腻、纳呆、身重、苔腻，但通常无明显口苦、胁胀及情志诱因，脉多滑而非弦。本案肝郁气滞的病机是关键。
