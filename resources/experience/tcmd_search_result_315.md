### 一、 模拟问诊路径（针对脏躁/神经官能症伴头痛场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要哪里不舒服？持续多久了？每次发作持续多长时间？如何能缓解？”
- **医案特征提取**：主诉为“头痛1个月余”，发作性（每次约1小时），可自行缓解。近期有明确诱因（6天前情绪激动后加重）。需重点询问头痛的**性质**（胀痛、昏沉）、**部位**（巅顶部）、**发作规律**及**诱发/缓解因素**。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉焦点**：观察患者**神情、面色**（是否焦虑、烦躁），注意有无特殊体态或动作（如因悲伤欲哭而情绪波动）。
- **触觉焦点**：询问患者**头痛时有无搏动感、紧束感**，以及**手指发胀**的具体感觉（是麻木还是单纯的胀感）。
- **医案特征提取**：头痛伴**巅顶部昏沉不舒**，情绪激动后加重，伴**手指发胀**。此为肝经循行部位（巅顶）和肝气不舒（肢端气滞）的表现。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质**（边尖红提示心肝有热）、**舌体**（胖大提示脾虚有湿）、**舌苔**（白厚腻提示痰湿内蕴）、**脉象**（弦主肝郁，细主阴血不足或湿阻）。
- **关联病史追问**：
    1.  **情志与精神**：“最近情绪怎么样？容易着急、生气或感到悲伤吗？睡眠如何（入睡困难、多梦、易醒）？”
    2.  **躯体伴随症状**：“有没有心慌、胸闷、气短的感觉？出汗情况如何（是否阵发性、与情绪或活动的关系）？口干吗？口苦吗？”
    3.  **既往体质与病史**：“平时容易累吗（素感疲乏无力）？有没有做过什么大手术（甲状腺、子宫切除术史，提示气血损伤、体质偏弱）？”

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重前做过什么检查（如头颅CT）？结果如何？之前有没有用过什么药或治疗方法？效果怎么样？”
- **医案特征提取**：已行头颅CT排除器质性病变，为功能性诊断（神经官能症）提供依据。问诊需确认西医检查结果，并了解既往治疗史以评估病情顽固程度。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝**（主症头痛、心烦急躁、脉弦）、**脾**（体胖、苔腻、疲乏）、**心**（眠差、悲伤欲哭、舌边尖红）。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为**脾虚**（气血生化不足，痰湿内生）；**标实**为**肝郁**（气机不畅）、**肝阳上亢**（阳亢于上）、**痰湿/痰浊内阻**（壅滞气机）。
- **推理公式**：
    - **[主症：情绪激动后头痛加重、心烦急躁] + [体征：口干苦、舌边尖红] → 推导出：肝郁化热，肝阳上亢**。
    - **[伴随症：疲乏无力、舌体胖大、苔白厚腻、胸闷] + [病史：多次手术史] → 推导出：脾虚失运，痰湿内生**。
    - **[全身症：悲伤欲哭、眠差] + [舌象：舌边尖红] → 推导出：痰热扰心，心神不宁**。
    - **综合**：脾虚（本）→ 肝郁乘脾、痰湿内生 → 肝郁化热伤阴 → 肝阳上亢 + 痰热扰心 → 证属**脾虚肝郁，肝阳上亢，心神不宁**。
- **鉴别要点**：
    1.  **单纯肝阳上亢证 vs 本证**：单纯肝阳上亢常伴面红目赤、耳鸣如潮、腰膝酸软（肝肾阴虚明显），舌红苔少，脉弦细数。**本证关键鉴别点在于有明显的脾虚痰湿征象**（体胖、苔腻、疲乏）和心神症状（悲伤欲哭），脉象弦而细，不一定是数脉。
    2.  **单纯痰湿中阻证 vs 本证**：单纯痰湿中阻以头重如裹、胸闷脘痞、呕恶痰涎为主，情志症状不突出。**本证关键鉴别点在于有明确的情志诱因和肝郁化火、肝阳上亢的表现**（心烦、口苦、头痛部位在巅顶）。
