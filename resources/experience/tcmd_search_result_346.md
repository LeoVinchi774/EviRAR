### 一、 模拟问诊路径（针对不寐/失眠伴情志与消化症状场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？持续多久了？最近有什么变化吗？”
- **医案特征提取**：
    - **病程长短与诱因**：失眠多梦反复发作6月余（长期），加重1周。需明确初始诱因（如工作压力增大）与近期加重诱因（如项目考核失利）。
    - **核心症状**：入睡困难（辗转1-2小时）、睡后易醒、醒后难再寐、多梦纷纭（焦虑思虑内容）。
    - **加重伴随症状**：胸闷胁胀、善太息、食欲不振、食后腹胀、大便溏薄。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点（望诊）**：
    - **精神与面色**：观察精神是否萎靡、面色是否萎黄无华。
    - **眼目**：观察双目是否干涩、眼睑有无浮肿。
    - **舌象**：重点观察舌质颜色（淡红）、舌体形态（胖大、齿痕）、苔质与苔色（薄白腻）。
- **听觉焦点（闻诊）**：
    - **语言与气息**：倾听语声是否低微、气息是否短促、有无频繁太息。
- **触觉焦点（切诊）**：
    - **脉象**：重点体会脉象的弦度、粗细、快慢（弦细而缓）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质淡红、舌体胖大边有齿痕、苔薄白腻；脉弦细而缓。
- **关联病史追问**：
    - **情志与性格**：“平时性格如何？容易多思多虑吗？最近情绪怎么样？”
    - **饮食与消化**：“平时饮食习惯如何？有无偏好生冷油腻？最近胃口、饭后感觉、大便情况怎样？”
    - **全身伴随症状**：“是否感觉神疲乏力、容易健忘？有无畏寒肢冷、小便清长？”
    - **月经情况（针对女性患者）**：“月经周期、经量、颜色如何？经期有无腹痛？”

**第四层：治疗经过与转归判断**
- **关键提问**：“之前自己用过什么药或保健品吗？效果怎么样？为什么这次选择来就诊？”
- **医案特征提取**：患者曾自行服用安神类保健品，症状“时轻时重”，提示病情反复，未得根本治疗。近期因情绪刺激加重，彻夜难眠，影响生活，故寻求系统中医治疗。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、心**。病起于肝（情志不舒，气机郁结），影响及脾（肝气犯脾，运化失职），最终累及心神（气血乏源，心神失养/被扰）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **标实**：肝气郁结（气滞）。
    - **本虚**：脾气虚弱，气血不足。
- **推理公式**：
    1.  **[主症：失眠多梦、易醒难寐]** + **[情志症状：胸闷胁胀、善太息、情绪抑郁]** + **[脉象：弦]** → **推导出“肝气郁结，扰动心神”**。
    2.  **[消化症状：食欲不振、食后腹胀、大便溏薄]** + **[全身症状：神疲乏力、面色萎黄]** + **[舌象：舌体胖大边有齿痕]** → **推导出“脾失健运，气血生化不足”**。
    3.  **[体征：眼睑浮肿、苔薄白腻]** → **佐证“脾虚水湿不运”**。
    4.  **综合**：肝郁（标） + 脾虚（本） + 心神失养/被扰（果） + **舌脉（舌淡红胖大齿痕苔白腻，脉弦细缓）** → **辨证结论：不寐病（肝郁脾虚证）**。
- **鉴别要点**：
    - **与单纯心脾两虚证鉴别**：单纯心脾两虚证以心悸、健忘、纳差、便溏、面色无华、舌淡脉细弱为主，**无明显胁胀、太息、脉弦等肝郁气滞表现**。本案兼有肝郁，故见胸闷胁胀、善太息、脉弦。
    - **与肝郁化火证鉴别**：肝郁化火证失眠多伴急躁易怒、口苦口干、头痛、目赤、便秘、舌红苔黄、脉弦数等**明显热象**。本案无热象，反见脾虚湿蕴之象（便溏、苔腻、脉缓），故为肝郁脾虚，未化火。
    - **与痰热扰心证鉴别**：痰热扰心证失眠多伴心烦、头重、胸闷、呕恶、苔黄腻、脉滑数等**痰热征象**。本案苔为白腻，脉不滑数，且以脾虚气滞为主，热象不显。
