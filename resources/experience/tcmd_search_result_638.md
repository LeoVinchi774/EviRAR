### 一、 模拟问诊路径（针对积聚/原发性胆汁性肝硬化场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次来主要是因为哪里不舒服？这个情况有多久了？”
- **医案特征提取**：患者主诉为“右胁胀满”，病程半年（自确诊PBC起）。需重点询问右胁不适的性质（胀、痛、刺痛）、诱因（情绪、饮食、劳累）及变化过程。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **皮肤**：观察肤色是否晦暗、有无黄染、有无抓痕或皮疹（对应“皮肤色暗”、“皮肤瘙痒”病史）。
    - **腹部**：观察腹部形态，有无膨隆、青筋暴露（对应“脾稍大”的CT结果，为积聚外候）。
- **触觉焦点**：
    - **胁肋部**：触诊右胁下有无压痛、有无痞块（积聚的直接体征）。
    - **腹部**：触诊腹部软硬，有无压痛、有无积块（重点在左胁下脾区，探查脾脏大小）。
- **医案特征提取**：肤色晦暗、脾脏稍大（积聚之征）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（红/淡）、舌边是否赤、舌苔颜色与厚薄（对应“舌质红边赤，苔薄白”）。
    - **脉诊**：脉象的力度（沉/浮）、形态（弦/滑/涩）、粗细（细/洪）（对应“脉沉弦细”）。
- **关联病史追问**：
    1.  **情志与体质**：“您平时性格如何？是否容易着急、生气或郁闷？”（对应“平素性急”）。
    2.  **全身症状**：
        - 二便：“大小便怎么样？颜色、质地如何？”（对应“大便溏稀，小便黄”）。
        - 津液：“是否经常感觉口干、口苦？”（对应“口干”）。
        - 精力与睡眠：“平时容易累吗？睡眠、胃口怎么样？”（对应“食纳、睡眠可”，但需追问“工作是否劳碌”以判断气虚成因）。
    3.  **女性患者**：需常规询问月经情况（周期、量、色、质），本案中月经正常，有助于排除血海病变，将病位聚焦于肝。
    4.  **既往治疗**：“之前用过什么药？效果怎么样？”（明确“熊去氧胆酸”治疗史及“肝功能改善不明显”的疗效瓶颈）。

**第四层：治疗经过与转归判断**
- **关键提问**：“您之前因为‘皮肤瘙痒、肝功能异常’做过肝穿刺确诊，最近复查情况如何？为什么觉得需要来看中医？”（引导患者提供关键实验室及影像学结果：肝功TBIL、ALT，肝脏硬度值，CT提示脾大等，以评估疾病阶段与严重程度）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝**（主症为右胁胀满，病位在肝经所布）。兼及**脾**（大便溏稀）、**肾**（久病及肾，气阴两虚之底）。
- **核心病性**：**本虚标实**。
    - **标实**：**肝郁**（性急、胁胀、脉弦）、**血热**（舌红边赤、皮肤色暗、小便黄）。
    - **本虚**：**气阴两虚**（口干、脉细、病程日久、劳碌伤气）。
- **推理公式**：
    1.  **[主症：右胁胀满] + [体质：平素性急] + [脉象：弦] → 推导出：肝气郁结**。
    2.  **[舌象：舌质红边赤] + [二便：小便黄] + [病史：皮肤瘙痒] → 结合肝郁日久，推导出：郁而化热，热入血分（血热）**。
    3.  **[症状：口干] + [脉象：细] + [病史：病程半年，劳碌] + [舌象：红（阴伤之象）但苔薄白（未至燥）] → 推导出：热邪伤阴，劳倦耗气，形成气阴两虚**。
    4.  **[体征：皮肤色暗] + [检查：脾稍大、肝脏硬度增高] → 结合血热病机，推导出：血热煎熬，血行不畅，渐成瘀滞，结为积聚**。
    - **综合辨证结论**：**肝郁血热，气阴两虚型积聚**。病机链条为：**肝郁 → 化热 → 伤阴耗气（气阴两虚） → 热灼血分（血热） → 血滞成瘀 → 结为积聚**。
- **鉴别要点**：
    1.  **与单纯肝郁脾虚证鉴别**：单纯肝郁脾虚常见胁胀、纳差、便溏、乏力，但舌多淡红或边有齿痕，苔白，脉弦细或弱，**无明显的热象（如舌红赤、小便黄）和阴虚之象（如口干）**。本案热象与阴虚征象明显，故非单纯肝郁脾虚。
    2.  **与湿热蕴结证鉴别**：湿热蕴结亦可见胁痛、小便黄、苔黄腻，但多伴口苦、恶心、身目黄染鲜明，**大便多黏滞臭秽而非溏稀，且热象偏于气分，伤阴表现不突出**。本案以血热、阴虚为主，苔薄白而非黄腻，可资鉴别。
    3.  **与纯虚无实证鉴别**：纯气阴两虚多见神疲乏力、口干咽燥、舌红少苔、脉细数，**胁肋胀满等气滞实证不明显**。本案有明显肝郁胁胀及血热、瘀积之实象，属虚实夹杂。
