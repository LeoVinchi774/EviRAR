### 一、 模拟问诊路径（针对心悸/室性早搏场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您心慌、心悸多久了？这次加重有多长时间？什么情况下会诱发或加重？”
- **医案特征提取**：病程长达4年，近期因作息不规律复发加重3个月。病起于上呼吸道感染后，提示外邪可诱发或加重本病。

**第二层：核心症状细查（问诊/切诊导向）**
- **症状特征追问**：
    - **心悸特点**：“心慌是持续的还是阵发性的？白天和晚上哪个时候更明显？”（医案特征：夜间较甚）
    - **伴随症状**：“除了心慌，有没有胸闷、气短、头晕、怕冷的感觉？”（医案特征：胸闷、气短、头晕、畏寒）
    - **精神情志**：“最近情绪怎么样？容易紧张、焦虑或者急躁吗？”（医案特征：焦虑）
- **医案特征提取**：心悸夜间加重，伴有胸闷、气短、乏力、头晕、畏寒、焦虑等全身及情志症状。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：重点观察舌色（暗红）、舌形（边有齿痕）、苔质（黄腻）、舌下络脉（瘀张程度）。
    - **脉诊**：仔细体会脉象（弦脉）。
- **全身状况追问**：
    - **饮食二便**：“胃口怎么样？大便干不干、顺不顺畅？”（医案特征：纳差，大便干）
    - **睡眠情况**：“睡眠好吗？容不容易入睡？做梦多不多？”（医案特征：眠差，入睡困难，眠浅梦多）
    - **女性患者必问**：“月经情况如何？量、色、质地怎么样？有没有血块？”（医案特征：月经量少色暗血块多）
- **医案特征提取**：舌暗红、边有齿痕、苔黄腻、舌下络脉重度瘀张，脉弦。全身症状涉及消化（纳差）、睡眠（眠差）、妇科（月经异常）等多系统。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过什么检查（如动态心电图）？结果如何？用过哪些药（中药/西药）？效果怎么样？有没有规律服药？”（医案特征：动态心电图显示室性早搏频发，曾服参松养心胶囊、美西律，但间断不规律，近期复发）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症心悸，病位在心）。关联脏腑：**肝**（脉弦、焦虑、月经血块提示肝气郁滞）、**脾**（舌边齿痕、纳差、乏力提示脾虚）、**肾**（夜间症甚、阴阳失调，与肾相关）。
- **核心病性**：**虚实夹杂**。**实**：气滞（脉弦、焦虑）、血瘀（舌暗、舌下络脉瘀张、经血有块）、湿热（苔黄腻）。**虚**：气虚（气短、乏力）、阴虚（大便干、眠差）、阳虚（畏寒）。总体为**本虚标实**之证。
- **推理公式**：
    1.  **[主症：心悸夜间加重] + [体征：舌暗红、舌下络脉重度瘀张、月经血块多] → 推导出：瘀血痹阻心脉**（夜间血行缓慢，瘀阻加重故心悸夜间甚）。
    2.  **[体征：苔黄腻、纳差、大便干] + [症状：头晕] → 推导出：湿热内蕴，困阻中焦**。
    3.  **[症状：气短、乏力、畏寒] + [体征：舌边齿痕] → 推导出：阳气亏虚**。
    4.  **[症状：焦虑、脉弦] + [月经异常] → 推导出：肝气郁滞**。
    5.  **综合以上：瘀血（核心） + 湿热 + 气虚/阳虚 + 肝郁 → 辨证结论：气滞血瘀证，兼夹湿热、阳气亏虚、阴阳失调**。
- **鉴别要点**：
    - **与单纯心血虚/心阴虚鉴别**：单纯虚证多见舌淡或红、少苔，脉细弱或细数，无显著瘀血（舌暗、络脉瘀张）或湿热（苔黄腻）征象。
    - **与单纯痰火扰心鉴别**：痰火证以心悸、失眠、苔黄腻、脉滑数为主，但瘀血征象（如固定刺痛、舌紫暗瘀斑）不突出，且畏寒、乏力等虚寒象少见。
    - **提示模型**：本案关键在于识别 **“瘀血”** 为贯穿始终的核心病机（舌脉、月经、夜间加重），同时不能忽视 **“湿热”** 与 **“正虚”（气、阳）** 的兼夹，以及 **“肝郁”** 对气血运行的影响，属于复杂证候的复合。
