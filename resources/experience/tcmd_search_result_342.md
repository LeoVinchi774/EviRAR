### 一、 模拟问诊路径（针对绝经前后诸症/阴虚火旺场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最不舒服、最想解决的是什么问题？这种情况持续多久了？”
- **医案特征提取**：患者主诉为“月经紊乱”与“潮热盗汗”两大核心。病程长达“近1年”，且“症状反复”，提示病情迁延，非新发。需明确“月经量少、周期延长”的具体情况（如周期天数、经期天数、经色、有无血块）及“潮热盗汗”的发作频率、时间（如夜间为主）和程度。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者**面色**（是否颧红）、**舌象**（舌色、舌苔厚薄与润燥、有无裂纹）。注意**皮肤**有无干燥、脱屑或抓痕（如医案中“颈部及眼睑皮肤瘙痒”）。
- **触觉焦点**：切诊**脉象**（脉位、脉力、脉率，重点感受是否“细”脉）。可询问患者“五心烦热”的具体感觉（手心、足心、心胸是否自觉发热）。
- **医案特征提取**：**舌红、苔少**是阴虚火旺的典型舌象；**脉细**为阴血不足之征。**皮肤瘙痒**为阴虚血燥生风的表现。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质红，苔少或无苔，脉细数或细**。这是辨证的关键客观依据。
- **关联病史追问**：
    1.  **月经史**：详细询问初潮年龄、既往月经周期、经量、经色、有无痛经。重点问末次月经时间、量、色，以及绝经年龄（如适用）。医案中“月经周期30～60天，行经2～3天，色红”是冲任失养、经血乏源的表现。
    2.  **全身症状**：系统询问有无**口干、口苦、咽干**（上焦虚火上炎）；**失眠、多梦、心悸**（心肾不交）；**头晕、耳鸣、腰膝酸软**（肝肾阴虚）；**大便干结、小便短黄**（津液亏耗）；**情绪波动、烦躁易怒**（阴虚阳亢）。
    3.  **治疗史**：询问是否接受过西医“激素替代治疗”或“中药治疗”，具体方案及效果如何（如医案中“效果欠佳”），以评估病情顽固性及既往辨证思路。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在其他地方是怎么治疗的？效果怎么样？为什么觉得效果不好，或者症状又反复了？”（旨在了解治疗抵抗原因，排除误治或方证不符）。
- **医案特征提取**：患者曾接受“激素替代治疗及中药治疗”但“效果欠佳，症状反复”，提示常规治疗未能切中“阴虚火旺、心肾不交”的核心病机，需深入辨证。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肾（阴）**、**心（火）**、**冲任二脉**。病本在肾阴亏虚，病标在心火偏亢，病变影响冲任。
- **核心病性**：**本虚标实**。**本虚**为**肾阴（精）亏虚**；**标实**为**虚火上炎**（心火、肝火）、**阴虚内热**、**津亏血燥**。
- **推理公式**：
    - **第一步（抓主症定病期）**：`[女性，50岁]` + `[月经周期紊乱、量少]` → **定位“绝经前后诸症”（围绝经期）**。
    - **第二步（据全身症候定病性）**：`[潮热（夜间/骨蒸）、盗汗]` + `[五心烦热、口干多饮]` + `[大便偏干]` → **指向“阴虚内热”**。
    - **第三步（据特定症状定病位兼夹）**：`[口苦、咽喉不利]` → **提示虚火上炎，涉及肝胆、肺胃**。`[寐欠佳、夜间多次热醒]` → **提示“心肾不交”（肾水不济心火）**。`[皮肤瘙痒]` → **提示阴虚血燥生风**。
    - **第四步（据舌脉确证）**：`[舌红、苔少]` + `[脉细]` → **确证“阴虚”本质，舌红为有热之象**。
    - **最终整合**：`[绝经前后年龄]` + `[阴虚内热症状群]` + `[心肾不交特征]` + `[阴虚舌脉]` → **辨证结论：绝经前后诸症，阴虚火旺证（心肾不交型）**。
- **鉴别要点**：
    1.  **与单纯肝肾阴虚证鉴别**：单纯肝肾阴虚多以头晕耳鸣、腰膝酸软、视力减退为主，热象不显或仅为低热。本案突出**心火亢盛**（失眠、口苦）与**虚热内扰**（骨蒸潮热、盗汗）并见，病位更侧重心肾。
    2.  **与肝郁化火证鉴别**：肝郁化火证情绪烦躁、胸胁胀痛、口苦目赤等症状突出，脉多弦数。本案虽有口苦，但以阴虚内热及心肾症状为主，脉为细脉，非弦象，且病程长，虚象明显。
    3.  **与湿热内蕴证鉴别**：湿热证可见潮热、汗出，但多为身热不扬、汗出黏腻，伴有身重、脘痞、苔黄腻等。本案汗出为盗汗，伴口干、舌红少苔，一派阴虚之象，无湿邪表现。
