### 一、 模拟问诊路径（针对心衰喘咳水肿危重场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次因为什么不舒服来的？这种情况多久了？和以前比有什么不一样？”
- **医案特征提取**：病程长达15年（水肿）、5年（喘咳），近期（1月）因“受寒”急剧加重。呈慢性、进行性、季节性（冬季）加重特点，已发展为“重度难治性心力衰竭”，常规西医治疗1月无效，进入危重状态。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **水肿**：观察水肿部位（全身、下肢、腹部）、程度（大腿及以下俱肿、腹大如鼓）、皮肤色泽（是否光亮、有无紫暗）。
    - **呼吸**：观察呼吸状态（极度困难、张口抬肩、不能平卧）、痰液性状（泡沫样、清稀、量多）。
    - **面容与肢端**：观察面色（两颧暗红晦滞）、口唇及指甲（紫绀）、汗出情况（额上冷汗如豆）、四肢末端（冰冷至肘膝）。
- **触觉焦点**：
    - **水肿**：按压水肿部位，评估凹陷程度及恢复速度（重度凹陷性水肿）。
    - **肢温**：触摸四肢末端至肘膝关节，感受皮温（冰冷）。
    - **腹部**：触诊腹部，评估腹水张力（腹大如鼓）。
- **医案特征提取**：全身重度凹陷性水肿、腹水、二尖瓣面容、唇甲紫绀、端坐呼吸、咳吐大量泡沫清稀痰、额出冷汗、四肢厥冷。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡紫）、舌苔（白滑）。
    - **脉象**：脉位（沉）、脉力（细）、脉势（欲绝）、脉率（至数难明，提示心房纤颤）。
- **关联病史追问**：
    - “以前诊断过什么心脏病？心功能怎么样？有没有房颤？”
    - “平时怕冷还是怕热？手脚凉不凉？这次加重和受凉有关系吗？”
    - “大便情况怎么样？小便量和颜色如何？”（医案提示大便3日未行，肾功能不全，需关注二便）。
    - “说话声音怎么样？感觉气够用吗？”（评估语言低微断续、气短程度）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次住院多久了？用了哪些药？效果怎么样？医生有没有下病重或病危通知？”
- **医案特征提取**：明确患者已住院1月，西医诊断为“重度难治性心力衰竭”等，经标准抗心衰治疗病情未控制，已下发病危通知，提示病情危殆，常规治疗无效，需中医紧急介入。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肾（根本）、肺（标象）、心（宿疾）、三焦（水道）**。久病及肾，肾阳虚衰为病本；寒水上犯射肺为急标；心阳不振、血瘀水停为病理基础。
- **核心病性**：**本虚标实，以虚（阳虚）为本，以实（寒水、血瘀）为标**。属**里、寒、虚**证，已濒临**阴阳离绝**之危候。
- **推理公式**：
    1.  **[久病水肿 + 畏寒肢冷厥逆 + 舌淡紫苔白滑 + 脉沉细欲绝]** → **肾阳虚衰，气化无权**（阳虚不能制水，故水肿；失于温煦，故畏寒厥冷；舌脉为阳虚寒盛、血行不畅之象）。
    2.  **[受寒诱发 + 喘咳不能平卧 + 咳吐大量泡沫清稀痰]** → **寒水射肺，肺气上逆**（寒水为阴邪，上犯于肺，壅塞气道，故喘咳痰稀）。
    3.  **[唇甲紫绀 + 两颧暗红晦滞 + 舌淡紫]** → **阳虚血瘀，气血不运**（阳虚寒凝，推动无力，导致血行瘀滞）。
    4.  **[额上冷汗如豆 + 脉微欲绝 + 语言低微断续]** → **阳气外越，阴阳离绝之先兆**（阴寒内盛，逼迫残阳外越，出现冷汗、脉绝等亡阳危象）。
- **鉴别要点**：
    - **与痰热壅肺喘证鉴别**：本证痰为**泡沫样、清稀、量多**，伴**畏寒肢冷**等全身寒象；痰热证痰多为黄稠、粘腻，伴发热、口渴、舌红苔黄腻等热象。
    - **与单纯脾虚水肿鉴别**：本证水肿程度**极重（全身、腹水）**，且伴有**喘咳、肢冷厥逆、脉微欲绝**等肾阳衰微、水气凌心的危重证候，病位更深，病情更重。脾虚水肿多以四肢、眼睑为主，全身寒象不如此证显著。
    - **与阴虚阳亢面红鉴别**：本证面红为**两颧暗红晦滞**，是虚阳浮越或血瘀所致，必伴**全身畏寒、四肢厥冷、冷汗**；阴虚阳亢面红多为午后颧红、潮热，伴五心烦热、舌红少苔。
