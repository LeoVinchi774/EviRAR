### 一、 模拟问诊路径（针对不孕症伴情志失调场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次来看诊，最主要想解决什么问题？”（引导患者陈述主诉，如“结婚多年未孕”或“月经不调”）。
- **医案特征提取**：结婚4年未孕（病程），月经周期紊乱、多错后（月经不调特征），经前乳房胀痛、小腹胀痛（与月经周期的关联性），心烦急躁、失眠梦多（情志症状）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者面色、神态（是否焦虑、烦躁），观察舌象（舌质颜色、舌体胖瘦、苔色苔质）。
- **触觉焦点**：切脉（脉象的弦、细、滑等特征），触诊腹部（小腹有无压痛、包块）。
- **医案特征提取**：舌质暗红、舌体稍胖大、苔薄白（望诊要点）；脉搏弦细（切诊要点）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（暗红提示血瘀或郁热）、舌体（胖大提示脾虚有湿）、苔（薄白提示湿浊不重或病在气分）、脉象（弦主肝郁，细主血虚或湿阻）。
- **关联病史追问**：
    1.  **月经史**：初潮年龄、周期、经期、经量、经色、有无血块、痛经情况（性质、部位、与经期的关系）。追问“经前或经期乳房、小腹具体感觉如何？”
    2.  **婚育史**：结婚年限、孕产史、避孕措施、配偶检查情况。
    3.  **情志与生活史**：“平时情绪如何？是否容易生气、焦虑或压力大？”“睡眠质量怎么样？容易入睡吗？多梦吗？”“饮食、二便情况如何？”（挖掘肝郁、脾虚、痰湿的成因）。
    4.  **既往诊疗史**：是否做过相关检查（如B超、激素水平）及结果，既往中医或西医治疗经过及效果。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前为了调理怀孕或月经，都做过哪些治疗？效果怎么样？”（了解治疗史，避免重复无效方案，评估病情顽固程度）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、心**。肝主疏泄，调畅气机与情志；脾主运化，为生痰之源；心主神明。病位涉及肝（气滞）、脾（虚、湿）、心（神扰）。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾虚；**标实**为肝郁气滞、痰湿阻滞、肝火/痰火内扰。病性属气滞、湿阻、痰凝、热扰，兼有血行不畅（经色暗）。
- **推理公式**：
    - **步骤1（抓主症，定核心矛盾）**：`[主症：结婚4年未孕]` + `[关键兼症：月经错后、量少、色暗、经前乳胀、小腹胀]` → 初步定位**冲任失调，肝郁气滞血瘀**。
    - **步骤2（结合全身与情志症状）**：`[上一步结论]` + `[情志症状：心烦急躁、失眠梦多]` + `[舌脉：舌暗红、脉弦细]` → 推导肝郁化火、上扰心神，形成**肝郁化火证**或**肝火扰心证**。
    - **步骤3（结合舌象与病机推导）**：`[上一步结论]` + `[舌象：舌体稍胖大]` + `[病机链条：长期肝郁（木郁）克伐脾土（脾虚）]` → 推导脾虚失运，生湿酿痰，形成**脾虚肝郁，痰湿内生**。
    - **步骤4（综合集成）**：`[肝郁气滞血瘀]` + `[肝火扰心]` + `[脾虚痰湿]` → 最终辨证结论：**1.不孕症（肝郁气滞，痰湿阻滞）；2.脏躁（脾虚肝旺，肝火内盛）**。其中“痰湿阻滞”是脾虚生湿与肝郁气滞共同导致气滞痰凝，阻塞冲任；“肝火内盛”是肝郁日久化火，与痰互结，上扰心神。
- **鉴别要点**：
    1.  **与单纯肾虚型不孕鉴别**：肾虚型常伴腰膝酸软、头晕耳鸣、月经量少质稀、色淡，舌淡苔白，脉沉细。本案无典型肾虚症，而以肝郁脾虚、痰火为著，舌质暗红而非淡，脉弦而非沉。
    2.  **与单纯血瘀型痛经/月经不调鉴别**：单纯血瘀常表现为痛经剧烈、拒按，血块多且大，舌紫暗或有瘀斑，脉涩。本案血瘀征象（经色暗）是肝郁气滞的继发表现，且伴随明显的痰湿与火扰症状，治疗需在疏肝健脾基础上兼以活血，而非专攻活血化瘀。
    3.  **痰湿与湿热的鉴别**：本案苔薄白而非黄腻，热象（心烦、失眠）主要源于肝火，而非湿热胶结，故病性以气滞痰阻化火为主，非湿热下注。
