### 一、 模拟问诊路径（针对长期呕吐、月经期加重场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您恶心、呕吐的情况具体多久了？是持续性的还是间断性的？在什么情况下会明显加重或诱发？”
- **医案特征提取**：病程长达20余年，呈间断性发作，且与月经周期有明确关联（月经期间尤甚），提示病机与冲任气血周期性变化密切相关。需重点询问月经周期、经量、经色、经质及伴随的腹痛情况。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者体型（消瘦）、面色（医案未明言，但气血不足、痰湿内阻者常见面色萎黄或淡白无华）。重点观察舌象（舌体胖瘦、颜色、齿痕、苔色苔质）。
- **触觉焦点**：询问并触诊胃脘部（是否疼痛、喜按拒按）、小腹部（冷痛程度、有无包块）。切脉（脉象的弦、滑、数、细等特征）。
- **医案特征提取**：胃脘隐痛（虚痛）、小腹冷痛（寒凝血瘀）、月经量少色黑（血瘀）、舌淡胖边有齿痕（脾虚湿盛）、苔黄腻（湿蕴化热）、脉弦滑（主痰湿、气滞）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡胖/红）、舌苔（黄腻）、舌边（齿痕）、脉象（弦滑）。这是判断虚实、寒热、痰湿、气滞的关键客观依据。
- **关联病史追问**：
    1.  **情志与生活史**：“您平时情绪如何？是否容易生气、烦躁或感到压力大？”（挖掘肝气郁结因素）。“结婚多年未育，对此事您内心感受如何？是否长期为此焦虑？”（挖掘核心情志致病诱因）。
    2.  **全身症状**：系统询问有无**胸闷、心悸、气短**（气机不畅，上焦郁闭）、**烦热、耳鸣**（肝郁化热或虚火上扰）、**手足麻木**（气血亏虚，不荣四末）、**纳差、消瘦**（脾胃虚弱，气血生化乏源）、**睡眠情况**（寐差，多因胃不和或心肝火旺）、**二便情况**（夜尿频-肾气不固或水湿不化；大便干+苔黄腻-湿热内结或津亏肠燥）。
    3.  **月经史**：详细询问月经周期、经量、经色、经质、有无血块、痛经性质（冷痛/刺痛/胀痛）、痛经与呕吐的关联时序。

**第四层：治疗经过与转归判断**
- **关键提问**：“这20多年里，您都做过哪些检查和治疗？效果怎么样？为什么觉得效果不理想？”（了解既往诊疗史，排除器质性疾病，印证“久病入络”、“久治不愈致情志不遂”的病机演变）。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**病在肝、脾（胃）、冲任**。以**脾胃**为中心（主纳运，胃气上逆则呕），**肝**为关键（主疏泄，情志不遂则肝气郁结，横逆犯胃），**冲任**为重要影响因素（月经期气血下注冲任，全身气机与血海变动，诱发或加重脾胃症状）。

- **核心病性**：**本虚标实，寒热错杂**。
    - **本虚**：脾胃虚弱（长期纳差、消瘦、舌淡胖有齿痕）。
    - **标实**：**气滞**（急躁易怒、胸闷、脉弦）、**血瘀**（月经色黑、痛经、病程久）、**痰（湿）阻**（呕吐、苔腻、脉滑）。
    - **寒热**：**上热**（舌尖红、烦热、苔黄）、**下寒/中寒**（小腹冷痛）。

- **推理公式**：
    1.  **主症（恶心呕吐）+ 诱因（月经期加重、情志因素）** → 提示病机与**肝气、冲任气血**密切相关，非单纯胃病。
    2.  **【脾胃虚弱证据】**（纳差、消瘦、舌淡胖有齿痕） + **【痰湿内阻证据】**（呕吐、苔腻、脉滑） → 推导出 **“脾虚生湿，胃气上逆”** 的基础病机。
    3.  **【气滞证据】**（急躁易怒、胸闷、脉弦、久治不愈史） + **【血瘀证据】**（月经色黑、痛经、病程20年） → 推导出 **“肝气郁结，久病入络致血瘀”** 的继发病机。
    4.  **【寒热错杂证据】**（小腹冷痛 + 舌尖红、苔黄） → 提示病机复杂，存在**下焦寒凝（冲任）与中上焦郁热**并存的情况。
    5.  **综合**：`[长期呕吐纳差]` + `[舌淡胖齿痕苔黄腻]` + `[脉弦滑]` + `[月经色黑痛经情志不畅]` → 辨证结论 **“呕吐（气滞血瘀痰阻证）”**。此证型概括了**肝郁气滞**（横犯脾胃）、**瘀血内停**（阻滞气机）、**痰湿中阻**（上逆为呕）三大病理要素，并以脾胃虚弱为内在基础。

- **鉴别要点**：
    1.  **与单纯“胃寒呕吐”鉴别**：单纯胃寒多见呕吐清水、喜温喜按、舌淡苔白滑、脉沉迟，无明显的**气滞**（急躁、胸闷、脉弦）、**血瘀**（经色黑、痛经）及**热象**（舌尖红、苔黄）表现。
    2.  **与单纯“肝胃不和呕吐”鉴别**：肝胃不和以气滞为主，常见胁肋胀痛、嗳气频繁、脉弦，但若无**长期病史、月经异常（色黑、血块）及典型血瘀舌脉**，则“血瘀”证据不足。本案是肝胃不和的深化与发展，兼夹了血瘀与痰阻。
    3.  **与“湿热中阻呕吐”鉴别**：湿热中阻以苔黄腻、脉滑数为核心，呕吐物多酸腐，但通常不伴明显的**脾胃虚象**（舌淡胖、齿痕）和**下焦寒凝血瘀证**（小腹冷痛、经色黑）。本案是脾虚生湿，郁而化热，属本虚标实，且病位更广。
