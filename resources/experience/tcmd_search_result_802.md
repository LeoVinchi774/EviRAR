### 一、 模拟问诊路径（针对心悸气短/风心病心衰场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要哪里不舒服？持续多久了？最近是加重了还是减轻了？”
- **医案特征提取**：主诉“心悸、气短25年，近两个月加重”。问诊需锁定**慢性病程（>20年）** 和**近期急性加重（2个月）**。重点询问**加重诱因**（如劳累、感染、情绪）及**活动耐量**（如“平地走多远/上几层楼会喘憋？”）。

**第二层：核心症状与体征细查（望闻问切导向）**
- **视觉焦点**：
    - **望神**：精神萎靡，面色晦暗或苍白。
    - **望形态**：有无**双下肢浮肿**（部位、程度、对称性）、有无颈静脉怒张。
    - **望舌**：舌体胖大（提示气虚或水湿），舌质暗红（提示阴虚血瘀），苔少（提示阴液不足）。
- **触觉焦点**：
    - **切脉**：重点体会**脉结代**（节律不齐，有间歇），是心悸、心气不足、血行不畅的重要指征。
    - **按诊**：按压下肢浮肿处，观察有无**凹陷**（凹陷性水肿提示水湿内停）。
- **医案特征提取**：**胸闷憋气活动后加重**（典型心气虚表现）、**时有双下肢浮肿**（心功能不全，水饮凌心射肺或泛溢肌肤）、**纳少寐差，周身乏力**（气血亏虚，心神失养）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌体胖大（气虚/水停）、舌质暗红（阴虚血瘀）、苔少（阴虚）。**舌质暗红与苔少并见**是“气阴两虚兼瘀”的关键舌象。
    - **脉象**：**脉结代**（心气心阴亏虚，脉道不充，血行艰涩而时有一止）。
- **关联病史追问**：
    - **既往史**：“您年轻时有没有得过风湿热、关节痛？”（追溯风湿性心脏病病因）。
    - **现病史**：详细询问**水肿**（从何时、何部位开始）、**睡眠**（入睡困难、多梦易醒）、**二便**（大便干燥提示阴亏肠燥）、**饮食**（纳少提示脾虚）。
    - **检查结果确认**：结合现代医学检查，询问或查阅有无**心脏杂音、房颤、肺瘀血、蛋白尿**等（对应医案中胸片、B超、心电图、尿蛋白结果），这些是“瘀血阻滞”和“水湿内停”的客观证据。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次因为什么来住院？之前用过什么药（特别是西药如利尿剂、强心药）？效果怎么样？”
- **医案特征提取**：患者因“近两个月加重”入院，提示门诊常规治疗可能已难以控制，需住院系统调理。治疗目标是改善心功能（益气养阴治本）与消除病理产物（活血利水治标）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症心悸、胸闷、脉结代），兼及**脾**（纳少、乏力）、**肾**（水肿、尿蛋白）与**肺**（憋气、胸片示肺瘀血）。病在**心之气血、脉络**。
- **核心病性**：**本虚标实**。
    - **本虚**：**气阴两虚**（心气亏虚、心阴不足）。
    - **标实**：**瘀血阻滞**（血行不畅）、兼有**水湿**（浮肿、肺瘀血）。
- **推理公式**：
    - **慢性心悸气短 + 活动后加重 + 乏力** → 提示 **心气亏虚**（推动无力）。
    - **心悸 + 寐差 + 大便干燥 + 舌暗红苔少** → 提示 **心阴不足**（濡养失职，虚热内扰）。
    - **舌质暗红 + 脉结代 + 胸闷 + 西医诊断（房颤、风心病瓣膜病变）** → 提示 **瘀血阻滞心脉**（血行不畅，心脉痹阻）。
    - **双下肢浮肿 + 舌体胖大** → 提示 **水湿内停**（气虚水停，或兼肾不主水）。
    - **综合**：**(心气虚 + 心阴虚) + (血瘀 + 水停)** → 辨证结论：**气阴两虚，瘀血阻滞**（兼水湿）。
- **鉴别要点**：
    - **与单纯心阳虚衰、水饮凌心证鉴别**：后者应有畏寒肢冷、面色㿠白、舌淡胖苔白滑、脉沉细或微细等**虚寒**之象，而本案有“舌暗红、苔少、大便干燥”等**阴虚内热**之征。
    - **与单纯心血瘀阻证鉴别**：后者以心胸刺痛、痛有定处、舌紫暗有瘀斑等**瘀血**症状为主，**气虚**（乏力、气短动则尤甚）和**阴虚**（干燥、舌红少苔）表现不突出。本案是虚中夹实，虚（气阴）为本，实（瘀）为标。
