### 一、 模拟问诊路径（针对“子宫切除术后，畏寒、烘热、肿胀、失眠”场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您手术后多久了？现在最主要、最困扰您的不舒服是什么？”
- **医案特征提取**：术后半年；主诉为“怯冷烘热阵作”（寒热交替）、“四肢及眼睑肿胀”、“夜间躁扰不宁，难以入睡”、“全身乏力”。需重点询问这些症状的**发作特点、时间规律及诱发因素**。
    - **追问示例**：
        - 关于寒热：“是怕冷和发热交替出现吗？哪个感觉更明显？一天发作几次？每次持续多久？怕冷时加衣服能缓解吗？发热时感觉从身体哪里先热起来？”
        - 关于肿胀：“肿胀是从什么时候开始的？是早上轻、下午晚上重吗？按下去有没有坑（凹陷性水肿）？小便量怎么样，颜色如何？”
        - 关于睡眠：“晚上是睡不着，还是容易醒？醒后还能再睡着吗？睡不着时心里烦不烦？白天精神怎么样？”

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者**眼睑、面部及四肢**的肿胀程度、肤色（是否晄白或暗滞）；观察其精神状态（乏力、烦躁与否）。
- **触觉焦点**：**按压肿胀部位**，检查是否为凹陷性水肿；触摸四肢末端，感知其温度（是否发凉）。
- **医案特征提取**：肿胀“入暮尤甚”，提示可能与水液代谢、阳气运行日节律有关，属虚性、气化不利所致的水肿。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质（颜色、瘀点）、舌苔（色、厚薄）、脉象（粗细、力度、节律）**。本案关键为“舌质淡紫，苔薄白，脉细”。
- **关联病史追问**：
    1.  **手术史**：“具体是什么手术？（确认子宫全切）手术过程顺利吗？术后恢复如何？月经情况（已绝经？）”
    2.  **全身症状**：“除了这些，还有没有心慌、头晕、耳鸣、腰膝酸软、口干口苦、出汗多的情况？胃口怎么样？大便干不干，稀不稀？”
    3.  **情志与生活**：“最近工作或家里事情多吗？情绪怎么样，容易生气或郁闷吗？”

**第四层：治疗经过与转归判断**
- **关键提问**：“手术后这些症状是慢慢出现的，还是一开始就有？之前有没有看过医生或吃过什么药（包括西药、中成药、保健品）？效果怎么样？”
- **医案特征提取**：本案为初诊，病史明确为术后半年新发诸症，未提及前期治疗。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任二脉**（直接受损），关联**肾、肝、脾**三脏。肾为冲任之本，肝藏血主疏泄，脾主运化水湿。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：阴阳两虚（以肾阳虚为基础，兼见阴虚虚火上炎之象），气血不足。
    - **实**：血瘀（术后脉络损伤）、水湿内停（气化不利）。
- **推理公式**：
    **[子宫全切手术史]** → 直接损伤**冲任**，累及肝肾 → **阴阳失调、气血亏虚**为病本。
    + **[畏寒阵作 + 全身乏力 + 脉细]** → **阳虚（尤以肾阳为基）** 失于温煦。
    + **[烘热阵作 + 夜间躁扰]** → **阴虚（肝肾阴亏）** 虚阳上浮，扰动心神。
    + **[四肢眼睑肿胀 + 入暮尤甚]** → **脾肾阳虚**，水湿运化、气化失常，午后阳气渐衰故肿甚。
    + **[舌质淡紫]** → **气虚推动无力**致血行不畅（淡为气虚，紫为血瘀）。
    = **辨证结论**：**手术后损伤冲任，阴阳失燮，虚瘀水停证**。
- **鉴别要点**：
    1.  **与单纯“阴虚火旺”证鉴别**：单纯阴虚火旺多见五心烦热、盗汗、口干咽燥、舌红少苔、脉细数，而**本案有明显畏寒、乏力、舌淡等阳虚之象**，属阴阳俱虚，寒热错杂。
    2.  **与单纯“脾虚湿盛”水肿鉴别**：单纯脾虚湿盛多见纳呆、便溏、舌淡胖有齿痕、苔白腻，水肿全天持续或晨起明显。**本案水肿“入暮尤甚”，且伴有明显的阴阳失调（寒热交替）症状**，病位更深，涉及肾阳与冲任。
    3.  **与“肝郁化火”失眠鉴别**：肝郁化火失眠多伴急躁易怒、胸胁胀痛、口苦、脉弦。**本案失眠源于“躁扰不宁”，是阴虚阳浮、心神不宁所致，与情绪直接关联不显，且脉细非弦**。
