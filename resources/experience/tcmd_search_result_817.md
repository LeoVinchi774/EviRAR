### 一、 模拟问诊路径（针对扩张型心肌病/心衰场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**： “您这次来看病，最主要感觉哪里不舒服？这个情况有多久了？”（针对心悸、胸闷、气短、水肿等核心症状）
- **医案特征提取**：
    - **病程**：病程较长（医案中已1年余），反复发作，提示病情顽固，正气已虚。
    - **加重因素**：活动（“动则更甚”）是明确诱因，提示心功能储备严重不足，属“劳则气耗”的典型表现。
    - **生活习惯**：需主动追问工作强度、作息规律、吸烟饮酒史（医案中患者“销售工作繁忙”、“每日抽烟两包以上”），此为耗气伤阳、影响康复的重要背景。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **面色**：重点观察面色是否㿠白、无华、少神（医案：面色白、少神），此为心阳不振、气血不荣于面的表现。
    - **水肿**：观察水肿部位（医案：下肢）、程度（轻度）、性质（凹陷性），并询问水肿与体位、时间的关系。
- **触觉焦点**：
    - **肢体温度**：触摸患者四肢末端，感知是否厥冷（医案：四肢厥冷），是判断阳气虚衰程度的关键。
    - **水肿**：按压水肿部位，检查是否为凹陷性，并感知皮肤温度（本案为寒水，皮温应偏低）。
    - **胸痛性质**：询问胸痛是隐痛、闷痛还是刺痛，是否固定（医案：胸部隐痛、闷胀），以鉴别气虚、血瘀或痰阻。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：必须观察舌体胖瘦（医案：舌淡胖）、舌边齿痕（有）、舌质颜色（淡）、苔质与苔色（苔水滑）。这是辨别阳虚水停、气虚湿盛的铁证。
    - **脉象**：必须仔细体会脉位（沉）、脉力（细）、脉势（微）。脉沉细微是少阴病主脉，是心肾阳气极度衰微的直接反映。
- **关联症状追问**：
    - **寒热**：必问畏寒怕冷程度（医案：畏寒），是全身性还是局部性，与外界温度的关系。
    - **二便**：询问小便量、色（医案：小便短少），大便是否溏薄，以判断水液代谢与脾肾阳气状态。
    - **神志与睡眠**：询问精神、体力状况（医案：乏力、少神）及睡眠质量（医案：睡眠差），反映气血阴阳的盛衰。

**第四层：治疗经过与转归判断**
- **关键提问**：
    - **诊断与治疗史**：“之前在医院确诊是什么病？用过哪些西药/中药？效果怎么样，为什么停了或换药？”（医案中明确有西药治疗史但反复发作）
    - **医嘱依从性**：主动了解并强调休息、戒烟、防感冒的重要性（医案按语重点强调，且患者未完全遵守导致康复延缓），询问患者执行困难，为后续治疗和宣教做准备。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**心、肾、脾**。病位主要在心，但已累及少阴（心肾），兼及太阴（脾）。心主血脉，肾主水，脾主运化。心阳衰微，累及肾阳，导致水液气化无权，泛滥为肿；脾失温煦，运化失职，湿浊内生。
- **核心病性**：**本虚标实，以虚为主，属里、寒、阴证**。
    - **虚**：**阳气虚衰**（心肾阳虚）为根本，兼有**气虚**。
    - **实**：因虚致实，产生**血瘀**（气虚推动无力）和**浊水停滞**（阳虚气化不利）。
- **推理公式**：
    1.  **[心悸气短、动则更甚] + [乏力、面色㿠白少神] + [舌淡胖有齿痕]** → 推导出 **“气虚”** 为核心病机。
    2.  **[畏寒、四肢厥冷] + [脉沉细微]** → 叠加在气虚之上，推导出 **“阳气虚衰”（少阴阳虚）** ，病性属 **“寒”** 。
    3.  **[胸部隐痛、闷胀]** → 在气虚基础上，推导出 **“气虚致瘀”** 的次要病机。
    4.  **[下肢凹陷性水肿、小便短少] + [苔水滑]** → 在阳虚基础上，推导出 **“阳虚水停，浊水内聚”** 的病理产物。
    5.  综合以上1-4点：**气虚（本） + 阳虚（寒化） + 血瘀 + 水停（标）** → 最终辨证结论：**“阳气式微，气虚血瘀，浊水停滞之少阴寒化证”**。
- **鉴别要点**：
    - **与少阴热化证鉴别**：关键鉴别点在于**寒热**。少阴热化证可见心烦、失眠、咽痛、舌红少苔、脉细数等阴虚火旺之象。本案一派畏寒、肢冷、舌淡、脉沉微，属典型寒化。
    - **与单纯水湿困脾证鉴别**：单纯水湿困脾多以脘腹胀满、纳呆、苔白腻为主，脉多濡滑，畏寒肢冷不明显，心系症状（心悸、胸痛）不突出。本案心肾阳虚症状显著，病位更深。
    - **与单纯气滞血瘀证鉴别**：单纯气滞血瘀之胸痛多为刺痛、固定拒按，舌质紫暗或有瘀斑，脉涩。本案胸痛为隐痛、闷胀，且与气虚、阳虚症状并见，属因虚致瘀，治疗需以补气助阳为主，活血为辅。
