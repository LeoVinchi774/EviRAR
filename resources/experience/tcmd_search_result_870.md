### 一、 模拟问诊路径（针对痫病/继发性癫痫发作场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次因为什么不舒服来就诊？发作时具体是什么感觉？这种情况持续多久了？以前有过类似情况吗？”
- **医案特征提取**：
    - **病程**：术后出现痫病发作2年，本次复发3天。提示病程长，呈反复发作性。
    - **发作特征**：面部肌肉掣跳频繁（局灶性运动性发作），无四肢抽搐，神志清楚但活动受限（复杂部分性发作可能），持续数分钟可自行缓解，一日数发。需重点询问发作频率、持续时间、有无先兆、有无意识完全丧失。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉焦点**：观察患者就诊时有无面部肌肉不自主抽动、眼神是否呆滞、口角有无牵动。发作时需家属描述发作具体形态（如“掣跳”的幅度、频率、是否对称）。
- **触觉焦点**：非发作期常规体格检查，重点检查神经系统有无阳性体征（如病理反射）。
- **医案特征提取**：发作时“面部肌肉掣跳频繁”、“难以自如活动”，是局灶性发作的典型表现，需与全面性强直-阵挛发作（大发作）相鉴别。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（红）、舌苔质地与颜色（白、厚）。本案舌红主热，苔白厚主痰湿内蕴。
    - **脉诊**：脉象（沉、缓）。脉沉主病在里，缓主湿或脾虚。
- **关联病史追问**：
    1.  **手术史**：“是什么原因做的手术？（左颞叶星形细胞瘤）术后恢复如何？癫痫是术后多久出现的？”（明确继发性病因）
    2.  **全身症状**：
        - **二便**：“平时大便怎么样？是成形还是稀溏？一天几次？”（本案：大便日行三次，时溏——提示脾虚湿盛）
        - **泌尿系统**：“小便感觉怎么样？有没有尿频、尿急、尿痛？”（本案：小溲涩痛，素有尿道炎病史——提示下焦湿热）
        - **上呼吸道**：“最近有没有嗓子不舒服、咳嗽？”（本案：咽部痛痒，微咳——提示上焦有热或风热）
    3.  **体质与诱因**：“发作前有没有情绪波动、劳累、感冒等诱因？平时怕冷还是怕热？睡眠、饮食如何？”

**第四层：治疗经过与转归判断**
- **关键提问**：“这两年来发作一直是这样吗？有没有用过什么药（中药或西药）？效果怎么样？这次复发前有没有停药或者遇到什么特殊情况？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝（胆）、心（脑）、脾**。病位在脑（清窍），与少阳胆经枢机不利、痰火上扰直接相关；脾虚生湿酿痰为病理基础。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **实**：热（少阳郁热、上焦热、下焦湿热）、痰（湿痰内聚）、气滞（枢机不利）。
    - **虚**：脾虚（运化失司，见便溏）。
- **推理公式**：
    1.  **[主症：反复发作性面部掣跳、神清但活动受限] + [病史：脑部术后] + [病机常识：痫病多痰作祟]** → 初步定位：**痰扰清窍**。
    2.  **[全身症：咽痛痒、微咳（上焦热）] + [舌红（热象）] + [脉沉（病在里）]** → 支持存在**郁热**。
    3.  **[全身症：小溲涩痛（下焦湿热）] + [大便时溏（脾虚湿盛）] + [苔白厚（痰湿内蕴）] + [脉缓（湿）]** → 支持存在**痰湿内蕴，兼夹湿热**，病机涉及三焦，以中焦脾虚湿盛为基础。
    4.  **综合1、2、3**：痰湿内蕴之体，因手术扰动，导致**少阳枢机不利**，胆火内郁，与痰湿互结，化为痰火，上扰心神脑窍（清窍），故发为痫病。证属**少阳郁热，痰扰清窍**。其“胸满烦惊”（病机指征）的内在病机与柴胡加龙骨牡蛎汤证相符。
- **鉴别要点**：
    - **与“肝风内动、痰蒙神窍”证鉴别**：后者常伴眩晕、头痛、肢麻，发作时抽搐剧烈，舌红苔黄腻，脉弦滑数。本案无典型肝风之象（如抽搐、弦脉），而以局部掣跳、郁热和痰湿表现为特点，热势相对缓和。
    - **与“心脾两虚”证鉴别**：后者痫病发作多因思虑劳倦诱发，平素心悸健忘、神疲乏力、纳差便溏，舌淡苔白，脉细弱。本案虽有脾虚便溏，但伴有明显的热象（舌红、咽痛、溲痛）和痰湿（苔厚），虚象不独主。
