### 一、 模拟问诊路径（针对流产后继发性痛经/月经不调场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请问您主要因为哪里不舒服来看病？这个情况有多久了？和月经有关系吗？”
- **医案特征提取**：
    - **病程**：3年（自人工流产术后起）。
    - **核心症状**：经期腹痛剧烈（“腹痛如绞”），月经周期延后（“每延期而至”）。
    - **加重/缓解因素**：疼痛拒按但喜温，需依赖止痛药；疼痛在完整子宫内膜脱落后减轻，但经后仍有隐痛。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望面色**：面色是否萎黄、苍白，有无光泽。
    - **望经血**：经血颜色（色淡或紫暗）、质地（有无血块或“烂肉样”组织物）、量多少。
- **触觉焦点**：
    - **按腹部**：腹痛时是喜按还是拒按？小腹有无凉感或包块？
    - **切肢体**：四肢末端是否温暖？有无麻木感？
- **医案特征提取**：腹痛拒按、喜温；经血夹有“烂肉样碎块”；面色黄；肢体麻木不温。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/紫暗）、舌体胖瘦、舌边有无瘀点瘀斑、苔色与厚薄。
    - **脉诊**：脉象的力度（有力/无力）、形态（弦、紧、细、滑）。
- **关联病史追问**：
    1.  “疼痛的具体位置和性质是怎样的？是胀痛、刺痛还是冷痛？”
    2.  “月经结束后，除了腹痛，还有没有其他不适？比如腰酸、乏力、头晕？”
    3.  “平时怕冷吗？精神、体力、睡眠、胃口怎么样？”
    4.  “3年前的人工流产术后，月经和身体感觉有什么明显变化吗？”
- **医案特征提取**：腰膝酸软、全身无力、神疲乏力（虚象）；舌淡苔薄、边有瘀斑点，脉弦紧细无力（虚实夹杂，瘀血内阻）。

**第四层：治疗经过与转归判断**
- **关键提问**：
    1.  “之前在其他地方诊断为什么病？做过哪些检查？（如：西医诊断“脱膜性痛经症”）”
    2.  “都尝试过哪些治疗？比如吃过什么中药或中成药？效果具体怎么样？（如：曾服桂枝茯苓丸效果不佳）”
    3.  “这次疼痛发作，和以往比有什么不同吗？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**胞宫（冲任）**，涉及**肝、肾、脾**三脏。病在血分，瘀阻胞脉。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：气血亏虚，肝肾不足（精血亏少）。
    - **实**：瘀血阻滞胞脉，兼有气滞（脉弦）、寒凝（喜温、肢冷）之象。
- **推理公式**：
    1.  **【虚证证据链】**：**人工流产史（损伤冲任气血）** + **经后隐痛、腰膝酸软、神疲乏力、全身无力、面色黄、舌淡、脉细无力** → 推导出 **气血亏虚、肝肾亏虚** 的病机基础。
    2.  **【实证证据链】**：**经期腹痛如绞、拒按** + **经血夹有烂肉样组织物（二诊反馈）** + **舌边有瘀斑点、脉弦紧** → 推导出 **瘀血阻滞胞脉，不通则痛** 的核心实证。
    3.  **【寒象证据链】**：**疼痛喜温、肢体不温** → 提示兼有 **寒凝** 因素，加重血瘀。
    4.  **【综合辨证】**：将以上虚、实、寒的证据链合并，得出最终结论：**辨证为气血亏虚、肝肾亏虚为本，瘀阻胞脉为标，虚实夹杂**。其“脱膜性痛经”的病理过程，中医解释为：流产后精血亏虚，胞宫失养，内膜（胞膜）附丽不固，脱落不畅，瘀阻脉道，故发为剧痛。
- **鉴别要点**：
    - **与单纯气滞血瘀型痛经鉴别**：单纯气滞血瘀者，体质相对不虚，疼痛以胀痛、刺痛为主，经血紫暗有块，舌紫暗或有瘀点，但**少有明显的神疲乏力、腰膝酸软、脉细无力等虚损表现**。本案患者虚象显著，故单纯活血化瘀（如用桂枝茯苓丸）效果不佳。
    - **与寒凝血瘀型痛经鉴别**：两者均有疼痛喜温、肢冷、血瘀表现。但**寒凝血瘀者以实寒为主**，疼痛剧烈，得热痛减明显，常伴月经后期、量少色暗，**虚象（如长期乏力、腰酸）不突出**。本案虚证是长期、根本的病因，寒象是伴随或加重的因素。
    - **治疗思路提示**：本案需 **“攻补兼施”** ，活血化瘀需配合大补气血、滋养肝肾，即“如欲通之，必先充之”，使气血充盈以推动血行，而非一味猛攻，否则易伤正气。
