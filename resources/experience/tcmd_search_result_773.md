### 一、 模拟问诊路径（针对胸痹心痛/冠心病心绞痛场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您心口（心前区）不舒服具体是怎么个感觉？是闷、是痛，还是两者都有？这种情况持续多久了？是持续性的还是一阵一阵的？”
- **医案特征提取**：病程2年余，反复发作，时作时止。**关键加重因素**：活动（劳累）后、进餐（饱食）后。

**第二层：局部体征细查（问诊/切诊导向）**
- **症状性质追问**：“疼痛是针刺样、压榨样还是闷胀感？具体在哪个位置？会不会向别处放射或牵连？”（重点探查疼痛性质与范围）
- **关联症状深挖**：“除了胸口不舒服，吃饭后胃部或腹部有没有胀、闷、痛的感觉？有没有恶心、反酸、食欲不振？”（重点探查脾胃症状）
- **医案特征提取**：心前区闷痛；饱餐后前胸、后背连及胃脘部胀闷疼痛，伴恶心、纳呆。提示**心胃（脾）同病**的典型特征。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身状态评估**：“平时感觉气够不够用？心慌吗？体力如何？怕冷还是怕热？大便情况怎么样？是干是稀？”
- **必查舌脉**：**舌象**（色、形、苔色、苔质）、**脉象**（部位、速率、力度、形态）。本案关键：舌淡红，苔白腻（痰湿之象）；脉沉缓而涩（沉主里，缓主湿，涩主血瘀）。
- **关联病史追问**：“有没有高血压、糖尿病、高血脂的病史？有多久了？平时怎么控制的？”（本案已提示糖尿病、高血压病史，需确认控制情况及年限）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个情况看过医生吗？做过哪些检查（如心电图）？用过什么药（西药或中药）？效果怎么样？”
- **医案特征提取**：心电图示T波异常改变，支持冠心病诊断。既往治疗史未详述，但病程长，提示病情迁延。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症所在）、**脾（胃）**（伴随症及病机根本）。涉及**手少阴心经**与**足太阴脾经**（“属脾络胃”“注心中”）。
- **核心病性**：**本虚标实**。
    - **本虚**：**脾胃气虚**（纳呆、便溏、年老、活动后加重）。
    - **标实**：**痰浊**（苔白腻、脉缓、恶心、饱食加重）、**血瘀**（心痛时作、脉涩）。
- **推理公式**：
    1.  **[主症：心前区闷痛、心悸、气短]** + **[加重因素：活动、饱食]** + **[伴随症：纳呆、便溏、胃脘胀闷]** → 推导病位涉及**心与脾胃**，病性属**气虚推动无力，气机郁滞**。
    2.  **[舌象：苔白腻]** + **[脉象：缓]** + **[症状：恶心、饱食胀闷]** → 佐证**脾虚生湿，湿聚成痰**（痰浊内阻）。
    3.  **[脉象：涩]** + **[症状：心痛时作]** → 佐证**心脉痹阻，血行不畅**（血瘀）。
    4.  综合以上：**脾胃气虚（本）** → 运化失司 → **生痰** + **血行无力致瘀** → **痰瘀互结，阻滞心脉（标）** → 发为**胸痹心痛**。
- **鉴别要点**：
    - **与单纯心脉瘀阻鉴别**：单纯血瘀证常以刺痛、固定不移、舌紫暗瘀斑、脉涩为主，**脾胃症状（纳呆、便溏、餐后胀闷）不显**。本案兼有明显脾虚痰湿证候。
    - **与单纯痰浊闭阻鉴别**：单纯痰浊证以胸闷如窒、苔腻脉滑为主，**气虚（气短、乏力、活动加重）及血瘀（脉涩、痛如针刺）征象不突出**。本案为气虚生痰，兼有血瘀。
    - **与寒凝心脉鉴别**：寒凝证疼痛遇寒加重、得温痛减，伴形寒肢冷，**苔白滑，脉沉紧**。本案苔白腻而非滑，脉沉缓涩而非紧，且无显著寒象。
