### 一、 模拟问诊路径（针对月经不调、带下病场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“您这次主要因为什么问题来看病？月经和平时有什么不一样？这种情况有多久了？”
- 医案特征提取：主诉为“月经不调”与“带下异常”。需明确病程长短、月经周期与经量变化的规律性（如是否持续数月）、症状是否在经期前后加重。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点（望诊）**：
    - **望经带**：经血颜色（淡/红/暗）、质地（稀薄/粘稠/血块）、量（多/少/适中）。带下颜色（白/黄/赤）、质地（稀/稠）、量（多/少）。
    - **望形体与局部**：面色是否萎黄或晄白？眼睑或面部有无浮肿？精神面貌（倦怠/有神）。
- **触觉焦点（切诊）**：
    - **脉诊**：脉象的力度、频率、形态（虚、迟是关键）。
    - **医案特征提取**：经色淡、质稀；带下色白、质稀；经期眼睑浮肿；神倦嗜卧。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - 舌质（淡/红/紫暗）、舌体（胖大/瘦薄/嫩）、舌苔（薄白/厚腻/黄）。
    - 脉象（沉/浮、迟/数、虚/实、细/滑）。
- **关联病史与全身症状追问**：
    - 消化系统：食欲如何？大便性状（溏泄/干结）？腹部有无冷感或胀满？
    - 精神与体力：是否容易疲劳、怕冷？四肢是否温暖？腰膝有无酸软或冷痛？
    - 睡眠与精力：是否嗜睡、精神不振？
    - 医案特征提取：神倦嗜卧、四肢乏力、纳差、便溏。

**第四层：治疗经过与转归判断**
- 关键提问：“之前是否为此看过医生或服用过药物（特别是寒凉或滋补药）？效果如何？”

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**脾、肾**。脾主运化、统血；肾主生殖、司二便。病位涉及太阴脾经与少阴肾经。
- **核心病性**：**虚、寒**。以**阳虚**为核心，兼有**气虚**与**水湿内停**。气血生化不足，温煦失职。
- **推理公式**：
    - **主症推导**：`[经期紊乱、色淡质稀]` + `[带下量多、色白质稀]` → 提示**气血亏虚、阳虚水湿不化**。
    - **全身佐证**：`[神倦嗜卧、四肢乏力]` → **气虚失养**；`[纳差、便溏]` → **脾虚失运**。
    - **舌脉定证**：`[舌质淡嫩、苔薄白]` → **阳虚气血不荣**；`[脉虚迟]` → **阳虚鼓动无力**。
    - **综合辨证**：`[主症+全身症状]` + `[舌淡嫩]` + `[脉虚迟]` → **辨证结论：脾肾阳虚证**。
- **鉴别要点**：
    1.  **与单纯脾气虚证鉴别**：单纯脾气虚可见乏力、纳差、便溏、舌淡，但**肾阳虚**的典型表现（如腰膝冷痛、畏寒肢冷、经色淡质稀如水、脉迟）不明显。本案脉“迟”及经带“质稀”是鉴别关键。
    2.  **与寒湿困脾证鉴别**：两者均有纳差、便溏、苔白、带下。但**寒湿困脾**以“实”为主，多见苔白腻、脉濡缓、肢体困重明显，而**脾肾阳虚**以“虚”为主，必有神疲、畏寒、舌淡嫩、脉虚等虚象。
    3.  **与肾阴阳两虚证鉴别**：肾阴阳两虚可见月经紊乱，但常兼有潮热、盗汗、口干等虚热象（阴虚表现），脉象多为细数。本案一派虚寒，无热象，可资鉴别。
