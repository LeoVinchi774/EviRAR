### 一、 模拟问诊路径（针对慢性心力衰竭/心水证场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您现在最不舒服的是什么？这种情况有多久了？”（针对主诉）、“以前有过心脏病、中风这类问题吗？确诊多久了？”（针对既往史）
- **医案特征提取**：患者主诉为“心悸、胸闷、乏力、下肢浮肿”，病程长达10年以上（慢性心力衰竭病史10年余），且为老年女性（70岁），有“中风”病史6年余。提示问诊需重点锁定“心”与“血”相关的慢性、进行性疾病史。

**第二层：核心症状细查（望诊/问诊导向）**
- **视觉焦点**：观察患者精神、面色、口唇颜色（是否萎黄、暗滞），重点观察下肢浮肿的部位（踝部、胫前）、程度（按之凹陷与否）、颜色（是否光亮或暗沉）。
- **触觉焦点**：触诊下肢皮肤温度（是否偏凉），按压浮肿处观察凹陷恢复速度（气虚、阳虚者恢复慢）。
- **医案特征提取**：患者表现为“下肢轻度浮肿”，结合年龄与病史，应重点评估水肿的“气虚水停”特征（如凹陷性、晨轻暮重），而非“湿热”特征（红肿热痛）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质**（颜色、胖瘦、有无瘀点瘀斑、齿痕）、**舌苔**（厚薄、颜色、润燥）、**脉象**（力度、粗细、节律）。医案中已明确：舌质暗（主瘀），边有齿痕（主气虚/脾虚湿盛），苔薄白（无热象），脉弦细（主气血不足兼有气机不畅）。
- **关联病史追问**：“除了心慌胸闷，平时体力怎么样？容易累吗？”（探气虚）、“大小便情况如何？大便干不干，几天一次？”（探津液与气机，医案中“大便难解”为重要佐证）、“晚上睡觉怎么样？能平躺吗？会不会憋醒？”（探心功能不全程度）、“怕冷还是怕热？手脚凉不凉？”（探阳气盛衰）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个病看过医生吗？用过什么药（中药或西药）？效果怎么样？”（了解既往治疗反应及病情稳定性）、“这次是什么原因让您觉得加重了或者来看病？”（寻找诱因，如劳累、感染、情绪波动等）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症心悸、胸闷）、**脾**（兼症乏力、大便难、舌有齿痕）、**络脉/血分**（久病、舌暗）。
- **核心病性**：**本虚标实**。**本虚**以**气虚**为核心（乏力、舌有齿痕），可兼血虚（年高、久病）；**标实**为**血瘀**（舌质暗、久病入络）与**水停**（下肢浮肿，因气虚推动无力所致）。
- **推理公式**：
    - **[主症：心悸、胸闷、乏力]** + **[体征：下肢浮肿、大便难解]** + **[舌脉：舌暗有齿痕、苔薄白、脉弦细]** + **[病史：老年、久病（心衰、中风）]** → **辨证结论：心衰（气虚血瘀，兼水停肠燥）**。
    - **推导链**：老年久病 → 耗伤气血 → **气虚**（乏力、舌有齿痕、脉细）→ 心气亏虚，心失所养 → 心悸、胸闷；气虚运血无力 → **血瘀**（舌暗）；气虚水液不运 → **水停**（下肢浮肿）；气虚大肠传导无力 → **肠燥便秘**（大便难解）。脉弦提示气机略有郁滞，但苔薄白无热象，故整体证候属虚、属瘀，无明显热象或痰象。
- **鉴别要点**：
    1.  **与“阳虚水泛”证鉴别**：两者均有水肿、心悸。**关键鉴别点**在于寒象是否显著。本证以“气虚”为主（乏力、舌淡暗有齿痕），寒象不显（苔白但不滑，未提及畏寒肢冷）。若见畏寒肢冷、水肿甚、舌淡胖苔水滑、脉沉迟，则偏向阳虚。
    2.  **与“痰瘀互阻”证鉴别**：两者均有胸闷、舌暗。**关键鉴别点**在于痰象。本证舌苔**薄白**，未提及痰多、体胖、苔腻等痰湿内蕴之象。若见苔腻、胸闷如窒、体胖，则需考虑痰瘀互阻。
    3.  **与“单纯阴虚血瘀”证鉴别**：两者均有瘀象（舌暗）和便秘。**关键鉴别点**在于津亏与虚热之象。本证便秘源于“气虚推动无力”，而非“津亏肠燥”（无口干、舌红少苔、脉细数等阴虚内热表现）。
