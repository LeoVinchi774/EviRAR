### 一、 模拟问诊路径（针对肾积水/肾结石伴湿热蕴结、肝郁脾虚场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“腰部感觉怎么样？是胀痛还是刺痛？持续多久了？小便情况如何？”
- **医案特征提取**：病程6个月，反复发作，腰部胀痛为主，伴有尿频、尿急、尿痛。提示病程较长，病情反复，病位在肾与膀胱。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望小便**：颜色（是否黄赤）、量（是否短少）、有无浑浊或沉淀物。
    - **望腹部**：有无胀满、形态。
- **触觉焦点**：
    - **切诊（按诊）**：腰部有无叩击痛、腹部有无胀满、压痛（尤其是胁肋部）。
- **医案特征提取**：小便色黄、量少；腰部胀痛、腰酸、腹胀；胸闷胁痛。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（红/淡），舌苔颜色与质地（黄腻/白腻/薄）。
    - **脉诊**：脉象（沉弦/滑数/细弱）。
- **关联病史追问**：
    1.  **精神情绪**：“最近心情怎么样？有没有感觉烦闷、爱叹气？”
    2.  **消化功能**：“胃口怎么样？饭后会不会腹胀、嗳气？”
    3.  **大便情况**：“大便干不干？几天一次？”
    4.  **体力状态**：“平时感觉累不累？有没有力气？”
    5.  **既往治疗**：“之前用过什么药？是输液还是口服？效果怎么样？”
- **医案特征提取**：神疲无力、食欲差、嗳气、大便秘结、胸闷胁痛、舌红苔黄腻、脉沉弦。提示存在肝郁、脾虚、湿热、阴亏等多重病机。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次为什么来我们这里看？之前在其他地方治疗过吗？效果具体怎么样？”
- **医案特征提取**：经西药输液治疗症状有所缓解但反复，腰部胀痛、小便拘急等症状未除，提示常规抗感染或对症治疗未能解决根本病机，需从中医整体辨证入手。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肾、肝、脾、膀胱**。病本在肝肾阴亏、肝郁脾虚，病标在湿热蕴结下焦（肾与膀胱）。
- **核心病性**：**本虚标实，虚实夹杂**。虚在肝肾阴虚、脾气不足；实在肝郁化火、湿热蕴结、气机阻滞。
- **推理公式**：
    1.  **[主症：腰部胀痛、小便频急涩痛色黄] + [舌脉：舌红苔黄腻] → 辨证结论：湿热蕴结下焦（膀胱气化不利，结石形成基础）。**
    2.  **[伴随症状：胸闷胁痛、嗳气] + [脉象：沉弦] → 辨证结论：肝气郁结，气机不畅。**
    3.  **[伴随症状：神疲无力、食欲差] + [病机推演：肝郁横犯脾胃] → 辨证结论：脾胃虚弱，运化失职。**
    4.  **[患者年龄：60岁] + [病程：反复6个月] + [病机按语：久病伤阴] → 辨证结论：肝肾阴亏（为肝郁化火、湿热伤阴的内在基础）。**
    5.  **综合以上1-4点 → 最终辨证：肝肾阴亏，肝郁化火，脾胃虚弱，湿热蕴结下焦。**
- **鉴别要点**：
    - **单纯湿热下注证**：多见小便灼热刺痛、口苦、苔黄腻，但通常无明显的胁痛、嗳气、神疲等肝郁脾虚症状，脉多滑数而非沉弦。
    - **兼夹血瘀证**：若腰部刺痛固定不移、舌质紫暗或有瘀点、脉涩，则需考虑湿热夹瘀。本案以胀痛为主，舌红而非紫暗，故血瘀不显，核心在于气滞（肝郁）与湿阻。
    - **肾阳虚水泛证**：亦可出现腰酸、小便不利，但多伴畏寒肢冷、小便清长、舌淡苔白、脉沉弱，与本例的热象（尿黄、舌红、苔黄）截然不同。
