### 一、 模拟问诊路径（针对慢性咳喘急性加重/肺心病场景）
**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“这次喘不上气是什么时候开始的？和以前发作有什么不一样？”
- 医案特征提取：慢性支气管炎病史30余年，并发肺源性心脏病，本次加重一周。提示问诊需锁定“慢性病史”与“急性加重”的时间节点及诱因。

**第二层：局部体征细查（望诊/闻诊/切诊导向）**
- 视觉焦点：观察面色、唇色、呼吸状态（是否张口抬肩）、有无水肿（尤其下肢）。
- 听觉/触觉焦点：听咳声高低、痰鸣音、呼吸音（干湿啰音）；切诊下肢有无凹陷性水肿。
- 医案特征提取：面色紫暗、唇舌紫绀、大口喘气、咳声低微、喉中痰鸣、双下肢凹陷性水肿。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：舌质颜色（紫暗）、舌体形态（嫩）、舌苔（少苔）；脉象（虚、细、数）。
- 关联症状追问：
    1.  汗出情况：“身上出汗多吗？是活动后出还是不动也出？”（对应：身有虚汗）
    2.  痰液性质与咯出难易：“痰多吗？是什么颜色？容易咳出来吗？”（对应：喉中痰鸣，不易咯出）
    3.  津液与饮水：“嘴里干吗？想不想喝水？喜欢喝热的还是凉的？”（对应：口舌干燥，不欲饮水）
    4.  二便情况：“小便通利吗？大便干不干？”（对应：尿不畅，便先干后软）
    5.  全身状态：“感觉累吗？胃口怎么样？胸口或胃脘部舒服吗？”（对应：气短不足以息，胃脘不舒）

**第四层：治疗经过与转归判断**
- 关键提问：“这次加重后用过什么药或做过什么治疗？效果怎么样？”（用于评估病情严重程度及对治疗的反应，为后续方案调整提供依据）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、肾**，兼及脾（胃脘不舒、便软）。病在肺络，根在肾虚。
- **核心病性**：**本虚标实**。本虚为**元气大虚、气阴两伤**（虚）；标实为**痰浊阻肺、兼有血瘀**（实）。整体属**虚实夹杂，以虚为主**。
- **推理公式**：
    1.  **[主症：喘促、气短不足以息、咳声低微] + [病史：久病30余年] + [舌脉：脉虚细数]** → 推导出 **“元气大虚，肺肾两虚”**（肾不纳气）。
    2.  **[体征：身有虚汗、口舌干燥、不欲饮水、舌嫩少苔] + [脉象：细数]** → 推导出 **“气阴两伤”**（气虚不固则汗出，阴虚津亏则口干、舌少苔，不欲饮水提示非实热伤津）。
    3.  **[体征：喉中痰鸣、不易咯出、双肺干湿啰音] + [舌象：舌质紫暗]** → 推导出 **“痰浊阻肺，兼有血瘀”**（痰阻气道则痰鸣、啰音；久病入络，气虚血行不畅，故舌紫暗）。
    4.  **[体征：双下肢凹陷性水肿、尿不畅]** → 佐证 **“肾虚水泛，气化不利”**（肾主水，肾虚不能化气行水）。
- **鉴别要点**：
    1.  **区分单纯肺气虚喘与肾不纳气喘**：单纯肺气虚多见喘促短气、声低懒言、自汗，但无腰膝酸软、呼多吸少等肾虚根蒂不固之象。本例有久病史、脉虚细数，病位更深，涉及肾根。
    2.  **区分实热痰喘与虚证痰喘**：实热痰喘多见痰黄稠、口渴喜饮、舌红苔黄腻、脉滑数。本例痰不易咯出但未言黄稠，且口干燥不欲饮、舌嫩少苔、脉虚细数，属虚痰、燥痰，为气阴亏虚、痰浊内生之象。
    3.  **区分水肿的寒热属性**：阳虚水泛多见水肿按之如泥、畏寒肢冷、小便清长、舌淡胖苔白滑。本例水肿为凹陷性，但伴口干燥、舌少苔、脉数，提示水停与阴虚并存，病机复杂，属气阴两伤、水液代谢失常。
