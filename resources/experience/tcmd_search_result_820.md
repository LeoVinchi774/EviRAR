### 一、 模拟问诊路径（针对胸痹合并喘证/心肺同病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您现在最不舒服的是什么？是胸闷、胸痛，还是喘不上气？哪个最明显？”
- **医案特征提取**：患者主诉为“气喘明显”，但既往有“心梗”病史，提示“胸痹”为本，当前“喘证”为标。问诊需锁定“气喘”与“胸闷/胸痛”的**主次关系**和**诱发因素**（如“动则喘息气急”）。

**第二层：核心症状细查（问诊/望诊导向）**
- **症状特征追问**：
    - **气喘**：是持续性的还是阵发性的？是吸气困难还是呼气困难？**活动后（动则）** 是否明显加重？夜间能否平卧？有无夜间憋醒？
    - **胸闷/胸痛**：具体位置（胸膺、后背）？性质（憋闷、刺痛、隐痛）？发作频率和持续时间？与气喘、劳累、情绪有无关联？
    - **咳痰**：痰量多少？痰的**质地（粘稠/稀薄）**、颜色（白/黄）？是否容易咳出？
- **医案特征提取**：**动则喘息气急、咳痰质粘、胸部闷痛**是核心症状群，问诊需量化其程度和关联性。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌体颜色（**质紫**提示血瘀）、舌苔颜色与质地（**淡黄浊腻**提示痰湿/痰热内蕴）。
    - **脉象**：脉的力度（有力/无力）、形态（**细弦**提示气血不足兼有气滞或痛证）。
- **关联病史与全身状态追问**：
    - **既往史确认**：“您之前有冠心病、心梗、动脉硬化这些病史吗？具体是哪一年确诊或发作的？”（确认**心脉痹阻**的病理基础）
    - **全身状况**：体力如何？是否容易疲劳、出汗（宗气不足）？饮食、睡眠、大小便情况（医案中“食纳、二便均正常”提示脾胃功能尚可，病位主要在心肺）。
    - **下肢情况**：有无**下肢浮肿**？（此为心衰常见体征，虽初诊未提，但三诊出现，是问诊关键点，提示水饮凌心射肺的可能转归）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次气喘发作后，有没有看过医生或住过院？当时诊断是什么（心功能不全/心衰）？用过什么药（如利尿剂、强心药）？效果怎么样？”（医案提示“1998年1月因气喘再次入院”，且三诊有“停用利尿剂病情尚不稳定”的记录，问清治疗史对判断病情严重程度和稳定性至关重要）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主血脉，病位在心脉）、**肺**（主气司呼吸，病及肺气宣降）。病机涉及**胸中（宗气之所聚）**。
- **核心病性**：**本虚标实**。
    - **标实**：**痰浊、血瘀**闭阻心脉与胸阳。
    - **本虚**：**宗气不足**（心肺气虚）、**胸阳不振**。
- **推理公式**：
    - **【主症：动则喘息气急】** + **【兼症：胸部闷痛、咳痰质粘】** + **【舌脉：舌质紫，苔淡黄浊腻，脉细弦】** + **【病史：心梗、动脉硬化史】**
    - **→ 辨证结论**：**心肺同病，痰瘀闭阻，宗气不足，胸阳不振**。
    - **推导步骤**：
        1.  **心梗病史 + 胸部闷痛 + 舌质紫** → 核心病机为**心脉瘀阻**。
        2.  **咳痰质粘 + 苔浊腻** → 兼夹**痰浊**内蕴，痰瘀互结，加重痹阻。
        3.  **动则喘息气急 + 脉细** → 提示**气虚**（宗气不足），心肺功能减退，活动后气耗更甚。
        4.  **胸闷 + 脉弦** → 提示气机不畅，**胸阳不振**，阳气不得舒展。
        5.  综合以上，病位由心及肺，形成**心肺气虚（宗气不足）为本，痰瘀痹阻胸阳为标**的复杂证候。
- **鉴别要点**：
    - **与单纯肺系喘证鉴别**：单纯肺系喘证（如哮喘、慢阻肺）多以**肺气壅塞或肺肾两虚**为主，**胸痛、心梗病史、舌质紫**等心系症状体征不典型。本案关键在于**心系病史与体征（胸痛、舌紫）** 与喘证并存。
    - **与单纯胸痹（心血瘀阻）鉴别**：单纯胸痹以**心胸刺痛、固定不移**为主，**气喘、动则尤甚**的症状不突出。本案**气喘**是心肺同病的突出表现，提示病已及肺，影响气机。
    - **痰湿与痰热倾向**：苔色“淡黄”提示痰浊有化热趋势，但尚未成典型“黄腻”之热象，处于痰湿向痰热转化的过渡阶段，治疗需留意。
