### 一、 模拟问诊路径（针对胸痹心痛/冠心病伴失眠场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您胸闷、气喘（或心前区不舒服）有多久了？具体是怎么个不舒服法（是闷、是痛、还是堵得慌）？”
- **医案特征提取**：病程6月余，呈慢性过程。胸闷、气喘、心前区隐痛是核心心系症状，且与活动（如上楼）明确相关，活动后加剧。

**第二层：局部体征与核心兼症细查（望诊/问诊导向）**
- **视觉焦点**：观察患者**体形胖瘦**（本案为偏瘦）、**面色**（本案为萎黄）、**精神状态**（本案乏力）。
- **问诊焦点**：
    1.  **心系症状细节**：胸闷气喘是持续还是阵发？心前区疼痛的性质（刺痛、隐痛、闷痛）、频率、持续时间？有无放射痛？心悸是感觉心跳快、重，还是乱？
    2.  **睡眠情况**：入睡是否困难？是否易醒？醒后能否再入睡？一晚总共能睡几个小时？多梦吗？梦的内容是平和还是纷扰？
    3.  **二便情况**：大便几天一次？质地是干是稀？排便是否费力（需重点追问有无“努挣”感）？
- **医案特征提取**：体形偏瘦、面色萎黄、乏力；心前区**隐痛**；入睡困难、易醒、多梦、睡眠时间极短（1-2小时）；大便**3-4日一行、偏干**。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/红/紫暗）、舌体胖瘦、有无齿痕、苔色（白/黄）、苔质（薄/厚/腻/少）。
    - **脉诊**：脉位（浮/中/沉）、脉力（有力/无力）、脉形（细/弦/滑）、脉率（数/迟）。**注意左右手对比**（本案右脉稍弱）。
- **关联病史与体质追问**：
    1.  **基础病史**：是否有明确的冠心病、高血压病史？具体分级、用药情况如何？（本案已提供，问诊时需确认）
    2.  **全身伴随症状**：有无头晕、耳鸣（需问有无旋转感）？有无口干、口苦？饮水喜温还是喜凉？食欲如何？
    3.  **气血状态挖掘**：是否容易疲劳、气短？有无怕冷或怕热？四肢是否温暖？
- **医案特征提取**：舌质**淡暗**，苔**薄白**；脉**沉细偏弦，右脉稍弱**。伴随**耳鸣头晕、口干但不苦、不喜多饮及冷饮**。纳食尚可。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个病看过医生或吃过药吗？效果怎么样？这次来就诊，最希望解决哪个问题？（是胸闷、失眠，还是乏力？）”
- **医案特征提取**：本案为初诊，旨在建立基线。后续复诊信息显示，治疗后胸闷乏力、睡眠改善是首要转归，但可能出现新情况（如二诊下肢浮肿），需动态评估。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症胸闷、心痛、心悸）、**脾胃**（气血生化之源，兼见面黄、体瘦、乏力、便秘）。
- **核心病性**：**本虚为主**（气虚、血虚、阳虚），**标实不显**（无明显痰、瘀、热等实邪壅盛之象）。整体属**虚证、寒象不著**。
- **推理公式**：
    1.  **[体瘦、面萎黄、乏力、脉沉细] + [右脉稍弱] → 指向脾胃气虚，气血生化不足。**
    2.  **[脾胃气虚] + [清阳不升] → 可推导出头晕、耳鸣、胸闷气喘（宗气生成不足，胸阳不展）。**
    3.  **[气虚推动无力] + [血虚失濡] → 可解释便秘（非热结，乃虚秘）、心前区隐痛（不荣则痛）、舌质淡暗（气虚血行不畅之象）。**
    4.  **[气血两虚，心神失养] + [脉细] → 直接导致心悸、失眠多梦、易醒。**
    5.  **[舌淡苔白、不喜冷饮] → 提示无明显热象，或兼有轻微阳气不足。**
    - **综合推导**：**脾胃气虚（根本）→ 气血两虚，清阳不升 → 心失所养，胸阳不振 → 发为胸痹、心悸、失眠**。证属：**脾胃气虚，清阳不升，心失所养**。
- **鉴别要点**：
    1.  **与痰浊闭阻型胸痹鉴别**：后者多见体胖、苔腻、脉滑，胸闷如窒，或伴痰多，本案无此象。
    2.  **与心血瘀阻型胸痹鉴别**：后者心痛如刺，痛处固定，舌质紫暗或有瘀斑，脉涩，本案为隐痛、舌仅淡暗，瘀象不典型。
    3.  **与心肾阳虚型胸痹鉴别**：后者畏寒肢冷、腰膝酸软、小便清长、脉沉迟等阳虚之象显著，本案阳虚证据不足（仅脉沉、不喜冷饮）。
    4.  **与阴虚火旺型失眠鉴别**：后者多见心烦、口干咽燥、舌红少苔、脉细数，本案口干但不喜饮、舌淡，可排除。
