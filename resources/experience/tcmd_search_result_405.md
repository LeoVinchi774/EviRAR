### 一、 模拟问诊路径（针对肺心病急性加重/心水场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次是因为什么不舒服来的？咳嗽、咳痰、气喘、浮肿这些症状持续多久了？和以前发作时感觉一样吗？”
- **医案特征提取**：患者有长达24年的慢性支气管炎病史，2年肺心病史，本次因“受寒”急性加重20天。病程长，反复发作，冬重夏轻，逐年加重。本次为急性加重期，症状突出。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **全身望诊**：观察患者**体位**（能否平卧？医案中为“半卧位”）、**口唇与指甲颜色**（有无紫绀？）、**面部与球结膜**（有无水肿？）、**颈静脉**（有无怒张？）、**胸廓形态**（有无桶状胸？）、**双下肢**（浮肿程度、范围，医案为“+++”）。
    - **分泌物望诊**：观察痰的**量**（每日约多少毫升？）、**色**（白/黄？）、**质**（稀/稠？）。
- **触觉/听诊焦点**：
    - **切诊**：触摸**四肢温度**（是否欠温？）、按压**双下肢**（有无凹陷性水肿？）。
    - **听诊**：重点听诊**两肺呼吸音**（有无湿性啰音？程度如何？医案为“+++”）。
- **医案特征提取**：半卧位、口唇紫绀、球结膜水肿、颈静脉怒张、桶状胸、两肺广泛湿啰音、双下肢重度凹陷性水肿、痰多色白质稀、四肢欠温。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（暗红？）、有无瘀点瘀斑、舌苔颜色与质地（白腻而厚？）。
    - **脉诊**：脉象形态（弦滑？）、脉力（重按是否无力？）。
- **关联症状追问**：
    - **寒热**：“怕冷吗？哪个部位特别怕冷？”（医案中“背部怯寒特甚”）。
    - **心肺症状**：“胸闷、心慌（心悸）得厉害吗？活动后是不是更重？”（医案中“气喘，动则尤甚，胸闷，心悸”）。
    - **二便与消化**：“胃口怎么样？嘴里感觉苦或者黏吗？大便干不干？小便量多不多？”（医案中“纳少，口苦，口黏，大便时结，小便量少”）。
- **医案特征提取**：背部怯寒、动则气喘、心悸、纳少口苦口黏、二便异常；舌暗红有瘀斑、苔白腻厚、脉弦滑重按无力。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发病后，在外面用过什么药（中药或西药）？效果怎么样？为什么决定来住院治疗？”（医案提示“经西医治疗未效”）。
- **医案特征提取**：本次因受寒诱发，院外治疗无效，病情危重（呼吸衰竭、心衰Ⅲ度）故入院。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、心、脾、肾**，以心肺为标，脾肾阳虚为本。病及于血络（瘀）与水道（水）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**气阳虚衰**（心、肺、脾、肾阳气亏虚）。
    - **标实**：**痰、瘀、水（饮）内停**，三者互结，壅塞肺气，上凌心肺。
- **推理公式**：
    1.  **[长期咳痰喘病史] + [动则气喘、咯痰无力、脉重按无力] → 肺肾气虚，摄纳无权。**
    2.  **[背部怯寒特甚、四肢欠温] + [舌苔白腻] → 阳气虚衰，失于温煦。**
    3.  **[痰多色白质稀] + [舌苔白腻而厚] + [两肺湿啰音] → 脾失健运，痰湿内伏于肺。**
    4.  **[口唇紫绀、舌质暗红有瘀斑] + [颈静脉怒张] → 心脉瘀阻，血行不畅。**
    5.  **[心悸、不能平卧、双下肢浮肿（+++）、小便量少] + [球结膜水肿] → 阳虚水停，水气凌心射肺。**
    6.  **[口苦、口黏、大便时结] + [脉弦滑] → 标实壅盛，郁而化热（或为湿郁、痰瘀化热之轻兆），腑气不畅。**
- **综合辨证结论**：**气阳虚衰（本），水气不化，痰瘀伏肺（标），且瘀象重于痰象**。证属“心水”、“肺胀”之危重阶段。
- **鉴别要点**：
    - **与单纯痰浊阻肺鉴别**：单纯痰浊阻肺虽可见咳痰、胸闷，但通常无如此严重的**紫绀、瘀斑、重度水肿及阳虚畏寒**之象。本案**痰、瘀、水、虚**四者并存，且阳虚为本。
    - **与阴虚水泛鉴别**：阴虚水泛亦可出现水肿、咳喘，但必有**舌红少苔、口干不欲饮、五心烦热**等阴虚内热之象。本案舌苔白腻厚、背部怯寒，一派**阳虚阴盛**之候，截然不同。
    - **提示模型**：在肺心病急性加重期，**阳虚、血瘀、水停**是核心病理三角。问诊和辨证时，必须同时评估**阳虚的程度**（畏寒部位、四肢温凉）、**血瘀的指征**（紫绀、舌脉）以及**水停的范围**（水肿部位、肺部啰音），并判断何者为主（本案为“瘀重于痰”）。
