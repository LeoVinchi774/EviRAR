### 一、 模拟问诊路径（针对带下赤白/慢性带下病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您白带异常的情况有多久了？具体是什么颜色、质地和气味？”
- **医案特征提取**：病程3年，近9个月加重，呈“绵绵不断”的慢性、迁延性特点。带下“赤白相杂”（白带中带血）是核心特征。

**第二层：局部体征细查（望诊/闻诊导向）**
- **视觉与性状焦点**：
    - **颜色**：是纯白色、黄色，还是白中带血（赤白相杂）？血色是鲜红、淡红还是暗红？（医案：状若桃红）
    - **质地**：是清稀如水，还是粘稠如涕？（医案：质稠粘为主）
    - **气味**：有无特殊气味？是腥味还是臭味？（医案：味微腥臭→腥臭）
- **伴随局部症状追问**：
    - **疼痛**：小腹或腰骶部有无不适？是隐痛、坠痛还是刺痛？（医案：小腹绵绵作痛，腰骶酸痛）
    - **瘙痒**：外阴有无瘙痒感？（医案：阴痒）
- **医案特征提取**：带下“赤白相杂、质稠粘、味腥臭”，伴“小腹绵绵痛、腰骶酸、阴痒”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（红/淡）？舌苔厚薄与颜色（白/黄/腻）？（医案：舌质红苔白薄）
    - **脉象**：脉的力度、频率、部位（沉/浮、细/滑、数/迟）？（医案：脉沉细）
- **全身症状与体质追问**：
    - **热象**：有无手足心发热、午后潮热、心烦？（医案：手足心灼热，梦多烦躁）
    - **虚象**：有无疲劳乏力、头晕、精神不振？（医案：头晕倦怠）
    - **月经情况**：月经周期、经量、经色、有无血块？与带下变化有无关联？（医案：月经先后无定期，量少挟血块）
    - **治疗史**：既往接受过何种治疗（中西药、手术）？效果如何？（医案：迭经中西医治疗效果欠佳）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过哪些检查（如妇科检查、B超）？结果如何？”、“经过之前的治疗，症状是完全没有改善，还是好转后又复发？”
- **医案特征提取**：妇检提示“宫颈中度糜烂”，B超排除了子宫附件器质性病变。治疗史提示病情顽固，常规疗效不佳。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**任脉、带脉、胞宫（子宫）**。病本在**脾、肾**（气阴亏虚），标在**虚火、血络**。
- **核心病性**：**本虚标实**。**虚**在气阴两虚（久带耗损）；**实**在虚火内扰、热灼血络。总体属**虚热证**。
- **推理公式**：
    1.  **长期带下 + 倦怠头晕 + 脉沉细** → 提示**气虚不固，久病耗伤**。
    2.  **带下赤白（夹血）+ 手足心灼热 + 梦多烦躁 + 舌红** → 提示**阴虚生内热，虚火扰动，灼伤阴络（血络）**。
    3.  **小腹隐痛、腰骶酸痛** → 病位在胞宫、任带，气虚失养，虚火煎灼所致。
    4.  **综合推导**：`[病程长、带下不止（气虚不固）]` + `[带中夹血、五心烦热、舌红（阴虚火旺，灼伤血络）]` + `[舌苔薄白、脉沉细（热非实火，虚象明显）]` → **辨证结论：气阴两虚，虚火灼络，任带不固**。
- **鉴别要点**：
    - **与单纯湿热下注鉴别**：单纯湿热下注带下多色黄、质稠、气臭，伴口苦、苔黄腻、脉滑数等**实热**之象。本案虽有“稠粘腥臭”，但病程长，伴明显倦怠、脉沉细，且舌红而苔**白薄**非黄腻，热象为“手足心灼热”的虚热，非全身实热。
    - **与脾肾阳虚带下鉴别**：脾肾阳虚带下多色白、质清稀、量多如注，伴畏寒肢冷、腰膝冷痛、舌淡苔白、脉沉迟等**虚寒**之象。本案带下虽久，但质稠、色赤白、有热象，截然不同。
    - **与瘀血阻滞鉴别**：瘀血所致带下亦可夹血，但多伴小腹刺痛拒按、血块紫暗、舌质紫暗有瘀斑、脉涩等**血瘀**特征。本案为“绵绵作痛”，舌红而非紫暗，血因热迫而非瘀阻，故非主证。
