### 一、 模拟问诊路径（针对黄疸持续不退/术后黄疸复发场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：请详细描述您黄疸（皮肤、眼睛发黄）的情况，持续多久了？是持续不退还是反复发作？最近是加重了还是减轻了？
- **医案特征提取**：病程长达1年3个月，进行性加重。有胆囊炎及胆囊切除手术史，术后出现黄疸并反复发作。拒绝手术治疗。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望面色**：面色是鲜黄、暗黄还是黧黑（如烟熏）？面部有无痤疮、色素沉着？
    - **望目睛**：巩膜黄染的颜色是鲜明如橘子色，还是深黄、青黄或晦暗？
    - **望皮肤**：全身皮肤黄染的程度与色泽，有无光泽？
    - **望舌象**：舌质颜色（淡、红、紫、黯），舌苔（色、厚薄、润燥）。
- **触觉/切诊焦点**：
    - **切脉**：脉象的力度（有力/无力）、脉位（浮/沉）、脉率（数/迟）、脉形（细/滑/涩）。
    - **按诊**：右胁下（肝区）有无压痛、叩击痛？腹部有无胀满、压痛？有无肝脾肿大？
- **医案特征提取**：颜面黧黑，目深黄，面部痤疮，舌质略紫黯。右胁痛。脉沉细、左脉带涩。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质紫黯提示瘀血；脉沉细涩提示病在里、气血亏虚或运行不畅。
- **关联症状追问**：
    1.  **寒热**：有无恶寒、发热或自觉心烦、手足心热？
    2.  **二便**：小便颜色（清、黄、赤）、量多少、有无灼热感？大便次数、性状（干、稀、溏薄）、颜色？
    3.  **饮食口味**：食欲如何？有无口干、口苦？是否想喝水？
    4.  **出血倾向**：有无鼻衄、齿衄、皮下瘀斑？女性患者需问月经周期、经量、经色、有无血块。
    5.  **精神与疼痛**：有无胸闷、脘腹胀满？疼痛性质（胀痛、刺痛、隐痛）及固定部位？
- **医案特征提取**：尿黄赤灼热，口干苦但不欲饮；鼻衄；月经延后、色黑；胸闷脘胀；大便溏薄。

**第四层：治疗经过与转归判断**
- **关键提问**：之前用过哪些治疗方法（中药、西药、针灸等）？效果如何？对哪些治疗有反应或无反应？
- **医案特征提取**：曾用清热利湿（茵陈蒿汤类）、疏肝和胃、针刺、外治及多种西药均无效，黄疸持续加深。既往使用活血药时黄疸曾略减。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝**（主藏血、主疏泄）、**脾**（主运化湿浊）、**血分**。
- **核心病性**：**实证**（瘀血、湿热内郁）为本，**兼有虚象**（病久气血耗伤）。**热**重于寒（无恶寒肢冷）。
- **推理公式**：
    1.  **[主症：持续加深的黄疸] + [望诊：面黧黑、目深黄、舌紫黯] + [问诊：月经色黑、鼻衄、胁久痛] → 核心病机：血郁（瘀）于肝**。
    2.  **[问诊：尿黄赤灼热、口干苦] + [无恶寒肢冷] → 兼夹病邪：湿热内蕴（偏于热）**。
    3.  **[切诊：脉沉细涩] + [病程：久病] + [治疗史：多种攻伐无效] → 病机属性：病久入络，气血运行不畅，兼有正气亏虚之象**。
    4.  **综合**：**血郁于肝（核心）** + **湿热郁脾（兼夹）** + **病久兼虚（背景）** → **辨证结论：黄疸（瘀血发黄为主，湿热为次，兼有虚象）**。
- **鉴别要点**：
    - **与单纯“湿热阳黄”鉴别**：单纯湿热阳黄常表现为身目鲜黄如橘子色，小便黄赤，发热口渴，舌红苔黄腻，脉滑数。本案虽有尿赤、口干苦等热象，但核心特征是**面黑、舌紫、经黑、脉涩**等一派瘀血征象，且用清热利湿剂无效，故非单纯湿热。
    - **与“寒湿阴黄”鉴别**：寒湿阴黄常表现为身目晦暗如烟熏，畏寒肢冷，口淡不渴，舌淡苔白腻，脉沉迟。本案虽有面黧黑、脉沉，但伴有尿赤灼热、口干苦等热象，无恶寒肢冷，故非寒湿。
    - **提示模型**：当黄疸病程迁延，常规清热利湿法无效，且出现**面色晦黯、固定痛处、出血、舌质紫黯、月经色黑、脉涩**等征象时，必须高度考虑**瘀血发黄**这一病机，治疗重点应从“利湿”转向“活血”。
