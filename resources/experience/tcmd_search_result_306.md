### 一、 模拟问诊路径（针对非哺乳期乳溢/乳泣场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请问您的主要不适是什么？是乳房有液体自己流出来吗？这种情况持续多久了？是持续性的还是间断性的？量多吗？什么颜色？”
- **医案特征提取**：主诉为“非哺乳期乳汁自溢”。问诊需明确病程长短、溢乳的持续性（持续/间断）、溢乳量（多/少）、颜色（清稀/稠厚/带血丝）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察乳房外观有无红肿、变形，乳头有无皲裂、内陷，溢液的颜色、质地（清稀如水/乳白/黄稠/带血）。
- **触觉焦点**：触诊乳房有无肿块、结节、压痛，肿块质地（软/硬/韧），范围及活动度。
- **医案特征提取**：医案未提供具体局部体征，但临床需重点排查以排除“其它乳腺疾病”（如乳腺增生、肿瘤等），这是鉴别诊断的关键。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡/红/暗）、舌苔（薄白/白腻/黄腻/少苔）、脉象（细弱/弦/弦数/细数）。
- **关联病史追问**：
    1.  **情志与月经**：“最近情绪怎么样？容易生气、郁闷吗？月经情况如何？周期准不准？经量多还是少？颜色质地怎么样？”（对应医案中“情志抑郁、月经量少、月经失调”）
    2.  **消化与精力**：“平时胃口怎么样？容易疲劳吗？怕冷还是怕热？”（对应脾胃气虚、肝郁克脾的可能）
    3.  **婚育与哺乳史**：“结婚了吗？生过孩子吗？最近一次哺乳是什么时候？”（对应医案中患者群体特征，未婚者需考虑生理性因素或特殊病因）

**第四层：治疗经过与转归判断**
- **关键提问**：“出现这个情况后，有没有去医院检查过？比如做过乳腺B超或者查过泌乳素吗？之前用过什么药（中药或西药）治疗吗？效果怎么样？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾（胃）、肾、冲任二脉**。乳房属胃经，乳头属肝经，乳汁为气血所化，与冲任关系密切。
- **核心病性**：**虚（气虚、阴虚）、实（气滞、郁热）、虚实夹杂**。病机涉及气血不固、气机郁滞、热迫血行、精血亏虚。
- **推理公式**：
    1.  **[主症：非哺乳期溢乳，质清稀] + [伴随：神疲乏力，纳差便溏] + [舌脉：舌淡苔白，脉细弱] → 辨证结论：脾胃气虚证（气不摄血/摄乳）**
    2.  **[主症：非哺乳期溢乳，情志波动后加重] + [伴随：胸胁胀闷，善太息，月经不调] + [舌脉：舌淡红苔薄白，脉弦] → 辨证结论：肝郁气滞证（肝失疏泄，气血逆乱）**
    3.  **[主症：非哺乳期溢乳，质可能较稠] + [伴随：烦躁易怒，口苦咽干] + [舌脉：舌红苔黄，脉弦数] → 辨证结论：肝郁化热证（热迫胃络，气血妄行）**
    4.  **[主症：非哺乳期溢乳，量少质稀] + [伴随：腰膝酸软，头晕耳鸣，月经量少或后期] + [舌脉：舌红少苔，脉细数] → 辨证结论：肝肾阴虚证（精亏血少，冲任失调，气血逆乱）**

- **鉴别要点**：
    1.  **辨虚实**：**虚证**（脾胃气虚、肝肾阴虚）多伴全身乏力、腰膝酸软等虚象，溢乳质清稀；**实证**（肝郁气滞、肝郁化热）多与情志相关，伴胸胁胀痛、口苦等实象。
    2.  **辨寒热**：**肝郁化热证**有明确热象（口苦、舌红苔黄、脉数）；**肝郁气滞证**与**脾胃气虚证**多属气分病变，无明显寒热。
    3.  **核心病机区分**：**“气不摄”**（气虚不固）与**“热迫行”**（热迫妄行）是导致“血/乳”外溢的两种相反病机，前者为虚、为功能减退，后者为实、为功能亢进，舌脉与全身症状是鉴别关键。**“气机滞”**（肝郁气滞）是气血运行通道受阻而逆乱，**“精血亏”**（肝肾阴虚）是气血化生之源不足兼虚火扰动，二者一实一虚，均影响冲任。
