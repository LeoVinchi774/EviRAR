### 一、 模拟问诊路径（针对胃痞/慢性萎缩性胃炎场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：请描述一下您胃部最主要的不舒服是什么感觉？这种情况持续多久了？什么情况下会诱发或加重？
- **医案特征提取**：主诉为“反复胃脘胀闷”，病程长达2年，呈慢性、反复发作特点。诱发因素为“饮食不节”，提示问诊需重点围绕饮食史展开。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者面色、神态。重点进行舌诊，包括舌色（红/淡）、舌体（胖瘦）、舌下络脉（有无迂曲增粗）、苔色（黄/白）与苔质（厚薄、润燥）。
- **触觉焦点**：脉诊，重点体会脉象的弦、滑、细、沉等特征。腹部触诊，了解胃脘部有无压痛、喜按或拒按。
- **医案特征提取**：舌稍红、苔黄、舌下络脉迂曲增粗，脉弦滑。此为问诊中必须获取的关键体征。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌色（红/淡）、舌下络脉（有无瘀血征）、苔色（黄/白）、脉象（弦、滑、细）。
- **关联病史追问**：
    1.  **饮食与消化**：食欲如何（纳一般）？有无口干、口苦、反酸、嗳气？大便的性状、次数如何（二便尚调）？
    2.  **情志与睡眠**：平时情绪、性格如何？是否容易紧张、焦虑、多思（平素易紧张多思）？睡眠质量怎样（寐差）？
    3.  **既往诊疗**：之前做过哪些检查（如胃镜、病理）？结果如何？用过什么药？效果怎样？
    4.  **全身状况**：有无乏力、怕冷或怕热、手足心热等全身性症状？

**第四层：治疗经过与转归判断**
- **关键提问**：这次来就诊，是之前的治疗效果不理想，还是症状又反复了？您对目前的治疗有什么期望？

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：脾、胃、肝。病在脾胃，涉及肝气疏泄。
- **核心病性**：本虚标实，虚实夹杂。**本虚**为脾胃气虚；**标实**为气滞、郁热、血瘀。
- **推理公式**：
    - **[主症 胃脘胀闷反复2年] + [诱因 饮食不节、情志不畅] → 推导病机起点：饮食伤脾，肝郁乘脾，导致脾胃气机升降失常。**
    - **[伴随症 纳一般、口干] + [舌脉 舌稍红、苔黄、脉弦滑] → 佐证气机郁滞，日久化热。**
    - **[舌象特征 舌下络脉迂曲增粗] + [病程 2年反复] → 佐证久病入络，气血运行不畅，形成瘀血。**
    - **[微观证据 胃镜病理示重度萎缩伴肠化] → 从“微观辨证”角度印证“瘀阻脉络”的病机，并提示病情较重，属顽疾。**
    - **综合推导**：长期饮食情志损伤 → 脾胃气虚（本）+ 肝气郁滞（标） → 气滞生热、气虚血瘀（化热成瘀） → **辨证结论：胃痞（脾虚气滞、化热成瘀证）**。
- **鉴别要点**：
    1.  **单纯肝胃不和证 vs 本证**：单纯肝胃不和多以胃脘胀痛、痛连两胁、嗳气频繁为主，舌苔薄白，脉弦，无明显气虚（如纳差、乏力）及瘀热（如舌红苔黄、舌下络脉曲张）之象。本证兼有脾虚与瘀热。
    2.  **脾胃虚寒证 vs 本证**：脾胃虚寒证多见胃脘隐痛、喜温喜按、食少便溏、畏寒肢冷，舌淡苔白，脉沉迟。本证虽有脾虚，但热象（苔黄）和瘀象（舌下络脉曲张）明显，属寒热错杂、虚实夹杂。
    3.  **胃阴不足证 vs 本证**：胃阴不足证以胃脘隐痛、饥不欲食、口干舌燥、大便干结、舌红少苔、脉细数为主。本证口干但二便调，苔黄而非少苔，且以胀闷为主，兼有气滞血瘀，可资鉴别。
