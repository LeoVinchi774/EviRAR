### 一、 模拟问诊路径（针对复发性口腔溃疡/口疮场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您口腔里不舒服（溃疡/烂了）多久了？是反复发作吗？最近一次加重有多久了？”
- **医案特征提取**：病程长达“多年”，具有“反复发作”、“加重半年”的特征。需重点询问发作频率、每次持续时间、有无明确的诱发或缓解因素（如饮食、情绪、劳累、季节等）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：溃疡的**具体位置**（如本案“口腔上壁”）、**数量**（多发）、**形态**（大小、深浅、边缘是否整齐）、**颜色**（溃疡面及周围黏膜的颜色，如淡红、鲜红、暗红）、**分泌物**（有无假膜、脓液）。
- **触觉/感觉焦点**：询问患者**疼痛性质**（灼痛、刺痛、隐痛）、**疼痛程度**（是否影响进食、说话）。医案中虽未详述，但问诊时应主动探查。
- **医案特征提取**：本案关键信息为“口腔上壁多发溃疡”，提示病位在上，且为多发性。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：必须观察并记录**舌质颜色**（淡、红、绛、紫）、**舌体形态**（胖瘦、齿痕）、**苔色**（白、黄）、**苔质**（厚、薄、腻、燥、剥脱）。本案核心舌象为“舌淡红，苔白花剥腻”。
    - **脉象**：必须诊察脉位（浮、沉）、脉率（数、迟）、脉形（滑、涩、弦）、脉势（有力、无力）。本案核心脉象为“脉浮滑数”。
- **关联症状追问**：
    1.  **全身寒热**：明确询问“平时是怕冷多还是怕热多？或者两者都有？”（本案为“怕冷怕热”）。
    2.  **消化系统**：询问**食欲**、**食后腹胀**、**大便情况**（性状、频率，本案“大便正常”但需常规询问以排除他证）。
    3.  **精神体力**：询问是否**乏力**、**气短**、**精神不振**（脾虚常见表现）。
    4.  **治疗史**：详细询问既往**中西医治疗经过及具体效果**（本案“中西医治疗偶有症状缓解，但反复发作”，尤其需关注是否长期使用清热解毒类药物）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前用过哪些药（特别是清热解毒的喷剂、含片或汤药）？效果怎么样？是不是用药好一点，停药就犯或者更重？”（本案原文提及“使用清热解毒喷剂等后好转却愈演愈烈”，这是鉴别虚火与实火的关键信息）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、胃**。口为脾之窍，舌为心之苗，但本案以脾胃气虚为本。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾气亏虚、胃阴不足；**标实**为湿邪郁阻、阴火内生。病性上，**气虚**（脾虚）与**郁热**（阴火）并存，兼夹**湿邪**。
- **推理公式**：
    - **[主症：口腔溃疡反复多年]** → 提示病程长，非单纯外感实火，应考虑内伤或本虚。
    - **[体征：舌淡红，苔白花剥腻]** → `舌淡红`偏淡提示气血不足，属虚；`苔花剥`提示胃气阴不足；`苔白腻`提示有湿邪停滞。此舌象组合是“脾虚湿郁兼阴伤”的典型表现。
    - **[脉象：脉浮滑数]** → `浮`非表证，可因虚阳浮越或郁热外达；`滑`主湿、主痰；`数`主热。合参为“郁热夹湿”之象。
    - **[全身症状：怕冷怕热，大便正常]** → “怕冷怕热”是气虚卫外不固、虚热扰动的表现；“大便正常”排除了明显的实热结滞或脾虚泄泻，但湿邪尚轻。
    - **[治疗反应：清热解毒药效差或反复]** → 反向印证非单纯实热证，过用寒凉更伤脾胃阳气，致病情缠绵。
    - **综合推导**：`长期反复口疮` + `舌淡苔花剥（虚）` + `苔腻脉滑（湿）` + `脉数怕热（热）` + `寒凉药效不佳` → **辨证结论：脾虚湿郁阴火证**。病机链条为：**脾胃气虚（本）** → 运化失司，湿邪内生（标1） → 气机郁闭，郁而化热，此热为“阴火”（标2） → 虚火上炎，熏灼口舌，发为溃疡。
- **鉴别要点**：
    1.  **与单纯胃火炽盛证鉴别**：后者溃疡多红肿疼痛剧烈，伴口渴喜冷饮、口臭、便秘、舌红苔黄、脉洪数有力。本案舌偏淡、苔白、脉浮而非沉实、且寒凉药效差，可资鉴别。
    2.  **与心脾积热证鉴别**：后者常伴心烦、失眠、小便短赤，舌尖红赤明显。本案病机核心在脾虚湿郁，热为郁热（阴火），非心火亢盛。
    3.  **与阴虚火旺证鉴别**：后者以舌红少苔或无苔、脉细数为特征，全身可见五心烦热、盗汗等明显阴虚症状。本案虽有苔花剥（阴伤），但苔腻、脉滑，湿象显著，且舌质不红，故非单纯阴虚。
