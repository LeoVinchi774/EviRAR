### 一、 模拟问诊路径（针对肝郁脾虚型不寐场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？是入睡困难，还是睡后容易醒，或者两者都有？这种情况是什么时候开始的，和什么事情有关吗？”
- **医案特征提取**：病程起于“与人争吵后”，呈急性发作。核心症状为“入睡困难，寐后易醒”。需明确失眠的具体形式（入睡难、易醒、多梦、早醒）及与情志刺激（如争吵、压力、焦虑）的直接关联。

**第二层：症状体征细查（问诊/望诊导向）**
- **主症深挖**：
    - **失眠特点**：“入睡需要多长时间？”“一夜会醒几次？”“醒来后还能再睡着吗？”“睡眠质量如何，感觉解乏吗？”
    - **情志与伴随症**：“最近情绪怎么样？容易生气、烦躁还是郁闷？”“除了失眠，有没有头痛（部位、性质）、身上一阵阵发热出汗（潮热汗出）的情况？”“吃饭胃口怎么样（纳少）？有没有腹胀、大便不成形？”
- **医案特征提取**：情志不畅（急躁）为诱因，核心症状群为“失眠（入睡难、易醒）+ 头痛 + 潮热汗出 + 纳少”。

**第三层：体质与舌脉信息采集（全身与舌脉）**
- **体质与病史追问**：“您平时性格是比较急躁、容易着急上火吗？（平素性情急躁）”“以前有过类似的失眠或消化方面的问题吗？”
- **必查舌脉**：
    - **望舌**：舌质颜色（是否暗红、淡红）、舌苔（苔色白/黄、厚/薄、润/燥）。**医案提示**：舌暗苔白。
    - **切脉**：脉位（浮/沉）、脉力（有力/无力）、脉形（弦/细/滑）。**医案提示**：脉沉。

**第四层：治疗反应与鉴别**
- **关键提问**：“出现这个问题后，自己用过什么方法或药物吗？效果怎么样？”（用于评估病情顽固程度及排除不当用药史）
- **鉴别提示**：需通过问诊排除其他原因所致失眠，如询问“有无心悸心慌、口干口苦、腰膝酸软、畏寒肢冷等？”以鉴别心肾不交、心脾两虚、阴虚火旺等证型。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、心**。肝主疏泄，情志所伤，病位首在肝；肝郁乘脾，影响运化，病及于脾；肝郁化热扰心，心主神明，故病位亦在于心。
- **核心病性**：**本虚标实，虚实夹杂**。**实**为肝气郁结，久郁化热；**虚**为脾气虚弱，心神失养。总体属气机郁滞兼有化热及脾虚。
- **推理公式**：
    1.  **【主症】失眠（入睡难、易醒）** + **【诱因】情志刺激（争吵）** + **【体质】平素性情急躁** → 推导病机起点为 **“肝郁气滞，神魂不安”**。
    2.  **【兼症】头痛** + **【舌象】舌暗** → 支持肝郁气滞，进而导致 **“气滞血瘀，不通则痛”**。
    3.  **【兼症】纳少** → 结合肝郁病机，推导为 **“肝旺乘脾，脾失健运”**。
    4.  **【兼症】潮热汗出** → 在肝郁基础上，提示有郁而化热，热迫津泄，为 **“肝郁化热，迫津外泄”**。
    5.  **【脉象】脉沉** → 可主气郁（气机内郁不达），亦可见于脾虚（气血不足鼓动无力），结合全身症状，支持肝郁脾虚之证。
    6.  综合以上：**肝郁（气滞、化热）** + **脾虚（运化弱）** + **扰心（神不宁）** → 辨证结论 **“肝郁脾虚，心神不宁”**。
- **鉴别要点**：
    - **与单纯肝郁化火证鉴别**：单纯肝火盛者，多见口苦、目赤、便秘、尿黄、舌红苔黄、脉弦数，脾虚症状（纳少、乏力）不明显。本案有“纳少”、“苔白”、“脉沉”，提示脾虚并存，非纯实火。
    - **与心脾两虚证鉴别**：心脾两虚者，失眠多伴心悸、健忘、头晕、面色无华、乏力明显，常由思虑过度、劳伤心脾所致，**情志郁怒诱因不突出**，舌多淡，脉细弱。本案有明显情志诱因及“性情急躁”、“潮热”等肝郁化热之象，可资鉴别。
