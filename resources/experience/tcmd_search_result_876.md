### 一、 模拟问诊路径（针对中风早期/先兆场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“您这次主要是因为什么不舒服来就诊的？这种情况是第一次出现，还是反复发作？每次发作持续多长时间？”
- 医案特征提取：症状多为**短暂性、一过性**发作（如语言謇涩、肢体无力），此为中风先兆期的关键特征。需重点询问眩晕、头痛的**发作频率、持续时间**及与情绪、劳累的关系。

**第二层：局部体征细查（望诊/切诊导向）**
- 视觉焦点：观察**面色**（是否面红目赤）、**眼神**（是否胀或充血）。观察肢体活动，有无短暂性活动不利。
- 触觉焦点：此证型局部体征（如肢体）在间歇期可能不明显，发作期可检查肌力、肌张力。重点在于全身状态观察。
- 医案特征提取：**面赤目胀**是肝热上冲的重要望诊指征。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：
    - **舌诊**：重点观察**舌质颜色**（红或暗红）、**舌下络脉**（有无瘀斑、迂曲）。
    - **脉诊**：仔细体会脉象是**弦滑**（主肝热痰瘀）还是**细涩**（主阴血不足兼瘀）。
- 关联病史追问：
    1.  **情志与饮食**：“平时工作生活压力大吗？容易心烦、急躁或发怒吗？”（挖掘肝火素旺的体质基础）“平时饮食偏好如何？是否喜食油腻、辛辣、肥甘厚味？”（挖掘痰瘀内生的饮食因素）。
    2.  **二便情况**：“大便怎么样？是干结难解，还是感觉黏腻、排不干净？”（确认腑气不通或湿热内蕴）。
    3.  **既往病史**：“以前有过高血压、高血脂或头晕头痛的病史吗？”（关联现代医学风险因素）。

**第四层：治疗经过与转归判断**
- 关键提问：“出现这些症状后，有没有去医院做过检查（如CT、MRI）？结果如何？”“之前用过什么药吗？效果怎么样？”（旨在排除其他疾病，并评估病情的紧急程度与既往干预效果，强调“防微杜渐”的诊疗时机）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝**（主症与情志相关）、**脑络**（病发之所）、**血脉/经络**（瘀血阻滞之处）。
- **核心病性**：**实证**。**热**（肝热）、**瘀**（血瘀），常兼夹**痰、滞**（由饮食不节、气机不畅所致）。
- **推理公式**：
    - **【肝热上扰】**：`[眩晕/头痛]` + `[面赤目胀]` + `[心烦急躁]` + `[舌质红]` → 提示肝经郁热，上冲头目。
    - **【瘀阻脑络】**：`[一过性语言謇涩/肢体无力]` + `[舌质黯/舌下瘀斑]` + `[脉涩]` → 提示瘀血阻滞，脑络不通，症状呈阵发性。
    - **【肝热与瘀血互结】**：`[肝热证据]` + `[瘀血证据]` + `[大便秘结/黏腻（腑气不通或湿热内蕴）]` → 综合推导出 **“肝热血瘀”** 的核心病机。
- **鉴别要点**：
    1.  **与单纯肝阳上亢证鉴别**：单纯肝阳上亢虽有头晕面赤，但**瘀血指征（舌黯瘀斑、固定刺痛）不明显**，且一过性神经功能缺损症状不典型。
    2.  **与痰热腑实证鉴别**：两者均可有便秘、舌红。但痰热腑实以**痰热壅盛**（喉中痰鸣、苔黄厚腻）和**腑实热结**（腹胀满痛、便干结）为突出表现，**瘀血征象相对次要**。肝热血瘀证则以**肝热与血瘀并重**，且症状具有**短暂性、先兆性**特点。
    3.  **与气虚血瘀证鉴别**：后者多见于中风后遗症期，以**乏力、气短、舌淡黯、脉细弱无力**等气虚表现为基础，**无肝热（面赤、心烦、脉弦）之象**。
