### 一、 模拟问诊路径（针对胸痹/冠心病心功能不全场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您胸口闷痛/不舒服有多久了？最近一次加重是什么时候？是怎么个痛法（闷痛、刺痛、绞痛）？”
- **医案特征提取**：病程8月，加重4天。疼痛性质为“胸闷痛”，劳累时诱发，持续10-15分钟，含服硝酸甘油可缓解。提示病程较长，呈劳累性发作，符合心绞痛特点。

**第二层：核心症状与功能状态细查（问诊/望诊导向）**
- **症状焦点**：
    - **胸痛**：诱因（劳累、情绪、饱食）、部位、性质、持续时间、缓解方式。
    - **心功能**：有无气促、呼吸困难（何时出现？静息时还是活动后？）、能否平卧、夜间有无憋醒（阵发性夜间呼吸困难）。
    - **伴随症状**：有无咳嗽、咳痰（痰的颜色、质地、量）、疲倦乏力程度、食欲、睡眠、口干口渴情况。
- **医案特征提取**：胸闷、气促动则加甚、不能平卧、咳嗽痰白、疲倦、纳差、睡眠欠佳。提示存在明显的心功能不全（心衰）及全身气虚、痰湿内阻表现。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡/红/紫暗）、舌体胖瘦、有无齿痕、瘀点瘀斑；舌苔颜色（白/黄）、质地（薄/厚/腻/浊）、润燥。
    - **脉象**：脉率（快/慢）、脉力（有力/无力）、脉形（细/滑/涩）。
- **关联病史追问**：有无高血压、糖尿病、高脂血症病史？有无吸烟、饮酒史？饮食习惯（是否喜食肥甘厚味）？此次加重前有无外感、劳累或情绪波动？
- **医案特征提取**：舌淡暗，苔白微浊，脉细数（初诊）；后见舌边齿印、瘀点瘀斑，舌底脉络迂曲紫暗，左脉弦，右脉紧涩。提示气虚（舌淡、齿印）、痰浊（苔白浊/腻）、血瘀（舌暗、瘀斑、脉涩）并存。患者为岭南地区老年男性，体质易受湿困。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次为什么来住院？之前都做过哪些检查和治疗（如冠脉造影、支架、搭桥建议）？效果怎么样？平时在吃什么药（西药如硝酸甘油、中药）？”
- **医案特征提取**：有明确“急性心肌梗死”病史，冠脉造影提示严重病变，曾建议搭桥术。入院后经初步治疗（利尿、扩血管等），浮肿、早搏好转，但胸闷、气促未根本缓解，仍需持续静滴硝酸甘油，为寻求进一步中医治疗入院。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症为胸闷痛），兼及**脾**（纳差、痰白、苔浊，脾为生痰之源）。
- **核心病性**：**本虚标实**。本虚为**气虚**（心气、脾气），标实为**痰浊**与**血瘀**互结。
- **推理公式**：
    1.  **气虚定位**：[主症：胸闷痛，劳累诱发] + [全身症状：疲倦、少气乏力、动则喘促] + [舌脉：舌淡、边有齿印，脉细/寸弱] → **心脾气虚**。
    2.  **痰浊定位**：[伴随症状：咳嗽、痰白、纳差] + [舌象：苔白微浊/腻] + [地域体质：岭南潮湿，脾易生湿] → **痰湿内阻**。
    3.  **血瘀定位**：[病史：陈旧性心梗] + [舌象：舌质淡暗、边有瘀点瘀斑、舌底脉络迂曲紫暗] + [脉象：脉涩] → **心血瘀阻**。
    4.  **病机关联推导**：气虚（推动无力）→ 津液不化，聚湿生痰 → 痰阻气机，血行不畅 → 痰瘀互结，痹阻心脉 → 发为胸痹。即 **“气虚 → 生痰 → 致瘀”** 的链条。
- **辨证结论**：**胸痹（气虚痰瘀证）**。
- **鉴别要点**：
    - **与单纯气滞血瘀证鉴别**：单纯气滞血瘀常伴胁胀、善太息，疼痛多为刺痛，舌紫暗或有瘀斑，但苔薄不腻，无明显痰湿症状（如咳痰、纳呆、苔浊）。本案有明显痰湿征象。
    - **与阳虚水泛证鉴别**：阳虚水泛多见于心衰晚期，以畏寒肢冷、全身浮肿（尤以下肢为甚）、小便不利、心悸怔忡为主，舌淡胖苔水滑，脉沉微。本案虽有下肢浮肿，但以气虚、痰瘀症状为主，未见明显畏寒、肢冷等阳虚寒象，故辨证重心不同。
