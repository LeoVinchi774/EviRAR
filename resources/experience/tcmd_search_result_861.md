### 一、 模拟问诊路径（针对郁病/焦虑抑郁伴躯体化症状场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次最主要想解决什么问题？是从什么时候开始的？”
- **医案特征提取**：病程日久（1年以上），主诉为“烦躁失眠、精神紧张、头昏头晕、畏惧摔倒而不敢外出”，并伴有“左侧足部麻热感”。需明确症状出现的先后顺序（如行走不稳在先，精神症状在后）及演变过程。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望神**：观察患者进入诊室时的精神状态（是否倦怠、紧张、恐惧）、面色（是否晦暗）。
    - **望舌**：重点观察舌质颜色（暗红）、舌体形态（瘦）、舌苔（白腻），**尤其必须查看舌下络脉**，注意其颜色、粗细、迂曲程度（+++）。
- **触觉焦点**：
    - **切脉**：必须诊双侧脉象，仔细体察左右手脉象差异（左脉沉弦，右脉沉细），以及迟脉的力度（数而无力）。
    - **局部**：询问并检查“足部麻热感”的具体部位、范围，有无客观的温度、颜色改变。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质暗红、体瘦、苔白腻，舌下脉络迂曲（+++）；左脉沉弦，右脉沉细，迟脉数而无力。
- **关联病史追问**：
    1.  **情志与睡眠**：“最近情绪怎么样？容易紧张、烦躁吗？晚上睡眠如何？是入睡困难，还是多梦易醒？”
    2.  **全身症状**：“有没有怕冷或怕热？有没有腰酸、腰痛、耳鸣、盗汗？大小便情况如何？”（医案提示无腰酸腰痛，大便干燥，需确认）。
    3.  **既往史与治疗史**：“以前有过什么大病吗？（如高血压、脑梗、肝豆状核变性等）针对这些病和现在的症状，都做过哪些治疗？效果怎么样？”（医案提示长期、多科、多方治疗无效）。
    4.  **生活与社会因素**（采用聊家常方式）：“最近家里或工作上有没有什么烦心事？平时活动多吗？穿衣比一般人怕冷吗？”（用于评估肾虚及情志诱因）。

**第四层：治疗经过与转归判断**
- **关键提问**：“您因为这个‘不敢外出、头晕失眠’的问题，都去过哪些科室？用过哪些药（中药或西药）？感觉有一点效果吗？”（医案关键信息：反复求治于神经内科、精神科、中医科而不效，此信息对判断病机复杂性和常规治疗无效至关重要）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在脑（元神之府）、肾、肝**。脑为病变之标，肾虚为病之本，肝热血瘀为病之枢。
- **核心病性**：**本虚标实，虚实夹杂**。本虚为**肾阴亏虚**；标实为**肝热、血瘀、气郁**。属**热**、属**瘀**。
- **推理公式**：
    1.  **[主症：烦躁失眠、精神紧张、畏惧外出] + [病程：日久不愈，多方治疗无效] → 提示病位在脑，病属“郁病”，非单纯肝气郁结，病机深痼。**
    2.  **[体征：舌体瘦、脉沉细] + [病史：长期慢性病消耗] → 指向阴血亏虚，病位在肾（肾主骨生髓，脑为髓海）。**
    3.  **[体征：舌质暗红、舌下脉络迂曲（+++）、左脉沉弦] + [症状：头昏头晕、足部麻热感] → 明确存在瘀血阻滞、肝经郁热（弦脉主肝，热煎血凝）。**
    4.  **[综合]：肾阴亏虚（本）→ 阴虚生内热，热灼肝经 → 血液受煎成瘀（标）→ 瘀热互结，阻滞脑络气机 → 脑神失养、失用 → 发为郁病（烦躁、失眠、紧张、恐惧）。**
- **鉴别要点**：
    - **与单纯肝气郁结证鉴别**：单纯肝郁多以情绪抑郁、胸胁胀满、善太息为主，舌脉以弦为主，瘀象不显。本案**舌下脉络显著迂曲（+++）** 是鉴别血瘀证的关键客观指征。
    - **与心脾两虚型郁病鉴别**：心脾两虚常伴心悸、健忘、纳差、便溏、舌淡脉弱。本案大便干燥、舌暗红、脉沉弦细，无脾虚之象，反显阴亏瘀热。
    - **与痰火扰心型鉴别**：痰火扰心多见心烦失眠、面红目赤、痰多黄稠、舌红苔黄腻、脉滑数。本案苔为白腻而非黄腻，脉不滑而沉细弦，热象与痰象均不典型，核心在于**阴虚血瘀**。
