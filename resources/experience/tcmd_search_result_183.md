### 一、 模拟问诊路径（针对子宫内膜息肉术后复发伴月经量少场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次主要因为什么问题来看病？这个问题持续多久了？之前因为这个息肉做过什么治疗吗？”
- **医案特征提取**：病程6个月余，为术后复发。需明确手术时间、术后病理结果、术后是否用药（如孕激素）及疗程、复发发现时间。平素月经周期（25-28天）尚规律，但经量“中偏少”是长期状态。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉/问诊焦点**：
    1.  **月经情况（核心）**：末次月经的**量、色、质、有无血块**。经期有无**腹痛**，疼痛性质（冷痛/胀痛/刺痛）、喜按/拒按、喜温/恶热。
    2.  **带下情况**：非经期带下的**量、色、质、有无异味**，尤其关注有无“锦丝带下”（排卵期透明拉丝白带）以判断肾气与排卵情况。
    3.  **腹部体征**：小腹有无自觉发凉、坠胀感。触诊（切诊）小腹有无压痛、有无包块（结合B超）。
- **医案特征提取**：量少、色淡暗、质稀夹小血块；小腹冷痛喜温；刻下无锦丝带下。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌体（胖瘦、齿痕）、舌色（淡/红/紫暗）、舌面（瘀点/瘀斑）、苔色与苔质（白/黄、滑/腻/燥）。
    - **脉象**：脉位（浮/沉）、脉力（有力/无力）、脉率（迟/数）、脉形（细/滑/涩）。
- **关联病史与体质追问**：
    1.  **全身症状**：精神体力（神疲乏力？）、畏寒怕冷（四肢、腰骶部是否发凉？）、饮食（纳差？）、二便（便溏或便秘？）。
    2.  **面色与皮肤**：面色（萎黄/晄白/暗沉？）、面部有无痤疮（部位、颜色）。
    3.  **生育相关**：年龄、婚育史、近期有无生育计划。
    4.  **辅助检查**：近期B超（内膜厚度、息肉/囊肿大小）、性激素六项（评估卵巢功能）结果。
- **医案特征提取**：神疲腰冷，纳差便溏，四肢不温；面色暗沉萎黄，面部痤疮散在；舌淡胖紫暗边齿痕瘀点，苔白滑，脉沉细涩。

**第四层：治疗经过与转归判断**
- **关键提问**：“上次手术后，医生给您开了什么药（如地屈孕酮）？吃了多久？效果怎么样？复查B超发现复发和囊肿是什么时候？之后有没有再尝试其他治疗？”
- **医案特征提取**：术后予地屈孕酮治疗3周期，复查仍复发并出现附件囊肿，提示单纯激素对抗治疗效不佳，需从中医整体调整体质入手。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**胞宫（子宫）** 为病变发生之地；**脾、肾**为病机根源（脾主运化、肾主生殖与温煦）；**冲任**为气血失调之通路。
- **核心病性**：**本虚标实**。**本虚**为**脾肾阳虚**（虚、寒）；**标实**为**痰浊、瘀血**互结于胞宫（实）。
- **推理公式**：
    1.  **[主症：息肉/囊肿复发] + [全身：神疲腰冷、四肢不温、纳差便溏] + [舌脉：舌淡胖有齿痕、苔白滑、脉沉细]** → 推导出 **“脾肾阳虚”** 这一根本病机。阳虚则温煦推动无力，水湿不化，气血运行迟缓。
    2.  **[主症：月经量少、色暗夹血块] + [体征：小腹冷痛、舌紫暗有瘀点] + [脉象：脉涩]** → 推导出 **“胞宫瘀滞”** 。血得寒则凝，阳虚寒凝导致血行不畅成瘀。
    3.  **[体征：息肉/囊肿（有形实邪）] + [舌象：舌胖苔滑] + [全身：纳差便溏]** → 结合阳虚水湿不化的病机，推导出 **“痰浊内生”** 。脾虚生湿，湿聚成痰。
    4.  综合以上：**脾肾阳虚（本）** 导致 **痰浊与瘀血（标）** 互结，停滞于 **胞宫冲任**，形成 **“癥瘕”（息肉/囊肿）** 并导致 **“月经过少”**。故证型为：**脾肾阳虚，痰瘀互结，胞宫瘀滞**。
- **鉴别要点**：
    1.  **与单纯肾阴虚血瘀证鉴别**：后者常有月经量少、色红或暗、但质地黏稠，伴五心烦热、口干咽燥、舌红少苔、脉细数等虚热之象，而无明显畏寒、便溏等阳虚症状。本案一派寒象，可资鉴别。
    2.  **与肝郁气滞血瘀证鉴别**：后者月经量少或多，色暗块多，经前乳胀、小腹胀痛，情绪抑郁或烦躁，脉弦。本案以阳虚寒凝为主，情绪症状不显，脉象沉细涩而非弦，可资鉴别。
    3.  **注意“痰”与“瘀”的权重**：本案舌苔**白滑**（提示湿/痰）、舌体**胖**有齿痕（提示脾虚湿盛）是辨“痰”的关键；而**舌紫暗有瘀点、经夹血块、脉涩**是辨“瘀”的关键。二者共同构成了“阴成形”的病理产物。
