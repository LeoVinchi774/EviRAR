### 一、 模拟问诊路径（针对狐惑病/白塞氏病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请问您主要因为哪里不舒服来看病？这个情况有多久了？”
- **医案特征提取**：患者主诉为“外阴部溃疡”、“口腔溃疡”。病程迁延（2005年始发，至2008年就诊），反复发作，且与月经周期相关（“来月经加重”）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **口腔/咽喉**：观察口腔、咽喉黏膜有无溃疡、糜烂，注意其大小、颜色、深浅、有无分泌物。
    - **外阴/肛门**：检查外阴、肛周有无溃疡、红肿，注意其形态、分泌物（如白带带血丝）。
    - **皮肤/关节/眼**：询问并观察有无皮肤结节红斑、关节肿痛、眼睛红赤畏光等白塞病其他典型表现。
- **触觉焦点**：
    - **溃疡局部**：询问溃疡有无疼痛、瘙痒感（本案特点为“不痛不痒无感觉，唯解小便时刺激痛”）。
    - **腹部/乳房**：触诊腹部有无压痛、包块（附件炎、囊肿史），询问乳房有无胀痛、结节。
- **医案特征提取**：溃疡特点为“不痛不痒”，但受尿液刺激痛。伴有“乳房胀痛”、“肛门坠胀”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：必须观察舌质颜色（暗淡）、舌苔颜色与质地（白滑略黄）。
    - **脉诊**：必须切诊脉象（沉、细、弦、无力）。
- **关联病史追问**：
    - **妇科情况**：月经周期、经量、经色、有无血块、经前/经期腹痛情况。白带量、色、质。有无妇科手术史（如囊肿切除）。
    - **泌尿系统**：有无尿频、尿急、尿痛、小便不畅、血尿、蛋白尿史。
    - **全身状态**：有无长期疲劳乏力、午后低热、口干咽燥、心烦失眠等。
    - **既往诊疗**：明确西医诊断（白塞病、子宫内膜异位症、附件炎等）及具体用药、疗效。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前用过哪些药（中药/西药）？效果怎么样？有没有什么不良反应？（如服活血化瘀药后子宫出血）”
- **医案特征提取**：患者曾服“活血化瘀药”导致子宫出血，提示体质不耐攻伐或辨证有偏；西药治疗效果不佳，提示病情顽固，需调整治疗思路。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、肾**（主司下焦、冲任、阴液），兼及**心、脾**（开窍于舌、口，主肌肉）。病位在下焦、官窍。
- **核心病性**：**本虚标实**。以**肝肾阴虚**为本（虚），以**毒热（湿热）内蕴、瘀血阻滞**为标（实）。整体属虚实夹杂，阴虚内热。
- **推理公式**：
    1.  **[主症：反复口、外阴溃疡]** + **[体征：月经量多、有紫红血块，经前腹痛，乳房胀痛]** + **[舌脉：舌暗淡、脉弦]** → **病位在肝，肝经郁热，疏泄失常，热毒循经上攻下注，兼有血瘀**。
    2.  **[主症：溃疡不痛不痒、病程迁延]** + **[体征：疲劳乏力、尿频、月经量多]** + **[舌脉：舌暗淡、苔白滑、脉沉细无力]** → **存在正气亏虚（气阴两虚）之象，尤以阴液亏损为基**。
    3.  **[体征：便干、尿黄、苔略黄]** + **[主症：溃疡]** → **内有郁热（毒热）**。
    4.  **综合推导**：长期病程 + 多系统损害（口、阴、肾、冲任） + 疲劳脉细 → **肝肾阴虚** 为发病基础。在此基础上，虚火内生，炼津成瘀，或湿热毒邪乘虚内伏，上熏下迫，腐蚀黏膜，发为溃疡。故证型为 **“肝肾阴虚，毒热内伏”**。
- **鉴别要点**：
    - **与单纯实热/湿热证鉴别**：单纯实热或湿热下注所致溃疡，多疼痛剧烈，红肿明显，病程较短，体质壮实，舌红苔黄腻，脉滑数有力。本案溃疡“不痛不痒”，伴明显乏力、脉沉细无力，提示虚象显著。
    - **与单纯血瘀证鉴别**：单纯血瘀证以固定刺痛、肿块、舌紫暗瘀斑、脉涩为主。本案虽有血瘀表现（经血块、舌暗），但置于“阴虚内热”和“疲劳脉细”的大背景下，血瘀为继发或兼夹病机，非核心病机。
    - **与脾肾阳虚证鉴别**：脾肾阳虚亦可致溃疡久不敛口，但多伴畏寒肢冷、大便溏泄、小便清长、舌淡胖苔白滑、脉沉迟无力等虚寒之象。本案有尿黄、便干、苔略黄，属热象，可资鉴别。
