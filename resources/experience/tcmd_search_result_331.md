### 一、 模拟问诊路径（针对不孕症伴情志失调场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要因为什么问题来看诊？结婚多久了？是否尝试过怀孕？是否做过相关检查？”
- **医案特征提取**：主诉为“结婚4年未孕”，病程明确。需追问不孕年限、是否进行过系统检查（如B超、配偶精液常规），以明确“原发性不孕”的诊断前提。

**第二层：月经与带下细查（问诊/望诊导向）**
- **核心周期询问**：“月经初潮是多大？平时的月经周期准不准？一般是提前还是推后？经期持续几天？经量是多是少？颜色是鲜红、暗红还是淡红？有没有血块？”
- **核心伴随症状询问**：“来月经前或来的时候，身体有什么不舒服吗？比如乳房胀痛、小腹坠胀或疼痛、腰酸？情绪上有没有变化？”
- **医案特征提取**：月经“周期紊乱，多错后，量少，色暗”，此为冲任失调、血行不畅之象。经前“乳房胀痛，小腹胀痛”是肝郁气滞的典型表现。

**第三层：情志与全身症状挖掘（问诊导向）**
- **情志状态追问**：“平时情绪怎么样？容易心烦、着急、发脾气吗？有没有感觉压力大、心情压抑？”
- **睡眠与神志追问**：“睡眠好吗？是入睡困难、多梦，还是容易醒？白天精神怎么样？”
- **全身伴随症状追问**：“平时容易出汗吗？是活动后出汗还是安静时也出汗？胃口怎么样？大便是否成形？”
- **医案特征提取**：“心烦急躁，失眠梦多，时汗出”是肝郁化火、痰火扰心的重要证据，指向“脏躁”诊断。

**第四层：体征与体质辨识（望诊/切诊导向）**
- **必查舌脉**：必须观察并记录“舌质、舌苔、舌体形态”，切诊“脉象”。
- **医案特征提取**：“舌质暗红”主有热、有瘀；“苔薄白”提示热未完全入里或湿未化热；“舌体稍胖大”是脾虚有湿的征象；“脉弦细”主肝郁、血虚或气机不畅。此为肝郁脾虚、兼有痰湿血瘀的复合舌脉象。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、心**。肝主疏泄，调畅气机与情志；脾主运化，为生痰之源；心主神明。病位在肝（疏泄失常），影响及脾（运化失职），上扰于心（神明不安）。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾虚（气血生化不足，运化失司）；**标实**为肝郁、气滞、痰湿、血瘀、肝火/痰火。
- **推理公式**：
    1.  **[结婚4年未孕] + [月经错后、量少、色暗、经前乳胀腹痛] + [脉弦]** → **核心病机：肝郁气滞，冲任失调**。
    2.  **[肝郁气滞] + [舌体胖大] + [月经色暗、舌暗红]** → **推导出：木郁克土，脾虚生湿；气滞导致血行不畅（血瘀）**。
    3.  **[肝郁脾虚，痰湿内蕴] + [心烦急躁、失眠多梦、时汗出] + [舌质暗红]** → **推导出：气郁痰阻，日久化火，痰火上扰心神（形成“脏躁”之证）**。
    4.  **综合**：脾虚（本） + 肝郁、气滞、痰湿、血瘀、肝火（标） → **最终辨证：不孕症（肝郁气滞，痰湿阻滞证）；脏躁（脾虚肝旺，肝火内盛证）**。
- **鉴别要点**：
    1.  **与单纯肾虚型不孕鉴别**：肾虚者常伴腰膝酸软、头晕耳鸣、性欲淡漠、月经色淡或暗、尺脉弱。本案虽有月经问题，但核心伴随症状是**经前乳胀、心烦急躁等肝郁化火之象**，且舌不淡、脉不弱，故非以肾虚为主。
    2.  **与单纯痰湿型不孕鉴别**：单纯痰湿者多见形体肥胖、胸闷呕恶、带下量多黏腻、苔腻。本案虽有脾虚痰湿之舌象（舌胖），但**情志症状（心烦失眠）极为突出**，且舌苔薄白而非厚腻，提示痰湿与气郁化火并存，病机更为复杂。
    3.  **治疗禁忌提示**：辨证为脾虚肝郁痰火，**禁用滋腻温补之品**（如熟地、鹿茸等），以防助湿生痰，加重气机壅滞。治法重在健脾以绝痰源，疏肝以调气机，清心以安神志。
