### 一、 模拟问诊路径（针对痿证/进行性肌无力场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您感觉哪里最不舒服？这种无力感是从什么时候开始的？是怎么发展变化的？”
- **医案特征提取**：主症为“进行性四肢无力”，病程5月余，起于产后。需重点询问无力症状的演变过程（是否逐渐加重）、具体活动受限情况（如上楼、翻身、举臂）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者形体、肌肉有无萎缩或假性肥大、皮肤色泽。医案中虽未明言，但痿证需常规观察。
- **触觉焦点**：触诊肌肉有无压痛、肌肉硬度（软或硬）。医案中实验室及肌电图提示“肌源性改变”，问诊时应关注肌肉是否有酸痛感（后续复诊出现“四肢酸痛”）。
- **医案特征提取**：核心是“无力”而非“疼痛”，但需关注有无伴随肌肉的异常感觉。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡红）、舌苔（薄黄腻）、脉象（软）。此为辨证关键。
- **关联症状追问**：
    1.  **脾胃功能**：“吃饭胃口怎么样？有没有腹胀？大便是什么形状的？粘不粘马桶？”（对应：食欲欠佳、便溏软挂厕）
    2.  **津液与湿热**：“口里感觉干吗？想喝热水还是凉水？嘴里感觉黏不黏？小便颜色如何？”（对应：口干渴欲温饮、口中黏腻、小便略黄）
    3.  **气血状态**：“平时容易累吗？有没有头晕、心慌？”（对应：易感疲劳、时有头晕）
    4.  **特殊病史**：“症状是在生产后出现的吗？哺乳情况如何？”（对应：产后发病、哺乳期）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在西医院做过哪些检查？诊断是什么？用过什么药吗？效果怎么样？”（对应：已确诊坏死性肌病，因哺乳期求诊中医，了解前期诊疗史以评估病情严重程度和选择安全治疗方案）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、胃、肌肉**。脾主四肢肌肉，为气血生化之源；胃为水谷之海。病位主要在脾。
- **核心病性**：**本虚标实**。**本虚为脾气虚弱**，**标实为湿热内蕴**。气血津液方面，表现为**气虚失养，兼有湿热困阻**。
- **推理公式**：
    - **[主症：四肢痿软无力]** + **[脾虚证候：疲劳乏力、纳呆、便溏]** + **[湿热证候：口干欲温饮、口腻、小便黄、苔黄腻]** + **[舌脉：舌淡红苔薄黄腻，脉软]** → **辨证结论：痿证（肉痿），脾虚湿热证**。
    - **推导链条**：
        1.  **定位在脾**：根据“脾主四肢肌肉”理论，四肢不用首先考虑脾病。
        2.  **定性为虚**：疲劳、纳呆、便溏是脾失健运、气血生化不足的典型表现，确立“脾虚”之本。
        3.  **辨识兼夹**：口干、小便黄、苔黄腻提示有“热”；口腻、苔腻、便溏挂厕提示有“湿”。湿热相合，困阻中焦，进一步妨碍脾的运化功能，并可能熏蒸肌肉，加重痿废。口干“欲温饮”提示热中夹虚，或湿遏热伏。
        4.  **综合诊断**：脾虚为本，湿热为标，肌肉失于气血濡养且为湿热所困，故发为肉痿。
- **鉴别要点**：
    1.  **与肝肾阴虚痿证鉴别**：后者常伴腰膝酸软、头晕耳鸣、舌红少苔、脉细数，而本案无典型肝肾阴虚表现，反有脾虚湿困之象。
    2.  **与纯湿热浸淫痿证鉴别**：纯湿热证通常起病较急，身重、胸脘痞闷、苔黄腻更显，但脾虚证候（如长期乏力、便溏）不突出。本案是脾虚基础上生湿化热，属虚实夹杂。
    3.  **与瘀血阻络痿证鉴别**：瘀血所致痿证多有外伤史或疼痛固定、舌质紫暗、脉涩等表现，本案初诊无此特征（后续出现腰痛与旧伤有关，属兼证）。
