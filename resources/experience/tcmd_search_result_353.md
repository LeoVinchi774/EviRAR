### 一、 模拟问诊路径（针对绝经后外阴瘙痒/阴痒场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您外阴瘙痒、不舒服有多久了？具体是痒、还是痛、还是干涩感？什么情况下会加重？”
- **医案特征提取**：病程3年，反复发作；绝经7年；夜间瘙痒加重；外用药涂抹无效。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：外阴形态（是否萎缩、色素是否减退）、颜色（是否充血、有无皮损）、分泌物情况（量、色、质）。
- **触觉焦点**：局部温度（有无灼热感）、湿度（干涩程度）、有无压痛或硬结。
- **医案特征提取**：外阴老年式，阴蒂及小阴唇萎缩，色素减退；阴道充血；患者自觉灼热、干涩、刺痛。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质颜色（红/黯红）、舌苔（薄厚、颜色、润燥）；脉象（弦/细/数等）。
- **关联病史追问**：“绝经几年了？有没有潮热、出汗？平时情绪怎么样？有没有口干、眼干、腰酸、便秘这些情况？”（围绕肝肾阴虚及内热症状展开）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在医院做过什么检查？诊断是什么？用过哪些药？效果怎么样？”（了解西医诊断及既往治疗史，评估病情顽固性）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：肝、肾；病在阴器（前阴），与足厥阴肝经、足少阴肾经关系密切。
- **核心病性**：本虚标实。**本虚**为肝肾阴虚，精血亏虚；**标实**为阴虚内热（虚热）、血燥生风。
- **推理公式**：
    1.  **【主症定位】** `绝经后 + 外阴瘙痒干涩刺痛` → 病位在肝肾（肝经绕阴器，肾开窍于二阴），病机与精血亏虚、失于濡养相关。
    2.  **【局部辨证】** `阴痒夜间尤甚 + 灼热感 + 干涩` → 提示“阴虚血燥生风”（夜间属阴，阴虚症状加重；燥热生风则痒；津亏失润则干涩疼痛）。
    3.  **【全身佐证】** `潮热汗出 + 口鼻眼干 + 腰酸 + 性急 + 便秘尿黄` → 系统性支持“肝肾阴虚，虚热内扰”的病机（阴虚生内热则潮热；津不上承则干燥；肾府失养则腰酸；肝阴不足，疏泄失常则性急；热灼津液则二便异常）。
    4.  **【舌脉印证】** `舌质黯红（阴虚有热或兼瘀滞）+ 脉弦（主肝病、气机不畅）` → 与肝肾阴虚、肝失疏泄的病机吻合。
    5.  **【综合辨证】** 以上证据链闭合，排除单纯湿热下注（无带下量多、色黄、秽臭等典型湿热象），最终指向 **“肝肾阴虚，血燥生风”** 证型。
- **鉴别要点**：
    - **与湿热下注证鉴别**：湿热证多见带下量多、色黄质稠、气味秽臭，舌苔多黄腻，脉滑数。本案虽有局部充血、小便黄，但核心症状为干涩、无带下异常，且全身见阴虚燥热之象，舌苔薄白，故可排除单纯湿热。
    - **与血瘀证鉴别**：血瘀证可见外阴皮肤粗糙、增厚、色紫黯，疼痛固定如针刺，舌质紫黯或有瘀点。本案舌质虽黯红，提示可能有瘀滞倾向，但主诉以“痒”和“干涩”为主，病机核心在于阴虚血燥，血瘀为次要或兼夹因素。
