### 一、 模拟问诊路径（针对慢性泄泻/便血粘液场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？这种情况持续多久了？”
- **医案特征提取**：主诉为“大便夹血带粘液”，病程长达“3年余”，具有长期、反复的特点。需追问排便频率（如每日几次）、便血与粘液的性质（颜色、量、是否与粪便混合）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察大便的性状（溏薄、水样）、颜色（血的颜色是鲜红、暗红还是紫暗）、是否带有脓冻样或蛋清样粘液。
- **触觉焦点**：询问并定位腹痛的具体位置（如左腹）、性质（隐痛、胀痛、刺痛）、有无压痛或包块。
- **医案特征提取**：左腹疼痛，大便夹血带粘液。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（颜色、有无瘀点瘀斑）、舌苔（颜色、厚薄、润燥）、脉象（粗细、力度、频率）。医案中为“舌质紫，舌苔白腻，脉细”。
- **关联病史追问**：
    1.  精神与体力：“是否容易疲劳、感觉没力气？”（对应神疲乏力）
    2.  饮食与消化：“胃口怎么样？饭后有没有腹胀、不消化？”（对应纳食减少）
    3.  情绪与睡眠：“平时情绪、压力如何？睡眠质量好吗？”（对应睡眠差，并关联肝郁）
    4.  既往诊疗史：“之前用过哪些药？效果怎么样？”（对应“服用多种药物疗效不佳”）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次是什么原因促使您来就诊？之前做过哪些检查，结果如何？”（引导患者提供如结肠镜等关键检查结果，以明确西医诊断基础，如本例“乙状结肠镜检查确诊为慢性结肠炎”）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在肝、脾、肠**。脾主运化，肝主疏泄，肠为传导之官。脾虚失运为本，肝郁气滞为标，湿热瘀血结于肠腑为标实。
- **核心病性**：**本虚标实，虚实夹杂**。本虚为**脾气虚弱**；标实为**肝气郁结、湿热内蕴、瘀血阻滞**。病性属**寒热错杂**，湿、热、瘀互结。
- **推理公式**：
    1.  **[主症：慢性泄泻、便夹粘液]** + **[伴随症：纳食减少、神疲乏力]** → 推导出 **脾虚失运，水湿下注**。
    2.  **[主症：左腹疼痛]** + **[伴随症：睡眠差、病程长、情志因素]** → 推导出 **肝气郁结，气机不畅**（肝经布胁肋，痛处固定提示气滞或血瘀）。
    3.  **[主症：便夹血]** + **[舌象：舌质紫]** → 推导出 **久病入络，瘀血阻滞**。
    4.  **[便夹粘液]** + **[舌象：苔白腻]** → 提示 **湿浊内蕴**。结合长期病程和肝郁化热可能，湿郁可化热，形成 **湿热瘀滞** 于肠道的复合病机。
    5.  **综合**：脾虚（乏力、纳少） + 肝郁（腹痛、眠差） + 湿热瘀滞（便血粘液、舌紫苔腻） → 辨证结论为 **肝郁脾虚，湿热瘀滞证**。
- **鉴别要点**：
    1.  **与单纯脾虚湿盛证鉴别**：单纯脾虚湿盛证多见大便溏泻、脘腹胀满、舌淡苔白腻，但**无腹痛、便血、舌紫**等肝郁、血瘀、热象的表现。
    2.  **与单纯肠道湿热证鉴别**：单纯肠道湿热证多见泻下急迫、肛门灼热、小便短赤、舌红苔黄腻，**无显著的神疲乏力、纳少等脾虚证**，且腹痛多为灼痛而非固定胀痛或刺痛。
    3.  **与瘀血阻络证鉴别**：瘀血阻络证以固定刺痛、舌质紫暗、脉涩为主，但**若无长期泄泻、粘液便及脾虚肝郁的全身症状**，则病位和病机重心不同。本案是脾虚肝郁基础上产生的继发性血瘀。
