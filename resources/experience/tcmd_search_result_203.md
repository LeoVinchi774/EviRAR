### 一、 模拟问诊路径（针对崩漏/异常子宫出血场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次来看病，最主要的不舒服是什么？”（引导患者描述“月经淋漓不尽”或“不规则阴道出血”的核心症状）。“这种情况持续多久了？是突然大量出血还是滴滴答答一直不干净？”
- **医案特征提取**：主诉为“月经淋漓不尽半年余”。病程较长（半年），出血特点为“量时多时少，淋漓不止”，且近期（诊刮术后第8天）仍有少量出血。需追问既往月经周期、经期、经量、经色及有无痛经，以明确本次为异常出血。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察或询问患者**经血的颜色、质地、有无血块**。医案中为“色黯，夹少许血块”。
- **触觉焦点**：崩漏患者局部体征不明显，问诊重点在于**出血的性状**。但需关注有无小腹疼痛（医案中三诊时出现），以判断是否兼夹血瘀。
- **医案特征提取**：经色暗、有血块提示“热盛血凝而瘀”或“久漏多瘀”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：必须查看**舌色、苔色、苔质**（医案：舌淡红，苔黄）；必须诊察**脉象**（医案：脉滑数）。这是判断寒热虚实的关键。
- **关联病史追问**：
    1.  **全身症状**：有无**疲乏、气短、头晕、四肢麻木**（气血亏虚）；有无**烦热、口渴、手足心热**（内热）；**食欲、睡眠、大小便情况**（医案：纳少，寐一般，小便黄，大便或干结）。
    2.  **诊疗史**：近期是否做过**妇科B超、诊断性刮宫、血常规**等检查？结果如何？（医案提示：B超示内膜厚26mm，诊刮病理报告，Hb 102g/L提示轻度贫血）。曾用过何种治疗（中药或西药）？效果如何？
    3.  **生育与月经史**：孕产史，初潮年龄，既往月经是否规律。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次出血前，有没有吃过什么药或者做过什么治疗？（如诊刮术）治疗后出血情况是好转了，还是依旧？”（医案中患者诊刮术后第8天仍出血，且既往服中药疗效欠佳，提示病情顽固，需综合调治）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任、胞宫**。与**肝、脾、肾**三脏功能失调密切相关。
- **核心病性**：**本虚标实，虚实夹杂**。标实为**血热、血瘀**；本虚为**气虚、阴血亏虚**。
- **推理公式**：
    1.  **主症（出血）**：月经非时而下，淋漓不止（崩漏） → 提示冲任不固，经血妄行。
    2.  **体征（热象）**：烦热口渴 + 小便黄 + 大便干结 + **舌苔黄，脉滑数** → 推导存在**内热（血热）**。
    3.  **体征（虚象与瘀象）**：疲乏无力 + 四肢麻木 + **舌淡红** + 血常规示贫血（Hb 102g/L） → 推导**气血亏虚**（长期失血所致）。经色黯、夹血块 → 推导**兼夹血瘀**。
    4.  **病机整合**：**血热**内扰，迫血妄行（标实） + **气虚**失于固摄，血失统摄（本虚） + **久漏致瘀**（病理产物） → 辨证结论：**血热扰冲，气虚不摄**（兼血瘀）。
- **鉴别要点**：
    1.  **血热证 vs. 气虚证为主**：需重点鉴别热象与虚象孰轻孰重。本案**烦热、苔黄、脉数**等热象显著，同时有**疲乏、舌淡、贫血**等虚象，属虚实夹杂，但热邪是“核心病因”和当前主要矛盾（治法首重清热凉血）。
    2.  **有无血瘀**：经血**色黯、有块**是鉴别要点。单纯血热出血多色鲜红、质稠；兼瘀则色暗有块，且可能伴有小腹疼痛。本案初诊即有血块，三诊时腹痛明显，提示瘀象贯穿病程。
    3.  **与单纯肾虚不固、脾不统血鉴别**：后两者通常无明显热象（如口渴、尿黄、便秘、苔黄、脉数），而以腰膝酸软、头晕耳鸣（肾虚）或食少便溏、神疲乏力（脾虚）及舌淡脉弱为主要表现。本案热象明显，故非单纯虚证。
