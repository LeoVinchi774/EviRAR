### 一、 模拟问诊路径（针对妇科术后诸证场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“手术后多久了？现在最主要的不舒服是什么？”（需引导患者聚焦于术后特有的异常症状）
- **医案特征提取**：明确手术类型（如结扎、人流、肌瘤切除等）、术后时间、核心症状（如恶露不绝、腹痛、月经紊乱）的起始与持续时间。

**第二层：局部体征与异常分泌物细查（望诊/闻诊/切诊导向）**
- **视觉与嗅觉焦点**：
    - **望诊**：观察恶露或经血的**颜色**（鲜红、暗红、紫黑）、**质地**（稀薄、黏稠、有无血块或组织物）、**量**（多少）。
    - **闻诊**：询问或注意分泌物有无**特殊气味**（腥、臭、秽）。
- **触觉焦点（切诊）**：
    - **腹部按诊**：检查**少腹、小腹**有无压痛、胀满感、有无包块或硬结。
    - **腰部按诊**：检查**腰脊**有无叩击痛、酸胀感。
- **医案特征提取**：恶露/经血“淋漓不绝”、“夹血丝”、“质腥秽臭”；疼痛性质为“坠胀”、“胀痛”。

**第三层：伴随体征与全身状态挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质（淡、红、暗、紫？有无瘀点瘀斑？）、舌苔（薄白、薄黄、腻、少苔？）。
    - **脉诊**：脉象（细、弱、涩、弦？）。
- **关联症状追问**：
    1.  **神志与睡眠**：“睡眠怎么样？容易入睡吗？梦多不多？”（对应：夜难入寐、寐则多梦）
    2.  **情志与心胸部感觉**：“最近心情如何？有没有感觉心慌、心里烦？”（对应：心悸心烦）
    3.  **头面官窍**：“有没有头晕、耳鸣？”（对应：头晕耳鸣）
    4.  **寒热感觉**：“有没有一阵冷一阵热的感觉？”（对应：时冷时热）
    5.  **全身机能**：“吃饭、大小便、体力怎么样？”（探查气血生化之源及整体虚损程度）

**第四层：治疗经过与体质背景追溯**
- **关键提问**：“手术后出血多不多？术后用过什么药或做过什么治疗？效果怎么样？”
- **体质与病史**：“平时身体怎么样？以前月经规律吗？有没有流产史或其他妇科手术史？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任二脉、胞宫（胞脉）**，关联**肝、肾、脾**三脏。
- **核心病性**：**本虚标实，虚实夹杂**。虚在**气血亏虚、肝肾不足**；实在**瘀血阻滞、离经之血留滞**。病性总体属**虚瘀并见**。
- **推理公式**：
    1.  **【手术创伤史】** + **【恶露淋漓/月经紊乱、少腹胀痛】** → 提示**冲任胞脉损伤，离经之血成瘀**。
    2.  **【出血日久/量多】** + **【头晕、心悸、寐差】** → 推导**气血耗伤，心肝失养**。
    3.  **【腰脊坠胀、耳鸣】** → 指向**肾气亏虚，肾府失养**。
    4.  **【经血色暗夹血丝、质腥秽、腹痛拒按（若存在）】** + **舌质暗紫/有瘀点、脉涩** → 确证**瘀血内阻**。
    5.  **【时冷时热】** → 提示**气血失和，营卫不调**或**正邪交争**。
    - **综合辨证结论**：**虚实夹杂、虚瘀并见，冲任胞脉损伤证**。具体可辨为**气血两虚、瘀阻胞脉**或**肝肾亏虚、瘀血内停**等亚型。
- **鉴别要点**：
    - **与单纯血瘀证鉴别**：单纯血瘀证多以刺痛、固定痛、色紫黑块多、舌紫暗脉涩为主，虚象不显。本病必兼见气血亏虚（如头晕乏力、心悸）或肝肾不足（腰酸耳鸣）之象。
    - **与单纯气血两虚证鉴别**：单纯气血两虚之月经病，多见经色淡、质稀、腹痛绵绵喜按，无血块及腥臭，少有明显瘀血征象。本病必有瘀阻之征（腹痛胀、色暗夹丝、淋漓难净）。
    - **与湿热下注证鉴别**：湿热下注之带下、腹痛，多见分泌物黄稠臭秽、小便短赤、舌红苔黄腻，热象明显。本病之“腥秽臭”源于瘀久，全身热象不一定是主要矛盾，且必有手术伤正病史。
