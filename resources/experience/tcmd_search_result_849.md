### 一、 模拟问诊路径（针对眩晕伴肢体麻木场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：您主要哪里不舒服？头晕多久了？除了头晕，身体有没有其他感觉，比如麻木、疼痛或者抽动？
- **医案特征提取**：主诉为“头晕伴左半身麻木3月”，病程较长（3个月），且症状（麻木、抽动）具有明确的偏侧性（左半身为甚）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者体型（是否肥胖、肌肉丰满）、面色（有无晦暗或潮红）、肢体活动度（有无活动不利）。
- **触觉焦点**：测量血压（明确数值及波动情况）。询问并触诊患者所述麻木、疼痛部位（如背部、四肢）的僵硬、沉重感，以及肌肉不自主抽动的频率和程度。
- **医案特征提取**：“身胖”、“四肢沉重，背部僵痛，左半身为甚”、“肌肉不自觉抽动”、“血压波动于180/110mmHg左右”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（颜色、有无瘀点、裂纹）、舌苔（颜色、厚薄、腻腐）；脉象（弦、缓、滑、涩等）。
- **关联病史追问**：
    1.  **饮食与体质**：平素饮食偏好如何？（喜食肥甘厚味）
    2.  **情志与睡眠**：近来情绪如何？是否容易急躁、发怒？睡眠质量怎样？入睡是否困难？
    3.  **二便情况**：大便是否通畅？几日一行？小便如何？
    4.  **既往治疗**：是否已确诊高血压？服用何种降压药？效果如何？血压控制是否稳定？
    5.  **其他不适**：有无胸闷、心悸、心前区不适或发凉感？有无口干、口苦？
- **医案特征提取**：“日常喜食肥甘厚味”、“易急躁，入睡困难，大便3日一行”、“平日时感心胸凉气难舒”、“舌暗淡有裂纹、苔微黄腻，脉弦缓”。

**第四层：治疗经过与转归判断**
- **关键提问**：这次因为什么来看病？是症状加重了，还是之前的治疗效果不好？（例如：虽然吃了降压药，但血压仍控制不佳，头晕、麻木没有改善？）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、经络**。肝主风、主疏泄，其病位在肝；脾主运化，其病位在脾；痰瘀痹阻，其病位在经络（尤以肢体、背部经络为主）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **标实**：**肝阳上亢**（阳亢化风）、**痰浊**、**瘀血**、**郁热**。
    - **本虚**：**脾气虚弱**（运化失司）、**阴血暗耗**（气血两虚）。
- **推理公式**：
    1.  **[主症：头晕、肢麻搐搦] + [脉象：弦] → 提示“肝风内动”**。
    2.  **[体质与饮食：体胖、嗜肥甘] + [伴随症：四肢沉重、苔腻] → 提示“脾虚湿盛，痰浊内生”**。
    3.  **[症状：左半身麻木、背部僵痛] + [舌象：舌暗淡] → 提示“痰瘀阻络，气血运行不畅”**。
    4.  **[伴随症：易急躁、大便干结] + [舌苔：微黄] → 提示“郁而化热”**。
    5.  **[舌象：有裂纹] → 提示“阴血暗耗”**。
    6.  **综合推导**：**肝风内动（阳亢）** + **痰浊内生（脾虚）** + **瘀血阻络** + **郁热** + **阴血暗耗** = **证型：肝阳上亢，痰瘀阻络**。
- **鉴别要点**：
    1.  **单纯肝阳上亢证**：多见头晕目眩、面红目赤、急躁易怒、舌红苔黄、脉弦数有力，但通常无明显的肢体沉重、麻木、苔腻等痰湿、瘀血阻络之象。
    2.  **单纯痰湿中阻证**：多见头重如裹、胸闷呕恶、苔白腻、脉滑，但肝阳上亢（如急躁、脉弦）和瘀血（如固定疼痛、舌暗）的表现不突出。
    3.  **气血两虚证**：多见眩晕动则加剧、面色苍白、神疲乏力、舌淡脉细弱，但本案例中肝阳、痰瘀等标实症状（血压高、苔黄腻、脉弦）更为显著，属于因实致虚、虚实夹杂。
    - **提示**：本案辨证的关键在于识别 **“肝风”与“痰瘀”相互胶结** 的复杂病机，以及 **“脾虚”（本）与“肝亢、痰瘀”（标）** 的因果关系。问诊和舌脉信息需同时捕捉肝、脾、经络三个层面的异常。
