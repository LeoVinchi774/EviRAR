### 一、 模拟问诊路径（针对带下异常/赤白带下场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？白带的情况具体是怎样的？”
- **医案特征提取**：
    - **病程长短**：带下异常已持续3年，近9个月加重。
    - **核心特征**：带下“赤白相杂”（白带中混有血性分泌物），质地“稠粘”，气味“腥臭”。
    - **加重/持续因素**：症状“绵绵不断”，数月不止，提示非急性发作，而是迁延不愈的虚损状态。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉与性状焦点**：
    - **颜色**：是纯白、淡黄、深黄，还是白中带血丝、血块？颜色是鲜红、淡红还是暗红？（医案：红白相杂，状若桃红）
    - **质地**：是清稀如水，还是粘稠如涕、如脓？（医案：质稠粘）
    - **气味**：有无特殊气味？是腥味、臭味还是酸味？（医案：味腥臭）
    - **量**：量的多少？是否需要用护垫？与月经周期有无关系？（医案：量时多时少，近9个月量多）
- **伴随局部症状追问**：
    - **小腹感觉**：小腹有无疼痛？是隐痛、坠痛还是刺痛？疼痛是持续性的还是阵发性的？（医案：小腹绵绵作痛）
    - **腰骶部**：有无酸、痛、坠胀感？（医案：腰骶酸痛）
    - **外阴**：有无瘙痒、灼热感？（医案：阴痒）

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（红、淡）、舌苔颜色与厚薄（薄白、黄腻）。（医案：舌质红苔白薄）
    - **脉象**：脉位（浮、沉）、脉力（有力、无力）、脉形（细、弦）。（医案：脉沉细）
- **全身症状与体质追问**：
    - **月经情况**：月经周期是否规律？经量、经色、质地如何？有无血块？（医案：月经先后无定期，量少挟血块）
    - **精神与寒热**：是否感觉疲劳、头晕？有无手足心发热、夜间盗汗？睡眠如何？情绪是否烦躁？（医案：头晕倦怠，手足心灼热，梦多烦躁）
    - **既往诊疗史**：是否做过妇科检查（如宫颈检查）或B超？结果如何？既往接受过何种治疗，效果怎样？（医案：妇检宫颈中度糜烂，B超无异常，迭经中西医治疗效欠佳）

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个问题都做过哪些检查和治疗？效果怎么样？这次为什么来就诊/希望解决什么问题？”
- **医案特征提取**：患者虽经治疗但“效果欠佳”，提示病情复杂或辨证不准，需重新审视“虚实夹杂”的本质。就诊时机为“经后1周”，需关注带下与月经周期的关联。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在任脉、带脉**，涉及**肝、脾、肾**三脏，以肾阴亏虚为核心。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为气阴两虚（以阴虚为主），**标实**为虚火与湿热。
- **推理公式**：
    1.  **长期带下（病程3年）** + **头晕倦怠、脉沉细** → 提示气血津液耗伤，存在**气虚**与**阴液亏损**的基础。
    2.  **带下赤白、质稠粘、味腥臭** + **手足心灼热、梦多烦躁、舌红** → 提示**阴虚生内热，虚火灼伤血络**，同时兼有**湿热**下注。
    3.  **小腹绵绵作痛、腰骶酸痛** + **月经先后无定期、量少** → 提示**任带二脉不固，胞宫失养**，与肝肾亏虚密切相关。
    4.  **综合推导**：[长期带下耗气伤阴] + [虚火灼络致赤带] + [任带不固致带下不止] + [舌红、脉沉细佐证阴虚有热] → **辨证结论：气阴亏虚，任带不固，虚火灼络**。
- **鉴别要点**：
    - **与单纯湿热下注鉴别**：单纯湿热证带下多色黄、量多、质稠、气味秽臭，伴口苦、苔黄腻、脉滑数等**实热**象明显，腹痛多为胀痛或刺痛。本案虽有湿热（质稠味臭），但核心在于“绵绵”的虚象（隐痛、倦怠、脉细）和虚热（手足心热、舌红），故为**虚中夹实**。
    - **与纯虚无火鉴别**：纯气虚或阳虚带下，多色白、质清稀、无臭或腥味，伴畏寒、舌淡、脉弱。本案有热象（腥臭、灼热、烦躁、舌红），故非纯虚。
    - **与恶性病变警示**：医案强调“须首先作详细妇科检查，予以确诊”。对于赤白带下，尤其是久治不愈者，必须通过现代医学检查（如宫颈刮片、活检）排除**宫颈癌、子宫内膜癌**等恶性病变，不可仅凭症状辨证。本案妇检已排除明显占位，聚焦于“宫颈糜烂”相关的慢性炎症与功能失调。
