### 一、 模拟问诊路径（针对鼻渊/慢性鼻窦炎急性发作场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您鼻子不舒服主要是什么感觉？这种情况持续多久了？”
- **医案特征提取**：患者主诉为“反复鼻塞不通，浊涕量多”，病程长达6年，提示为慢性病程急性发作。需重点询问**发作诱因**（如本次或首次发病是否与受凉、感冒有关）、**症状特点**（鼻塞是持续性还是交替性，浊涕的颜色、质地、量）以及**既往诊断与治疗史**（如是否做过CT检查，诊断为何，用过何种药物，效果如何）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望鼻**：观察鼻腔黏膜颜色（是否充血、肿胀），鼻甲大小，鼻道内有无脓性分泌物。
    - **望咽喉**：重点观察咽后壁有无充血、淋巴滤泡增生，扁桃体有无肿大及分泌物。
- **触觉/嗅觉焦点**：
    - **触诊**：可轻压鼻窦区域（如额窦、上颌窦）检查有无压痛。
    - **闻诊**：注意患者有无口臭。
- **医案特征提取**：本例咽后壁充血、淋巴滤泡增多，提示上呼吸道存在热性病理改变；口臭为胃热或肺热上蒸之象。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：必须观察舌质颜色（红/淡）、舌苔颜色与质地（黄/白，薄/厚）。本例为“舌质红，苔薄黄”。
    - **脉诊**：需诊察脉位（浮/沉）、脉率（数/缓）、脉力。本例为“脉沉缓”。
- **关联症状追问**：
    - **热象**：有无口干、口渴（喜冷饮或热饮）、咽干咽痛。
    - **肺系症状**：有无咳嗽、咳痰（痰色、质、量），有无嗅觉减退。
    - **全身状况**：询问饮食、睡眠、二便情况以判断脾胃功能及整体气血状态。询问是否容易感冒，以判断卫外功能。
    - **既往史**：有无过敏性鼻炎、鼻息肉等其他鼻部疾病史。
- **医案特征提取**：本例有“口臭咽干，渴喜饮水”的里热伤津表现，以及“易感外邪”的肺卫不固倾向。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次症状加重是什么原因？之前治疗（如抗生素、鼻用激素等）效果怎么样？症状是持续存在还是时好时坏？”
- **医案特征提取**：患者“间断治疗效不佳”，提示病情顽固或既往治疗未完全对证。本次就诊为慢性基础上的急性发作，需明确当前是外感诱发，还是内伤因素主导。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、鼻窍**（肺开窍于鼻，邪气犯肺，上壅鼻窍）。兼涉**表（卫分）**。
- **核心病性**：**实证、热证**。以**风热外袭，肺经郁热**为核心，热邪熏蒸，津液为涕，肺气失宣，鼻窍壅塞。
- **推理公式**：
    - **[主症：反复鼻塞、浊涕量多6年，急性发作] + [兼症：口臭、咽干、渴喜饮水] + [舌脉：舌红苔薄黄，脉沉缓] → 辨证结论：风热犯表，肺失宣降，邪热熏蒸鼻窍。**
    - **分步推导**：
        1.  **辨病**：以鼻流浊涕为主症，诊断为“鼻渊”。
        2.  **辨病程与诱因**：慢性病史，急性发作，起于“受凉”，提示外邪诱发，病位在表在肺。
        3.  **辨病性（寒热）**：“浊涕”、“口臭”、“咽干渴饮”、“舌红苔黄”等一系列症状，均指向**热邪**为患。
        4.  **辨病邪与病机**：结合起病诱因（受凉后化热）和热象，病邪为**风热**。风热犯肺，肺失宣降，津液输布失常，炼液为浊涕；肺热上蒸，故口臭咽干；热伤津液，故渴喜饮水。脉沉缓提示热邪虽盛，但未完全浮越于表，或兼有湿滞。
        5.  **综合辨证**：病机链条为**风热外袭 → 肺卫失宣 → 肺经郁热 → 上熏鼻窍 → 津凝为浊涕**。故证型为“风热犯表，肺失宣降，邪扰清空，熏蒸鼻窍证”。
- **鉴别要点**：
    - **与风寒犯肺鼻渊鉴别**：风寒证多见清稀涕、畏寒重、发热轻、舌淡苔白、脉浮紧。本例涕浊、口渴、舌红苔黄，显然为热象。
    - **与胆腑郁热鼻渊鉴别**：胆热证常伴头痛剧烈、烦躁口苦、耳鸣、脉弦数等肝胆火旺之象。本例以肺经症状（咽干、渴饮）和表证背景为主，肝胆症状不显。
    - **与脾胃湿热鼻渊鉴别**：脾胃湿热证多见涕黄量多如脓、脘腹胀满、纳呆、苔黄腻。本例纳食如常，二便调，苔薄黄而非腻，热象主要在肺，湿象不著。
    - **与肺脾气虚鼻渊鉴别**：虚证鼻渊病程更长，涕清或粘白，遇风冷加重，伴气短乏力、易感冒、舌淡脉弱。本例虽有“易感外邪”的虚象苗头，但当前以“浊涕、口臭、舌红”等实热证为主，属本虚（肺卫不固）标实（风热郁肺）。治疗当先治其标，清热透邪。
