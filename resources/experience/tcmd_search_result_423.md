### 一、 模拟问诊路径（针对肺胀/慢性咳喘心悸水肿场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：您这次主要因为哪里不舒服来看病？这个咳嗽、喘、心慌的毛病有多久了？是怎么一步步发展过来的？
- **医案特征提取**：病程长达6年，呈进行性加重（咳喘→心悸→水肿）。易感外邪，感邪即发，是病情反复和加重的重要诱因。动则气喘、心悸加剧是心肺功能严重受损的标志。

**第二层：局部体征细查（望诊/闻诊/切诊导向）**
- **视觉焦点**：
    - **望神**：精神萎靡或疲惫状态。
    - **望色**：面色是否虚浮、晦暗？口唇、指甲有无青紫（发绀）？
    - **望形**：胸廓形态是否异常（如桶状胸）？呼吸时有无张口抬肩、鼻翼煽动？双下肢有无水肿？
- **闻诊焦点**：
    - **听声音**：咳嗽声音是重浊还是无力？有无喉间痰鸣？呼吸声是否急促、浅快？
    - **闻气味**：痰液有无特殊腥臭味？（本案痰白稀，但若化热可有腥味）
- **触觉焦点**：
    - **切诊（按诊）**：下肢水肿处按压后凹陷是否不易恢复（按之凹陷）？胸廓叩诊音是否过清？
    - **医案特征提取**：桶状胸、叩诊过清音（肺气肿体征）；下肢凹陷性水肿（水饮内停）；口唇发绀（痰瘀阻络）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查症状追问**：
    - **痰**：痰的量是多还是少？颜色是白是黄？质地是稀是稠？是否容易咳出？（本案：量多、色白、质稀、泡沫状）
    - **胸**：是否感觉胸闷、胸痛？疼痛部位固定吗？会不会牵拉到后背？（本案：胸闷如窒、胸痛牵背）
    - **心**：平时有心慌、心悸的感觉吗？在什么情况下会加重？（本案：心悸，动则尤甚）
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/红/暗/紫）？舌体胖瘦？有无瘀点瘀斑？苔的颜色、厚薄、润燥？（本案：舌暗红，苔腻微黄）
    - **脉诊**：脉象的力度（有力/无力）、速度（迟/数）、形态（沉/浮、细/洪）？（本案：脉沉细弱）
- **关联病史追问**：既往是否有长期的“老慢支”、哮喘病史？是否做过相关检查（如CT、肺功能、心脏彩超）？诊断结果是什么？本次发病前有无感冒、受凉等诱因？

**第四层：治疗经过与转归判断**
- **关键提问**：这次发病后，有没有在其他地方看过？用过什么药（中药或西药）？效果怎么样？您希望通过这次治疗，主要解决什么问题？（如：减轻咳喘、消除水肿、改善心慌）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、脾、心**。病位首在肺，久病及脾，进而累及于心。病理产物（痰、瘀、水）壅滞于肺，是核心病所。
- **核心病性**：**本虚标实**。
    - **本虚**：以**肺脾气虚**为根本，后期可兼**心阳虚**。
    - **标实**：以**痰浊、血瘀、水饮**壅阻为标，本案痰浊已有轻微化热之象（苔微黄）。
- **推理公式**：
    1.  **久病咳喘 + 痰多稀白 + 易感外邪 + 脉弱** → 推导出 **肺脾气虚，卫外不固** 之本。
    2.  **痰多稀白 + 胸闷气喘 + 苔腻** → 推导出 **痰浊壅肺，肺失宣降** 之标。
    3.  **心悸 + 胸痛牵背 + 面唇发绀 + 舌暗** → 推导出 **心脉痹阻，痰瘀互结**（由肺及心，气虚致瘀）。
    4.  **下肢水肿 + 按之凹陷** → 推导出 **阳虚水停**（肺脾虚及心阳，气不化水）。
    5.  **舌暗红 + 苔腻微黄** → 综合提示 **正虚痰瘀内阻，兼有郁而化热** 之机。
    - **综合结论**：**肺胀（肺脾气虚，痰浊壅肺，兼心脉瘀阻，水饮内停）**。
- **鉴别要点**：
    1.  **与单纯哮病鉴别**：哮病发作时喉中哮鸣有声，呼吸急促困难，但缓解后如常人。本案为肺胀，病程长，有胸廓形变（桶状胸）和心悸水肿等脏器受损表现，缓解期亦有症状，属不可逆性病变。
    2.  **与胸痹（真心痛）鉴别**：两者均有胸痛。胸痹心痛多以心胸部位憋闷、绞痛为主，痛引肩背或左臂内侧，常于劳累、饱食、情绪激动后突发。本案胸痛与咳喘、痰多密切相关，是肺病及心、痰瘀痹阻所致，属于**肺心病**范畴的胸痛，其根本在肺。
    3.  **痰浊属性鉴别（寒痰/热痰/湿痰）**：本案痰色白质稀呈泡沫状，主体为**寒痰/湿痰**。但苔现微黄，提示部分痰浊有郁而化热趋势，属 **“寒热错杂”** ，但以寒湿为本，郁热为轻。问诊需仔细区分痰色、质、量的动态变化。
