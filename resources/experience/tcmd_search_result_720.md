### 一、 模拟问诊路径（针对胸痹/心悸场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请问您主要哪里不舒服？什么时候开始的？是怎么引起的？”
- **医案特征提取**：
    - **病程**：发病1年，起于感冒后月余。
    - **核心症状**：左胸刺痛、心悸、气短。
    - **加重因素**：劳累后加重。
    - **特殊时间规律**：心悸、胸闷常在半夜子时（23:00-1:00）后发作，导致惊醒。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - 面色：是否苍白无华（面色晄白）。
    - 形体：是否消瘦。
    - 精神状态：是否萎靡。
- **触觉焦点**：
    - 四肢温度：是否发凉（形寒肢冷）。
- **医案特征提取**：面色晄白、形体消瘦、形寒肢冷。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡）、舌苔（薄）。
    - **脉象**：脉的力度、速度、节律（沉细无力，时见代脉/结代脉）。
- **关联症状追问**：
    - 睡眠：是否多梦、易醒？醒后能否再入睡？
    - 饮食：胃口如何？是否不想喝水（纳呆不饮）？
    - 体力：是否容易疲劳、气短乏力？
    - 既往史：近期或发病前有无外感病史？
    - 治疗史：是否服用过西药（如心律平）？效果及依赖性如何？

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过什么检查？西医诊断是什么？用过什么药？效果怎么样？”
- **医案特征提取**：西医诊断为“冠状动脉供血不足，频发室性早搏”，长期依赖“心律平”控制，但根本症状未愈。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**。病位在心，涉及心之气血阴阳。
- **核心病性**：**本虚标实，以虚为主**。
    - **虚**：气阴两虚（气短、乏力、消瘦、舌淡），心阳不振（形寒肢冷、脉沉无力）。
    - **实/标**：心脉瘀阻（左胸刺痛）、心神不宁（夜寐多梦、心悸惊醒）。
- **推理公式**：
    - **[主症：左胸刺痛、心悸、劳后尤甚]** + **[全身体征：气短乏力、消瘦、形寒肢冷]** + **[舌脉：舌淡苔薄、脉沉细无力时见代脉]** → **辨证结论：气阴两虚，心阳不振**。
    - **推导链条**：
        1.  **起病诱因**：感冒后发病 → 外邪耗伤气阴。
        2.  **心阴亏虚**：阴不制阳，虚阳浮越，扰动心神 → 夜寐多梦、心悸惊醒（子时后阴尽阳生，更易扰动）。
        3.  **心气（阳）不足**：
            - 鼓动无力，心脉失养，血行不畅 → 左胸刺痛、脉沉细无力。
            - 气虚失于固摄，心脉运行不续 → 脉见“代”象（早搏）。
            - 阳气虚不能温煦 → 形寒肢冷。
        4.  **气血生化不足**：气阴两虚，脾胃失养 → 纳呆不饮、形体消瘦、面色晄白。
- **鉴别要点**：
    - **与单纯心阳不振鉴别**：单纯心阳不振以畏寒肢冷、胸痛遇冷加重、舌淡胖、脉沉迟或微细为主，**少有明显的心悸惊醒、多梦等阴血亏虚、虚火扰神之象**。本案兼有气短乏力（气虚）、夜寐多梦（阴虚），故为气阴两虚兼心阳不振。
    - **与心血瘀阻实证鉴别**：心血瘀阻实证以胸痛如刺、痛处固定、入夜尤甚、舌质紫暗有瘀斑、脉涩为主，**全身虚象（气短、乏力、形寒）不显**。本案虽有刺痛，但伴随一系列气、阴、阳虚损之象，瘀血为气虚推动无力所致，属因虚致瘀，治疗需以补虚为主，兼以通脉。
