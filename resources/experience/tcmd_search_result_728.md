### 一、 模拟问诊路径（针对胸闷胸痛/胸痹场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您胸口具体哪个位置不舒服？是闷、是痛还是两者都有？这种不舒服持续多久了？什么时候最容易发作或加重？”
- **医案特征提取**：病程1个月有余，时轻时重。加重因素：精神压力大（高考复习）、劳累（过劳）、吸气时加重。既往有胃病史。

**第二层：局部体征细查（问诊/切诊导向）**
- **症状焦点**：
    - **疼痛性质**：心前区疼痛的具体性质（刺痛、闷痛、隐痛？）。
    - **胸闷特点**：是否与呼吸、情绪、饱食有关？吸气时是否加重（医案已提示）？
    - **心悸心慌**：发作的频率、持续时间及诱因。
- **医案特征提取**：心前区疼痛、胸闷、气短、心慌，且吸气时加重。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身症状追问**：
    - **精神与体力**：是否感觉疲倦乏力、精神不振、头昏沉？
    - **脾胃运化**：饮食胃口如何？是否有胃脘或腹部胀满？大便的性状（稀溏、黏腻、成形？）？
    - **肢体感觉**：是否感觉四肢或身体沉重？
- **必查舌脉**：
    - **舌象**：舌质颜色（淡/红/暗/紫？）、舌体形态（胖大、瘦薄？有无齿痕？）、舌苔（颜色、厚薄、润燥、腻腐？）。**医案关键**：舌质暗淡，舌体胖大、边有齿痕，舌苔白腻。
    - **脉象**：脉的位、数、形、势。**医案关键**：脉弦滑。
- **关联病史追问**：平素饮食习惯（是否喜食生冷肥甘？）、脾胃功能状况（长期胃病史）、近期精神压力与劳累情况。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过哪些检查（如心电图）？结果如何？用过什么药（中药或西药）？效果怎么样？”
- **医案特征提取**：心电图提示二尖瓣关闭不全。曾服用心血管相关中成药（复方丹参片等）及营养心肌药（肌苷片），但病情时轻时重，疗效不佳。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、脾（胃）**。病位在心（心胸），病根在脾（脾胃虚弱，运化失司）。
- **核心病性**：**本虚标实**。**本虚**为脾胃气虚、脾阳不运；**标实**为痰浊内盛、气机郁滞、兼有血瘀。病性属**阴、里**，痰浊为患，性偏**寒湿**。
- **推理公式**：
    1.  **[主症：胸闷、胸痛、气短] + [全身症状：体倦无力、四肢沉重、头昏沉、精神不振] + [脾胃症状：脘腹胀满、饮食量小、大便稀溏] → 推导出“脾虚湿困、清阳不升”**。
    2.  **[舌象：舌质暗淡（气血不畅）、舌体胖大边有齿痕（脾虚湿盛）、苔白腻（痰湿内停）] + [脉象：弦（主气滞、痰饮）、滑（主痰湿）] → 印证并强化“痰浊内盛、气机阻滞”**。
    3.  **[病史：素有胃病、饮食不佳（脾虚基础）] + [诱因：精神压力大、过劳（耗伤脾气）] → 明确病因病机为“脾胃虚弱，运化失司，聚湿生痰”**。
    4.  **综合以上：脾虚生湿酿痰 → 痰浊上犯心胸 → 痹阻胸阳，阻滞心脉 → 发为胸痹（痰浊内盛证）**。
- **鉴别要点**：
    - **与心血瘀阻证鉴别**：两者均有胸痛。心血瘀阻证疼痛多为**刺痛、固定不移**，舌质**紫暗或有瘀斑**，脉**涩**。本案虽有“舌质暗淡”提示轻度血行不畅，但核心体征是**苔白腻、脉滑、体倦沉重、便溏**等一派痰湿之象，瘀血为次。
    - **与心气（阳）虚证鉴别**：两者均有气短、乏力。心气（阳）虚证多见**心悸怔忡、自汗、面色㿠白、舌淡苔白、脉弱或结代**，痰湿、气滞的实证表现不突出。本案脘腹胀满、苔腻、脉弦滑等实证明显，属虚实夹杂，以痰浊标实为主。
    - **与肝气郁结证鉴别**：两者均可因情志诱发，有胸闷、脉弦。肝气郁结证胸胁胀痛走窜，善太息，与情绪波动关系更密切，常伴咽部异物感，**少有明显痰湿（苔腻、体沉、便溏）及脾虚表现**。本案病机核心在脾生痰湿，上蒙心胸，非单纯肝郁。
