### 一、 模拟问诊路径（针对崩漏/异常子宫出血场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次阴道流血是什么时候开始的？具体是哪一天？出血持续多少天了？现在每天出血量怎么样，是什么颜色？”
- **医案特征提取**：患者主诉为“阴道流血27天未净”，病程较长，属“漏下”（经期延长）。需重点询问出血的起始时间（Lmp：2017年7月17日）、持续时间（27天）、当前出血量（少量）及颜色（色淡红）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察出血的颜色、质地（有无血块）、量（少量、中量、大量）。医案中为“色淡红”，提示可能兼有虚或寒。
- **触觉焦点**：询问有无小腹疼痛、坠胀感，以判断有无瘀血或气滞。医案中“无经行腹痛”，但需结合舌脉判断瘀血。
- **医案特征提取**：出血“色淡红”而非鲜红或暗红，结合“无腹痛”，初步排除实热或剧烈血瘀腹痛，但需结合舌脉“淡紫”考虑虚中夹瘀。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：必须查看舌质（颜色、瘀点）、舌苔（色、厚薄）、脉象（粗细、弦滑、迟数）。医案中为“舌淡紫，苔白，脉细弦”，是辨证的关键依据。
- **关联病史追问**：
    1.  **月经史**：“平时月经规律吗？一般多少天来一次？一次来几天？量多不多？颜色和血块情况？有没有痛经？”（医案中既往月经“7/30天，量中，色红，块少，无经行腹痛”，此为正常基线，与当前异常形成对比）。
    2.  **孕产史与避孕史**：“怀孕过几次？生过几个孩子？现在用什么方式避孕？”（医案中“G3P2，采用工具避孕”，提示有多次孕产史，可能耗伤肾气，且需排除妊娠相关出血）。
    3.  **全身症状**：“最近有没有头晕、乏力、心慌、怕冷或怕热、腰酸、睡眠、胃口、大小便怎么样？”（医案中初诊“二便调”，但二诊出现“头晕，乏力，纳眠差”，提示病程日久，气血已伤）。
    4.  **年龄与绝经情况**：“今年52岁，有没有绝经的迹象？比如月经开始不规律、潮热出汗等？”（患者处于围绝经期，肾气渐衰是崩漏的常见生理基础）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次出血之前，有没有看过医生或者吃过什么药？效果怎么样？”（医案为初诊，但后续复诊信息提示治疗反应，用于评估疗效和调整方案）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肾、冲任、胞宫**。肾为先天之本，主封藏；冲为血海，任主胞胎。患者年届七七，肾气渐衰，封藏失职，冲任不固，病位在肾与冲任。
- **核心病性**：**本虚标实，虚实夹杂**。虚为**肾虚**（阴阳两虚，偏于阳虚），实为**血瘀**。整体病性属虚中夹瘀。
- **推理公式**：
    1.  **[主症：经漏不止27天] + [出血色淡红] + [年龄52岁] → 指向肾气亏虚，封藏失职，冲任不固（虚证）**。
    2.  **[舌象：舌淡紫] → 提示气虚（淡）兼有血瘀（紫）**。苔白提示无明显热象。
    3.  **[脉象：脉细弦] → 细主气血亏虚，弦主气机不畅或疼痛，此处结合无腹痛，可能提示肝气不舒或经脉拘急，亦可见于虚证**。
    4.  **综合推导**：肾虚（封藏失司，冲任失固）为本，导致阴血不能内守而漏下；病程日久，离经之血留滞成瘀，瘀血阻滞胞宫，新血不得归经，加重出血。最终证型为：**肾虚血瘀，冲任失固**。诊断依据原文按语精准概括：“肾失封藏，冲任失调，阴血不能内守，加之瘀血阻滞，新血不能归经，故经漏不止。”
- **鉴别要点**：
    1.  **与单纯肾阴虚型崩漏鉴别**：单纯肾阴虚多见出血色红、质稠，伴五心烦热、舌红少苔、脉细数。本案出血色淡红、舌淡紫苔白，无明显热象，且方中用仙茅、巴戟等温阳药，故非单纯阴虚。
    2.  **与单纯血热型崩漏鉴别**：血热型多见出血量多、色深红或紫红、质稠，口渴烦热，舌红苔黄，脉滑数。本案无此热象，可排除。
    3.  **与脾不统血型崩漏鉴别**：脾虚型多见出血量多、色淡质稀，伴神疲乏力、面色萎黄、食少便溏，舌淡胖有齿痕，脉弱。本案初诊乏力不明显，舌淡紫而非淡胖，且病位首责于肾，故非主证。但二诊出现明显气虚症状，说明病机可转化或兼夹。
    4.  **与纯血瘀型崩漏（癥瘕等）鉴别**：纯血瘀型常伴小腹刺痛拒按，血块多且大，舌紫暗或有瘀斑，脉涩。本案“无经行腹痛”、“块少”，瘀血征象相对较轻，且与肾虚并见，故为肾虚血瘀，而非单纯血瘀实证。
