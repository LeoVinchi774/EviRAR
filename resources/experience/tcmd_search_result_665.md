### 一、 模拟问诊路径（针对肾病综合征水肿加重/腹水场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：“这次水肿加重，主要感觉哪里最不舒服？小便情况怎么样？”
- 医案特征提取：病程长达三年余，反复发作（屡消屡作）。本次因感冒诱发加重，以腹部膨大、高度腹水为突出表现，伴有严重少尿（24小时约100ml）。

**第二层：局部体征细查（望诊/切诊导向）**
- 视觉焦点：重点观察腹部形态（是否膨隆如鼓）、皮肤颜色与光泽（有无绷紧发亮）、下肢及颜面水肿程度。
- 触觉焦点：腹部叩诊（是否为移动性浊音，判断腹水）；按压胫前、足踝等部位，观察凹陷程度及恢复速度。
- 医案特征提取：高度腹水（腹膨大），水肿以腹水为重，腹胀难忍。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：舌质、舌苔（色、质、厚薄）、脉象（部位、力度、形态、速率）。本案关键为“舌苔白腻，脉象弦滑”。
- 关联病史追问：
    1.  “水肿反复发作期间，尿蛋白情况如何？”（本案提示+～++）
    2.  “最近胃口怎么样？有没有恶心、想吐的感觉？”（不能进食，恶心呕吐）
    3.  “感觉手脚心或心胸部位烦热吗？口干想不想喝水？”（五心烦热，口干舌燥）
    4.  “最近有没有怕冷、发烧、咳嗽等感冒症状？”（近二月因感冒加重）

**第四层：治疗经过与转归判断**
- 关键提问：“水肿加重后，用过哪些药？效果怎么样，停药后如何？”（本案曾用速尿，尿量稍增但停药即复发，提示单纯利尿治标不治本）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、胃、三焦（中焦为主）**。病本在脾（主运化水湿），病标在胃（受纳腐熟）、三焦（水道通调）。水肿以腹水为重，病位侧重中焦。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为脾气虚弱（运化失职）；**标实**为**湿热中阻**（湿与热结）、**气机壅滞**（升降失常）、**水饮内停**。
- **推理公式**：
    **[主症：高度腹水、严重少尿]** + **[兼症：腹胀难忍、恶心呕吐、五心烦热、口干]** + **[舌脉：苔白腻、脉弦滑]** → 辨证结论 **脾湿胃热，升降失常，湿热中阻，气滞水停**。
    - **推导步骤**：
        1.  **水肿、少尿、苔白腻** → 提示 **水湿内停**。
        2.  **水肿以腹水为重、腹胀、恶心呕吐、不能食** → 病位在 **中焦脾胃**，提示 **脾不运湿，胃不降浊，气机壅滞**。
        3.  **五心烦热、口干舌燥** → 提示 **内热** 存在。
        4.  **脉弦滑** → 弦主气滞、水饮，滑主痰湿、热盛。
        5.  **综合**：水湿（苔腻）与内热（口干烦热）并见，结于中焦（腹胀呕恶），气机升降逆乱（脾不升清，胃不降浊），故辨证为 **脾湿胃热，湿热中阻，气滞水停**。
- **鉴别要点**：
    - **与单纯脾肾阳虚水泛证鉴别**：后者多见全身浮肿、腰膝酸冷、畏寒肢凉、小便清长或短少但色清、舌淡胖苔白滑、脉沉迟。本案有“五心烦热、口干”等热象，脉弦滑而非沉迟，故可排除。
    - **与湿热下注膀胱证鉴别**：后者水肿以下肢为甚，伴小便频急、灼热、涩痛，舌红苔黄腻，脉滑数。本案水肿以腹水为重心，伴明显脾胃升降失常症状（腹胀、呕恶、不食），病位偏中上焦，故不同。
