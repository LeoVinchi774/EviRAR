### 一、 模拟问诊路径（针对崩漏/月经不调场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次月经是什么时候开始的？和以前相比，量、色、质有什么不同？持续多少天了？”
- **医案特征提取**：患者主诉“月经不规律半年，量时多时少，周期不定”，提示病程较长，为慢性、反复发作的月经失调。近1周“血量增加如崩”，提示病情急性加重，进入“崩中”阶段。问诊需明确“不规律”的具体表现（周期提前、延后、或先后无定期）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：**经血颜色**（鲜红、淡红、暗红、紫黑）、**质地**（有无血块、血块大小与颜色）、**经量**（需量化，如日用卫生巾数量、有无大血块涌出）。
- **触觉焦点**：**腹痛性质**（胀痛、刺痛、冷痛、隐痛、喜按拒按）、**腰骶部感觉**（酸痛、空坠感、冷感）。
- **医案特征提取**：本例“色鲜红，有血块，腹不痛，腰酸”。其中“色鲜红”提示有热象；“有血块”提示有瘀，但“腹不痛”说明瘀滞不重，可能为离经之血；“腰酸”是肾虚的典型定位症状。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质**（红、淡、紫暗）、**舌苔**（薄、厚、白、黄、腻）、**脉象**（沉、细、数、滑、弦）。本例为“舌红，苔薄白，脉沉细数”，是阴虚内热、精血不足的关键证据。
- **关联病史追问**：1. **年龄与生育史**（“年过六七”即42岁以上，肝肾渐衰；有无流产、生产史）。2. **既往病史**（如医案中“慢性肾炎、子宫肌瘤”，需问清诊断时间、治疗情况，以评估肾气与胞宫状况）。3. **全身伴随症状**（如头晕耳鸣、心悸失眠、五心烦热、口干、气短乏力、畏寒肢冷等，本例“食眠尚可”为阴性排除信息）。4. **诱因**（有无近期劳累、情绪波动、外感等）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这半年月经不调，有没有看过医生或吃过药？效果怎么样？”（了解既往诊疗史及对药物的反应，为本次辨证用药提供参考）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、肾**（藏血、主生殖、系冲任之本）；**冲脉、任脉**（血海、阴脉之海，主月经）；**胞宫**（病位之标）。
- **核心病性**：**本虚标实**。**本虚**为**肝肾阴血亏虚**（虚）；**标实**为**虚热内生**（热）与**离经之血成瘀**（瘀，但较轻）。总体为**阴虚内热，冲任不固**。
- **推理公式**：
  1.  **【主症：崩漏（量多如崩）+ 经色鲜红】** → 提示有“热”象，迫血妄行。
  2.  **【伴随症：腰酸 + 年龄46岁 + 慢性肾炎病史】** → 强烈指向“肾虚”病位（腰为肾之府，年过六七肾气衰，慢性肾炎耗伤肾精）。
  3.  **【舌脉：舌红 + 脉细数】** → 佐证“阴虚内热”（舌红主热，细主阴血不足，数主热象）。
  4.  **【舌脉：脉沉】** → 提示病在里，正气不足，鼓动无力。
  5.  **【伴随症：经血有块 + 腹不痛】** → 提示有“瘀”，但非主要矛盾（有块为瘀，不痛说明非气滞血瘀之实证，可能为出血过多、离经之血暂未化尽）。
  6.  **综合推导**：**肝肾阴血不足（本虚）** → 阴不制阳，**虚热内扰（标热）** → 热扰冲任，血海不宁 → **冲任失固，经血妄行（崩漏）**。
- **辨证结论**：**肝肾不足，虚热扰动胞脉，冲任不固**。
- **鉴别要点**：
  1.  **与“实热崩漏”鉴别**：实热者多伴**面红、口干喜冷饮、便秘尿黄、舌红苔黄、脉滑数有力**，且发病急，多因外感热邪或情志化火。本例脉“沉细数”无力，兼腰酸、病史长，属虚热。
  2.  **与“脾不统血崩漏”鉴别**：脾虚者多伴**面色萎黄、气短懒言、纳差便溏、舌淡苔白、脉细弱**，经色多淡红质稀。本例经色鲜红、舌红，热象明显，可排除。
  3.  **与“血瘀崩漏”鉴别**：血瘀重者**腹痛拒按，血块多且大，色紫黑，舌质紫暗有瘀点，脉涩**。本例腹不痛，瘀象不显，仅为次要兼证。
  4.  **与“肾阳虚崩漏”鉴别**：肾阳虚者多伴**畏寒肢冷、腰膝冷痛、小便清长、经色黯淡质稀、舌淡苔白、脉沉迟**。本例经色鲜红、舌红脉数，属虚热而非虚寒。
