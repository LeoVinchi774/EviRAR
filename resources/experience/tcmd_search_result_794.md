### 一、 模拟问诊路径（针对心衰、水肿、阴盛格阳危重场景）
**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次最难受的是什么？这种情况有多久了？”
- **医案特征提取**：患者主诉应为“全身浮肿、心悸气短、腹中灼热”。病程特点是“多年风心病，反复浮肿”，本次加重“2个月”，且西医常规治疗（地高辛、呋塞米）效果不佳，浮肿“消而复肿”，关键症状“腹中灼热如火燎”始终未减。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望神色**：精神是否委顿？面色是苍白、晦暗还是潮红？
    - **望形态**：全身浮肿程度，下肢是否肿甚？有无颈脉怒张（颈静脉充盈）？
    - **望局部**：下肢皮肤颜色（苍白、紫暗）？水肿按压后恢复情况（如泥、如棉）？
- **触觉焦点**：
    - **切肌肤**：下肢及腹部皮肤温度（冰凉还是灼热）？按压水肿处，是否凹陷不起（如泥）？
    - **切胸腹**：有无胸水、腹水征？
- **医案特征提取**：下肢肿甚且“冰凉”，按之“凹陷如泥”；面色“苍暗”；颈脉“怒张”；腹中自觉“灼热难当”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌体胖瘦？舌色（淡、紫、暗）？舌苔（有无、厚薄、润燥）？本案关键：舌光无苔、润、紫暗。
    - **脉诊**：脉位深浅？脉率快慢？脉力强弱？脉形有无特殊（如雀啄、屋漏、虾游等怪脉）？本案关键：六脉“虾游之象”（脉在皮肤，如虾游水，时而一跃即逝，是阳气浮越将脱的危象）。
- **关联症状追问**：
    - **寒热**：身上怕冷还是怕热？有无阵发性身热、面赤、热气上冲感？
    - **汗出**：平时易出汗吗？是自汗还是盗汗？活动后是否加重？
    - **心系症状**：心悸、胸闷、气短的程度？与活动（如行走）的关系？能否平卧？
    - **水道症状**：小便量多少？颜色？有无口渴欲饮？
    - **兼症**：有无咳嗽、咳痰？痰中是否带血？肢体有无麻木？
- **医案特征提取**：心悸气短“动则更甚，不能行走”；“两足麻木”；“腹中灼热难当，时而热气上冲则面赤、身热、头晕、自汗出”；“咳嗽痰少带血”；“口不渴，小便短少”。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为什么住院？用过哪些药？效果怎么样？为什么选择出院来看中医？”
- **医案特征提取**：明确有“风心病、心房颤动、心功能Ⅲ级”的西医诊断史；长期服用地高辛、利尿剂（呋塞米）但“浮肿消而复肿”，“腹中灼热”症状未缓解，疗效不佳是患者转求中医的核心原因。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、肾**。心主血脉，肾主水，心肾阳衰为本病根本。兼及**肺**（咳嗽、喘促）、**脾**（水湿运化）。
- **核心病性**：**本虚标实，虚实夹杂，阴阳离决之危候**。
    - **本虚**：心肾阳气极度虚衰（气阳欲脱），兼有阴液亏虚（阴阳互根，阳损及阴）。
    - **标实**：寒水停聚（全身浮肿、小便少）、血流瘀阻（舌紫暗、心悸）、虚阳浮越（格阳于上/于外）。
- **推理公式**：
    1.  **[全身浮肿、下肢冰凉、按之如泥] + [心悸气短、动则甚] + [小便短少、口不渴] + [舌润紫暗] → 推导出：心肾阳气大虚，水湿内停（阴寒内盛）。**
    2.  **[腹中灼热如火燎] + [阵发性面赤、身热、头晕、自汗] + [咳血] → 推导出：虚阳被阴寒格拒，浮越于上/外（格阳证）。** 此组“热象”与第一组的“寒象”形成尖锐矛盾，是辨证关键。
    3.  **[舌光无苔] + [虾游脉] → 推导出：阳气浮越将脱，阴液亦亏，气阴大虚，脉气不续。**
    4.  **综合1、2、3 → 最终辨证结论：阴盛格阳，气阳欲脱，寒水停聚，血瘀络阻（虚阳浮越）。** 此为真寒假热、阳气外越的危重证候。
- **鉴别要点**：
    - **与实热证鉴别**：实热证之身热、面赤、咳血多伴口渴喜冷饮、小便黄赤、舌红苔黄、脉数有力。本案虽见“热象”，但伴随一系列**阳虚阴盛**之象（口不渴、尿清短、肢厥、舌润不干、脉象危殆），故非实热。
    - **与单纯阳虚水泛证鉴别**：单纯阳虚水泛可见水肿、畏寒、肢冷、心悸、小便不利，但**不会出现明显的“热象”**（如腹中灼热、面赤身热）。本案出现格拒之“热象”，提示阳虚更甚，已达阴阳离决之边缘，病势更险。
    - **“虾游脉”的警示**：此脉象是气阴将绝、虚阳躁动之危象，是判断病情凶险、急需回阳固脱的关键指征，需与常见的细弱脉、结代脉严格区分。
