### 一、 模拟问诊路径（针对慢性前列腺炎合并不育场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次来主要是哪里不舒服？这种情况有多久了？”（引导患者说出“不育”主诉及“前列腺炎”病史）
- **医案特征提取**：已婚4年未育（核心诉求），慢性前列腺炎病史8年，时有发作（病程长，反复发作）。

**第二层：局部体征细查（问诊/切诊导向）**
- **问诊焦点（排尿与局部症状）**：
    - “排尿时或排尿后有什么异常感觉吗？比如疼痛、灼热、或者有没有东西流出来？”（捕获尿道不适、终末滴白）
    - “小腹、会阴、睾丸这些地方感觉怎么样？是胀、是痛、是冷还是热？疼痛在什么情况下会加重或减轻？”（捕获坠胀冷痛、得温痛减）
- **医案特征提取**：尿道不适、终末乳白色分泌物（湿热下注）；小腹、会阴、睾丸坠胀冷痛，得温痛减（寒凝气滞，肾阳亏虚）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身症状与体质追问**：
    - “平时怕冷吗？手脚凉不凉？跟周围人比，穿衣厚薄怎么样？”（捕获畏寒肢冷，深秋即穿厚衣）
    - “腰部和膝盖感觉怎么样？有没有酸软无力？”（捕获腰膝酸软）
    - “最近睡眠怎么样？有没有遗精、早泄的情况？性欲如何？”（捕获性欲减退、遗精早泄）
    - “平时情绪怎么样？容易着急、生气或者多思多虑吗？”（捕获情志不畅、焦虑多疑）
- **必查舌脉**：
    - 舌诊：舌质（色）、舌苔（色、质、厚薄）。医案特征：**舌苔白滑**（主寒湿、痰饮）。
    - 脉诊：寸、关、尺三部脉象，重点体察脉位、脉力、脉形。医案特征：**脉沉细弦**（沉主病在里，细主气血虚或湿阻，弦主肝郁、疼痛）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前因为这个病做过哪些检查和治疗？效果怎么样？”（引导患者提供实验室检查结果及既往疗效，为辨证和预后判断提供依据）
- **医案特征提取**：前列腺液检查（白细胞升高，卵磷脂小体减少）；精液常规（精子数量、活力、畸形率异常）。这些是诊断“精浊”、“不育”及评估病情严重程度的关键客观依据。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、肾、下焦（精室、膀胱）**。肝经循行绕阴器，情志不畅影响肝之疏泄；肾主生殖、藏精，开窍于二阴；湿热瘀浊结于下焦精室。
- **核心病性**：**本虚标实，虚实夹杂**。**虚**在肾阳亏虚；**实**在肝郁气滞、湿热内蕴、瘀血阻滞。
- **推理公式**：
    1.  **[情志不畅、焦虑多疑] + [脉弦] → 肝郁气滞**
    2.  **[畏寒肢冷、腰膝酸软、会阴冷痛、得温痛减] + [舌苔白滑、脉沉细] → 肾阳亏虚，寒湿内停**
    3.  **[尿道不适、终末滴白] + [前列腺液白细胞升高] → 湿热瘀阻下焦**
    4.  **[以上1+2+3] + [已婚4年未育、精液质量差] → 肝郁、肾虚、湿热瘀互结，共同导致精室失养、精元受损（不育）**
- **鉴别要点**：
    - **单纯肾阳虚 vs 兼夹肝郁湿热**：单纯肾阳虚多见全身性畏寒、精神萎靡、阳痿滑精，但**无**明显的尿道刺激症状（滴白）、局部坠胀疼痛及焦虑情绪，舌脉多为舌淡胖、苔白、脉沉迟无力。本案兼具**畏寒与局部冷痛**、**情绪不畅**及**尿道滴白**，是鉴别关键。
    - **单纯湿热下注 vs 兼夹肾虚肝郁**：单纯湿热下注多见尿频、尿急、尿痛、尿道灼热、滴白量多色黄，舌红苔黄腻，脉滑数，**无畏寒、腰膝酸软、性功能明显减退及长期情志病史**。本案热象不显（苔白滑），且寒象（畏寒冷痛）、虚象（腰酸、性功能差）、郁象（焦虑）并见，属复合证型。
