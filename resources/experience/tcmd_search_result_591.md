### 一、 模拟问诊路径（针对胃痞/慢性萎缩性胃炎伴肠化场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最不舒服的是什么？这个情况持续多久了？什么时候会加重或减轻？”
- **医案特征提取**：主诉为“胃胀痛不适，餐后症状明显”，提示病位在胃，病性属气机不畅。病程“病延日久”，结合西医诊断“慢性萎缩性胃炎伴肠化”，提示病程长，属慢性、迁延性疾病。

**第二层：局部体征细查（望诊/问诊导向）**
- **症状焦点**：
    - **胃部症状**：胃胀/痛的性质（胀痛、刺痛、隐痛？）、具体部位、与饮食（餐后）、情绪、寒温的关系。有无反酸、烧心、嗳气、嘈杂、恶心、呕吐。
    - **腹部体征**：腹部是否柔软，有无压痛、包块。
    - **二便情况**：大便的频次、性状（干结如羊屎？）、排便是否费力；小便情况。
- **医案特征提取**：餐后胃胀痛明显（脾虚不运）、时有反酸烧心（胃气上逆）、便秘（3-5日一次，津亏或气虚推动无力）、胃寒肢冷（阳气不足）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡、红、暗、紫？）、舌体胖瘦、有无瘀点瘀斑、齿痕；舌苔颜色（白、黄）、厚薄、润燥、有无剥脱。
    - **脉诊**：脉位（浮、中、沉）、脉力（有力、无力）、脉形（弦、细、滑、涩）。
- **关联病史追问**：
    1.  **睡眠情况**：是否入睡困难、多梦、易醒、早醒？睡眠质量如何？（医案提示“睡眠差”）
    2.  **全身状况**：是否怕冷/怕热？手脚是否温暖？精神体力如何？有无口干、口苦、饮水偏好？
    3.  **既往病史**：有无肝炎、胆囊炎等肝胆系统病史？有无长期服药史（如非甾体抗炎药）？胃镜及幽门螺杆菌（Hp）检查结果如何？
- **医案特征提取**：舌暗红（提示有热、有瘀）、苔薄白（未见明显黄腻热象）、脉沉弦细（沉主里，弦主肝郁气滞或痛，细主气血虚）。有“慢性乙型病毒性肝炎多年病史”（提示肝病传脾的潜在病机）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过哪些治疗（中药、西药）？效果怎么样？这次为什么来就诊？”
- **医案特征提取**：患者为初诊，自带化验单Hp(-)、生化正常、乙肝两对半阳性。治疗目标是缓解当前症状（胃胀、反酸、便秘、失眠）并逆转或控制胃粘膜的萎缩与肠化生病理改变。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾胃**（主症为胃胀痛、便秘），兼及**肝**（脉弦、有肝病史）、**心**（睡眠差）。
- **核心病性**：**虚实夹杂，本虚标实**。
    - **虚**：气虚（餐后胀甚、脉细）、阳虚（胃寒肢冷）、阴血亏虚（便秘、舌暗红）可能。
    - **实**：气滞（胃胀、脉弦）、血瘀（舌暗红、病程久）、痰瘀互结（胃粘膜肠化、萎缩被视为微观“痰瘀”积聚）、郁热（反酸烧心）。
- **推理公式**：
    1.  **[主症 胃胀痛餐后加重] + [全身症 胃寒肢冷] + [舌脉 脉沉细]** → 指向 **脾胃气虚/阳虚**，运化无力，气机壅滞。
    2.  **[主症 反酸烧心] + [舌象 舌暗红]** → 提示 **胃气上逆，兼有郁热**。
    3.  **[兼症 便秘] + [病程 日久] + [舌象 舌暗红]** → 提示 **津液不足或气虚推动无力，久病入络致瘀**，肠道失润。
    4.  **[兼症 入睡困难多梦易醒] + [脉象 脉弦]** → 提示 **肝郁扰心，心神不宁**。
    5.  **[微观病理 萎缩、肠化] + [病程 日久] + [舌象 舌暗]** → 中医视为 **“痰瘀互结”** 于胃络的微观表现。
    6.  **综合推导**：脾胃气虚（本）→ 运化失职（气滞、生湿）→ 久病及络（血瘀）→ 与湿浊互结（痰瘀）→ 郁而化热（上逆）。同时肝病宿疾（肝郁）乘克脾土，加重气滞。最终形成 **气虚血瘀、痰瘀互结、虚实夹杂** 的复杂证型。
- **鉴别要点**：
    1.  **与单纯脾胃虚寒证鉴别**：单纯虚寒证多见舌淡胖、苔白滑、便溏、喜温喜按，热象不显。本案有反酸烧心、舌暗红，提示夹杂郁热与瘀血。
    2.  **与单纯肝胃郁热证鉴别**：单纯郁热证多见胃脘灼痛、口干口苦、舌红苔黄、脉弦数，虚寒之象不显。本案有明显胃寒肢冷、脉沉细，提示阳虚气虚为本。
    3.  **与单纯津亏便秘鉴别**：单纯津亏多见口干欲饮、舌红少苔、脉细数。本案便秘与胃寒、脉沉并见，需考虑气虚推动无力与阴津不足并存。
