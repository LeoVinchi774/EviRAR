### 一、 模拟问诊路径（针对胸痹心痛/冠心病心绞痛场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要哪里不舒服？胸闷、气短多久了？最近一个月有没有加重？”
- **医案特征提取**：主症为“胸闷、气短”，病程长达“2年”，呈“时作时止”的发作性特点，近“月余”有加重趋势。需重点询问发作的诱因（如劳累、情绪、饱食）、持续时间、缓解方式（如休息、服药）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者“形体”是否“肥胖”。观察面色、口唇颜色（有无紫暗）。
- **触觉焦点**：重点在于脉诊。医案中脉象为“沉缓”。需体会脉位、脉率、脉力及有无涩象。
- **医案特征提取**：“形体肥胖”、“脉沉缓”。此环节重点在于获取舌脉信息，为辨证提供客观依据。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：必须详细记录“舌色”（淡红）、“苔色与苔质”（白腻）。脉象需记录“脉位”（沉）、“脉率”（缓）。
- **关联病史追问**：
    1.  既往史：“是否有高血压、糖尿病病史？控制情况如何？”（医案已提示，需确认年限及用药）。
    2.  个人史：“长期吸烟、饮酒吗？具体量和年限？”（医案已提示，需量化）。
    3.  饮食习惯：“平时饮食偏好如何？是否嗜食肥甘厚味、生冷油腻？”（从“饮食不节”逆推）。
    4.  伴随症状：“除了胸闷气短，是否感觉全身乏力？”“胃部有没有不舒服，比如嘈杂、反酸、烧心、胀满？”（从“胃脘嘈杂、烧心反酸”逆推，挖掘脾胃症状）。
    5.  二便与睡眠：“大小便、睡眠情况如何？”（医案中“饮食、二便如常，眠可”，但问诊时必须常规确认）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过什么检查？（如心电图、冠脉造影）结果如何？”“是否做过介入治疗（如支架）或服用过什么药物（中药、西药）？效果怎么样？”“这次为什么来寻求中医治疗？”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症胸闷、气短，病位在心脉）。关联**脾（胃）** （伴随胃脘症状、形体肥胖、苔腻，提示脾失健运，痰湿内生）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**气虚**（乏力、气短）。
    - **标实**：**痰浊**（苔白腻、形体肥胖）、**血瘀**（胸闷、冠脉狭窄病史）、**郁热**（胃脘嘈杂、烧心反酸，为痰瘀日久化热之象）。
- **推理公式**：
    1.  **[胸闷、气短（时作时止）] + [冠脉狭窄病史] → 初步定位“心脉痹阻”。**
    2.  **[乏力、气短] + [舌淡红] → 提示“气虚”基础。**
    3.  **[形体肥胖] + [苔白腻] + [脉缓] → 提示“痰湿内盛”。**
    4.  **综合“气虚”与“痰湿”：气虚推动无力，津液不布，聚湿成痰 → 形成“气虚痰阻”。**
    5.  **“气虚痰阻” + [心脉痹阻] + [脉沉（主里）] → 气不行血，痰阻脉道，导致“血瘀”。**
    6.  **[胃脘嘈杂、烧心反酸] → 提示痰瘀互结，蕴滞中焦，日久“化热”。**
    7.  **最终整合：气虚（本） + 痰浊 + 血瘀 + 郁热（标） → 辨证结论为“胸痹心痛（痰浊血瘀证，本虚标实，气虚痰瘀，痰瘀化热）”。**
- **鉴别要点**：
    1.  **与单纯“气滞血瘀证”鉴别**：单纯气滞血瘀常伴胸胁胀痛、善太息、脉弦，舌质紫暗或有瘀斑，但苔腻不显，无明显气虚（乏力）及化热（胃脘嘈杂）表现。本案苔腻、乏力是关键区别点。
    2.  **与“痰热互结证”鉴别**：痰热互结可见舌红苔黄腻、心烦、口干苦，热象更为显著且贯穿始终。本案热象仅局限于胃脘，且舌淡红苔白腻，热为痰瘀日久所化，属局部兼证，非主导病性。
    3.  **与“寒凝心脉证”鉴别**：寒凝则胸痛遇寒加重、形寒肢冷、舌淡苔白、脉沉紧。本案无寒象，反有化热倾向，脉沉缓而非紧。
