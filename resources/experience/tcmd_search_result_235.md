### 一、 模拟问诊路径（针对闭经场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“月经多久没来了？以前出现过这种情况吗？持续多长时间了？”
- **医案特征提取**：病程数年，反复发作；依赖外源性激素（雌激素、黄体酮）才能行经；现已停经半年。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉/问诊焦点**：
    - **经期伴随症状**：有无周期性乳房、少腹、小腹胀闷或疼痛？疼痛的性质（胀痛、刺痛）和规律如何？
    - **带下情况**：平时白带的量、色、质如何？（如：量少、色白、质稀）
- **医案特征提取**：每月有周期性乳房胀闷、少小腹胀疼；带下量少、色白、质稀。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质颜色（淡红/淡白/暗紫）、舌苔（薄白/白腻/黄腻）、脉象（细涩/弦细/沉弱）。
- **关联病史与体质追问**：
    1.  **年龄与职业**：年龄多大？从事什么工作？（如：40岁，教师，思虑可能较多）。
    2.  **情绪与压力**：平时情绪如何？是否容易抑郁、烦躁或生闷气？
    3.  **脾胃功能**：食欲、消化、大便情况如何？（为判断脾虚提供依据）。
    4.  **生育与手术史**：有无生育史、流产史或盆腔手术史？（排除器质性病变）。
- **医案特征提取**：脉细涩，苔薄白，舌质如平（正常）；患者为40岁女性，处于“五八之年”，阴气自半的生理阶段。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前为调经做过哪些治疗？效果怎么样？是否必须依赖药物（如黄体酮）才能来月经？”
- **医案特征提取**：病史明确提示“每次必用雌激素、黄体酮治疗，月经始能来潮”，属于典型的药物依赖性闭经，提示自身气血生化、疏泄功能严重失调。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、冲任二脉**。肝主疏泄，调畅气机与血海；脾为气血生化之源；冲为血海，任主胞胎。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：肝血不足，血海空虚（本）。
    - **实**：肝气郁结，疏泄失常（标）。
- **推理公式**：
    **[主症：药物依赖性闭经数年] + [体征：周期性乳胀、少腹胀痛（肝郁气滞）] + [兼症：带下量少色白质稀（脾虚湿蕴？或血海不充）] + [舌脉：脉细涩（血虚血行不畅），苔薄白，舌质平（无显著热象或瘀象）] + [年龄：40岁（“阴气自半”，精血渐亏）] → 辨证结论：肝失生发（疏泄），血海空虚。**
- **鉴别要点**：
    1.  **与单纯血虚证鉴别**：单纯血虚闭经多见面色苍白、头晕心悸、舌淡脉细弱，但**无周期性乳胀、少腹胀痛**等明显气滞症状。本案气滞（胀痛）与血虚（脉细、依赖外源激素）并存。
    2.  **与痰湿阻滞证鉴别**：痰湿闭经多见形体肥胖、带下量多粘腻、舌苔厚腻。本案带下“量少、色白、质稀”，苔薄白，不支持典型痰湿。
    3.  **与血瘀证鉴别**：血瘀闭经多见少腹刺痛拒按、舌质紫暗有瘀点、脉涩。本案舌质如平，脉虽涩但兼细，且疼痛以“胀”为主，提示气滞为先，血瘀不显（初诊时）。二诊经行有紫块，提示气血通行后，原有轻微瘀滞得以显现。
- **病理链条梳理**：
    **年龄增长，阴血渐亏（生理基础） → 肝气郁结（职业、情绪等因素），疏泄失常 → 肝“以生血气”功能减弱（《内经》），气血生化不足 → 冲任失养，血海空虚 → 月经闭止不行。** 气郁则胀（乳胀、腹胀），血虚则脉细，行涩则脉涩。治疗需**疏肝（解郁以助生发）扶脾（健脾以资化源）养血（补益以充血海）** 三者并举。
