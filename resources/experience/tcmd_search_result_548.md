### 一、 模拟问诊路径（针对溃疡性结肠炎/休息痢活动期场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您主要因为哪里不舒服来就诊？这种情况持续多久了？最近一次加重是什么时候，有什么原因吗？”
- **医案特征提取**：病程1年余，呈间断性发作，病情时轻时重。本次因“情志不遂”在6天前急性加重。提示问诊需重点挖掘**病程的反复性（休息痢特点）** 和**明确的诱发或加重因素（饮食、劳累、情绪）**。

**第二层：局部体征细查（问诊/望诊导向）**
- **核心症状追问**：
    - **大便性状与频率**：“现在一天大便几次？是水样、稀糊状还是成形？大便里有没有粘液、脓液或者鲜血？血和脓是混在一起还是分开的？”
    - **腹部感觉**：“肚子疼吗？具体在哪个位置？是隐隐作痛还是绞痛？疼的时候想不想大便？大便后疼痛能缓解吗？有没有总想拉但又拉不干净的感觉（里急后重）？”
- **医案特征提取**：黏液脓血便（湿热浊毒伤络）、日行14-15次（活动期严重度）、排便不尽感（里急后重）、时有腹痛（气机不畅，肠络不通）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身症状与体质询问**：
    - **饮食与体力**：“最近胃口怎么样？有没有口干、口苦？身上感觉没力气吗？”
    - **精神与睡眠**：“情绪怎么样，容易烦躁或发脾气吗？晚上睡眠好不好？”
    - **既往体质与习惯**：“平时饮食习惯怎么样？是不是喜欢吃油腻、辛辣、生冷的食物？（挖掘脾虚湿蕴的体质基础）”
- **必查舌脉**：
    - **舌诊**：必须观察舌色（红/暗红）、舌苔（色黄、质腻厚薄）。
    - **脉诊**：必须切诊脉象（弦、滑、数）。
- **医案特征提取**：口干口苦（湿热上蒸）、烦躁（肝郁化热或热扰心神）、周身乏力（脾虚）、食欲欠佳（脾失健运）、寐差（热扰心神或脾虚血亏）。舌暗红苔黄腻（湿热内蕴，兼有瘀滞），脉弦滑（主肝郁、主湿热）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这个病之前在医院明确诊断过吗？（如结肠镜、病理结果）都用过哪些药？（如美沙拉嗪、激素）效果怎么样？为什么这次来中医治疗？”
- **医案特征提取**：已有明确西医诊断（溃疡性结肠炎）及病理依据，曾用西药（美沙拉嗪、泼尼松）但病情控制不理想、反复发作，为寻求中西医结合或纯中医治疗而来。此信息对评估病情严重度、慢性化及制定治疗方案至关重要。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肠腑（大肠）**，与**脾、肝**关系密切。
- **核心病性**：**本虚标实，虚实夹杂**。**本虚**为**脾虚**（运化无力）；**标实**为**湿热、浊毒、瘀血**蕴结肠道。
- **推理公式**：
    1.  **[主症：黏液脓血便，日行十余次] + [舌脉：苔黄腻，脉滑] → 推导出“湿热”或“浊毒”蕴肠。**（湿热熏灼，肠络受损，血肉腐败）
    2.  **[伴随症：周身乏力、食欲欠佳] + [病史：饮食不节、病程迁延] → 推导出“脾虚”基础。**（脾主运化，脾虚则湿生，且正气不足）
    3.  **[加重因素：情志不遂] + [伴随症：烦躁、脉弦] → 关联“肝气不舒”。**（肝郁乘脾，加重脾虚；肝郁化热，助长湿热）
    4.  **[大便性状：脓血便] + [舌象：舌暗红] → 提示“瘀血”存在。**（热毒壅盛，灼伤血络，血行不畅成瘀；“久病入络”）
    5.  **综合推导**：将以上要素整合：在**脾虚**体质基础上，因饮食、情志等因素，导致**湿热**内蕴，日久与瘀血互结，酿生**浊毒**，蕴滞于**肠腑**，损伤肠络。故证型为：**脾虚湿热，浊毒蕴肠证**。
- **鉴别要点**：
    - **与“大肠湿热证”鉴别**：单纯大肠湿热证多以急性发作、泻下急迫、肛门灼热、口渴喜冷饮为特点，**脾虚**的全身症状（如长期乏力、纳差）和**病程迁延**的特点不突出。本案有明显脾虚病史和现症，属虚实夹杂。
    - **与“脾虚湿盛证”鉴别**：脾虚湿盛证多见大便溏泻、腹胀纳呆、肢体困重，但**热象**（如口苦、烦躁、舌红苔黄、脓血便）和**毒瘀**（舌暗、脓血）不明显。本案热、毒、瘀征象显著。
    - **“浊毒”概念的辨识**：当湿热瘀血胶结，病势缠绵，症状秽浊（如黏液脓血便腥臭、病情反复），单纯“湿热”不足以概括时，需考虑“浊毒”为患，治疗需在清热化湿基础上，加强**解毒、化浊、活血**之力。
