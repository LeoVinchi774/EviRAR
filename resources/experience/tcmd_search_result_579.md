### 一、 模拟问诊路径（针对便血/上消化道出血场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次主要是哪里不舒服？大便是什么颜色、什么性状？每天解几次？量多不多？”
- **医案特征提取**：病程10余天，主症为“解黑色柏油样大便，每日2-3次，量多”，提示为上消化道出血的典型表现。需重点询问起病诱因（如饮食、劳累、情绪）、出血量（与平时排便对比）及病程长短。

**第二层：局部体征细查（问诊/切诊导向）**
- **腹部问诊焦点**：“胃脘部（上腹部）疼痛吗？是哪种痛（隐痛、刺痛、胀痛）？喜按还是拒按？喜温还是喜凉？”
- **全身伴随症状追问**：“怕冷吗？手脚凉不凉？感觉累不累、有没有力气？头晕吗？恶心、想吐吗？”
- **医案特征提取**：胃脘隐痛、肢冷、乏力、无恶心、头晕。需重点鉴别疼痛性质（隐痛喜温喜按提示虚寒）及全身虚寒、气血不足表现。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡/红/紫）、舌苔（色、厚薄、润燥）；脉象（细/沉/弱/数）。
- **关联病史追问**：“以前有什么老毛病？（如慢性胃炎、肾病、血透史）”“这次出血前，用过什么药？在别的医院怎么治疗的？效果怎么样？”
- **医案特征提取**：有慢性胃炎、肾功能衰竭（定期血透）病史；外院抑酸、止血治疗效果不佳；望诊见“贫血貌”；舌淡，脉细。需系统回顾慢性病史对体质的影响及既往治疗反应。

**第四层：治疗经过与转归判断**
- **关键提问**：“为什么从上一家医院出院/转诊？家属和您对进一步检查（比如胃镜）有什么顾虑或打算？”
- **医案特征提取**：因患者高龄，家属暂不同意胃镜检查，常规西医疗效不佳后寻求中医治疗。问诊需了解患者及家属的治疗意愿与决策背景，为制定中西医结合方案提供依据。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾胃（中焦）**，涉及胃肠脉络。久病及肾，但当前出血主责在脾不统血。
- **核心病性**：**本虚标实，以虚为主**。**虚**在脾胃阳气虚弱、气血两虚；**寒**在中焦虚寒；**实**在血溢脉外（出血）。
- **推理公式**：
  1.  **主症定位**：`黑色柏油样便（远端上消化道出血）` + `胃脘隐痛` → 病位在**脾胃（中焦）**。
  2.  **病性辨寒热虚实**：
      - `胃脘隐痛` + `肢冷` + `（推断）喜温喜按` → 提示**中焦虚寒**。
      - `乏力` + `头晕` + `贫血貌` + `舌淡` + `脉细` → 提示**气血两虚**（脾为气血生化之源，出血亦致血虚）。
      - `久病（慢性胃炎、肾衰）` + `常规止血效差` + `气虚不摄之象` → 出血病机非火热迫血，而是**气虚血失统摄**。
  3.  **综合辨证**：`脾胃（中焦）病位` + `虚寒（病性）` + `气血两虚（状态）` + `血失统摄（病机）` → 辨证结论：**脾胃虚寒，血失统摄**。
- **鉴别要点**：
  - **与湿热蕴结便血鉴别**：后者多见便血鲜红或紫暗，肛门灼热，口苦，舌红苔黄腻，脉滑数。本案无热象，反见一派虚寒，可资鉴别。
  - **与脾胃气虚不摄鉴别**：两者均有气虚不摄。但本案明确伴有`肢冷`、`（推断）喜温喜按`等**阳虚生寒**之象，故辨证为“脾胃虚寒”而非单纯“脾胃气虚”，治疗上需加强温阳之力（如用桂枝、生姜）。
  - **与瘀血阻络出血鉴别**：瘀血所致出血常伴刺痛、痛处固定、舌质紫暗有瘀点瘀斑。本案为隐痛、舌淡，无典型瘀血征象，故血余炭之用意在收敛止血兼化瘀，防离经之血留瘀，而非主治瘀血。
