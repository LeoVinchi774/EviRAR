### 一、 模拟问诊路径（针对“食入即吐”场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您呕吐多久了？主要在什么时候吐？是吃完就吐吗？吐出来的是什么东西（食物、清水、酸水）？”
- **医案特征提取**：病程长（3年），近3月加重，呈“食入即吐”特点，与进食直接相关。体重下降2kg提示消耗性病程。需追问呕吐物的性状（医案未明言，但临床需问清），有无酸腐味。

**第二层：局部体征与诱因细查（问诊/望诊导向）**
- **症状关联追问**：“呕吐前或呕吐时，肚子疼不疼？肚子胀不胀？怕不怕冷？喜欢喝热的还是凉的？”（医案中无腹痛腹泻，但需明确腹部喜暖恶寒等定性信息）
- **精神情绪与生活史挖掘**：“平时容易紧张、生气或者压力大吗？学习或训练（如滑冰）紧张时会不会加重？”（医案提示“易紧张”）“从事什么运动？训练环境是否寒冷？”（医案关键：长期花样滑冰，寒邪外袭史）
- **医案特征提取**：“食入即吐”（胃气上逆），“易紧张”（肝气不舒诱因），“长期冰上运动”（寒邪外袭、内伤脾胃的独特病因）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身状态问诊**：“精神体力怎么样？感觉累吗？睡眠、大小便如何？”（医案：精神疲倦、眠安、大便偏少、小便调）
- **必查舌脉**：**舌象**（色、形、苔）：舌淡红（非红赤，热象不显），体稍胖（脾虚湿蕴之形），苔稍腻（湿浊内停）。**脉象**：脉弦（主肝郁、主痛），紧（主寒、主痛）。需重点体会弦紧并见的脉感。
- **既往治疗反馈**：“之前做过什么检查？吃过什么药（如吗丁啞）？效果怎么样？”（医案：外院诊为“浅表性胃炎”，西药及中药效差，提示病机复杂或辨证未准）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次因为什么原因觉得必须来看了？（症状加重、体重持续下降）之前治疗无效，您自己觉得可能是什么原因？（引导患者表达对寒、紧张等因素的自我觉察）”
- **医案特征提取**：因“近3月加重，体重下降”且外院治疗“效果欠佳”前来就诊，提示病情进入新阶段或需要调整治疗思路。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在肝、脾、胃**。肝经郁滞，横逆犯胃；脾胃虚寒，运化失司，胃气上逆。
- **核心病性**：**本虚标实，寒热错杂（以寒为主）**。
    - **虚**：脾胃阳气虚（久病、消瘦、舌体胖、精神疲倦）。
    - **实**：肝气郁滞（易紧张、脉弦）、寒湿内停（苔腻、脉紧）。
    - **寒**：外寒内侵（冰上运动史），内生虚寒（脾胃阳虚）。
- **推理公式**：
    1.  **【主症定位】** `食入即吐` → 提示胃气不降，反而上逆，病位在胃。
    2.  **【病因追溯】** `长期冰上运动史` + `舌淡胖、脉紧` → 推导**外寒内侵，损伤脾胃阳气**，致脾胃虚寒。
    3.  **【病机关联】** `易紧张` + `脉弦` → 推导**肝气郁结**，木郁乘土。
    4.  **【虚实辨证】** `久病（3年）` + `消瘦、精神疲倦` + `舌体稍胖` → 支持**脾胃气虚**为本。
    5.  **【湿象佐证】** `苔稍腻` + `舌体胖` → 脾虚运化不力，**湿浊内生**。
    6.  **【综合辨证】** `胃气上逆（主症）` + `脾胃虚寒（病因、舌脉）` + `肝气郁滞（情志、脉象）` = **证属肝气郁滞，脾胃虚寒**。肝郁与脾寒互为因果，共同导致胃失和降。
- **鉴别要点**：
    - **与单纯胃寒证鉴别**：单纯胃寒多见呕吐清水、喜温畏寒、脘腹冷痛、苔白滑，但**少有情志因素（易紧张）及脉弦**等肝郁表现。
    - **与肝火犯胃证鉴别**：肝火犯胃亦可见呕吐，但多伴**吞酸嘈杂、口苦、烦躁易怒、舌红苔黄、脉弦数**等热象，与本例舌淡红、脉弦紧（偏寒）不同。
    - **与食积呕吐鉴别**：食积多呕吐酸腐、脘腹胀满、吐后反舒、苔厚腻，常有暴饮暴食史，本例有食欲但食入即吐，且病程长，非单纯食积。
