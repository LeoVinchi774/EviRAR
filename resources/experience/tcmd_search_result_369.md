### 一、 模拟问诊路径（针对外感寒湿夹热证/感冒场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您哪里最不舒服？这种情况持续多久了？”（引导出主诉：恶寒发热、全身酸痛、头痛项强）
- **医案特征提取**：病程6天（属急性外感病），主症为恶寒发热、全身酸痛、头痛项强，提示表证、经络不通。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望神色**：观察患者是否精神困倦、面色是否偏白或晦滞。
    - **望痰涕**：观察咯痰的色（白）、质（稀/稠）、量（少）。
- **触觉焦点**：
    - **切脉**：重点体会脉象是浮（主表）是沉，是滑（主湿/痰）是紧（主寒）。
    - **问汗**：主动询问并确认“身上有汗吗？”（本案关键：无汗，提示腠理闭塞，寒邪束表）。
- **医案特征提取**：无汗、全身酸痛、咯少量白痰、脉浮滑。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：“请伸舌头。”观察舌质（淡红）、舌苔（色白、厚薄、润燥）。
    - **脉诊**：仔细体察脉位（浮）、脉形（滑）。
- **关联症状追问**（围绕寒、湿、热三个病理要素展开）：
    1.  **辨寒热**：“怕冷和发烧哪个更明显？发烧时体温感觉高吗？”（本案：恶寒发热并见，以恶寒为主）。
    2.  **辨湿邪**：“除了酸痛，身体感觉沉重吗？头感觉蒙着不清爽吗？”（可引申出身重、头重如裹等湿象）。
    3.  **辨化热**：“嘴里感觉苦吗？口渴想喝水吗？想喝凉的还是热的？”（本案：口苦微渴，提示已有化热伤津趋势）。
    4.  **辨肺气**：“咳嗽厉害吗？痰容易咳出来吗？嗓子痒不痒？”（本案：偶咳、白痰，提示肺气失宣，寒邪伤肺）。
- **医案特征提取**：口苦微渴（热象）、舌淡红苔白（表寒湿为主，热象未显于舌）、脉浮滑（表证夹湿/痰）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这六天自己用过什么药吗？比如退烧药、感冒冲剂？感觉有效果吗？”（了解前期干预，判断病邪是否入里或兼夹药误）。
- **医案特征提取**：初诊未提及既往用药，直接根据当下证候辨证。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在肌表（太阳经为主，涉及太阴经）**。恶寒发热、无汗、头痛项强为太阳经气被遏；全身酸痛为湿邪困阻经络；咳嗽咯痰为肺（太阴）失宣降。
- **核心病性**：**本虚标实，急性期以邪实为主**。邪实为**外感风寒湿邪郁表，兼有里热初起**。气血状态为卫阳被郁，经络气血运行不畅。
- **推理公式**：
    **[恶寒发热 + 无汗 + 头痛项强]** → 推导为 **风寒束表，卫阳被郁**（太阳表实证）。
    **[全身酸痛 + 脉滑]** → 叠加 **湿邪困阻经络肌肉**。
    **[口苦 + 微渴]** → 提示 **表邪已有部分化热，热郁伤津**。
    **[咳嗽 + 咯白痰 + 舌苔白]** → 佐证 **寒邪伤肺，肺气不宣**。
    **综合 [舌淡红苔白] 与 [脉浮滑]** → 印证 **表证为主，寒湿偏重，热象尚轻**。
    → **辨证结论**：**感冒（寒湿夹热证）**，即外感风寒湿邪，郁而化热。
- **鉴别要点**：
    1.  **与单纯风寒表实证（麻黄汤证）鉴别**：关键在于有无“湿”与“热”。单纯风寒证以恶寒重、发热轻、无汗、脉浮紧为特点，**无全身酸痛、口苦、脉滑等湿与热的征象**。
    2.  **与风热犯表证（银翘散证）鉴别**：风热证以发热重、恶寒轻、有汗、咽痛、舌边尖红、苔薄黄、脉浮数为特点。**本案恶寒重、无汗、苔白，热象仅见口苦微渴，故非主证**。
    3.  **与暑湿感冒鉴别**：多发夏季，必有暑邪伤气耗津之象，如身热汗出不畅、心烦口渴、小便短赤、苔黄腻等。**本案发于2月（冬春之交），无暑象**。
    4.  **与单纯里热证鉴别**：本案热象（口苦微渴）是继发于表寒湿郁闭之后，**表证（恶寒无汗）未解是其前提**，不可误判为纯里热而用寒凉清里，恐致冰伏邪气。
