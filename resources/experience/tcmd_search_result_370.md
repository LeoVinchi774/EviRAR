### 一、 模拟问诊路径（针对不寐/失眠场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的困扰是什么？从什么时候开始出现的？”
- **医案特征提取**：患者主诉为“入睡困难1周”，但病程需追溯至“1月余前患感冒发热”。问诊需明确失眠的具体表现（入睡困难、眠浅易醒）及**精确的发作或加重时间段**（本案为晚11时至凌晨5时）。

**第二层：症状特点与伴随体征细查（问诊/望诊导向）**
- **症状细节追问**：
    - **睡眠质量**：“是睡不着，还是睡不踏实、容易醒？醒后还能再入睡吗？”
    - **主观感受**：“睡不着的时候，心里是什么感觉？（如烦乱、焦虑、心慌）”
    - **伴随症状**：“除了失眠，身体还有没有其他不舒服？（如腰酸、口干、手足心热）”
- **医案特征提取**：**“似睡非睡，烦乱不安，腰酸”**。需重点询问心烦的性质（是否伴焦虑、燥热感）及腰酸的程度与性质（是空痛还是酸软）。

**第三层：全身状态与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：观察舌质颜色（红、淡）、舌苔（薄厚、颜色、润燥）。
    - **脉诊**：诊察脉象的**部位（左右手）、形态（弦、细、大）、力度**。
- **关联病史追问**：
    - **起病诱因**：“失眠出现前，有没有感冒、发烧、劳累、情绪波动或其他疾病？”
    - **全身状况**：“胃口、大小便、体力精神怎么样？（本案纳尚可、二便调）”
    - **体质倾向**：“平时怕冷还是怕热？手脚心热不热？容易口干吗？”

**第四层：治疗经过与时间规律确认**
- **关键提问**：
    - “这次失眠之前是怎么得的感冒？用过什么药？（本案：自服退烧药汗出）”
    - “失眠症状在一天之中有没有固定的加重或缓解时间？（本案：锁定“子时至寅时”）”

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、肾**（少阴经）。病机关键在于心火亢于上，肾水亏于下，心肾不交。
- **核心病性**：**虚热（阴虚火旺）**。本质为肾阴亏虚，不能上济心火，导致心火独亢，属本虚标实，以阴虚为本，火旺为标。
- **推理公式**：
    1.  **主症定位**：`[失眠（入睡困难、眠浅易醒）]` + `[特定时间规律（子时至寅时加重）]` → 提示病位与**少阴经（心肾）** 相关（依据“少阴病欲解时”理论反推为“欲剧时”）。
    2.  **病性定性**：`[心烦（烦乱不安）]` + `[舌象（舌质红）]` → 提示存在**内热（火旺）**。
    3.  **病机关联**：`[腰酸]` + `[脉象（右脉弦细）]` → 提示**肾阴亏虚**（腰为肾之府，细脉主阴血不足）。
    4.  **综合辨证**：综合以上信息，`[少阴病位]` + `[阴虚火旺病性]` + `[心肾不交病机]` → 辨证结论：**不寐（少阴热化、心肾不交证）**。
- **鉴别要点**：
    - **与少阴寒化证鉴别**：两者病位均在少阴。**热化证**以心烦、失眠、舌红、脉细数为主；**寒化证**以“但欲寐”（精神萎靡）、畏寒肢冷、小便清长、舌淡苔白、脉沉微为主。本案无心烦畏寒，而有烦乱舌红，故排除寒化。
    - **与单纯心火亢盛证鉴别**：单纯心火亢盛亦可见心烦失眠，但多无腰酸、脉细等肾阴亏虚之象，且失眠时间规律性不强。
    - **与肝火扰心证鉴别**：肝火扰心之失眠多伴急躁易怒、口苦、头痛、脉弦数有力，而本案脉象**左弦大（或有肝阳浮动）但右弦细（肾阴不足）**，且无典型肝火症状，故病机核心在心肾。
