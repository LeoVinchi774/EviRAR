### 一、 模拟问诊路径（针对系统性红斑狼疮/皮肤红斑伴发热场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的皮肤问题是什么？具体在哪些部位？伴随发热吗？”
- **医案特征提取**：主诉为“发热、面部及背部起红斑1年余”。病程长（1年余），发热为“不规则发热”，提示非外感急性发热，需重点询问发热规律（如午后、夜间）、与皮疹加重的关系。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察红斑的**形态**（是块状还是连成片状？）、**颜色**（鲜红、暗红？）、**表面特征**（有无脱屑、结痂、萎缩？本例为“表皮有皮屑脱落类似牛皮癣”）。
- **触觉焦点**：皮损处**温度**（灼热感？）、**硬度**（是否高起于皮肤？）、**疼痛或瘙痒感**。本例提及“红肿”，提示局部有热象。
- **医案特征提取**：皮损分布于**面部、背部**，呈**块状或片状红肿**，伴**脱屑**。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质、舌苔**（本例：苔薄白）、**脉象**（本例：弦细数）。此为辨证关键。
- **关联症状追问**：
    1.  **疼痛**：“除了皮肤，身体其他部位有无疼痛？具体在颈、项、背、腰吗？”（本例有颈、项、背、腰痛）。
    2.  **热象与津液**：“是否感觉口干、咽干？喜欢喝热水还是冷水？”（本例有咽干）。“头部或身体其他部位出汗情况如何？是自汗还是盗汗？”（本例头部易出汗）。
    3.  **神志与情志**：“平时情绪、睡眠如何？是否容易心烦？”（本例有心烦）。
    4.  **二便与饮食**：“大小便情况如何？胃口怎样？”（医案未提及，但问诊时必须补充，以判断里证及水湿情况）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在哪里确诊的？用过什么药（尤其是激素）？效果和反应如何？”（本例已明确诊断为“系统性红斑狼疮”，曾用激素治疗“未见明显疗效”，提示病情顽固，常规西医疗效不佳）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**少阳**（半表半里）、**肌肤**、**血分**、**水饮**。病邪郁于少阳，影响气血津液运行，外发于肌肤，内停为水饮。
- **核心病性**：**本虚标实**。**虚**在血虚、津液不足；**实**在邪郁少阳、水饮内停。整体属**半表半里之热证兼有水饮血虚**。
- **推理公式**：
    **[不规则发热] + [咽干、心烦、头汗] + [脉弦]** → 提示邪郁**少阳**，枢机不利，郁而化热。
    **[面部背部红斑、脱屑] + [颈项背腰痛] + [脉细]** → 提示**血虚**不荣，肌肤失养，兼有血分郁热或水饮阻滞经络（“血虚水盛”）。
    **综合[舌苔薄白]（未见明显热苔或厚腻苔，提示热未完全入里成实，水湿不重）与[脉数]** → 佐证有热，但非纯里实热。
    **最终辨证结论**：**邪郁少阳，血虚水盛**。
- **鉴别要点**：
    1.  **与单纯太阳表证鉴别**：虽有发热、身痛，但病程长、不规则发热、有咽干心烦等半表半里证，非单纯恶寒、脉浮之表证。
    2.  **与阳明里热鉴别**：虽有发热、红斑（热象），但无大汗、大渴、脉洪大等阳明经证，亦无腹满、便秘等阳明腑实证，舌苔亦非黄燥。
    3.  **与单纯血热发斑鉴别**：如犀角地黄汤证，多伴舌绛、斑色深红、出血倾向等热入营血之象。本例兼有脉细、身痛、苔白，提示兼有血虚与水饮，非纯热血瘀。
    4.  **“血虚水盛”与“湿热蕴结”鉴别**：后者多见舌苔黄腻、小便黄赤、带下异常等湿热下注之象。本例苔薄白、脉细，更支持血虚为本，水饮为标，热势相对不剧。
