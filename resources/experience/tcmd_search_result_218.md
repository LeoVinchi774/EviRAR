### 一、 模拟问诊路径（针对产后气血亏虚场景）

**第一层：主诉与病程锁定（必问）**
- 核心询问语句：产后多久了？目前最困扰您的几个不适是什么？（请按主次顺序说）
- 医案特征提取：产后43天（明确“新产后”阶段），主诉为乏力、虚汗、乳汁少、胃胀、关节痛、便溏等多重、复合性不适。

**第二层：局部体征细查（望诊/切诊导向）**
- 视觉焦点：
    - **望神、望色**：观察产妇精神是否萎靡，面色是否苍白或萎黄无华。
    - **望形态**：观察其坐姿、活动时是否显得疲惫无力。
    - **望局部**：观察恶露情况（已净否？量、色、质）、乳房充盈度（是否柔软不胀）、关节有无红肿变形。
- 触觉焦点：
    - **切肌肤**：触摸皮肤，感受是否潮湿多汗（自汗/盗汗？），触之是否温度偏低或正常。
    - **切腹部**：轻按胃脘部，询问有无胀满压痛。
    - **切关节**：按压疼痛关节，辨别是酸痛、冷痛还是刺痛，有无固定痛点。
- 医案特征提取：乏力、虚汗不止、乳汁稀少、胃胀、关节痛（多为酸痛，属气血亏虚，筋脉失养）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- 必查舌脉：
    - **舌诊**：舌质颜色（淡红/淡白？），舌体胖瘦（有无齿痕？），苔色与质地（薄腻/白腻/黄腻？）。
    - **脉诊**：脉象是沉、细、弱、缓？还是浮、数、滑？（本案为“脉沉”，主里证、虚证）。
- 关联病史追问：
    - **产程与出血情况**：分娩过程是否顺利？产时出血量多不多？有无大出血史？
    - **饮食与二便**：产后食欲如何？有无胃胀、反酸？大便性状是稀溏还是干燥？小便情况如何？
    - **睡眠与情绪**：睡眠质量如何？是否多梦易醒？情绪是否稳定，有无焦虑、抑郁？
    - **既往体质**：孕前及孕期体质如何？有无慢性脾胃病史或贫血史？

**第四层：治疗经过与转归判断**
- 关键提问：产后这些症状是从什么时候开始的？有没有用过什么药或做过调理？效果怎么样？

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、胃、心、肝**。病在脾胃，因气血生化之源不足；累及心肝，因血虚不养心则眠差，不养筋则关节痛，血虚气弱固摄无权则汗出。
- **核心病性**：**本虚为主，虚实夹杂**。本质为**气血两虚**（虚），兼有**脾虚湿困**（因虚致实，苔薄腻、便溏）及**中焦气机不畅**（胃胀）。
- **推理公式**：
    - **[主症：产后乏力、虚汗不止、乳汁稀少]** → 高度指向**气血亏虚**（气虚无以固表则汗出，血虚无以化乳则乳少，气血俱虚则神疲乏力）。
    - **[伴随症：胃胀、便溏] + [舌脉：舌淡红、苔薄腻、脉沉]** → 支持**脾虚失运，湿浊内停**之兼证（脾虚不运则胃胀、便溏；气血不足故舌淡，湿浊未化故苔腻；病在里且虚，故脉沉）。
    - **综合推导**：**产后（气血骤虚之特殊生理阶段）** + **气血亏虚主症群** + **脾虚湿困次症群** → **辨证结论：气血不足证（核心），兼脾虚湿蕴**。
- **鉴别要点**：
    - **与“阳虚证”鉴别**：两者均有乏力、汗出、便溏。阳虚证必有**畏寒肢冷、喜温喜按、舌淡胖嫩、脉沉迟**等明显寒象。本案关节痛但未言冷痛，舌为淡红非淡胖，脉沉未言迟，故以气血虚为主，寒象不显。
    - **与“肝郁气滞证”鉴别**：两者均可有胃胀、乳少、眠差。肝郁气滞证必有**情志抑郁、胸胁胀痛、善太息、脉弦**等气机郁结之象。本案以虚性症状（乏力、汗出、脉沉）为主，胃胀考虑脾虚气滞，非肝郁主导。
    - **提示模型**：产后病辨证，**“多虚多瘀”** 是基本背景。本案虽未见明显瘀血指征（如腹痛拒按、恶露色暗有块、舌有瘀点），但在治疗气血虚时，常需佐以轻微活血之品，使补而不滞。本案重点在于区分**纯虚无邪**与**虚中夹湿/滞**。
