### 一、 模拟问诊路径（针对蛋白尿/慢性肾炎复发场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次蛋白尿复发多久了？最早是什么时候发现的？当时是怎么发现的（比如体检、泡沫尿）？”
- **医案特征提取**：病程长达15年，近期（1月）复发。复发诱因（如感染、劳累）需追问。需明确既往诊断（如“慢性肾小球肾炎”）及治疗史。

**第二层：核心症状与体征细查（望诊/问诊导向）**
- **视觉与问诊焦点**：
    1.  **小便情况**：“小便泡沫多不多？泡沫是不是很久不散？小便颜色、量怎么样？”（对应“精微下泄”）
    2.  **全身状态**：“感觉累不累？是全身没力气，还是某个部位特别困重？这种累和活动有关系吗？”（对应“疲乏身困”）
    3.  **消化系统**：“大便怎么样？是成形还是稀的？一天几次？有没有吃完饭就想上厕所的感觉？”（对应“大便质稀”）
    4.  **睡眠情况**：“睡眠怎么样？是睡不着、容易醒，还是梦多？”（对应“眠差”）
- **医案特征提取**：泡沫尿（蛋白尿）、疲乏身困、便溏、眠差。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌体大小、颜色（淡/红/暗），舌苔厚薄、颜色（白/黄/腻），舌边有无齿痕。
    - **脉诊**：脉位（浮/沉）、脉力（有力/无力）、脉形（细/滑）。
- **关联病史追问**：“以前有没有水肿的情况？有没有腰酸、腰痛、怕冷或者怕热的感觉？饮食胃口怎么样？”（用于鉴别脾、肾两脏病位侧重及兼夹证候）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次复发后，有没有去医院检查过？查了尿常规吗？结果怎么样（几个+）？最近有没有吃过什么药？效果如何？”（获取客观检查指标，评估病情严重程度及对治疗的反应）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾**（为主），兼及于**肾**。
- **核心病性**：**虚**（脾气虚弱）、**实**（湿邪内阻）。属本虚标实，以脾虚为本，湿阻为标。
- **推理公式**：
    - **[主症A：蛋白尿（泡沫尿）]** + **[全身症状B：疲乏身困、大便质稀]** + **[舌脉C：舌淡胖苔厚边有齿痕，脉沉]** → **辨证结论 [D：脾虚湿阻证]**。
    - **推导链条**：
        1.  **疲乏身困、大便质稀** → 指向**脾**的运化、升清功能失常（脾虚失运，清阳不升，水湿下注）。
        2.  **舌淡胖、边有齿痕** → 是**脾气虚弱、水湿内停**的典型舌象。
        3.  **苔厚** → 提示有**湿浊**内蕴。
        4.  **脉沉** → 主病在里，气虚鼓动无力。
        5.  **蛋白尿（精微下泄）** → 在脾虚的背景下，可解释为**脾不升清，固摄无权**，导致水谷精微（蛋白）随尿液漏出。
        6.  **眠差** → 脾虚气血生化不足，**血不养心**所致，是脾虚的继发表现。
- **鉴别要点**：
    - **与单纯肾气不固证鉴别**：肾气不固以腰膝酸软、夜尿清长、遗精早泄等肾系症状为主，舌象多淡，但齿痕、厚苔不典型，脉多沉弱。本案脾系症状（疲乏、便溏）及舌象（齿痕、厚苔）更为突出。
    - **与湿热内蕴证鉴别**：湿热证可见小便黄赤、灼热，口干口苦，舌红苔黄腻，脉滑数。本案无热象（舌淡、苔白厚、脉沉），故排除。
    - **提示模型注意**：慢性肾炎蛋白尿常脾肾同病，需根据症状、舌脉权重判断以脾虚为主还是肾虚为主。本案脾虚湿困的证候链条完整，是辨证的关键。
