### 一、 模拟问诊路径（针对皮肤紫斑/肌衄场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您皮肤上的瘀斑（青紫块）出现多久了？主要在哪些部位？有没有什么诱因？”
- **医案特征提取**：病程2个月有余，下肢多发，面积如手掌大小。需重点询问有无外伤、感染、服药史等以排除继发性因素。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：紫斑的颜色（鲜红、紫红、紫暗）、形态（点状、片状、融合成片）、分布范围（是否对称、是否高出皮面）、有无新发或消退迹象。
- **触觉焦点**：紫斑处皮肤温度、有无压痛、有无瘙痒感。医案中提示“皮肤偶尔作痒”。
- **医案特征提取**：紫斑“下肢多发、面积如手掌”，属皮下出血，非红肿热痛，与丹毒等炎症性红斑相鉴别。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（颜色、胖瘦）、舌苔（厚薄、润燥、颜色）、脉象（沉浮、迟数、弦滑、粗细）。医案中为“舌质稍红，舌体稍胖，苔少，脉沉弦细”。
- **关联病史追问**：
    1.  **出血倾向**：除了皮肤，有无牙龈出血、鼻衄、便血、尿血？月经情况如何？（医案提示“月经量多，夹有血块”）。
    2.  **全身状况**：近期有无乏力、头晕、心慌、气短？（神疲乏力、头晕）。睡眠、情绪如何？（失眠多梦、急躁易怒）。
    3.  **汗出情况**：白天是否容易出汗（自汗）？夜间睡觉时是否出汗（盗汗）？
    4.  **消化系统**：有无恶心、干呕、食欲、二便情况？（时作干呕，纳可，二便正常）。
    5.  **既往体质**：平素身体如何？是否容易感冒、疲劳？（平素身体羸弱）。
    6.  **检查结果**：是否查过血常规？重点关注血小板、白细胞计数。（医案提示白细胞、血小板减少）。

**第四层：治疗经过与转归判断**
- **关键提问**：“出现紫斑后，有没有在其他地方看过？用过什么药（特别是西药如激素、免疫抑制剂，或中药）？效果怎么样？” 此问有助于判断病情顽固程度和治疗反应，为后续治疗方案调整提供依据。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾、肝、肾**。脾为气血生化之源，主统血；肝藏血，体阴而用阳；肾藏精，精血同源。病位以**脾**为核心。
- **核心病性**：**本虚标实，以虚为主**。**本虚**为**气阴两虚**（气虚、阴虚），**标实**为**虚火内生**及**离经之血**（血瘀）。
- **推理公式**：
    1.  **主症（皮肤紫斑）** + **体质基础（平素羸弱、神疲乏力）** + **舌脉（舌体稍胖、脉沉细）** → **推导出“气虚”**（气不摄血，血溢脉外）。
    2.  **主症（皮肤紫斑）** + **伴随症（心烦易怒、失眠多梦、自汗盗汗、月经量多）** + **舌脉（舌质稍红、苔少、脉弦）** → **推导出“阴虚火旺”**（虚火灼伤脉络，迫血妄行）。
    3.  **月经夹有血块** → **提示兼有“血瘀”**（离经之血便是瘀）。
    4.  **综合**：**气虚证** + **阴虚火旺证** + **兼夹血瘀** → **辨证结论：肌衄（气虚阴亏证）**。
- **鉴别要点**：
    1.  **与单纯血热妄行证鉴别**：单纯血热证多见于实证，紫斑颜色鲜红或深红，常伴发热、口渴、便秘、尿赤、舌红苔黄、脉数有力。本例虽有热象（心烦、舌稍红），但为虚火，且伴有明显气虚（乏力、舌胖、脉沉细）和阴虚（盗汗、苔少）之象，脉不数反沉细。
    2.  **与单纯脾不统血证鉴别**：单纯脾不统血以气虚失摄为主，紫斑色淡，伴气短、懒言、食少、便溏、舌淡胖、脉弱。本例除气虚外，还有明确的阴虚火旺症状（心烦失眠、盗汗、舌红苔少），病机更为复杂。
    3.  **与瘀血阻络证鉴别**：瘀血阻络证紫斑颜色紫暗，痛有定处，舌质紫暗或有瘀点瘀斑，脉涩。本例血块为兼证，主因是气阴两虚导致出血，出血后形成继发性血瘀，并非原发性瘀血阻络。
