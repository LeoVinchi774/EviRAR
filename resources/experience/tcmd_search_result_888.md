### 一、 模拟问诊路径（针对外伤后继发癫痫场景）

**第一层：主诉与病程锁定（必问）**
*   **核心询问语句**： “请详细描述一下您（或患者）发作时的情况？从什么时候开始发作的？发作前有没有明确的头部外伤史？”
*   **医案特征提取**： 发作时**神志不清、两目上视、四肢抽搐**，每次约**5分钟**后自行苏醒，发作频率为**一月数发**。明确的诱因是**跳跃倾跌，头部受震**。

**第二层：发作特征与诱因细查（问诊/望诊导向）**
*   **视觉焦点**： 发作时**眼神状态（上视、直视、斜视）**、**面色（发作时与平时）**、**肢体姿态（抽搐形式、有无口吐白沫、咬舌）**。
*   **问诊焦点**： 发作前有无**先兆（如头晕、幻视、幻听、腹部不适）**？发作后状态（**是否昏睡、头痛、乏力、记忆缺失**）？发作频率、持续时间有无规律？有无明确的**诱发因素（如劳累、情绪激动、睡眠不足）**？
*   **医案特征提取**： 发作时**神志不清、两目上视、四肢抽搐**，发作后**逐渐苏醒**。诱因为**明确外伤史**。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
*   **必查舌脉**： **[舌色、舌体胖瘦、瘀点瘀斑]、[苔色、苔质厚薄润燥]、[脉象（濡、滑、弦、涩、数等）]**。
*   **关联病史与体质追问**： 平时**面色、精神、体力、食欲、睡眠**如何？**形体胖瘦**？有无**头晕、头痛（部位、性质）**？外伤后有无**遗留症状（如头痛、头晕、记忆力下降）**？
*   **医案特征提取**： 平素**面色少华，形体羸弱**，提示气血不足、体质偏虚。**脉濡滑**提示痰湿内蕴，**舌苔薄黄**提示痰浊有化热趋势。

**第四层：治疗经过与转归判断**
*   **关键提问**： “之前是否在其他地方诊治过？用过什么药物或疗法？效果如何？”
*   **医案特征提取**： 本医案为初诊，未提及既往治疗史。但问诊时需明确，以评估病情顽固程度及用药参考。

### 二、 辨证诊断逻辑链（模型内部推理用）
*   **核心病位**： **脑络（心、肝）**。外伤直接损伤脑部络脉；肝主风，心主神明，风阳上扰、神明失守则发为痫证。
*   **核心病性**： **本虚标实，虚实夹杂**。**标实**为**瘀血、痰浊、风阳**；**本虚**为**气血亏虚（脾虚生化乏源）**。病性偏于**内风、痰热**。
*   **推理公式**：
    1.  **[明确外伤史] + [发作性神昏、抽搐] → 定位脑络受损，瘀血内停为发病基础。**
    2.  **[发作时两目上视、四肢抽搐] → 提示肝风内动，风阳上扰清窍。**
    3.  **[脉濡滑] + [形体羸弱、面色少华] → 提示痰浊内阻（濡滑脉），兼有气血不荣（羸弱、少华），病机涉及脾虚生痰。**
    4.  **[舌苔薄黄] → 提示痰浊有化热倾向，或风阳化热。**
    5.  **综合推导：外伤瘀血 + 内生痰浊 → 瘀浊交阻于脑络 + 肝风内动/风阳上扰 → 癫痫发作。**
*   **鉴别要点**：
    *   **与“痰火扰神”型癫痫鉴别**： 后者通常无明确外伤史，发作更剧烈，平素性情急躁，面红目赤，口苦便秘，舌红苔黄腻，脉弦滑数。本证虽有苔黄，但整体热象不著，且**有明确外伤史和瘀血指征（此为关键）**，兼有虚象。
    *   **与“心脾两虚”型癫痫鉴别**： 后者发作症状或较轻，但平素心悸健忘、神疲乏力、食少纳呆、面色无华等虚证表现非常突出，舌淡苔白，脉细弱。本证虽见面色少华、形体羸弱，但**脉象濡滑提示实邪（痰浊）仍为主要矛盾**，虚为兼夹。
    *   **与“惊痫”鉴别**： 惊痫多由惊恐诱发，小儿多见，发作时惊叫、恐惧状，平素胆怯易惊。本证**诱因为机械性外伤（震伤）**，病机核心不同。
