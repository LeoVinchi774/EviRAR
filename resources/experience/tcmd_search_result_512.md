### 一、 模拟问诊路径（针对胃脘痛/十二指肠溃疡场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您胃痛具体是什么感觉？是隐隐作痛还是胀痛？在一天中什么时候最明显？吃饭后感觉怎么样？”
- **医案特征提取**：疼痛性质为“隐痛、胀痛”，时间规律为“黎明为著”，与饮食关系为“食后痞胀不适”。提示病程较长（医案按语提及“病程较长”），需追问病程长短及反复发作情况。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者面色、神态，是否面色萎黄、精神不振。
- **触觉焦点**：重点按压中脘（上腹部正中）及周围区域，检查有无压痛、喜按还是拒按、有无包块。
- **医案特征提取**：局部体征为“中脘轻度压痛”，提示病位在胃腑，属虚中夹实，压痛不剧。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌象**：必须观察舌质颜色、舌苔颜色与分布（尤其注意舌边与舌中部的差异）。**脉象**：仔细体察脉的力度、流利度与形态。
- **关联病史追问**：1. 伴随症状：是否伴有嗳气、反酸、烧心、口干口苦、食欲、大便情况（颜色、性状）、体力状况（是否乏力）。2. 诱发与缓解因素：情绪、饮食生冷或辛辣、劳累后是否加重。3. 既往检查：是否做过胃镜、幽门螺杆菌检测，结果如何？
- **医案特征提取**：伴随症状为“嗳气，偶有泛酸，乏力”。舌脉为“舌质淡红，苔色边白、中间微黄，脉濡”。胃镜结果为关键客观依据。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发病前有没有吃过什么药（特别是西药如止痛药）？效果怎么样？之前看过中医吗，用过什么方子？”
- **医案特征提取**：本医案为初诊方案，但问诊时应了解既往治疗史，以评估病情复杂程度及对当前辨证的参考价值。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾胃**（以中焦脾胃为核心，涉及肝气疏泄）。
- **核心病性**：**本虚标实，寒热错杂**。**虚**在中气不足（脾胃气虚）；**实**在气机郁滞；**热**为郁久所化之热；局部存在“寒”象（苔边白）。
- **推理公式**：
    1.  **[主症“胃脘隐痛、胀痛，食后痞胀，乏力”] + [脉象“濡”]** → 推导出 **“中虚（脾胃气虚）”** 的病机基础。脉濡主虚、主湿，在此处契合中气不足之象。
    2.  **[症状“胀痛、嗳气”] + [局部体征“中脘压痛”]** → 推导出 **“气滞”** 的病机。气机不畅，不通则痛、则胀。
    3.  **[症状“偶有泛酸”] + [舌象“苔中间微黄”]** → 推导出 **“兼有郁热”** 的病机。气滞日久可化热，热扰胃腑则泛酸，苔中黄为热象显现。
    4.  **[舌象“苔边白”] + [病程较长（医案按语）] + [病位在脾胃]** → 提示存在 **“寒”或“湿”** 的底子，或为素体脾阳不足，或为气滞影响中焦运化而生内寒湿，形成 **“寒热互结”** 之局。
    5.  综合以上：**中虚（本） + 气滞（标） + 郁热（标） + 寒象（局部/基础）** → 辨证结论为 **“中虚气滞、兼有郁热（脾胃不和，寒热互结）”**。
- **鉴别要点**：
    1.  **与单纯脾胃虚寒证鉴别**：单纯虚寒证多见胃脘冷痛、喜温喜按、泛吐清水、舌淡苔白滑、脉沉迟，无明显胀痛、嗳气及苔黄之热象。本案虽有“苔边白”的寒象基础，但兼有气滞郁热，故属寒热错杂。
    2.  **与肝胃郁热证鉴别**：肝胃郁热证常因情志诱发，胃脘灼痛、嘈杂泛酸、口苦口干、急躁易怒、舌红苔黄、脉弦数，其“热”与“气滞”更为突出，而“中虚”之本不明显。本案“乏力、脉濡”中虚之象显著，热象相对较轻（仅苔中微黄、偶泛酸），故病机核心不同。
    3.  **与饮食积滞证鉴别**：饮食积滞多由暴饮暴食引起，症见脘腹胀满疼痛、拒按、嗳腐吞酸、厌食、舌苔厚腻，其病性纯实，病程短，无“隐痛、乏力”等虚象。
