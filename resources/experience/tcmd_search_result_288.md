### 一、 模拟问诊路径（针对胎漏/妊娠期出血场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次怀孕后，阴道出血是什么时候开始的？出血量、颜色、质地有什么变化？是持续不断还是时有时无？”
- **医案特征提取**：妊娠29天前（即孕早期）开始出血，病程已持续20余日，出血量由少渐多。有5次相似的出血流产史，提示为“滑胎”或“数堕胎”的宿疾。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察出血的颜色（医案未明言，但根据“气血虚夹寒热”可推测可能色淡或夹有血块）、腹部外形有无异常膨隆或凹陷。
- **触觉焦点**：询问并触诊少腹（小腹）疼痛的具体位置、性质（如隐痛、坠痛、冷痛）、喜按还是拒按。医案中为“轻微疼痛”，需明确其性质。
- **医案特征提取**：少腹轻微疼痛。此点需与宫外孕等急症剧烈腹痛相鉴别。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：必须观察舌质颜色（淡、红、紫暗）、舌体胖瘦、有无齿痕；苔的质地（厚薄、润燥）、颜色（白、黄、灰黑）及分布。**医案关键**：舌质淡红，苔腻且黄白夹杂。
    - **脉诊**：必须诊察脉位（浮、中、沉）、脉力（有力、无力）、脉形（细、滑、涩）。**医案关键**：脉沉弱。
- **关联病史与体质追问**：
    1.  “平时身体怎么样？容易疲劳、怕冷还是怕热？胃口、大便如何？”（探查气血阴阳及脾胃状态）
    2.  “以往的流产，都是在怀孕多久发生的？当时有什么症状？”（明确宿疾模式）
    3.  “这次怀孕前后，有没有受过外伤、情绪波动大、或过度劳累？”（探寻诱因）
    4.  “做过哪些检查？（如B超）结果如何？”（医案已提示“无器质性病变”，但问诊需确认，以排除胎停育、宫外孕等）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次出血后，用过什么药？（中药或西药）效果怎么样？”**医案特征提取**：曾服用中西药但“未能取得治疗效果”，提示病情复杂或既往辨证用药未完全切中病机。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任、胞宫**。病本在于**脾、肝、肾**（气血生化、藏血、系胎之源）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：气血两虚（胎失所养，冲任不固）。
    - **实**：寒、热、湿邪夹杂，阻滞冲任。
- **推理公式**：
    1.  **[主症：妊娠期阴道出血] + [脉象：沉弱]** → **指向“气血虚弱”**。气不摄血，血不养胎，冲任失固，故胎漏下血；脉沉主里，弱主气血不足。
    2.  **[舌苔：腻]** → **指向“湿浊内阻”**。苔腻为湿浊内停之象，湿邪阻滞气机，可影响冲任气血调和。
    3.  **[舌苔：黄白夹杂]** → **指向“寒热错杂”**。白苔主寒、主表，黄苔主热、主里，黄白相间提示体内寒热之邪交织，气机紊乱。
    4.  **[伴随症：少腹轻微疼痛]** → **支持“不通则痛”**。可由气血虚弱、运行无力所致，亦可因寒、热、湿邪阻滞冲任气血所致。
    5.  **综合推导**：气血虚弱（出血、脉弱）为发病之本；寒热湿邪（苔腻黄白）交织为致病之标。最终辨证为：**气血虚夹寒热湿证**。
- **鉴别要点**：
    1.  **与单纯肾虚胎漏鉴别**：单纯肾虚常伴腰膝酸软、头晕耳鸣、脉沉细，舌淡苔白，无明显寒热夹杂或湿浊之象（苔不腻、不黄白夹杂）。
    2.  **与血热胎漏鉴别**：血热证出血色鲜红、质粘，常伴心烦、口干、便秘、舌红苔黄，脉滑数，无明显气虚（脉不弱）及寒象（苔不白）。
    3.  **与癥瘕伤胎（如子宫肌瘤）鉴别**：需依靠辅助检查（B超）明确有无器质性病变。本医案已排除此点。
    4.  **注意**：**“舌质淡红”** 是关键信息。若舌质淡白，则血虚更重；若舌质红，则热象更显。本案舌质淡红，提示血虚与热象均未至极，处于一种夹杂状态，与苔黄白夹杂相互印证。
