### 一、 模拟问诊路径（针对肝硬化/子宫肌瘤/癥瘕场景）

**第一层：主诉与病史锁定（必问）**
- **核心询问语句**：“您最不舒服的是哪里？具体怎么个疼法？疼了多久了？”
- **医案特征提取**：
    - **主诉**：肝区（右胁肋部）疼痛，性质为胀痛或刺痛，疼痛剧烈时影响睡眠，按压后可缓解，体位改变（如侧卧）时可牵引至背部。
    - **病史**：有明确的肝病（肝炎、肝硬化、脂肪肝、肝囊肿）及妇科（子宫肌瘤）“有形”病变史，提示病程长，病势深。

**第二层：局部体征与症状细查（望闻问切导向）**
- **问诊焦点**：
    1.  **疼痛性质**：是胀痛、刺痛还是隐痛？是否随情绪波动？
    2.  **伴随症状**：有无胸闷、憋气、腹胀？有无口苦、口干、口臭？
    3.  **饮食二便**：食欲如何？有无胃脘胀满？大便次数、性状（偏干或溏）？小便量及颜色？
    4.  **睡眠与情志**：睡眠质量如何？是否多梦易醒？平时情绪如何？是否易怒、压抑？
- **医案特征提取**：
    - **症状**：肝区疼痛（气滞血瘀）、憋气（气机不畅）、口苦（肝郁化热）、食欲不佳（肝木克脾土）、大便偏干（热结或津亏）、汗少（气机郁闭）。
    - **体征（需主动检查/追问）**：腹部触诊（有无腹水、胁下痞块/肝脾肿大）、面色（是否晦暗或萎黄）。

**第三层：全身状态与体质挖掘（舌脉为核心）**
- **必查舌脉**：
    - **舌象**：舌质（暗、紫、有瘀点/斑）、舌苔（薄黄、腻、微腻）。
    - **脉象**：脉象（沉、弦、细、涩、滑）。医案二诊提示“脉势沉小，重取微弦”。
- **关联病史与体质追问**：
    - **妇科情况**：月经周期、经量、经色、有无血块、有无痛经？（女子以肝为先天）
    - **全身状况**：近期体重有无明显变化（如医案二诊体重增加提示水湿内停）？有无水肿（如胫前）？体力、精力如何？
    - **情志因素**：近期有无精神压力、情绪抑郁或焦虑？（肝主疏泄）

**第四层：治疗经过与检验指标**
- **关键提问**：
    - “之前针对肝病和肌瘤做过哪些治疗（中西医）？效果怎么样？”
    - “最近有没有复查过？比如B超、肝功能、甲胎蛋白（AFP）这些指标怎么样？”（医案中甲胎蛋白增高是重要客观指标，提示肝病活动或癌变风险，需关注）

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肝**（为主），涉及**脾、胃、冲任**。肝经布胁肋，主疏泄；肝藏血，女子经产与肝密切相关。肝硬化、子宫肌瘤均为肝经循行部位或肝所主之血分形成的“癥瘕”。
- **核心病性**：**实证为主，属本虚标实**。标实为**气滞、血瘀、痰（湿）结**；初诊兼有**郁热**。病程日久可伤及肝阴、脾气。
- **推理公式**：
    1.  **【肝区疼痛、憋气、情绪压抑】 + 【脉弦】 → 肝郁气滞**（气机不畅，不通则痛）。
    2.  **【肝硬化、子宫肌瘤（有形包块）、甲胎蛋白增高】 + 【疼痛固定、舌质暗】 → 血瘀成癥**（气滞日久，血行不畅，凝结成块）。
    3.  **【食欲不佳、腹胀、体重增加（二诊）、苔腻】 + 【脂肪肝、腹水】 → 脾虚湿困/痰湿结聚**（肝病传脾，脾失健运，水湿内停，与瘀血互结）。
    4.  **【口苦、大便偏干】 → 肝郁化热**（气郁日久化火）。
- **辨证结论整合**：**肝郁气滞，血瘀痰结**（兼有郁热）。其病理链条可概括为：**情志不遂或湿热疫毒 → 肝失疏泄（气滞） → 乘犯脾胃（湿聚） → 血行不畅（血瘀） → 气、血、痰湿互结于胁下、胞宫 → 形成癥瘕（肝硬化、肌瘤）**。
- **鉴别要点**：
    - **与单纯肝气郁结鉴别**：单纯肝气郁结以胀痛、情绪波动大、善太息为主，少有固定包块及甲胎蛋白等实验室指标异常。本案已有明确“形”变（硬化、肌瘤）和“质”变指标（AFP增高），**血瘀证**是关键鉴别点。
    - **与单纯湿热蕴结鉴别**：湿热蕴结多以黄疸、口苦黏腻、小便黄赤、舌红苔黄腻为主，腹胀多以实满为主。本案虽有口苦，但汗少、苔微腻、脉沉小，且以疼痛、包块为主症，**气滞血瘀重于湿热**。
    - **与虚证（肝脾两虚、肝肾阴虚）鉴别**：虚证疼痛多为隐痛，伴明显乏力、眩晕、腰膝酸软、舌淡或红少苔。本案初诊疼痛剧烈，二诊体重反增（水湿），脉沉小但重取弦，提示**邪实（气、血、水）仍为主要矛盾**，虚象未显或较轻。
