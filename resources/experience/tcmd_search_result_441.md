### 一、 模拟问诊路径（针对慢性咳喘、肺胀/肺心病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您咳嗽、咳痰、气喘多久了？是持续性的还是反复发作？每次发作或加重有什么诱因吗？”
- **医案特征提取**：病程长达6年，呈慢性、进行性加重。易感外邪，感邪即发，提示存在“本虚”基础。动则气喘、心悸益甚，是心肺气虚的典型表现。

**第二层：局部体征细查（望诊/闻诊/切诊导向）**
- **视觉焦点**：
    - **望神色**：观察面色、口唇颜色（如晦暗、发绀）。
    - **望形态**：观察胸廓形态（如桶状胸）、呼吸状态（如张口抬肩）、有无水肿（如面部虚浮、下肢水肿）。
    - **望痰液**：询问并观察痰的色（白/黄）、质（稀/稠）、量（多/少）、形（泡沫状/块状）。
- **听觉与触觉焦点**：
    - **闻诊**：听咳嗽声音、呼吸音（有无哮鸣音、痰鸣音）。
    - **切诊**：叩诊胸部（过清音提示肺气肿），按压下肢（有无凹陷性水肿）。
- **医案特征提取**：面色晦暗、口唇发绀（痰瘀互结）；桶状胸、叩诊过清音（肺气胀满）；痰多、色白质稀呈泡沫状（痰浊/寒饮）；下肢按之凹陷（水饮内停）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（暗红/淡红）、舌体胖瘦、苔色（白/黄）、苔质（腻/厚/薄）。
    - **脉诊**：脉位（浮/沉）、脉力（有力/无力）、脉形（细/滑）、脉率（数/迟）。
- **关联病史追问**：
    - “除了咳喘，有没有心慌、心跳不齐的感觉？活动后是不是更明显？”（探查心系受累）
    - “平时怕冷还是怕热？容易出汗吗？胃口、大便怎么样？”（探查脾肺气虚及卫表不固）
    - “胸部除了闷，有没有疼痛？疼痛的位置和性质是怎样的？”（探查胸阳痹阻、心血瘀滞）
- **医案特征提取**：舌暗红（有瘀）、苔腻微黄（痰浊兼有化热趋势）、脉沉细弱（里虚证）。伴随心悸、胸痛牵背（心脉痹阻）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前在医院做过哪些检查？诊断是什么？（如肺CT、心脏彩超）用过哪些药？效果怎么样？”（明确西医诊断与既往治疗反应，评估病情严重程度及治疗基线）。
- **医案特征提取**：外院已诊为“肺源性心脏病”，提示病程已由肺及心，进入肺胀重症阶段。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、脾、心**。病位首在肺，久病及脾，进而累及于心。肺主气司呼吸，脾主运化水湿，心主血脉。肺脾两虚为病本，痰浊、血瘀、水饮壅阻于肺、心为病标。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：肺脾气虚（久咳耗气，卫外不固，运化失职），心阳亦可能受累。
    - **标实**：痰浊壅肺、心血瘀阻、水饮内停。兼有轻微化热之象（苔微黄）。
- **推理公式**：
    1.  **[久病咳喘（>3年）] + [痰多色白质稀] + [易感外邪] + [脉弱]** → 推导出 **肺脾气虚，卫外不固，津液不布，水湿内停**。
    2.  **[胸闷如窒、胸部膨满（桶状胸）] + [咳喘、呼吸困难] + [苔腻]** → 推导出 **痰浊壅肺，肺气胀满，宣降失常**。
    3.  **[心悸、动则尤甚] + [胸痛牵背] + [面唇发绀、舌暗红]** → 推导出 **心脉痹阻，心血瘀滞**（由肺病及心，气虚推动无力，痰阻血瘀所致）。
    4.  **[双下肢水肿、按之凹陷] + [面部虚浮]** → 推导出 **水饮内停**（肺脾肾气化失常，水液泛溢肌肤）。
    5.  **[苔微黄]** → 提示 **痰浊有化热趋势**（可能因久郁或感邪所致）。
- **综合辨证结论**：**肺胀（肺脾气虚，痰浊壅肺，兼心血瘀阻，水饮内停）**。
- **鉴别要点**：
    - **与单纯痰热壅肺证鉴别**：单纯痰热证多见痰黄稠、发热、舌红苔黄腻、脉滑数，热象明显而无明显气虚、血瘀、水肿表现。本例虽有苔微黄，但痰白稀、脉沉细弱、病程久、动则加重，虚象和瘀象更为突出。
    - **与单纯心阳虚水泛证鉴别**：单纯心水证以心悸、喘促、水肿为主，咳痰可能不突出，且常伴畏寒肢冷、舌淡胖苔白滑等阳虚寒象。本例咳痰量多是核心症状，病根在肺脾，累及于心，是肺胀发展的结果。
    - **提示模型**：在肺胀（肺心病）的辨证中，需动态评估 **“痰、瘀、水、虚”** 四者的主次和兼夹关系。本例是四者俱备的典型复杂证候，治疗需 **益气固本、化痰祛瘀、泻肺利水** 多法并用。
