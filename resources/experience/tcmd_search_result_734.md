### 一、 模拟问诊路径（针对冠心病PCI术后胸痹场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次主要因为哪里不舒服来看病？这种不舒服（如胸闷、胸痛、气短）在什么情况下最容易出现或加重？比如走路、上楼、情绪激动时？”
- **医案特征提取**：患者为“PCI术后”状态，病程长（术后3年），主症为“活动后气短，伴喘息，时有心前区疼痛”，提示劳力性心绞痛，且症状与心脏供血不足直接相关。

**第二层：核心症状细查（问诊/切诊导向）**
- **胸痛/胸闷特征追问**：“胸痛具体在哪个位置？是像针刺、压榨还是闷痛？每次持续多久？含服硝酸甘油后多久能缓解？”（医案：心前区疼痛，硝酸甘油可缓解）
- **气短/喘息特征追问**：“气短到什么程度？比如走多远、上几层楼会发作？平时安静坐着时会不会喘？”（医案：活动后气短、喘息）
- **全身伴随症状追问**：“平时怕冷还是怕热？手脚凉不凉？有没有口干、口苦？胃口、睡眠、大小便怎么样？”（医案：四肢逆冷、畏寒、口干口苦、纳差、夜寐易醒、大便困难）

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：必须观察舌质颜色（是否暗、紫）、舌苔（色、厚薄、润燥），诊察脉象（部位、力度、频率、节律）。（医案：舌暗紫苔薄白，脉沉细）
- **关联病史与体质追问**：“您高血压、冠心病多少年了？平时血压控制得怎么样？目前还在服用哪些西药？”（医案：平素服用降压、抗血小板等西药，血压控制尚可）“除了心脏问题，平时肠胃功能怎么样？容易胃胀、腹胀吗？”（医案：胃胀，腹胀满）“有没有腰酸腿软、夜尿多的情况？”（为脾肾虚衰提供线索）

**第四层：治疗经过与转归判断**
- **关键提问**：“您做完支架手术后，症状是改善了还是和以前差不多？最近有没有因为症状加重去过急诊或调整过药物？”（医案：为PCI术后复诊，旨在评估术后长期状态及中医药干预的切入点）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症为胸痹）、**脾**（纳差、腹胀满）、**肾**（四肢逆冷、畏寒、年高久病）。病位在心，其本在脾肾。
- **核心病性**：**本虚标实**。
    - **本虚**：**气虚**（神疲乏力、活动后气短）、**阳虚**（四肢逆冷、畏寒）、**阴虚**（口干）。
    - **标实**：**血瘀**（心前区疼痛、舌暗紫）、**痰浊**（推断于脾虚运化失司）、**气滞**（胃胀、腹胀满）。病理产物为**痰瘀互结**。
- **推理公式**：
    1.  **[主症：活动后气短、胸痛] + [全身症状：神疲乏力、四肢逆冷] + [舌脉：脉沉细]** → 推导出 **心气（阳）虚衰，肾阳不足**（气为血帅，气虚推动无力；阳虚失于温煦）。
    2.  **[主症：胸痛（固定）] + [舌象：舌暗紫]** → 直接指向 **心脉瘀阻**（血瘀证）。
    3.  **[伴随症状：纳差、腹胀满、大便困难] + [病机推断：脾肾虚衰，水液运化失司]** → 推导出 **脾失健运，痰湿内生**（脾为生痰之源）。
    4.  综合以上：**心气（阳）虚 + 肾阳虚 + 脾虚 + 血瘀 + 痰湿** → 整合为最终证型：**气虚血瘀、脾肾虚衰，痰瘀互结**。气虚血瘀为直接表现，脾肾虚衰为根本原因，痰瘀互结为病理结果。
- **鉴别要点**：
    - **与单纯寒凝心脉证鉴别**：两者均有畏寒、四肢冷、胸痛。但本案兼有**口干口苦、纳差腹胀、大便困难**等中焦气机不畅、郁而化热伤阴之象，非纯寒证，属**寒热错杂、虚实夹杂**。
    - **与单纯气滞血瘀证鉴别**：两者均有胸痛、腹胀。但本案有明确的**神疲乏力、脉沉细**等气虚表现，以及**四肢逆冷、畏寒**等阳虚之象，虚象显著，非纯实证。
    - **提示模型**：老年PCI术后患者，辨证需**尤其重视“本虚”**（脾、肾、心气阳），标实（瘀、痰）常因虚而生。问诊时需将“乏力、怕冷、肠胃功能、二便”与“胸痛”置于同等重要地位。舌质暗紫是血瘀的关键客观指征。
