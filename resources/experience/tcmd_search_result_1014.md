### 一、 模拟问诊路径（针对复发性口腔溃疡/口糜场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您口腔溃疡反复发作多久了？这次发作有多严重？”
- **医案特征提取**：病程长达2年余，呈周期性、反复发作，近期再发3天。疼痛剧烈，多方治疗乏效，提示病情顽固。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：溃疡的形态（大小、形状、数量）、颜色（中央、周围、假膜颜色）、位置。
- **触觉/感受焦点**：疼痛的性质（灼痛、刺痛、隐痛）、程度。
- **医案特征提取**：溃疡数个、大小不一、中央凹陷、周围有红晕、表面覆黄白色假膜、伴灼痛。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌色（暗红）、舌形（裂纹、齿痕）、苔质与色（白、厚腻）；脉象（整体沉弦濡偏实，左关脉弦实）。
- **关联症状追问**：
    1.  **头面五官**：“除了口腔，有没有口干、口苦？有没有头痛（偏头痛）？”
    2.  **消化系统**：“胃口怎么样？有没有胃胀、胃满、反酸烧心？大便情况如何（干不干、稀不稀、颜色）？”
    3.  **精神与睡眠**：“睡眠好吗？情绪怎么样？”
    4.  **二便情况**：“小便颜色、量如何？”
    5.  **既往体质与病史**：“您平时身体底子怎么样（形体壮实或瘦弱）？有没有慢性病史（如慢性阻塞性肺疾病）？”
- **医案特征提取**：口干口苦、时有右侧偏头痛、胃脘痞满、大便不干、小便黄、夜寐欠佳、形体壮实、有慢性阻塞性肺疾病病史。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前用过哪些药（中药/西药）？效果怎么样？这次发作前有没有什么诱因（如饮食、劳累、情绪）？”
- **医案特征提取**：迭经中西医治疗乏效，提示常规清热泻火思路可能不效，需考虑更复杂的病机（如寒热错杂、升降失常）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**中焦脾胃**（主病位，升降失常）、**肝胆/少阳**（兼病位，郁火上炎）。
- **核心病性**：**虚实夹杂**（脾胃升降失常为本虚，湿热、郁火为标实）。**寒热错杂**（中焦寒热失调）。**病机涉及气滞、湿热、郁火、津伤**。
- **推理公式**：
    - **【主症：反复口腔溃疡伴灼痛】** + **【体征：溃疡周围红晕、覆黄白假膜】** → 提示局部有**湿热郁火**上熏于口。
    - **【全身症：胃脘痞满】** + **【舌脉：苔白稍厚腻、脉沉弦濡】** → 提示**中焦脾胃气机升降失常，湿浊内停**，形成“痞”证。
    - **【伴随症：口干口苦、小便黄】** + **【舌脉：舌暗红中裂纹、左关脉弦实】** → 提示**肝胆/少阳郁火内炽**，且**胃津已有亏耗**（裂纹）。
    - **【综合】**：局部湿热火毒 + 中焦寒热痞结 + 少阳郁火 + 胃津亏虚 → **辨证结论：中焦脾胃郁热夹湿，少阳火热内热**（即寒热错杂、湿热内蕴、郁火上炎之复合证型）。
- **鉴别要点**：
    1.  **与单纯心脾积热证鉴别**：单纯心脾积热常见溃疡鲜红、疼痛剧烈，伴心烦、口渴、便秘、舌红苔黄脉数。本案例虽有热象，但兼有**胃脘痞满、苔白厚腻、脉濡**等湿浊与气机阻滞之象，非单纯实热。
    2.  **与阴虚火旺证鉴别**：阴虚火旺常见溃疡反复、疼痛较轻、伴五心烦热、口干不欲饮、舌红少苔脉细数。本案例虽有**舌中裂纹**提示津伤，但**苔白厚腻、脉实**，湿浊与郁火标实证更突出，非纯虚证。
    3.  **与单纯脾胃虚寒证鉴别**：脾胃虚寒可见溃疡色淡、隐痛、遇冷加重，伴食少便溏、畏寒肢冷、舌淡苔白脉弱。本案例**小便黄、口干口苦、脉弦实**，热象明显，可资鉴别。
