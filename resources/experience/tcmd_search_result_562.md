### 一、 模拟问诊路径（针对慢性腹泻/泄泻场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您腹泻多久了？大便的具体情况是怎样的？是水样、稀溏还是带粘液？一天大概几次？”
- **医案特征提取**：病程长达3年，呈慢性、反复发作。腹泻与便秘（便结）交替出现。发作时腹泻次数多（日10余次），缓解期仍溏泻（日4-6次）。

**第二层：症状发作规律与诱因深挖（问诊导向）**
- **发作诱因追问**：“腹泻通常在什么情况下发作或加重？比如饮食（吃油腻、生冷后）、情绪、受凉后？”
- **腹痛特点追问**：“腹泻前是否一定腹痛？腹痛是什么性质的（绞痛、隐痛）？泻后腹痛是缓解还是依旧？”
- **医案特征提取**：初因“寒冷饥饿”诱发，后“饱食荤腥”可诱发或加重。典型“腹痛即泻，泻下急迫，泻后痛止”。发作无定时，缓解期仍有“腹中隐痛”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身伴随症状**：“除了腹泻腹痛，平时怕冷吗？手脚凉不凉？胃口怎么样？饭后容易腹胀吗？感觉乏力吗？”
- **必查舌脉**：舌质（红/淡）、舌苔（色、厚薄、润燥）；脉象（弦、缓、数、沉等）。
- **医案特征提取**：舌红苔白，脉弦缓。病程长，提示脾胃已伤，存在“中阳不振”的全身性虚寒基础（如可能存在的畏寒、乏力），但舌红又提示并非纯寒，或有郁热或阴伤。

**第四层：治疗经过与体质倾向判断**
- **关键提问**：“这三年都用过哪些药（中药或西药）？效果如何？是能完全止住，还是暂时缓解后又复发？”
- **体质与生活史**：“平时的饮食习惯如何？是否经常饮食不规律、过饥过饱？”
- **医案特征提取**：曾服“止泻药可暂安”，但“屡治不愈”，提示单纯止涩无效，病机复杂（虚中夹实）。病因明确与“寒冷饥饿”、“饥饱不均”相关，指向脾胃损伤的病史。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾胃**（运化失常）、**大肠**（传导失司）。涉及**肝**（脉弦，痛泻交作，提示肝气乘脾可能）。
- **核心病性**：**本虚标实，寒热错杂**。
    - **本虚**：**中阳（脾阳）不振**（病程长，寒、饥诱发，脉缓）。
    - **标实**：**寒湿内蕴**（苔白，脉缓，受寒诱发）、**气滞**（腹痛、脉弦）、**食积**（饱食荤腥诱发，脘腹胀）。
    - **特殊矛盾点**：长期腹泻却间或“便结”，此为“积久必滞”，湿邪与糟粕胶结，形成虚中夹实之证。舌红而非淡白，提示久泻伤阴或阳气郁而化热之可能，但苔白主寒湿仍在，故属寒热虚实夹杂之复杂局面。
- **推理公式**：
    - **[主症：慢性腹泻（3年）] + [关键特征：腹痛即泻、泻后痛止 + 腹泻与便秘交替] + [舌脉：舌红苔白、脉弦缓] + [诱因：寒、饥、饱食诱发] → 辨证结论：泄泻（中阳不振，寒湿内蕴，虚中夹实证）。**
    - **推导链**：
        1.  **久泻伤脾** → 脾阳亏虚（中阳不振），运化无力 → 水湿内停（寒湿内蕴）。
        2.  运化无力，加之饮食不节 → 食积停滞（虚中夹实）。
        3.  湿盛则泻，积滞内阻则便结 → 故见泻、结交替。
        4.  脾虚肝乘，气机失调 → 故见腹痛、脉弦。
        5.  舌红可为久泻伤阴或湿郁微热之象，但苔白、脉缓、寒诱为主，故定性仍以**中阳不振、寒湿为主**，兼夹气滞、积滞及轻微阴伤或郁热。
- **鉴别要点**：
    - **与单纯脾胃虚寒证鉴别**：单纯虚寒证多见完全不化、腹部冷痛喜温按、舌淡苔白润、脉沉迟。本案有**腹痛即泻、泻后痛止**的肝脾不调特点，有**便结交替**的积滞实证，且**舌红**，非纯虚纯寒。
    - **与肝郁脾虚（痛泻要方证）鉴别**：痛泻要方证以情绪诱发、腹痛即泻为核心。本案虽有此症，但**有明确的寒、饥、饱食等伤阳、伤食病史**，且**病程更长、虚实夹杂更甚**（便结交替），病机重心在“中阳不振，寒湿内蕴”为本，肝乘为标。
    - **与湿热泄泻鉴别**：湿热泄泻多见泻下急迫、肛门灼热、小便短赤、舌红苔黄腻。本案虽泻下急迫，但**苔白、有受寒史、脉缓**，无热象，故可排除单纯湿热。
