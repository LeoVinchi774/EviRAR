### 一、 模拟问诊路径（针对“气窜、发凉、胀痛”场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：请具体描述一下您感觉“有气乱窜”的位置、范围和感觉（是酸、胀、疼还是其他感觉）？这种情况出现多久了，最近是加重了还是减轻了？
- **医案特征提取**：病程“月余”，有明确“近日加重”的时点。起病诱因为“吹空调着凉”，提示外寒因素。症状范围从“心下（胃脘）”至“大腿根”，并向下延伸至“脚尖”，具有明确的纵向循行特征。

**第二层：局部体征细查（望诊/切诊导向）**
- **触觉焦点（患者主观感受与医者切诊结合）**：
    - **问寒热**：身体哪些部位感觉发凉？是皮肤表面凉还是感觉骨头里、深处冒凉气？（如：腰部两侧、从心下到脚尖、大脚趾）。
    - **问气感**：气窜的感觉在什么情况下会缓解或加重？（如：打嗝后可缓解，提示气逆上出则舒）。
    - **问疼痛性质**：除了气窜，具体是酸、胀还是疼？疼痛是固定的还是游走的？
- **医案特征提取**：症状以“气窜”、“发凉”为核心，伴随“酸、胀、疼”。缓解方式为“打嗝”，提示病机与“气逆”相关。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/红/紫暗），舌苔颜色与厚薄（薄白/腻/黄），舌体是否胖大、有无齿痕或抖动。
    - **脉诊**：脉位深浅（沉/浮），脉的力度与流畅度（濡/细/弦/缓）。
- **关联病史与全身状态追问**：
    - **脾胃功能**：是否有胃胀、心下堵闷、食欲不振、打嗝反酸？
    - **头部症状**：有无头痛、头晕、头部感觉异常（如发空、发蒙）？
    - **妇科与年龄特征**：对于中年女性，必须询问月经情况（周期、量、色、质），是否已绝经或处于围绝经期（“年届七七，天癸渐竭”）。
    - **体质基础**：平素是否怕冷、手脚凉、精力体力如何？
- **医案特征提取**：伴随“心下堵，胃胀，不欲食，头痛，半个脑袋发空”。舌象为“舌淡，苔薄白”，脉象为“脉沉濡”，均支持虚寒之象。患者年龄（50岁）及“天癸渐竭”是重要的体质背景。

**第四层：治疗经过与转归判断**
- **关键提问**：之前是否治疗过？用过什么方法或药物？效果如何？（用于判断病情的顽固性及对治疗的反应）。
- **医案特征提取**：本医案为初诊，无既往治疗史，但通过后续复诊（二至四诊）详细记录了服药后症状的演变，如“气窜感、足凉感基本消失”转为“关节酸、有进风感”，再出现“阵发性手足心燥热”，体现了证候的动态变化和治疗侧重点的调整。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲脉**，兼及**足厥阴肝经、足太阴脾经、足少阴肾经**。冲脉为“十二经之海”、“血海”，其循行“起于胞中，下出会阴，并足少阴之经，挟脐上行，至胸中而散”。患者症状从心下（胸中散部）至大腿根（阴股内廉）再至脚尖（内踝后，入足下），与冲脉主干及分支循行高度吻合。
- **核心病性**：**本虚标实**。
    - **本虚**：**血虚**（精血匮乏，源于“天癸渐竭”）、**阳气不足**（脉沉、身凉）。
    - **标实**：**寒凝**（外感寒邪，阻滞经脉）、**气逆**（气机紊乱，上冲下窜）。
- **推理公式**：
    1.  **[主症：纵向气窜、发凉] + [诱因：着凉] + [年龄体质：七七之年，天癸竭] → 定位病在奇经，尤重冲脉，病机涉及血虚寒凝。**
    2.  **[体征：打嗝缓解] + [伴随症：胃胀、心下堵] → 推导存在“逆气里急”的病机，气机上逆。**
    3.  **[舌脉：舌淡苔薄白，脉沉濡] → 佐证体内无热，属虚、属寒、属气血运行无力。**
    4.  **综合推导**：**（年高精血亏虚之体 + 外寒侵袭）→ 冲脉失养，寒邪凝滞 → 气血运行受阻，气机逆乱 → 产生沿冲脉循行部位的“气窜、胀痛、发凉”及“逆气里急”所致的胃胀、打嗝、头痛等症状。**
- **辨证结论**：**邪伤冲脉，血虚寒凝，逆气里急**。
- **鉴别要点**：
    - **与肝气郁结鉴别**：肝郁气滞之胀痛多局限于胸胁、脘腹，情绪波动时加重，脉多弦，少有全身性、规律性的纵向发凉感。本例气窜范围广泛且与经脉循行相关，伴明显寒象，病位更深在奇经。
    - **与单纯脾胃虚寒鉴别**：脾胃虚寒以脘腹冷痛、喜温喜按、呕吐清水为主，症状多局限于中焦。本例症状范围远超中焦，上至头、下至足，符合冲脉“渗诸阳，灌诸精”、“渗三阴”的广泛联系特点。
    - **与风寒表证鉴别**：风寒表证以恶寒发热、头身疼痛、脉浮为主，病位在表。本例脉沉、无发热，病位在里、在经。
