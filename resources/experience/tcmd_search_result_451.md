### 一、 模拟问诊路径（针对慢性咳喘急性发作/肺胀场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次咳嗽、咳痰、喘促是怎么不舒服？有多久了？以前有没有类似情况？”
- **医案特征提取**：病程长达8年，反复发作，天气变化或受凉是明确的诱发和加重因素。本次急性加重仅2天，提示外感诱因。

**第二层：核心症状细查（望诊/闻诊/问诊导向）**
- **症状性质追问**：
    - **咳痰**：“痰是什么颜色？是稀的还是稠的？量多不多？”（医案：痰少色白质稀）
    - **喘息**：“喘是持续的还是阵发的？是活动后加重还是安静时也喘？”（医案：气短，动则气促）
    - **诱因确认**：“这次发病前有没有着凉、劳累或者接触什么特殊的东西？”（医案：2天前着凉）
- **医案特征提取**：痰白质稀提示寒痰或虚痰；动则气促是典型气虚表现；受凉诱发提示外邪引动宿疾。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身伴随症状追问**：
    - **肾系症状**：“有没有腰酸腿软、耳鸣、听力下降？小便情况怎么样，次数多不多，晚上起夜几次？”（医案：腰膝酸软、耳鸣、小便频数）
    - **表证鉴别**：“有没有怕冷、发烧、身上疼或者流清鼻涕？”（医案：无发热恶寒）
    - **一般情况**：“吃饭、睡觉、大便怎么样？”（医案：纳眠尚可，大便正常）
- **必查舌脉**：
    - **舌诊**：观察舌体颜色、胖瘦，舌质是淡、红还是暗？舌苔是白是黄，是厚是薄？（医案：舌质暗红苔白）
    - **脉诊**：重点体会脉的深度（浮沉）、力度（有力无力）、流利度（滑涩）。（医案：脉沉滑）
- **关联病史追问**：“以前做过肺功能检查吗？诊断是什么？平时用什么药维持治疗？”（医案：有慢阻肺病史，规律吸入支气管扩张剂）

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重后，自己用过什么药吗？效果怎么样？这次来主要是想解决什么问题？”（医案：既往规律吸入治疗，本次急性加重来诊）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺、肾**。病程初期在肺，久病及肾。
- **核心病性**：**本虚标实**。本虚为**肺肾气虚**，标实为**痰浊、血瘀**（兼有轻微外感）。
- **推理公式**：
    1.  **[主症：慢性咳喘8年，动则气促]** + **[舌脉：脉沉]** → 指向 **气虚**（肺肾气虚，肾不纳气）。
    2.  **[症状：腰膝酸软、耳鸣、小便频数]** → 锁定 **肾虚**（肾精亏虚，肾气不固）。
    3.  **[症状：痰白质稀]** + **[舌脉：苔白]** → 提示 **寒痰/湿痰**（肺失宣降，津液成痰）。
    4.  **[舌象：舌质暗红]** → 提示 **血瘀**（久病入络，气虚推动无力）。
    5.  **[脉象：脉滑]** → 支持 **痰湿** 内停。
    6.  **[诱因：受凉后急性加重]** → 提示 **外感风寒** 引动内疾（虽无典型表证，但病因为外感，方中用荆芥佐证）。
- **综合推导**：**肺肾气虚**（气短、动则喘、脉沉、肾系症状） + **兼夹血瘀**（舌暗） + **痰浊内蕴**（咳痰、苔白、脉滑） + **外感诱因**（受凉病史） = **肺胀（肺肾气虚兼血瘀证）**。
- **鉴别要点**：
    - **与单纯肺气虚证鉴别**：单纯肺气虚多见乏力、自汗、易感冒，但无腰膝酸软、耳鸣、小便频数等**肾虚**表现。
    - **与痰热郁肺证鉴别**：痰热证多见痰黄黏稠、口渴、舌红苔黄腻、脉数，本案痰白质稀、苔白，**无热象**。
    - **血瘀证的辨识**：在慢性肺系疾病中，**舌质暗、紫或有瘀斑**是判断兼夹血瘀的关键微观指征，即使患者未主诉刺痛等典型瘀血症状。
