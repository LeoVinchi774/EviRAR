### 一、 模拟问诊路径（针对癫证/精神分裂症场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请问您主要因为什么不舒服来就诊？这种情况持续多久了？是怎么引起的？”
- **医案特征提取**：患者以“失眠、阵发性喜笑不休、阵发性发怒不能自控”为主诉。病程为“日久不解”，提示病情迁延。起病有明确“情志不遂”诱因。西医诊断“精神分裂症”，且西药（冬眠灵、卡马西平）治疗初期有效后逐渐失效，提示病情顽固。

**第二层：局部体征细查（望诊/闻诊导向）**
- **视觉焦点**：观察患者**表情与神态**（是否呆板、苦闷、默默不语）、**眼神**（是否灵活、有无神采）。
- **听觉/行为焦点**：注意患者**言语**（是否主动、语速、内容）、**情绪**（有无无故发笑或易怒的发作性表现）。
- **医案特征提取**：表情呆板苦闷、默默不语、阵发性喜笑与愤怒。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌象**（舌体胖瘦、舌色、有无瘀斑瘀点、苔色与厚腻程度）、**脉象**（脉位、脉力、脉率、流畅度）。
- **关联病史追问**：1. **情绪与睡眠**：“除了哭笑和发怒，平时情绪怎么样？容易烦躁、紧张吗？睡眠如何，是难以入睡、多梦还是易醒？” 2. **躯体症状**：“有没有感觉胸闷、胁肋胀痛、头晕、头重、或者喉咙有痰堵着的感觉？” 3. **月经情况（针对女性患者）**：“月经是否规律，经血颜色如何，有无血块，经前情绪波动是否更大？”
- **医案特征提取**：舌体胖大、质紫黯有瘀斑、苔白腻、脉滑有力。伴随失眠。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前用过哪些药物（中药/西药）？效果怎么样？有没有因为效果不好而加量或换药？”
- **医案特征提取**：西药（冬眠灵、卡马西平）治疗史，初期有效后失效，加量亦无效，提示病机复杂，非单纯镇静可解，需从痰、瘀、郁、虚综合论治。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**心**（主神明）、**肝**（主疏泄，调畅情志）。病机涉及**脾**（生痰之源）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **标实**：**气滞**（肝郁）、**血瘀**、**痰浊**（或痰热）。属实证、郁证。
    - **本虚**：**心气虚**（或兼心阴虚）。
- **推理公式**：
    1.  **[主症：阵发性喜笑不休]** + **[病位理论：心藏神]** → 提示病位在**心**，神明被扰。
    2.  **[主症：阵发性发怒不能自控]** + **[病位理论：肝主疏泄，在志为怒]** → 提示病位在**肝**，肝气郁结，疏泄失常。
    3.  **[舌脉：舌胖大、苔白腻、脉滑]** → 提示**痰湿内盛**。
    4.  **[舌脉：舌质紫黯有瘀斑]** → 提示**瘀血内阻**。
    5.  **[病史：情志不遂日久，西药无效]** + **[症状：表情呆板苦闷]** → 提示存在长期**肝气郁结**（气滞），且病机深入，已与痰、瘀互结。
    6.  **[综合]**：长期情志不遂（**肝郁气滞**）→ 气滞血行不畅（**血瘀**）；肝郁乘脾，脾失健运（**痰湿内生**）。痰、瘀、气郁三者互结，上扰**心神**（心窍），加之病程日久耗伤心气，形成**气虚为本，痰、瘀、气郁为标**的复杂病机。故诊断：**癫证（气虚，肝气郁血瘀，痰浊扰心）**。
- **鉴别要点**：
    1.  **癫证与狂证**：癫证属阴，以沉默痴呆、语无伦次、静而多喜（或兼有郁怒）为特征；狂证属阳，以喧扰不宁、躁妄打骂、动而多怒为特征。本案虽有发怒，但以呆板苦闷、阵发性哭笑为主，属癫证范畴。
    2.  **单纯肝郁化火与痰瘀互结**：单纯肝郁化火常见舌红苔黄、脉弦数，心烦易怒、口苦。本案舌紫黯、苔白腻、脉滑，提示痰、瘀病理产物显著，非单纯火证。
    3.  **心脾两虚与痰瘀扰心**：心脾两虚之失眠、神疲多伴心悸、纳差、舌淡脉细弱。本案脉滑有力、舌有瘀斑，标实征象突出，虚象（气虚）被实邪掩盖。
