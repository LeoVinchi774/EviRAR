### 一、 模拟问诊路径（针对慢性肾炎蛋白尿/水肿场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“发现尿蛋白多久了？最近有什么不舒服，感觉和以前有什么不一样？”
- **医案特征提取**：病程长达10年（久病），1周前因“受凉”诱发（外感加重），表现为“颜面肿胀”和“尿蛋白增加”（水肿+蛋白尿加重）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察**颜面及眼睑**有无浮肿（医案中“颜面轻度水肿”）、**面色**是否红润（医案中“面色少华”）、**精神**状态（医案中“精神差”）。
- **触觉焦点**：按压水肿部位，观察有无凹陷（水肿性质）、腹部有无胀满（医案中“腹胀”）。
- **医案特征提取**：水肿以颜面为主，非全身性重度水肿；面色无华，精神不振。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（淡/红）、舌苔（薄白/黄腻）、脉象（沉濡/细弱/弦滑）。**医案中为：舌质淡，苔薄白，脉沉濡。**
- **关联病史追问**：
    1.  **消化系统**：“胃口怎么样？有没有腹胀、肚子咕噜响？大便一天几次，是成形的还是稀的？”（医案中“纳食差，腹胀，大便不成形，2-3次/日”）。
    2.  **全身症状**：“平时容易累吗？感觉身体沉重吗？口里是苦还是干？”（医案中“体重倦怠，口苦口干”）。
    3.  **治疗史**：“之前用过什么药？效果怎么样？激素是怎么减停的？”（医案中“服强的松治疗，尿蛋白未完全阴转”）。
    4.  **诱因与小便**：“这次加重前有没有着凉、劳累？小便量跟平时比有变化吗？”（医案中“受凉后出现”，“尿量一般”）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次为什么来看病？是水肿加重了，还是检查指标变差了？”（结合主诉“加重1周”和检查“尿蛋白（2+）”）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**脾**（为主），涉及**肾**（久病及肾）。病在**中焦**，影响**水液代谢**与**精微固摄**。
- **核心病性**：**本虚标实**。**本虚**为**脾气（阳）虚**；**标实**为**内湿停滞**。
- **推理公式**：
    - **核心症状群（脾虚失运）**：`[纳食差]` + `[腹胀]` + `[大便溏稀]` → 提示**脾失健运**。
    - **水湿内停证据**：`[颜面水肿]` + `[体重倦怠]` + `[脉沉濡]` → 提示**水湿内停**（湿性重浊，脉濡主湿）。
    - **气虚不荣证据**：`[面色少华]` + `[精神差]` + `[舌质淡]` → 提示**气血生化不足**。
    - **精微下泄证据**：`[长期蛋白尿]`（脾不升清，精微下注） + `[受凉后加重]`（外邪引动内湿） → 强化**脾虚湿困，清阳不升**的病机。
    - **综合辨证**：`[脾虚失运症状群]` + `[水湿内停证据]` + `[气虚不荣证据]` + `[精微下泄证据]` → **辨证结论：脾虚湿阻证**。
- **鉴别要点**：
    1.  **与脾肾阳虚证鉴别**：本证虽有久病史，但无明显的**腰膝酸冷、畏寒肢冷、夜尿清长**等肾阳亏虚典型症状，水肿也非以下肢为甚的阴水，故病位以脾为主。
    2.  **与湿热内蕴证鉴别**：本证虽有“口苦口干”，但**舌质淡、苔薄白而非黄腻，大便溏稀而非黏滞臭秽**，脉象为沉濡而非滑数，故热象不显，湿邪性质偏于寒湿或湿浊，而非湿热。
    3.  **与风水相搏证鉴别**：本证虽有“受凉”诱因和“颜面水肿”，但病程长，以**脾虚内湿**为基础，无**恶风发热、咽喉肿痛、脉浮**等表证，故非急性风水。
