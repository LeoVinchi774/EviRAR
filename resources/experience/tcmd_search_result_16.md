### 一、 模拟问诊路径（针对乳痈/乳腺炎术后迁延不愈场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您乳房肿痛、流脓有多久了？这次加重或复发前有什么诱因吗？比如情绪波动、劳累或饮食不当？”
- **医案特征提取**：病程长达7月余，呈“反复”发作特点，有明确的手术史（切开排脓术）及术后激素治疗史，提示病程迁延，正邪交争。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察乳房局部皮肤颜色（是否发红）、肿胀范围、乳头状态（有无内陷、发红）、伤口形态（是否愈合、有无肉芽）、渗出物的性质（脓血、黄水）与量。
- **触觉焦点**：触摸乳房肿块或疼痛区域的温度（灼热感）、硬度（软硬、有无波动感）、压痛程度及范围，检查腋下淋巴结有无肿大。
- **医案特征提取**：右乳房肿痛、乳头发红、皮肤灼热、伤口未愈合、流脓血。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质颜色（红/淡红）、舌苔（黄/白、厚/薄）、脉象（数/细/滑）。
- **关联病史追问**：“近期情绪如何？是否容易生气、郁闷或焦虑？”（情志因素）。“平时胃口、睡眠怎么样？有没有口干、口苦的感觉？”（肝胃郁热、脾胃状态）。“大小便情况如何？”（判断热邪是否影响二便）。
- **医案特征提取**：精神疲倦、心情忧郁、口干苦、胃纳一般、睡眠一般；舌红，苔微黄，脉细数。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过什么治疗？（如手术、用药）效果怎么样？伤口愈合情况如何？”（评估既往治疗反应及当前正邪态势）。
- **医案特征提取**：行切开排脓术及激素治疗后“伤口愈合差，反复流脓血”，提示热毒未清，正气已伤，局部气血壅滞未解。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：病在**肝、胃（乳房属胃经，乳头属肝经）**，涉及**乳络**。病机关键为肝经郁滞，胃热壅结，热毒蕴聚于乳房局部。
- **核心病性**：属**本虚标实，虚实夹杂**。**实证**为**气滞、热毒、血瘀**（局部肿痛、灼热、流脓血）；**虚证**为**脾气虚、气血耗伤**（精神疲倦、伤口不敛、脉细）。病性偏**热**（口干苦、舌红苔黄、脉数、局部灼热）。
- **推理公式**：
    1.  **[主症：反复乳房肿痛渗液7月，术后不愈]** + **[局部体征：皮肤灼热、流脓血]** + **[全身症：口干苦]** → 提示**热毒蕴结**。
    2.  **[全身症：心情忧郁]** + **[病位在乳房（肝经所过）]** → 提示**肝气郁结**，气滞是化热成痈的起始病机。
    3.  **[全身症：精神疲倦]** + **[病程：迁延7月]** + **[治疗史：术后、激素治疗后]** + **[脉象：细]** → 提示**气血耗伤，正气不足**（脾气虚），故伤口难敛。
    4.  **[舌脉：舌红苔微黄，脉细数]** → **舌红苔黄脉数**佐证热象；**脉细**佐证气血亏虚。
    5.  **综合推导**：**肝郁（因）** 导致**气滞乳络**，郁久**化热成毒（热盛）**，热盛肉腐成脓，加之病程迁延、手术伤正，致**气血亏虚**，形成**肝郁热盛，兼有气血不足**之证。
- **鉴别要点**：
    - **与单纯肝郁气滞证鉴别**：单纯肝郁气滞以乳房胀痛、结块为主，疼痛与情绪相关，无明显红、热、化脓及全身热象（口干苦、舌红苔黄、脉数）。本案有明显热毒蕴结表现（红肿热痛、流脓血），故非单纯气滞。
    - **与纯实热毒炽盛证鉴别**：纯实热毒证多见于乳痈初起或成脓期，红肿热痛剧烈，伴高热、便秘、脉洪数等全身实热证明显，正气未虚。本案病程长，有疲倦、脉细等虚象，属虚实夹杂。
    - **与气血两虚证鉴别**：气血两虚证以伤口苍白、脓液清稀、肉芽不生、全身乏力、面色无华、舌淡脉弱为主，热象不显。本案虽有虚象，但局部红肿热痛、舌红苔黄等热象仍为主要矛盾，故辨证为肝郁热盛为本，兼有气虚。
