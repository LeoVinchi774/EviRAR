### 一、 模拟问诊路径（针对“肺胀”急性加重/肺心病心衰场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次因为什么不舒服加重来就诊的？咳嗽、气喘和以前比有什么不同？不能平卧有多久了？”
- **医案特征提取**：患者有“慢性肺系疾病病史”，本次为急性加重。病程长，本虚基础存在。加重因素为外感或劳累等诱发“痰瘀水饮”壅盛，导致心肺功能失代偿。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望神**：精神萎靡或烦躁？医案中“不能平卧”提示端坐呼吸，属喘脱危象前兆。
    - **望色**：面色是否晦暗？**口唇、指甲青紫**（紫绀）是血瘀缺氧的典型体征。
    - **望形**：**胸廓呈桶状**（肺气肿体征），**颈静脉怒张**（右心衰竭体征），**球结膜及双下肢浮肿**（水饮内停、溢于肌肤）。
- **触觉/听诊焦点**：
    - **切诊**：触摸**四肢温度**（医案中“四肢欠温”为阳虚失温），按压**双下肢**检查水肿程度（凹陷性水肿+++）。
    - **闻诊/听诊**：听诊**两肺湿啰音**（+++，提示痰饮壅肺，水气凌心犯肺）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：**舌质暗偏红，有瘀斑**（主血瘀，偏红提示或有郁热）；**舌苔白腻而厚**（主痰湿内盛）。此为“痰瘀互结”的典型舌象。
    - **脉象**：**脉弦滑**（主痰饮、气滞），但**重按无力**（主里虚，尤其是阳气虚）。此为“本虚标实”的典型脉象。
- **关联症状追问**：
    - **寒热**：“怕冷吗？哪个部位最明显？”（医案中“背部怯寒特甚”是阳虚卫外不固的突出表现）。
    - **汗液**：“容易出汗吗？出汗后怕风吗？”（可辅助判断气虚、阳虚程度）。
    - **二便**：“大便干不干？几天一次？小便量多少，颜色如何？”（医案中“大便时结”为气虚推动无力或津液不布；“小便量少”为阳虚气化不利，水液内停）。
    - **饮食与口味**：“胃口怎么样？嘴里感觉苦还是黏？”（医案中“纳少”为脾虚；“口苦、口黏”为痰湿内蕴，郁而化热或胆气上逆）。
    - **心悸**：“心慌心跳的感觉是持续的还是阵发的？和活动有关系吗？”（医案中“心悸”为水气凌心所致）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重前用过什么药？（中药/西药）效果怎么样？为什么觉得没效果或控制不住了？”（医案明确提示“经西医治疗未效”，说明常规抗感染、平喘等治疗已难以纠正其“阳虚痰瘀水停”的核心病机，需中西医结合强化温阳、化瘀、利水治疗）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**病在肺、脾、肾、心**。以**肺**为病变中心，累及于**脾**（生痰之源）、**肾**（纳气、主水之根）、**心**（主血脉，水气凌心）。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**气阳虚衰**（以肺、脾、肾阳气虚为主）。
    - **标实**：**痰浊、血瘀、水饮**壅塞于肺，凌心射肺。
- **推理公式**：
    1.  **[慢性病史 + 气喘动则尤甚 + 咯痰无力 + 怯寒肢冷]** → 推导出 **“气阳虚衰”** （肺肾气虚，卫阳不温）。
    2.  **[痰多色白质稀 + 苔白腻而厚 + 脉滑]** → 推导出 **“痰浊伏肺”** （脾虚生湿，聚湿成痰）。
    3.  **[口唇指甲青紫 + 舌质暗有瘀斑 + 颈静脉怒张]** → 推导出 **“血瘀内阻”** （气虚推动无力，阳虚寒凝，痰阻气滞，皆可致瘀，且“瘀重于痰”）。
    4.  **[双下肢浮肿 + 小便量少 + 不能平卧 + 心悸 + 两肺湿啰音]** → 推导出 **“水气不化，水饮凌心射肺”** （阳虚不能化气行水，瘀阻水道，水湿内停，上犯心肺）。
    5.  **综合1-4** → 辨证结论：**肺胀（气阳虚衰，水气不化，痰瘀伏肺，瘀重于痰）**。其病机关键为 **“阳虚失温，痰瘀壅塞，水停凌心”**。
- **鉴别要点**：
    - **与单纯“痰热壅肺”证鉴别**：后者多见痰黄黏稠、发热、口渴、舌红苔黄腻、脉滑数，一派热象，无明显的畏寒、肢冷、浮肿等阳虚水停表现。
    - **与单纯“肺肾气虚”证鉴别**：后者以气喘、乏力、自汗、声低为主，痰、瘀、水饮等“标实”之象不突出，无显著青紫、浮肿及白腻厚苔。
    - **注意“口苦、口黏”的辨证**：在此案中，此症并非主证热象的体现，而是在**痰湿（苔白腻厚）壅盛的基础上，郁而微化热，或气机壅滞导致胆气上逆**所致，不能因此否定整体“阳虚痰瘀水停”的本质。治疗上仍以温化为主，佐以通降（如用生大黄）。
