### 一、 模拟问诊路径（针对肺胀/慢性咳喘加重场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次主要因为什么不舒服来看病？咳嗽、咳痰、喘气的情况和以前比有什么不一样？加重多久了？”
- **医案特征提取**：病程长达10余年，提示慢性、迁延性疾病（肺胀）。本次急性加重5天，诱因不明显（“无明显诱因”），提示在慢性虚损基础上，外邪或内伤因素诱发。

**第二层：局部体征细查（望诊/闻诊/切诊导向）**
- **视觉焦点**：
    - **望神**：观察患者精神、面色（是否萎靡、晦暗）。
    - **望形态**：观察胸廓形态（有无桶状胸）、呼吸频率与深度（是否浅促）、有无张口抬肩。
    - **望痰色质**：重点询问并观察痰的颜色（白/黄）、性状（稀/稠/泡沫状）、量（多/少）。
    - **望口唇与甲床**：重点观察有无口唇、指甲青紫（发绀），提示血瘀。
- **听觉/嗅觉焦点**：
    - **闻诊**：听咳嗽声音（有力/无力），听呼吸音（有无哮鸣音、痰鸣音），听语言声音（是否低微）。
    - **听诊（现代医学结合）**：双肺听诊，明确干湿性啰音的范围与性质。
- **医案特征提取**：痰**白质稀、量多**（提示寒饮或气虚不化湿）；**口唇紫绀（+）**（明确血瘀体征）；双肺**干湿性啰音**（提示气道痰阻、痉挛）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/红/暗/紫），舌体胖瘦，苔色（白/黄）、苔质（腻/厚/薄/润/燥）。
    - **脉诊**：脉象的力度（有力/无力）、频率（数/迟）、形态（滑/涩/弱）。
- **关联病史追问**：
    1.  **吸烟史**：“抽烟多久了？每天抽多少？有没有戒烟打算？”（长期烟毒是重要病因）。
    2.  **功能状态**：“活动能力怎么样？走多远、上几层楼会觉得气短？平时容易累吗？”（评估肺肾气虚程度）。
    3.  **全身症状**：“睡眠怎么样？胃口如何？大小便正常吗？怕冷还是怕热？”（判断整体阴阳气血状态及兼夹证）。
    4.  **诊疗史**：“以前做过什么检查（如肺功能、CT）？结果如何？用过什么药，效果怎样？”（明确疾病分期与严重程度）。
- **医案特征提取**：**舌暗，苔稍白腻，脉弱**（舌暗主血瘀，苔白腻主湿/痰，脉弱主气虚）；**易疲乏**（气虚典型表现）；**夜寐不佳**（可能与气喘、痰扰或心神失养有关）；**二便通调**（提示中焦脾胃功能尚可，病位主要在上焦与下焦）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重后，有没有在其他地方看过？用过什么药（中药或西药）？效果如何？为什么选择来看中医？”（了解前期治疗反应，评估病情顽固性及患者依从性）。
- **医案特征提取**：患者曾于“外院”检查并诊断，但“未予系统诊疗”，此次为求中药治疗而来，提示病情迁延，西医基础治疗可能不充分或患者寻求综合调理。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肺、肾**，兼及**血络**。肺主气司呼吸，肾主纳气，久病咳喘，肺气先伤，久则及肾。舌暗、唇绀为瘀血阻络之象。
- **核心病性**：**本虚标实**。
    - **本虚**：以**气虚**（肺肾气虚）为主，表现为久病、活动后气短、易疲乏、脉弱。
    - **标实**：兼夹**痰湿**（痰白质稀量多、苔白腻）、**血瘀**（舌暗、口唇紫绀）。
    - **寒热**：整体偏**寒**（痰白质稀，无热象描述）。

- **推理公式**：
    1.  **[主症：反复咳嗽喘息10余年，活动后气短] + [全身症：易疲乏] + [脉象：弱]** → 推导出 **“气虚”** 为基本病机。
    2.  **[病程：10余年久病] + [病位在肺] + [肾主纳气功能减退（动则气喘）]** → 推导出气虚由肺及肾，形成 **“肺肾两虚”**（特别是肺肾气虚）。
    3.  **[体征：舌暗、口唇紫绀（+）]** → 直接指向 **“血瘀”**。
    4.  **[体征：痰白质稀量多、苔白腻] + [无热象]** → 指向兼夹 **“寒痰/湿痰”** 内阻。
    5.  综合以上：**肺肾两虚（本） + 血瘀痰阻（标）** → 辨证结论：**肺肾两虚兼血瘀证**（痰湿作为兼夹因素蕴含其中）。

- **鉴别要点**：
    1.  **与单纯痰湿阻肺证鉴别**：单纯痰湿阻肺证多以咳嗽、痰多、胸闷为主，舌苔腻，但气虚表现（如动则气喘、脉弱）和血瘀表现（舌暗、唇绀）不突出，且病程相对较短。
    2.  **与肺肾阴虚证鉴别**：肺肾阴虚证常见干咳少痰、痰粘带血、口干咽燥、舌红少苔、脉细数等阴虚内热之象。本案痰白质稀、无热象，可资鉴别。
    3.  **与阳虚水泛证鉴别**：阳虚水泛证多见于肺胀后期，除咳喘、气短外，常伴心悸、肢体浮肿、畏寒肢冷、小便不利等。本案仅二便通调，未见明显水肿及严重畏寒，故以气虚为主，未至阳虚水泛。
    4.  **提示模型**：在慢性阻塞性肺疾病（肺胀）的辨证中，**“久病入络”致瘀**和**“久病及肾”致虚**是两个关键演变规律，问诊和辨证时需主动寻找相关证据（如唇舌色、活动耐力）。
