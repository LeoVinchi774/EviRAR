好的，作为资深中医临床带教专家，我将对提供的崩漏医案进行深度剖析，提炼出可用于临床教学和模型推理的标准化问诊路径与辨证逻辑。

### 一、 模拟问诊路径（针对月经淋漓不净/崩漏场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次月经来了多久还没干净？出血量怎么样，是像水龙头一样哗哗地流，还是像屋檐滴水一样滴滴答答？”
- **医案特征提取**：**病程长（28天）**，**出血特点为“漏”（淋漓不净、时多时少、点滴而下）**。需明确区分“崩”（暴下如注）与“漏”（淋漓不绝），两者病势缓急不同，治法侧重有异。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉焦点（问诊+望诊）**：**经血的颜色（淡红、鲜红、暗红、紫黑）**、**质地（清稀、黏稠、有无血块）**。
- **关键追问**：“血的颜色是鲜红的还是淡的？质地是稀的像水，还是稠的有血块？”
- **医案特征提取**：**血色淡、质清稀**。这是判断虚证（气虚、阳虚）与血热、血瘀的关键鉴别点。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身症状追问**：“除了出血，人感觉累不累？有没有心慌、气短、头晕、怕冷或者手脚心发热的感觉？”
- **必查舌脉**：**舌质（淡/红/暗）、舌苔（白/黄/腻/少）、脉象（沉/浮、迟/数、有力/无力）**。
- **体质与病史挖掘**：患者年龄（14岁，青春期，肾气初盛未充）、既往月经情况（初潮年龄、周期是否规律）、有无过度劳累、饮食不节或情志刺激史。
- **医案特征提取**：**神疲气短（气虚典型表现）、眼眶黯（肾虚或血瘀之象）、舌苔白、脉沉弱（里虚寒之象）**。

**第四层：治疗经过与转归判断**
- **关键提问**：“出血这么长时间，之前有没有看过医生或吃过什么药（中药或西药）？效果怎么样？”
- **目的**：了解既往治疗反应，判断病情的顽固程度和可能的兼夹证（如是否因误治或过用寒凉导致寒凝血瘀），为本次“澄源”（消除病因）提供线索。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任、胞宫**（直接病位）；**脾、肾**（根本病位）。崩漏基本病机为冲任不固，不能制约经血。
- **核心病性**：**虚证**（以气虚为主）、**寒证**（非实寒，乃阳虚生内寒或气虚不温）。气血状态为**气虚不摄，血失统固**。
- **推理公式**：
    1.  **[主症：月经淋漓不净28天，点滴而下]** → 提示病势缓，属“漏”，多与虚、瘀有关。
    2.  **[体征：血色淡、质清稀]** + **[全身症：神疲气短]** → **强烈指向气虚**。气为血之帅，气虚不能摄血，故血下不止；气虚不能生血、化赤，故血色淡质稀；气虚机能减退，故神疲气短。
    3.  **[舌脉：舌苔白，脉沉弱]** + **[体征：眼眶黯]** → **支持并深化虚证判断，且指向脾肾两虚**。脉沉主里，弱主虚，苔白不黄，排除热象；眼眶属肾，其色黯，提示肾气不足或兼有血瘀（本例以虚为主）。
    4.  **综合推导**：**气虚失摄（脾虚为主）** 是导致“漏下”的直接病机；结合**脉沉弱、眼眶黯**等，考虑其气虚根源与**肾气未充（患者14岁）或肾阳不足**有关，形成**脾肾两虚，冲任不固**的最终证型。
- **鉴别要点**：
    - **与血热证鉴别**：血热崩漏多见**经血深红或紫红、质稠、有血块，伴心烦、口渴、舌红苔黄、脉数**。本案血色淡、质稀、苔白、脉弱，截然不同。
    - **与血瘀证鉴别**：血瘀崩漏多见**经血紫暗、有大量血块、小腹刺痛拒按、舌质紫暗有瘀点、脉涩**。本案虽眼眶黯，但血色淡、质稀、无腹痛，脉弱非涩，瘀象不显，方中少量化瘀药（三七、益母草）主要起“通因通用”、防留瘀之效，并非主治。
    - **与单纯脾虚证鉴别**：需关注是否有**腰膝酸软、头晕耳鸣、畏寒肢冷、小便清长**等肾虚（尤以肾阳虚）表现。本案“眼眶黯”、“脉沉”已提示病位及肾，故诊断为脾肾两虚，而非单纯脾虚。
