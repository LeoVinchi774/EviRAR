### 一、 模拟问诊路径（针对慢性心力衰竭/心衰病场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最不舒服、最想解决的主要问题是什么？这种情况持续多久了？”（针对主诉）“具体在什么情况下会加重？比如走路、上楼后感觉如何？”（针对诱因与程度）
- **医案特征提取**：主诉为“反复气促10年余”，表明病程长，属慢性病。加重因素明确为“爬楼梯约4层后出现气促不适”，提示活动耐量下降（心功能Ⅱ级）。

**第二层：核心症状细查（问诊导向）**
- **心肺功能焦点**：
    - **气促/呼吸困难**：性质（活动后/静息时）、程度（能爬几层楼、走多远）、缓解方式。
    - **胸闷/胸痛**：有无、性质、频率、持续时间。
    - **体力状况**：精神、体力、是否容易疲劳（少气懒言、精神疲倦）。
- **全身伴随症状焦点**：
    - **津液代谢**：有无口干、口渴（咽干口燥）、饮水偏好（喜冷/喜热）。
    - **消化功能**：食欲、饭量（纳差）。
    - **二便情况**：大便性状、次数（大便干）、小便量及颜色。
    - **水肿情况**：询问双下肢、脚踝、腰骶部有无水肿（本例中“双下肢无水肿”为重要阴性体征，需主动问及）。
- **医案特征提取**：精神疲倦、少气懒言（气虚）；咽干口燥、大便干（阴虚）；偶有胸闷（心肺气机不畅）；纳差（脾虚运化不及）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：舌色（暗/淡/红）、舌体（胖瘦、齿痕）、苔色（黄/白）、苔质（干/润、厚/薄）。
    - **脉诊**：脉位（浮/沉）、脉率（数/迟）、脉力（有力/无力）、脉形（细/滑/涩）。
- **关联病史追问**：
    - **既往史**：有无高血压、冠心病、心肌病、糖尿病等基础病史。
    - **检查史**：近期是否做过心脏彩超、脑钠肽（BNP/NT-proBNP）等检查？结果如何？（如医案中提供的具体数值）
    - **治疗史**：目前是否服用西药（如利尿剂、ACEI/ARB、β受体阻滞剂等）或中药？效果如何？
- **医案特征提取**：舌暗（血瘀）、苔黄干（阴虚内热）、脉细涩（气血两虚兼瘀）；心脏彩超示心脏扩大、射血分数降低；BNP显著升高。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次是因为什么情况来就诊/复诊的？是症状加重了，还是来常规调理？”（明确就诊目的）“之前用过什么药（中药/西药）？感觉效果怎么样？”（评估治疗反应与病情稳定性）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、脾**。以心为主，涉及脾。心主血脉，心气亏虚则血行无力；脾为气血生化之源，脾虚则气阴生化不足。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**气虚**（精神疲倦、少气懒言、活动后气促）与**阴虚**（咽干口燥、大便干、苔黄干）并存。
    - **标实**：**血瘀**（舌暗、脉涩）。
- **推理公式**：
    1.  **气虚证推导**：[主症：活动后气促] + [全身症状：精神疲倦、少气懒言] + [病机基础：年老、病程长] → **气虚（心脾气虚）**。
    2.  **阴虚证推导**：[症状：咽干口燥、大便干] + [舌象：苔黄干] → **阴虚（心阴/津液亏虚）**。
    3.  **血瘀证推导**：[舌象：舌暗] + [脉象：脉涩] + [病机：气虚推动无力，血行不畅] → **血瘀**。
    4.  **综合辨证**：**气虚证** + **阴虚证** + **血瘀证** → **辨证结论：心衰病（气阴虚兼血瘀证）**。
- **鉴别要点**：
    1.  **与单纯气虚血瘀证鉴别**：单纯气虚血瘀证通常无明显的“咽干口燥、大便干、苔黄干”等阴液亏耗、虚热内生的表现。本例**阴虚**症状明显，是鉴别关键。
    2.  **与阳虚水泛证鉴别**：阳虚水泛证（心肾阳虚）应有畏寒肢冷、小便不利、全身浮肿（尤以下肢为甚）、舌淡胖苔白滑等**寒象与水饮内停**的典型表现。本例无水肿、无寒象，反有热象（苔黄），可资鉴别。
    3.  **与痰浊闭阻证鉴别**：痰浊闭阻证以胸闷、痰多、苔腻、脉滑为主要表现。本例虽有“偶有胸闷”，但无痰多、苔腻之象，且以气阴两虚和血瘀为主，痰浊不显（方中化痰药主要针对岭南地域特点及预防痰湿滋生）。
