### 一、 模拟问诊路径（针对胸闷心悸、脉迟/胸痹、迟脉症场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：请详细描述一下您最不舒服的感觉是什么？比如胸闷、心慌、头晕，哪个最明显？这种情况持续多久了？最近有什么原因导致它加重了吗？
- **医案特征提取**：病程长达“10余年”，提示慢性、久病。近期加重因素明确为“过劳、受凉”，为外因诱发内伤宿疾。

**第二层：核心症状与诱因细查（问诊/切诊导向）**
- **症状性质与程度追问**：胸闷是持续性的还是阵发性的？心慌（心悸）是在活动时明显还是安静时也发作？头晕是感觉天旋地转还是头脑昏沉不清？活动后这些症状是加重还是减轻？
- **体征量化与动态观察**：必须测量并记录心率、血压。询问患者自我感觉最难受时的心跳快慢。
- **医案特征提取**：症状“动则加重”，心率“48次/分钟”，脉象“沉细迟”，共同指向心阳鼓动无力、气血运行迟缓的核心病机。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身伴随症状追问**：除了胸口不舒服，有没有怕冷、手脚发凉、腰膝酸软、精神疲惫、气短不想说话的情况？观察面色如何？（引导患者或家属描述）
- **必查舌脉**：必须观察并记录舌质颜色（淡/红/紫暗）、舌苔颜色与质地（白/黄，薄/厚/腻）。必须仔细诊察脉象，重点体会脉的“位、数、形、势”，特别是脉率（迟）、脉力（沉细无力）。
- **医案特征提取**：“面色苍白，腰酸肢冷，全身乏力”是典型的阳虚失温、机能减退表现。“舌淡苔白，脉沉细迟”是虚寒证的关键舌脉依据。

**第四层：病史与治疗经过追溯**
- **关键提问**：之前在医院做过哪些检查？诊断是什么（如冠心病、病窦综合征）？用过什么药（西药或中药）？效果怎么样？这次是因为什么直接原因来看病的？
- **医案特征提取**：明确西医诊断“冠心病、病窦综合征”及心电图结果“冠状动脉供血不足、窦性心动过缓”，为中医辨证提供重要的现代医学参照和疗效评价指标。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心、肾**。心主血脉，肾为元阳之根。心阳不振，鼓动无力则脉迟、心悸；肾阳衰微，不能温煦则肢冷、腰酸。
- **核心病性**：**本虚标实**。
    - **本虚**：以**心肾阳虚**为核心，兼有气虚（乏力、气短）。
    - **标实**：因阳虚生内寒，导致**寒凝**与**血滞（瘀）**。病性属**虚寒**。
- **推理公式**：
    - **[主症：胸闷、心悸、动则加重] + [全身证：面色苍白、腰酸肢冷、乏力] + [舌脉：舌淡苔白、脉沉细迟] + [病史：年老、过劳受凉诱发] → 辨证结论：心肾阳虚，寒凝血滞。**
    - **推导链**：
        1.  **脉迟、心率慢、畏寒肢冷** → 指向**阳虚有寒**（阳气虚衰，温煦推动无力）。
        2.  **腰酸、年老** → 病位涉及**肾**（腰为肾之府，年老肾气自衰）。
        3.  **胸闷、心悸、动则加重** → 病位重点在**心**（心阳不振，胸阳不展，心脉痹阻）。
        4.  **面色苍白、乏力、气短** → 兼有**气虚**（阳气亏虚，机能衰退）。
        5.  **综合**：心肾之阳俱虚，阴寒内盛，凝滞心脉，气血运行不畅，故成**心肾阳虚、寒凝血滞**之证。
- **鉴别要点**：
    - **与单纯心气虚证鉴别**：单纯心气虚多见心悸、气短、乏力、自汗，舌淡苔白，脉弱或结代，但**畏寒肢冷、腰酸等肾阳虚证不显，脉象以“弱”为主而非典型的“沉细迟”**。
    - **与痰浊阻痹胸阳证鉴别**：痰浊证之胸闷多以憋闷、窒塞感为主，可伴痰多、体胖、苔腻，脉多滑或弦滑，**无明显的畏寒肢冷、脉迟等虚寒象**。
    - **与心血瘀阻证鉴别**：心血瘀阻证胸痛如刺、固定不移，舌质紫暗或有瘀斑，脉涩。本案虽有血滞，但以**阳虚寒凝为因，虚寒症状（肢冷、脉迟、舌淡）为矛盾主要方面**，瘀象相对次要。
