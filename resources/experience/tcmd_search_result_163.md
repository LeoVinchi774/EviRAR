### 一、 模拟问诊路径（针对继发性痛经/寒凝血瘀场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“请描述一下您痛经的具体情况，从什么时候开始的？和以前相比，疼痛的性质、程度、时间有什么变化？”
- **医案特征提取**：
    - **病程**：2年（继发性痛经，提示非先天因素，需追溯诱因）。
    - **加重趋势**：从“以前不怎么痛”到“痛的受不了”，程度显著加重。
    - **关键诱因追问点**：需主动询问生活习惯，特别是饮食偏好（喜冷饮）、经期起居（吹空调、受凉史）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点（望经血）**：
    - **颜色**：经血颜色是鲜红、淡红、暗红还是紫黑？（医案：黑色血块）
    - **质地与量**：经血量是多是少？有无血块？血块大小、质地如何？（医案：经血量偏少，有黑色血块）
    - **伴随物**：有无膜样或肉样组织排出？
- **触觉与感觉焦点（问诊结合）**：
    - **疼痛性质**：是刺痛、冷痛、胀痛还是隐痛？疼痛部位是否固定？（医案：小腹**刺痛**，部位固定）
    - **疼痛缓解/加重因素**：热敷或按压后疼痛是否减轻？遇冷是否加重？（医案隐含：寒邪加重瘀滞）
    - **全身反应**：疼痛时是否伴有冷汗、恶心、呕吐、腹泻或头晕？（医案：疼到**冒冷汗**）

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉（医案未明示，但辨证必需，模型需主动“询问”）**：
    - **舌象**：舌质是淡红、淡白、紫暗还是有瘀点瘀斑？舌苔是薄白、白腻还是其他？（推断：应为**舌质紫暗或有瘀点，苔白或白腻**）
    - **脉象**：脉是弦、紧、涩、沉还是细？（推断：应为**脉沉紧或弦涩**，主寒、主痛、主瘀）
- **关联病史与体质追问**：
    - **月经周期**：周期是否规律？提前还是推迟？（医案：经期**推迟**3-5天）
    - **生活史**：平素饮食偏好吗？是否喜食生冷、辛辣？经期有无贪凉、涉水、淋雨史？（医案：**平素喜喝冰饮，经期常吹空调**）
    - **情绪与压力**：近期情绪如何？是否易焦虑、生气或抑郁？（治疗方案中提及调节情绪，需作为常规问诊项）
    - **二便情况**：大小便是否正常？有无形寒肢冷等全身寒象？

**第四层：治疗经过与转归判断**
- **关键提问**：“之前痛经时是如何处理的？是否服用过止痛药或其他药物？效果如何，停药后是否会复发？”
- **医案特征提取**：需服用**止痛药**缓解，但**停药后疼痛反复**，提示单纯镇痛未治本，需中医辨证干预。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**胞宫（子宫）**、**冲任二脉**。病位在下焦，与肝经循行密切相关（肝经绕阴器，抵小腹）。
- **核心病性**：**实证**为主。病性属**寒**、属**瘀**。具体为**寒湿**客于胞宫，导致**气血（血）瘀滞**。
- **推理公式**：
    - **[主症A：经期小腹固定刺痛] + [体征B：经血色黑、有块、量少、推迟] + [病史C：平素嗜冷、经期感寒] + [推断舌脉D：舌紫暗、脉沉紧]**
    - **→ 辨证结论：气血瘀滞，寒湿阻滞证**。
    - **推导链条**：
        1.  **寒邪内侵**：患者“喜喝冰饮”、“经期吹空调” → 导致**寒湿内停**，客于胞宫。
        2.  **血因寒凝**：“血得寒则凝” → 寒性收引凝滞，使气血运行不畅，形成**瘀血**。
        3.  **瘀阻胞脉**：瘀血阻滞冲任、胞宫脉络 → 表现为**小腹刺痛（痛有定处）**、**经血夹黑色血块（血瘀特征）**。
        4.  **冲任不畅**：寒凝血瘀，阻滞通道 → 导致**经血量偏少、经期推迟**。
        5.  **不通则痛**：以上所有病理环节最终导致“不通”，故疼痛剧烈，需服止痛药，且反复发作。
- **鉴别要点**：
    - **与单纯气滞血瘀证鉴别**：单纯气滞血瘀常由情志不舒引起，疼痛以胀痛为主，受寒加重不明显，舌质紫暗但苔未必白腻，脉多弦涩而非沉紧。**本案关键区别点在于明确的寒邪诱因（嗜冷、吹空调）和“寒象”病理基础**。
    - **与虚寒性痛经鉴别**：虚寒证多为阳气不足，内生虚寒，疼痛以冷痛、隐痛为主，喜温喜按，经色淡、质清稀，常伴全身畏寒、小便清长等，舌淡苔白，脉沉迟无力。**本案为实寒（外寒）与血瘀相兼，疼痛剧烈（刺痛），经色黑有块，是鉴别核心**。
