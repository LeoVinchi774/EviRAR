### 一、 模拟问诊路径（针对尿频尿急/淋证迁延不愈场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您小便不舒服（尿频、尿急、排尿不畅）有多久了？最近半个月是不是明显加重了？”
- **医案特征提取**：病程长达2年，呈迁延性、反复性。**关键加重因素**为“劳累”、“情绪不佳”、“精神紧张”。提示病机与“劳”和“郁”密切相关。

**第二层：局部症状与诱因细查（问诊导向）**
- **症状性质追问**：“小便时是感觉灼热刺痛，还是只是憋胀、排不干净？小肚子（小腹）有没有坠胀或急迫感？”
- **诱因深度挖掘**：“请您仔细回想，每次发作或加重，是不是跟工作压力大、生气、或者身体特别累有关系？是劳累后马上出现，还是休息不好之后出现？”（紧扣“肝郁”与“脾肾虚”两大病机线索）
- **医案特征提取**：小便不畅（非剧痛），小腹急胀。症状与情绪、劳累呈明确正相关。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身伴随症系统询问**：
    - **气机与情志**：“除了小便问题，平时会不会觉得胸闷、喜欢叹气？情绪容易烦躁或低落吗？睡眠怎么样？”
    - **气血与脾虚**：“会不会经常觉得没力气、容易累？脸色自己觉得怎么样？”
    - **肾虚表现**：“腰部感觉怎么样？是酸软还是冷痛？”
- **必查舌脉**：
    - **舌诊**：观察舌质颜色（淡/红）、舌体胖瘦、苔色与质地（白腻/黄腻）。
    - **脉诊**：重点体会脉象是弦（主肝郁、痛）、滑（主湿、痰）、还是细（主虚）或数（主热）。
- **医案特征提取**：胸闷气短、乏力、面色不华、腰酸痛、睡眠差。舌质淡苔白腻，脉弦滑。此为**肝郁（弦）、脾虚湿困（淡、白腻、乏力）、肾虚（腰酸）** 的复合表现。

**第四层：治疗经过与体质损伤判断**
- **关键提问**：“之前都做过哪些检查（如尿常规）？结果如何？用过哪些药，特别是中药，比如清热利湿的方子（如八正散）或抗生素，效果怎么样？”
- **医案特征提取**：检查示尿白细胞轻微或无（0-1+），不符合典型湿热淋证。长期使用抗生素及苦寒中药（八正散、龙胆泻肝汤）**疗效不佳**，反提示可能损伤脾胃阳气，导致病机复杂化（由实转虚或虚实夹杂）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、脾、肾、三焦、膀胱**。以肝气郁滞为病机枢纽，影响三焦气化；脾肾亏虚为病理基础，膀胱气化不利为症状显现之处。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **标实**：气滞（肝郁）、湿阻（膀胱滞涩）。
    - **本虚**：脾气虚、肾气不足。
    - **寒热**：整体偏寒或寒热错杂（舌淡苔白腻，提示寒湿或湿浊；但病史有“热”治无效，需综合判断）。
- **推理公式**：
    1.  **[主症：情绪/劳累诱发尿频急 + 小腹急胀] + [脉弦] → 推导出：肝郁气滞，影响水道通调**。
    2.  **[体征：乏力、面色不华 + 舌淡] + [病史：苦寒药伤中] → 推导出：脾气虚弱，运化失职**。
    3.  **[体征：腰酸痛 + 病程迁延] → 推导出：肾气亏虚，固摄、气化失司**。
    4.  **[舌苔白腻 + 脉滑 + 小便不畅] → 推导出：水湿内停，膀胱气化滞涩**。
    5.  **综合1-4，结合[胸闷气短（肺气不利）] → 最终辨证：肝郁气滞，膀胱滞涩，脾肾亏虚，气化不利（三焦壅滞）**。
- **鉴别要点**：
    - **与单纯膀胱湿热证鉴别**：单纯湿热下注常见小便灼热刺痛、舌红苔黄腻、脉滑数，且清利湿热药（如八正散）应有效。本案舌淡、苔白腻、苦寒药无效，可排除单纯实热。
    - **与单纯脾肾阳虚证鉴别**：单纯脾肾阳虚多见小便清长、畏寒肢冷、舌淡胖苔滑，脉沉迟。本案有明显情绪诱因、小腹急胀、脉弦，提示气滞为主要矛盾之一，非纯虚证。
    - **提示模型**：对于病程长、反复发作、常规清热利湿无效的“淋证”，必须跳出“湿热”定式思维，重点考察**情志因素（肝）**、**体质状态（脾肾）** 及**前期治疗对体质的损伤**。脉“弦”是辨别肝郁气滞的关键指征。
