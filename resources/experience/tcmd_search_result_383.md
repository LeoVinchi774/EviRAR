### 一、 模拟问诊路径（针对阴虚外感/体虚感冒场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：这次感冒多久了？主要感觉哪里不舒服？（引导患者描述“感冒”的核心症状）
- **医案特征提取**：病程可能迁延，常规感冒药（如辛温解表或清热解毒类）效果不佳。需重点询问**素体状况**（如“平时就容易口干、怕热、盗汗吗？”）及**诱发因素**（如“感冒前是否有熬夜、劳累、或病后未愈的情况？”）。

**第二层：局部体征细查（望诊/闻诊导向）**
- **视觉/听觉焦点**：
    - **望诊（痰、咽）**：观察咳嗽时痰的性状（是否粘稠难咯、有无血丝）、咽喉部是否干燥、红肿程度。
    - **闻诊（咳声）**：听咳嗽声音是否清脆或干涩。
- **医案特征提取**：**痰稠难咯或带血**、**咽干**是阴虚内热灼津成痰、损伤肺络的关键体征。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：必须查看舌质颜色（是否红或绛）、舌苔（是否少苔、无苔或剥苔）。
    - **脉象**：必须诊察脉的粗细与速率（是否细或细数）。
- **关联病史与症状追问**：
    1.  **发热特点**：发热时怕冷吗？是怕风还是怕冷？（重点区分“微恶风寒”与“恶寒重”）。
    2.  **汗出情况**：出汗多吗？是白天出汗还是晚上睡觉时出汗？（明确有无**盗汗**）。
    3.  **津液状况**：口渴吗？想喝冷水还是热水？大便干不干？
    4.  **虚热征象**：平时或生病时手心、脚心感觉发热吗？（明确**手足心热**）。
    5.  **神志与睡眠**：有没有心烦、失眠？

**第四层：治疗经过与转归判断**
- **关键提问**：之前用过什么药？（中药或西药）感觉效果怎么样？为什么觉得效果不好？（用于印证“常规治疗无效”的病史，强化阴虚体质与普通外感治法不匹配的判断）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺卫**（表证所在）、**肺阴**（本虚所在），涉及**肾阴**（久病或纵欲伤阴可及肾）。
- **核心病性**：**本虚标实**。**本虚**为**阴虚**（津液亏虚），**标实**为**外感风邪**（表证）。整体病性为**外有风邪，内有虚热**。
- **推理公式**：
    - **外感表证层**：`[身热微恶风寒]` + `[头痛头晕]` + `[汗少]` → 提示**风邪袭表**，但邪正斗争不剧烈（热不高、恶寒轻），因阴液不足，汗源不充。
    - **阴虚内热层**：`[咽干口渴]` + `[痰稠难咯/带血]` + `[手足心热]` + `[盗汗]` + `[心烦]` + `[大便干]` → 指向**阴液亏虚，虚热内生**，上灼肺络，下耗肠津。
    - **舌脉印证层**：`[舌红少苔/光红]` + `[脉细/细数]` → 为**阴虚内热**的典型客观体征。
    - **综合辨证**：`[表证证据（风邪）]` + `[阴虚内热证据]` + `[舌脉支持]` + `[素体/病史提示]` → **辨证结论：阴虚外感证**。
- **鉴别要点**：
    1.  **与普通风热感冒鉴别**：两者均有发热、咽干。**关键鉴别点**在于：风热感冒舌红**苔薄黄**，脉**浮数**，口渴喜饮，痰黄易咯，无手足心热、盗汗等阴虚内热之象，且用辛凉解表药有效。
    2.  **与气虚感冒鉴别**：两者均为体虚感冒。**关键鉴别点**在于：气虚感冒以**乏力、气短、懒言、自汗、舌淡苔白、脉浮无力**为主，无阴虚内热表现。
    3.  **与单纯阴虚内热证（无外感）鉴别**：**关键鉴别点**在于有无**身热恶风寒、头痛**等表证。单纯阴虚证无表证，发热多为午后或夜间低热，不恶风寒。
