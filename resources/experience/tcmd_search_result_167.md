### 一、 模拟问诊路径（针对人工流产术后恶露不绝场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次主要是因为什么不舒服来就诊？”、“出血持续多久了？具体是哪天开始的？”
- **医案特征提取**：锁定“人工流产术后阴道流血30天不尽”这一核心主诉。需明确手术日期、术后出血的初始量、持续时间及变化过程。重点询问术后常规处理（如清宫）及用药史（如“消炎片”）。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察出血的**颜色**（鲜红、淡红、暗红）、**质地**（有无血块、血块大小与颜色）、**量**（需量化，如日用卫生巾数量或与平时月经对比）。
- **触觉焦点**：询问及触诊**小腹**有无坠胀、隐痛、冷感或压痛，疼痛是否固定。
- **医案特征提取**：“血色鲜红或淡红时有小血块”、“小腹坠胀隐痛”。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌象**（舌色、舌体胖瘦、苔色与厚腻）、**脉象**（本案未提供，问诊时必查，如细弱、涩等）。
- **关联病史追问**：1. **全身状况**：有无神疲、乏力、气短、懒言、头晕、自汗、畏寒、食欲、睡眠情况。2. **既往体质**：平素是否体虚、易疲劳。3. **手术及治疗史**：人工流产的具体孕周、手术过程是否顺利、术后是否行清宫术（次数）、是否使用抗生素或止血药。
- **医案特征提取**：“神疲乏力”、“舌淡，苔薄微黄腻”。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前都做过哪些治疗（如清宫、服药）？效果怎么样？”、“出血情况对日常生活和工作有什么影响？”
- **医案特征提取**：患者已行“两次清宫术”并服“消炎片”，但“流血仍不能停止”，提示常规抗炎、清宫治疗效果不佳，需从气血、冲任角度深入辨证。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**胞宫**、**冲任二脉**。与**脾**（气血生化）、**肾**（固摄冲任）密切相关。
- **核心病性**：**本虚标实**。**本虚**为**气虚**（气不摄血），**标实**为**血瘀**（瘀阻胞宫，血不归经）。整体病性偏**虚**，兼有**瘀滞**。舌苔微黄腻提示可能兼有轻微湿热或瘀久化热之象，但非主要矛盾。
- **推理公式**：
    1.  **主症定位**：[人工流产术后30天阴道流血不止] → 病位在**胞宫、冲任**，属“产后恶露不绝”范畴。
    2.  **虚证辨识**：[神疲乏力] + [舌淡] + [病程长、反复清宫伤正] → 推导存在**气虚**（气为血之帅，气虚不能固摄血液）。
    3. **实证辨识**：[小腹坠胀隐痛] + [血色鲜红或淡红时有小血块] → 推导存在**血瘀**（瘀血内阻，新血不得归经；气机不畅则胀痛）。
    4.  **病机整合**：**气虚不摄** + **瘀血内阻** → 辨证结论：**气虚夹瘀证**。气虚为本，导致出血不止和全身乏力；血瘀为标，导致腹痛和血块，两者互为因果，形成“虚→出血→瘀→更虚”的恶性循环。
- **鉴别要点**：
    1.  **纯虚证（气虚/阳虚）**：出血色淡质稀，无血块，腹痛喜温喜按，畏寒肢冷明显。本案有血块和隐痛，排除纯虚。
    2.  **纯实证（血热/血瘀）**：出血色深红、质稠，腹痛拒按，舌红苔黄或舌紫暗，脉弦数或涩有力。本案神疲乏力、舌淡，虚象显著，非纯实。
    3.  **感染湿热**：出血臭秽，小腹灼痛，发热，舌红苔黄腻。本案仅苔“微黄腻”，且用过抗生素，湿热不显，或为兼夹或瘀久微化热。
    **提示模型**：本案辨证关键在于把握“**气虚为本，血瘀为标**”的核心病机。治疗需**益气固摄**与**化瘀止血**并举，不可一味收涩或猛攻瘀血。方中益气药（太子参、山药）与化瘀止血药（桃仁、川芎、益母草配炭类药）同用，正体现了这一思路。
