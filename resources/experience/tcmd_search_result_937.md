### 一、 模拟问诊路径（针对糖尿病性视网膜病变/视瞻昏渺场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您眼睛不舒服主要是什么感觉？是看东西模糊、有黑影飘动，还是看东西变形？这种情况有多久了？哪只眼睛更严重？”
- **医案特征提取**：病程半年，呈“逐渐下降”趋势，有明确“右眼为甚”的侧重性。需追问视力下降的起病时间、发展速度及有无诱因。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：1. **视力检查**：精确记录双眼裸眼及矫正视力。2. **眼底检查（核心）**：重点观察视网膜有无出血（点状、片状、火焰状）、微动脉瘤、硬性渗出、棉绒斑、静脉形态（有无串珠、迂曲）、黄斑区有无水肿及出血、有无新生血管或玻璃体积血。
- **医案特征提取**：本例表现为“散在点片状出血、微动脉瘤、黄斑区硬性渗出、视网膜前出血、双眼黄斑水肿”，属非增殖期重度典型表现。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌象**：舌质颜色（红/暗红/淡红）、舌体胖瘦、有无瘀点瘀斑、苔质（薄/厚）、苔色（白/黄）、苔的润燥（少苔/无苔/剥苔）。**脉象**：脉位（浮/沉）、脉率（数/迟）、脉力（有力/无力）、脉形（细/弦/滑）、脉势（涩/流利）。
- **关联病史追问**：1. **基础病史**：“您有糖尿病（消渴）病史吗？确诊多少年了？近期血糖控制得怎么样？”（本例为12年）。2. **全身症状**：围绕阴虚火旺与瘀血内阻展开：“平时有没有口干想喝水？有没有腰酸腿软、没力气？手脚心会不会感觉发热？晚上睡觉容易出汗吗？睡眠怎么样？大便干不干？”（本例有口干、腰膝酸软、手足心热、夜间盗汗）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次视力下降以来，有没有去医院看过？做过哪些检查（如眼底照相、OCT、荧光血管造影）？用过什么药（口服或眼内注射）？效果怎么样？”（用于评估病情阶段、既往治疗反应及确定当前治疗方案切入点）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、肾**（肝肾同源，开窍于目）。**病络**：目络（视网膜血管）。
- **核心病性**：**本虚标实**。**本虚**：肝肾阴虚，气阴两虚。**标实**：虚火内生，瘀血阻络，水湿停滞。
- **推理公式**：
    1.  **[主症：视力逐渐下降]** + **[病史：消渴（糖尿病）史12年]** → 推导病机基础为“久病耗伤气阴”。
    2.  **[伴随症：口干、腰膝酸软、夜间盗汗、手足心热]** + **[舌脉：舌暗红少苔，脉细]** → 印证并锁定“肝肾阴虚，阴虚火旺”的核心病机。
    3.  **[舌象：边有瘀点]** + **[脉象：涩]** + **[眼底体征：视网膜出血、微动脉瘤（络损血溢）]** → 明确存在“瘀血阻络”的病理环节。
    4.  **[眼底体征：黄斑区硬性渗出、黄斑水肿]** → 提示在阴虚血瘀基础上，兼有“水湿（痰湿）停聚”。
    5.  综合以上：**消渴日久，气阴两伤（病根）** → **肝肾阴虚，虚火上炎（核心病机）** → **灼伤目络，血溢脉外（出血）** → **血滞为瘀，瘀水互结（出血、渗出、水肿）** → **目窍失养，神光发越受阻（视力下降）**。
- **辨证结论**：视瞻昏渺（双眼），证属**阴虚火旺、瘀阻目络证**（兼水湿）。
- **鉴别要点**：
    1.  **与单纯肝肾阴虚证鉴别**：单纯阴虚证可见视力减退、眼干涩、头晕耳鸣、舌红少苔、脉细数，但**无明显的瘀血指征（如舌瘀点、脉涩、眼底出血）和虚火征象（如盗汗、五心烦热）**。本例兼有虚火与血瘀，病机更复杂。
    2.  **与脾虚湿困证鉴别**：脾虚湿困所致者，视力下降多伴视物昏朦、头重如裹、纳呆便溏、舌淡胖苔白腻、脉濡滑。眼底以渗出、水肿为主，**出血表现不突出，且无阴虚火旺的全身症状**。本例虽有水肿，但以阴虚火旺兼血瘀为主证。
    3.  **与气滞血瘀证鉴别**：气滞血瘀证常与情绪相关，或有眼外伤史，表现为视力骤降或眼前固定黑影，胁胀胸闷，舌紫暗或有瘀斑，脉弦涩。**其全身症状以气滞为主，无明显阴虚或虚火表现**。本例瘀血源于阴虚火旺灼络，病机根源不同。
