### 一、 模拟问诊路径（针对哮病/哮喘发作场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次主要哪里不舒服？胸闷、气喘的情况持续多久了？以前有过类似情况吗？”
- **医案特征提取**：
    - **病程长短**：反复发作二十余年，幼年起病，提示宿疾、慢性病程。
    - **复发频率与诱因**：多在天气变化、受凉后发作，明确“外寒引动”的诱因。
    - **加重因素**：本次“再发加重7天”，需追问具体加重原因（如再次受凉、劳累等）。

**第二层：局部体征细查（望诊/闻诊导向）**
- **听觉焦点（闻诊）**：“气喘时喉咙里有没有痰鸣声或哮鸣音？咳嗽时痰多吗？痰是什么颜色、质地？容易咳出来吗？”
- **视觉焦点（望诊）**：观察患者呼吸状态（是否张口抬肩、鼻翼煽动）、面色（是否㿠白）、痰液性状（是否清稀）。
- **医案特征提取**：
    - **痰鸣气喘**：哮病典型表现。
    - **痰白清稀**：寒痰、饮邪的特征性表现。
    - **夜间易发**：提示阳气不足，夜间阴寒加重。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - 舌象：舌质（淡/红）、舌体（胖/瘦）、苔色（白/黄）、苔质（腻/滑）。
    - 脉象：脉位（浮/沉）、脉力（有力/无力）、脉形（细/滑）。
- **全身症状追问**：
    - 寒热：“平时怕冷吗？手脚凉不凉？发作时有没有怕冷的感觉？”（挖掘“畏寒肢冷”）。
    - 汗出：“平时容易出汗吗？白天还是晚上？动一下就出还是不动也出？”（区分自汗、盗汗）。
    - 鼻部症状：“有没有鼻子堵、鼻子痒、打喷嚏、流清鼻涕？”（关联“肺开窍于鼻”）。
    - 二便：“大小便怎么样？有没有小便清长、大便稀溏？”（辅助判断阳气盛衰）。
- **医案特征提取**：
    - **平素畏寒肢冷**：阳虚体质或寒邪伤阳的长期表现。
    - **汗出较多**：需辨明是肺气不固的自汗，还是其他原因。
    - **鼻塞、鼻痒**：肺气不利，外邪（风寒）袭表或鼻窍的局部表现。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发作前有没有看过医生或吃过什么药（中药/西药）？效果怎么样？平时有没有长期使用什么药物来控制（如吸入剂）？”
- **目的**：了解既往治疗反应，评估病情严重程度和慢性管理情况，为当前治疗方案提供参考。

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**肺**（主症为胸闷、气喘、咳嗽），兼及**脾**（生痰之源）、**肾**（气之根，畏寒肢冷之根本）。
- **核心病性**：**本虚标实**。
    - **标实**：**寒**、**痰**（饮）。以寒邪引动，痰气交阻于气道为急性发作期主要矛盾。
    - **本虚**：**阳气亏虚**（肺、脾、肾）。平素畏寒肢冷、脉沉细为长期表现。
- **推理公式**：
    1.  **[主症：反复发作性痰鸣气喘] + [诱因：受凉后发作] + [痰象：痰白清稀] → 提示病属“哮病”，病性偏“寒”。**
    2.  **[全身症：平素及刻下畏寒肢冷] + [舌脉：舌淡胖，脉沉细] → 提示存在“阳气不足”（肺脾肾阳虚）之本虚。**
    3.  **[发作期特征：受寒诱发、痰白清稀、夜间加重] + [舌脉：脉滑] → 锁定急性期病机为“寒痰（饮）伏肺，遇感触发”。**
    4.  **[伴随症：汗出、鼻塞鼻痒] → 佐证肺卫不固、肺窍不利。**
- **综合辨证结论**：**哮病（冷哮证/寒痰伏肺证），兼肺脾肾阳气亏虚。**
- **鉴别要点**：
    - **与热哮鉴别**：热哮多见痰黄黏稠、面赤、口渴喜冷饮、舌红苔黄腻、脉滑数。本案痰白清稀、畏寒、舌淡，可排除。
    - **与风哮鉴别**：风哮常突发突止，喉中痰鸣如哨，多与过敏因素相关，虽可有鼻痒，但痰象、寒热体征不突出。本案有明确寒象，可资鉴别。
    - **辨汗出性质**：需区分是肺气亏虚、卫表不固之自汗，还是痰阻气机、营卫不和之汗。结合畏寒肢冷、脉沉细，更支持阳气虚不固摄。
