### 一、 模拟问诊路径（针对心悸胸闷/胸痹反复发作场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“最近一周，您心慌、胸闷、胸痛发作得是不是比以前频繁了？具体是怎么个不舒服法？”
- **医案特征提取**：病程长达10年（慢性久病），近1周呈**频繁发作**的急性加重趋势。问诊需重点锁定“频繁发作”这一关键变化。

**第二层：局部体征细查（问诊/切诊导向）**
- **症状性质追问**：
    - **胸闷胸痛**：是闷痛、刺痛还是隐痛？疼痛位置固定吗？每次发作持续多久？与劳累、情绪或饱食有关吗？
    - **心悸**：是感觉心跳快，还是心跳沉重、有空虚感？活动后是否加重？
- **医案特征提取**：症状为**心悸、胸闷胸痛**，提示病位在心与心脉。问诊需细化其性质（如闷痛多痰阻，刺痛多血瘀），并探寻诱因（如劳累耗气、饱食伤脾）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **全身症状追问**：“除了心口不舒服，有没有感觉精神不振、特别容易累？胃口怎么样？肚子胀不胀？平时是不是比别人更容易出汗，尤其是白天不活动也出汗？”
- **必查舌脉**：
    - **舌诊**：舌质颜色（淡/红/紫暗），舌苔质地与颜色（白腻/黄腻/薄白）。
    - **脉诊**：脉的力度（有力/无力）、速率（数/迟）、形态（细/滑/涩）。
- **关联病史追问**：“您冠心病病史有10年了，平时是怎么控制的？有没有胃病或者消化不好的老毛病？”
- **医案特征提取**：**神萎乏力、腹胀食少、自汗**是全身性气虚（尤其是脾胃气虚）的核心表现。**舌淡苔白腻，脉细涩**是阳气不足、痰湿内停兼有血瘀的典型舌脉。问诊必须系统收集这些信息。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发作频繁，之前用过什么药或治疗方法吗？效果怎么样？”
- **医案特征提取**：本医案为门诊初诊，但问诊时需了解既往治疗史，以评估病情顽固程度和治疗反应，为“损其心者，益其脾胃”的治则提供背景。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主症心悸、胸闷胸痛）、**脾（胃）**（兼症腹胀食少、神萎乏力）。
- **核心病性**：**本虚标实**。
    - **本虚**：**阳气（中气）不足**（乏力、自汗、舌淡、脉细）。
    - **标实**：**痰浊、血瘀痹阻心脉**（胸闷胸痛、苔白腻、脉涩）。
- **推理公式**：
    1.  **久病冠心病史（10年）** → 提示病程迁延，久病多虚、多瘀。
    2.  **[主症：心悸、胸闷胸痛频繁发作]** + **[舌脉：脉细涩]** → 指向**心脉痹阻**，且脉细提示气血不足，涩提示血行不畅。
    3.  **[伴随症：神萎乏力、腹胀食少、自汗]** + **[舌象：舌淡]** → 共同指向**脾胃气虚、阳气不足**（气虚则机能减退、固摄无权）。
    4.  **[舌象：苔白腻]** → 是**痰湿内停**的明确指征。
    5.  综合推导：**脾胃气虚（本）** → 气血生化不足，心失所养；运化失司，痰湿内生 → 与久病之瘀血相合，形成**痰瘀互结（标）** → **痹阻心脉** → 发为胸痹（胸闷胸痛、心悸）。故证属**阳气不足、痰瘀痹阻证**。
- **鉴别要点**：
    - **与单纯心阳不振证鉴别**：单纯心阳不振亦可见心悸、胸闷、乏力、自汗、舌淡，但多兼形寒肢冷，舌苔多白滑而非白腻，脉多沉微而非细涩，**无明显的痰湿（苔腻）和血瘀（脉涩、痛处固定）征象**。
    - **与单纯痰热扰心证鉴别**：痰热扰心可见心悸、胸闷，但多伴心烦、失眠、口干苦，舌红苔黄腻，脉滑数，**无气虚（乏力、自汗、舌淡）表现**。
    - **提示模型**：本案的关键在于识别出“脾胃气虚”这一根本病机，以及“痰”、“瘀”两种病理产物，三者共同构成了“本虚标实”的复杂证候。治疗上需**补中益气以治本，化痰祛瘀以治标**，而非单纯活血化瘀或温通心阳。
