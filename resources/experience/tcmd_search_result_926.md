### 一、 模拟问诊路径（针对青风内障/正常眼压性青光眼场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您眼睛主要有哪些不舒服？这种情况有多久了？是持续性的还是阵发性的？”
- **医案特征提取**：病程长达10余年，呈慢性、隐袭性进展。主症为“双眼眼胀、虹视”（视物有彩虹光圈）。需重点询问发作诱因（如情绪波动、劳累、暗处久留）、加重或缓解因素。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **问诊**：询问视力变化（视物模糊、视野缺损感）、有无眼前黑影、闪光感。
    - **专科检查（必查）**：视力（Vod/Vos）、眼压（需多次、不同时段测量）、视野检查（寻找鼻侧阶梯等特征性缺损）、眼底检查（视盘杯盘比、视神经纤维层厚度）。
- **医案特征提取**：本例眼压虽在正常范围（14.7-15.0 mmHg），但视野已出现“右眼鼻侧阶梯缺损”，此为诊断关键。提示问诊需结合客观检查，不能仅凭单一指标。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：舌质（颜色、有无瘀点瘀斑）、舌苔（色、质、厚薄）、脉象（频率、力度、形态）。本例为“舌略紫苔白，脉细数”。
- **关联症状追问**：
    1.  **头部与情志**：“有没有头晕、眩晕？发作时是什么感觉？是否与情绪、劳累有关？”（对应眩晕、胸闷、气紧，提示肝失疏泄）。
    2.  **腰府与精力**：“平时是否容易腰酸、膝盖无力？精力如何？”（对应腰酸，提示肾虚）。
    3.  **二便与睡眠**：“大小便情况如何？睡眠质量好吗？”（本例大便秘结，提示可能有内热或津亏；纳寐可，提示脾胃尚和）。
    4.  **全身血瘀征象**：“女性患者需问月经情况：周期、经量、颜色、有无血块、经期腹痛性质。”（后续复诊出现经期小腹刺痛、色暗有块，印证血瘀）。
- **关联病史追问**：“您以前有没有诊断过‘梅尼埃病’、‘高血压’或‘偏头痛’等疾病？”（本例有梅尼埃病史，提示可能与内耳平衡及气血失调相关）。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前针对眼睛的问题做过哪些治疗（如滴眼药水、口服药、激光或手术）？效果怎么样？最近有没有自行停药或调整治疗方案？”
- **医案特征提取**：患者曾在外院确诊但治疗不详，后因停药半年导致病情加重（视野缺损扩大）。强调治疗依从性与定期随访的重要性。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肝、肾、目络（玄府）**。肝开窍于目，主疏泄，调畅气机；肾藏精，精生髓，髓通于脑，目系属脑。肝肾同源，共养目窍。络窍阻滞是神水（房水）运行不畅的直接病理环节。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：肝肾亏虚（精血不足）。
    - **标实**：气机郁滞、脉络瘀阻（络窍阻滞）。
- **推理公式**：
    1.  **[主症：眼胀、虹视] + [全身症：眩晕、腰酸] + [舌脉：脉细]** → 指向 **肝肾亏虚**（肝阴/肾精不足，目窍失养，虚风内动则眩，腰为肾之府）。
    2.  **[全身症：胸闷、气紧] + [舌象：舌略紫]** → 指向 **肝失疏泄，气滞血瘀**（肝气不舒则胸闷气紧；气滞日久，血行不畅则舌紫）。
    3.  **[脉象：数] + [兼症：大便秘结]** → 提示可能存在 **郁而化热** 的倾向（脉数主热，便秘可为津亏或热结）。
    4.  **综合**：肝肾亏虚（本） + 气滞血瘀，络窍不通（标） → **辨证结论：肝肾失调，络窍阻滞证**。
- **鉴别要点**：
    1.  **与单纯肝火上炎证鉴别**：后者多见眼胀痛剧烈、头痛、面红、口苦、尿黄、舌红苔黄、脉弦数等实热证突出，虚象不显。本例虚象（眩晕、腰酸、脉细）明显，热象不著。
    2.  **与单纯痰湿上泛证鉴别**：后者多见头重如裹、胸闷痰多、舌苔白腻、脉滑。本例苔白不腻，无典型痰湿征象。
    3.  **注意病程动态演变**：如本例四诊时，因停药复发，兼见“咯黄痰、苔黄、五心烦热”，证候演变为“肝肾阴虚、痰热内蕴、脉络瘀滞”，提示模型需根据复诊信息动态更新辨证。
