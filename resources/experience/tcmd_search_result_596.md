好的，作为资深中医临床带教专家，我将对提供的医案进行深度分析，提炼出针对“慢性胃病（脾胃虚寒夹瘀毒）”这一病种的标准化问诊路径与辨证逻辑，以服务于医生模型的RAG参考。

### 一、 模拟问诊路径（针对慢性胃痛/萎缩性胃炎场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您胃痛（或胃不舒服）多久了？具体是怎么个痛法？是冷痛、隐痛、胀痛还是刺痛？什么情况下会加重或缓解？”
- **医案特征提取**：病程长达5年，属慢性病程。疼痛性质为“冷痛”，具有“冬季加重，得温则舒”的典型寒性特点，提示病性属寒。

**第二层：局部症状与消化功能细查（问诊导向）**
- **核心询问语句**：
    1.  **疼痛与温度**：“平时怕不怕冷？手脚凉不凉？用热水袋捂一下胃会不会舒服些？”
    2.  **饮食与消化**：“胃口怎么样？吃饭后容易胀吗？喜欢吃热的还是凉的？”
    3.  **二便情况**：“大便怎么样？是干的还是稀的？颜色、次数、形状如何？有没有发现过大便颜色发黑？”
- **医案特征提取**：畏寒肢冷（全身虚寒）、得温则舒（寒证）、食欲不振、食后腹胀（脾虚失运）、大便溏薄清稀（脾虚湿盛）、偶见黑便（瘀血/出血信号）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **望舌**：重点观察舌体颜色（淡/红/紫暗）、形态（胖/瘦、有无齿痕）、舌苔（色、质、厚薄、润燥）。医案提示“舌淡胖、苔白滑”。
    - **切脉**：重点体会脉的位、数、形、势。医案提示“脉沉迟”。
- **关联病史追问**：
    - **现代医学检查**：“之前做过胃镜吗？结果如何？有没有查过幽门螺杆菌？治疗过吗？”（医案已提供：萎缩性胃炎C3型、肠化、Hp阳性史）。
    - **治疗史**：“之前用过什么药？效果怎么样？有没有做过中医调理？”

**第四层：治疗经过与转归判断**
- **关键提问**：“您这次来就诊，最主要想解决什么问题？（如胃痛、怕冷、还是大便问题？）之前针对这些症状，用过什么方法？感觉效果怎么样？”

### 二、 辨证诊断逻辑链（模型内部推理用）

  - **核心病位**：**脾胃**（中焦）。病位主要在脾、胃二脏，涉及中焦阳气。
  - **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：**阳虚**（脾胃虚寒），兼有气虚（脾失健运）。
    - **标实**：**寒凝、血瘀、湿浊、毒邪**。病程日久，“寒凝血瘀”，形成“瘀毒”；脾虚生湿，湿浊内停。
  - **推理公式**：
    1.  **[主症：胃脘冷痛，得温则舒] + [全身症：畏寒肢冷] + [舌脉：舌淡胖苔白滑，脉沉迟]** → **推导出核心病机：脾胃虚寒（中阳不足）**。
    2.  **[病程：5年日久] + [体征：偶见黑便] + [现代检查：萎缩、肠化（视为“内痈”、“毒损”之象）]** → **推导出继发病机：寒凝血瘀，瘀毒内阻**。
    3.  **[伴随症：食欲不振、食后腹胀、大便溏薄]** → **佐证脾虚失运，水湿不化**。
    4.  **综合**：脾胃虚寒（本）+ 瘀毒湿浊内阻（标） = **辨证结论：脾胃虚寒，瘀毒内阻**。
  - **鉴别要点**：
    1.  **与单纯脾胃虚寒证鉴别**：单纯脾胃虚寒证多见胃痛喜温喜按、畏寒、便溏，但一般无“黑便”此等瘀血出血征象，舌脉多以淡、白、弱为主，少见明确的“毒损”（如肠化）病理基础。本案关键鉴别点在于“偶见黑便”及胃镜“萎缩、肠化”，提示在虚寒基础上已衍生“瘀”与“毒”。
    2.  **与肝胃不和证鉴别**：肝胃不和证胃痛多与情绪相关，表现为胀痛、窜痛，伴嗳气、反酸、胸闷、善太息，舌苔薄白或薄黄，脉弦。本案无情绪诱因，以冷痛、畏寒为主，脉沉迟而非弦，可资鉴别。
    3.  **与寒热错杂证鉴别**：如半夏泻心汤证之上热下寒，可见胃脘痞满、嘈杂、反酸、口苦与肠鸣下利、畏寒并见，舌苔常黄白相间。本案一派虚寒之象，无明显热象（如口苦、苔黄、小便黄），故可排除。
