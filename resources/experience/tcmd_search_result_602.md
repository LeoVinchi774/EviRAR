### 一、 模拟问诊路径（针对胃脘痞/慢性胃炎场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您最主要的胃部不适是什么？（如胀、痛、堵）？这种情况持续多久了？是持续存在还是间断发作？最近一年有没有明显加重？”
- **医案特征提取**：主诉为“间断胃胀10余年，加重1年余”。提示问诊需明确病程长、反复发作、近期加重的特点，锁定“痞满”为核心症状。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：观察患者**形体胖瘦**、**面色**、精神面貌。注意**腹部形态**（是否平坦或胀满），胃脘部有无异常搏动或隆起。
- **触觉焦点**：轻按**胃脘部**，询问有无压痛、胀闷感或硬块。注意腹部皮肤的**温度**。
- **医案特征提取**：形体瘦、面色萎黄、胃胀（无形之胀，气滞为主）。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**舌质颜色**（红/淡）、**舌苔颜色与质地**（黄腻/白腻/薄）、**脉象**（左右手分别诊察，注意滑、弦、细等）。
- **关联症状追问**：
    1.  **饮食与消化**：“胃口怎么样？饭后胃胀会加重吗？有没有嗳气、反酸、烧心？食物吃下去感觉能消化吗？”
    2.  **口味与口渴**：“嘴里发干吗？特别是晚上？想不想喝水？喝了水胃里舒服还是更难受？”
    3.  **二便情况**：“大便怎么样？是成形还是不成形？干结还是稀溏？有没有规律？”
    4.  **睡眠与情志**：“晚上睡眠好吗？是不是多梦？平时容易心烦、着急、生气或者感觉压力大吗？有没有手心脚心发热的感觉？”
- **医案特征提取**：纳差、食后不化、嗳气；夜间口干不欲饮、饮水后胃不适；大便时干时稀；五心烦热、夜休差、梦多；舌红苔黄腻，左脉滑右脉弦。

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过胃镜或其他检查吗？结果如何？用过哪些药（中药或西药）？效果怎么样？”
- **医案特征提取**：已行胃镜检查（慢性浅表性胃炎），有明确西医诊断。此为初诊，需了解既往治疗史以评估病情顽固性。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**胃**（主症为胃胀、纳差、食后不化）、**肝**（脉弦、情志相关症状）、**胆**（苔黄腻、左脉滑，与痰热相关）。病位在**中焦脾胃，涉及肝胆**。
- **核心病性**：**虚实夹杂，以实为主**。实为**热**（舌红、苔黄、五心烦热）、**痰**（苔腻、脉滑）、**气滞**（胃胀、嗳气、脉弦）；虚为**脾虚**（纳差、食后不化、形瘦面黄）及潜在的**阴伤**（夜间口干）。
- **推理公式**：
    **[主症：长期、加重的胃胀、嗳气（气机痞塞）]**
    + **[全身症状：纳差、食后不化、形瘦面黄（脾运不及）；五心烦热、夜休差梦多（内热扰心）；口干不欲饮、饮后胃不适（痰湿内阻，津不上承且水饮不化）]**
    + **[舌脉：舌红苔黄腻（痰热内蕴），左脉滑（痰热偏于中焦/胆），右脉弦（肝气郁滞）]**
    → **辨证结论：胃脘痞（肝郁化火，胆热犯胃证）**。
    *推导链条*：长期情志不遂或饮食不节 → **肝气郁结**（右脉弦）→ 郁久**化火**（舌红、五心烦热）→ 肝火横逆犯胃，并影响胆腑疏泄 → 胆腑郁热，炼液为**痰**（苔黄腻、左脉滑）→ **胆热痰浊**上扰心神（夜休差、梦多）并**犯胃**，与胃中气机搏结 → 导致**胃气壅滞，升降失司**（胃胀、嗳气、纳差、大便不调）→ 日久影响脾运，气血生化不足（形瘦面黄）。
- **鉴别要点**：
    1.  **与单纯脾胃湿热证鉴别**：单纯脾胃湿热多见脘腹痞满、口苦口粘、大便粘滞臭秽，舌苔黄腻，但**脉象多滑数或濡数，少有明显弦象，且五心烦热、夜休差等肝火扰心症状不突出**。本案脉弦、梦多，提示病位兼涉肝胆。
    2.  **与肝胃不和证（气滞为主）鉴别**：肝胃不和以脘胁胀痛、嗳气频繁、情绪诱发为主，**舌苔多薄白或薄黄，脉弦**，但**苔腻、脉滑、痰热征象不明显**。本案苔黄腻、左脉滑，是胆热痰阻的关键鉴别点。
    3.  **与胃阴不足证鉴别**：胃阴不足亦可见口干、纳差、便干，但**舌红少苔或无苔，脉细数**，且胃部以嘈杂、隐痛为主，少见明显的胀满、苔腻。本案口干但不欲饮，且苔黄腻，是痰湿阻遏而非单纯阴亏。
