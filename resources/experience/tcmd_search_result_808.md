### 一、 模拟问诊路径（针对心衰水肿/心悸加重场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次来主要是因为哪里不舒服加重了？是心慌、胸闷，还是腿肿得厉害？”
- **医案特征提取**：患者有“风心病多年”的慢性病史，本次为“近日”急性加重。问诊需明确“加重”的具体诱因（如劳累、感染、情绪波动）及持续时间。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **水肿**：观察下肢浮肿的范围（踝部、小腿、大腿）、程度（是否“凹陷性”），以及皮肤颜色（是否光亮、有无紫暗）。
    - **神志面色**：观察患者精神、面色（是否萎黄、苍白），有无烦躁不安（“心烦不安”）的表现。
- **触觉焦点**：
    - **水肿**：按压胫骨前或足踝，检查凹陷程度及恢复速度，判断水肿性质。
    - **四肢温度**：触摸患者手足，感知其温度（本案为“手足清冷”）。
- **医案特征提取**：**凹陷性浮肿**、**手足清冷**。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌诊**：必须观察舌质颜色（淡、红、紫暗）、舌体形态（胖大、有无“齿痕”）、舌苔（薄白、厚腻、水滑）。
    - **脉诊**：仔细诊察脉位（浮、沉）、脉力（有力、无力）、脉率（迟、数），本案为“脉沉略弱”。
- **关联病史与症状追问**：
    1.  **心系症状**：心慌（心悸）是阵发还是持续？胸闷是否与活动相关？有无胸痛？
    2.  **水液代谢症状**：小便量、颜色、次数如何？（本案“小便量少”）。大便性状、次数如何？（本案“大便稀薄”）。
    3.  **全身机能症状**：是否感觉气短、乏力（“气短乏力”）？怕冷还是怕热？睡眠如何？
    4.  **基础病史确认**：风湿性心脏病（风心病）的诊断年限、既往心功能情况、用药史。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次加重后，有没有用过什么药（特别是西药如利尿剂、强心药）？效果怎么样？” “以前有没有因为类似情况住过院？”

### 二、 辨证诊断逻辑链（模型内部推理用）

- **核心病位**：**心、肾**，病在**少阴经**（心肾两脏）。水湿泛溢，病位亦涉及**脾**（大便稀薄、舌有齿痕）。
- **核心病性**：**本虚标实**。
    - **本虚**：**阴阳两虚**，以**阳虚**（少阴虚寒）为矛盾主要方面。
    - **标实**：**水湿内停**。
- **推理公式**：
    1.  **【主症定位】**：`心悸` + `胸闷` + `下肢浮肿` → 病位主要在心，涉及水液代谢（心肾相关）。
    2.  **【定性为阳虚寒化】**：`手足清冷` + `脉沉略弱` + `舌质淡` → 指向**阳气虚衰，不能温煦**。
    3.  **【佐证水湿内停】**：`下肢凹陷性浮肿` + `小便量少` + `大便稀薄` + `舌有齿痕` → 脾肾阳虚，气化失司，**水湿内停、泛溢**。
    4.  **【辨明阴阳两伤】**：在`阳虚`（上述症状）的基础上，出现`心烦不安` → 提示阳损及阴，**阴阳两虚，水火失济**（虚阳浮越或阴不敛阳均可致烦）。
    5.  **【综合辨证】**：`（心悸、胸闷）` + `（手足清冷、脉沉弱、舌淡）` + `（浮肿、尿少、便溏）` + `（心烦）` → **辨证结论：心肾阴阳两虚（少阴虚寒为主），水湿停聚**。
- **鉴别要点**：
    1.  **与单纯心阳虚水泛证鉴别**：单纯心阳虚水泛常见心悸、浮肿、畏寒、舌淡胖，但**通常无“心烦”等明显的阴伤或虚热表现**。本案“心烦不安”是阴阳两虚、水火不交的关键鉴别点。
    2.  **与脾肾阳虚水肿鉴别**：脾肾阳虚水肿以全身浮肿、腰膝冷痛、腹胀便溏为主，**心悸、胸闷等心系症状不突出**。本案心系症状（心慌、胸闷）是主诉，定位更偏少阴心肾同病。
    3.  **与湿热内蕴水肿鉴别**：湿热所致水肿多伴小便黄赤、舌红苔黄腻、身热、脉数等**热象**，与本案的“手足清冷、舌淡苔白、脉沉弱”等**寒象**截然相反。
