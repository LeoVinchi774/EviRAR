### 一、 模拟问诊路径（针对肺结节场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您是因为什么不舒服来就诊的？这种情况持续多久了？咳嗽有什么特点（干咳还是有痰，痰的颜色、质地、量）？”
- **医案特征提取**：主诉为“反复咳嗽1个月”，病程较长，且经“规范抗生素治疗无效”，提示非典型细菌感染，需关注常规治疗反应不佳的线索。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：**（此为医案缺失信息，需重点追问与观察）** 观察患者面色、精神状态。咳嗽时是否有痛苦表情？痰的形态、颜色（白、黄、清稀、黏稠）？
- **触觉焦点**：**（此为医案缺失信息，需重点追问与观察）** 询问患者咳嗽时是否伴有胸痛、胸闷？疼痛位置是否固定？有无胁肋胀满感？
- **医案特征提取**：西医影像学提示“实性结节影，大小约13mmx10mm，可见分叶征和胸膜凹陷征”，中医问诊需将此“有形之结”与患者体感（如胸闷、刺痛）相关联。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：**（此为医案关键缺失信息，必须补充）** 舌象（舌体胖瘦、舌色、舌下络脉、苔色、苔质厚薄腻燥）、脉象（弦、滑、涩、细等）。
- **关联病史追问**：1. **饮食起居**：平素饮食偏好（是否喜食肥甘厚味、生冷）、作息是否规律、有无熬夜史？ 2. **情志状态**：近期有无工作压力大、情绪抑郁或急躁易怒？ 3. **既往体质**：是否常感身体困重、口中黏腻、大便黏滞不爽？有无其他部位结节病史（如甲状腺、乳腺）？

**第四层：治疗经过与转归判断**
- **关键提问**：“之前做过哪些检查和治疗？效果怎么样？医生对结节的性质有什么判断或建议？”（如医案中“抗生素治疗无效”、“建议手术”）
- **医案特征提取**：患者经历了“抗生素治疗无效”和“被建议手术”两个关键节点，问诊需了解患者对此的心理状态和对治疗方式的期望，为选择中医药治疗建立信任基础。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肺**（主症为咳，病灶在肺）。关联**脾**（痰湿生成之源）、**肝**（气机疏泄，影响津液输布与气血运行）。
- **核心病性**：**本虚标实**。**标实**为痰湿、瘀血互结；**本虚**涉及脾虚失运（生痰）、肺气失宣（储痰）、肝郁气滞（助痰凝血）。
- **推理公式**：
    1.  **[主症：反复咳嗽，抗生素无效]** + **[现代影像：肺部有形结节]** + **[体质背景：现代人常见痰湿体质]** → 提示病机非单纯外感，而是内伤痰湿凝聚。
    2.  **[结节影像特征：分叶征、胸膜凹陷征]** → 中医类比为“癥积”、“痰核”，提示病理产物结聚日久，**兼夹血瘀**（“痰瘀互结”）。
    3.  **[治疗原则：调理整体体质，改善内部环境]** + **[医嘱：避生冷油腻，规律作息]** → 反推病机根本在于**脾失健运，水湿内停，聚湿成痰**，上贮于肺。
    4.  **（需补充）**[若见舌淡胖有齿痕、苔白腻，脉滑] → 佐证**痰湿蕴肺**。
    5.  **（需补充）**[若见舌质暗或有瘀点、脉涩] → 佐证**痰瘀互结**。
- **辨证结论**：**痰湿蕴肺，痰瘀互结证**。
- **鉴别要点**：
    - **与单纯痰湿蕴肺鉴别**：单纯痰湿证多以咳嗽痰多、色白易咯、胸闷脘痞、苔腻脉滑为主，结节可能较小、边缘光滑（影像学类比）。本证因夹“瘀”，故结节影像可见“分叶”、“胸膜凹陷”等提示形态不规则、有牵拉的征象，且病程可能更长，或伴固定刺痛感。
    - **与气阴两虚夹瘀鉴别**：后者常见于久病或放疗后，伴有干咳少痰、口干咽燥、潮热盗汗、舌红少苔有裂纹等阴虚内热之象。本证以痰湿实证为主，热象不显。
    - **与肝郁化火犯肺鉴别**：后者咳嗽常随情绪波动，伴面红目赤、口苦咽干、胁肋灼痛、舌红苔黄脉弦数等明显热象。本证情志因素可能为诱因或加重因素，但核心病机在脾肺痰湿。
