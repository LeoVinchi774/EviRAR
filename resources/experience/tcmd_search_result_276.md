### 一、 模拟问诊路径（针对不孕症/肾亏湿阻场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次主要来看什么问题？未避孕未孕有多长时间了？之前有过怀孕或流产史吗？”
- **医案特征提取**：主诉为“未避孕1年未孕”，病程明确。关键病史为“结婚2年，2021年孕五月时自然流产1胎”，提示继发性不孕，且流产史是重要的病因线索。

**第二层：局部体征细查（望诊/问诊导向）**
- **视觉/问诊焦点**：
    1.  **月经情况**：周期、经期、经量、经色、有无痛经（医案中“末次月经8月13日”，周期28天，经期7天，二诊提及“经量正常，色暗红，无痛经”，问诊时需系统采集）。
    2.  **带下情况**：带下的量、色、质、气味（医案中“白带色黄”，提示有热或湿）。
    3.  **小腹感觉**：有无坠胀、疼痛及其性质（医案中“小腹坠胀”）。
- **医案特征提取**：带下色黄、小腹坠胀、月经周期尚规律但经色暗红。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - **舌象**：舌质颜色（淡/红/暗）、舌苔颜色与厚薄（薄白/黄腻）（医案：舌质淡红，苔薄白）。
    - **脉象**：脉的力度、频率、形态（医案：脉细）。
- **关联症状追问**：
    1.  **全身状态**：精神、体力、睡眠（医案：神乏易倦，夜寐尚安）。
    2.  **腰府感觉**：有无腰酸、腰痛、膝软（医案：时有腰酸）。
    3.  **二便情况**：大便的干稀、频率；小便的清浊、频次（医案：大便干结，2日一行）。
    4.  **饮食胃口**：纳食情况（医案：纳食尚可）。
- **关键病史确认**：确认并详细询问流产的具体情况（孕周、原因、术后调养）及输卵管检查结果（医案：输卵管造影提示“双侧输卵管通而欠畅”）。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次发病以来，做过哪些检查和治疗？效果怎么样？”（医案已提供B超及造影结果，问诊时需主动获取或确认此信息）。
- **周期追踪**：后续复诊需重点询问月经来潮时间、经量色质变化、大便及疲劳感等核心症状的改善情况（如医案中二诊“药后大便干结稍缓”）。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**肾、脾、冲任、胞宫（输卵管）**。肾主生殖，为冲任之本；脾为气血生化之源；冲任失调，胞宫（及输卵管）脉络受阻，难以摄精成孕。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **本虚**：肾气亏虚（流产耗伤）、气血不足。
    - **标实**：湿浊、瘀血、郁热阻滞胞络（输卵管）。
- **推理公式**：
    1.  **[主症：继发不孕] + [病史：流产后] + [全身症状：神乏易倦、腰酸、脉细] → 推导出“肾气亏虚，气血不足”之本**。
    2.  **[局部体征：白带色黄、小腹坠胀] + [检查：输卵管通而欠畅] + [兼症：大便干结] → 推导出“湿瘀互结，郁而化热，阻滞胞络”之标**（气滞湿阻则小腹坠胀，湿郁化热则带黄，瘀热内结则便干）。
    3.  **[舌脉：舌淡红苔薄白，脉细] → 支持气血亏虚之象，虽热象不显于舌，但病机关键在于络脉瘀阻化热**。
    4.  **综合结论**：肾亏（本）与湿阻（标）并存，证属**肾亏湿阻**。病机关键为肾虚胞脉失养，兼湿瘀热阻滞胞宫脉络，两相作用，故难成孕。
- **鉴别要点**：
    - **与单纯肾虚不孕鉴别**：单纯肾虚常伴月经量少、色淡、头晕耳鸣、性欲淡漠，舌淡苔白，脉沉细。本案兼具**白带色黄、小腹坠胀、输卵管不畅、大便干结**等明显的湿、瘀、热实证表现。
    - **与肝郁气滞不孕鉴别**：肝郁者常伴情志抑郁、胸胁胀痛、月经先后不定、经前乳胀。本案情绪症状不显，而以**疲劳、腰酸**等肾虚症状及**带黄、腹坠**等湿热下注症状为主。
    - **提示模型**：本案辨证要点在于抓住“**流产后**”这一损伤肾气的起点，以及“**输卵管通而欠畅**”这一现代医学检查结果所对应的中医“湿瘀阻络”病机，将全身虚象与局部实象有机结合。治疗需**通补兼施**，补益肾气气血以固本，祛湿化瘀通络以治标。
