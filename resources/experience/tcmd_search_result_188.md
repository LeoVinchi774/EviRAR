### 一、 模拟问诊路径（针对崩漏/月经淋漓不尽场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“这次月经是什么时候开始的？持续多少天了？和以前正常的月经相比，量、颜色、质地有什么不同？”
- **医案特征提取**：主诉为“月经淋漓不净2个月”。需重点锁定异常出血的起止时间、总时长、与既往月经周期的对比。询问“量时多时少”、“色深红”、“量多时有大血块”等具体特征。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **望经血**：当前出血量（“刻下量不多”）、颜色（“色深红”）、有无血块及大小（“无血块”，但需追问量多时情况）。
    - **望舌**：舌质与舌苔（医案中“舌淡红，苔薄白”）。
- **触觉/听觉焦点**：
    - **切脉**：脉象（医案中“脉细弦”）。
    - **问伴随症状**：有无腰酸、腹痛（医案中“无”）、小腹冷感（后续复诊出现）等局部不适。
- **医案特征提取**：经血“色深红”提示有热或瘀；“量多时有大血块”是瘀血内阻的关键指征；舌淡红苔薄白为虚象或热象不显之象；脉细为虚，弦主肝郁或痛。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：必须记录**舌色（淡红）、苔色（薄白）、脉象（细弦）**。
- **关联病史与体质追问**：
    1.  **全身状态**：睡眠如何（“夜寐欠佳，易醒，醒后难入眠”）、情绪如何（“焦虑，易烦躁”）、精力体力（后续出现“自觉疲劳感”）、二便情况（“大便易稀溏”）。
    2.  **月经史**：初潮年龄、既往月经周期（“7/26天”）、经量、色、质、有无痛经。此为判断本次异常的基础。
    3.  **生育与手术史**：有无生育史（医案未提，需问）、有无宫腔操作史（如“诊刮术”及其病理结果）。
    4.  **年龄与生理阶段**：患者44岁，需考虑**围绝经期**卵巢功能波动背景。
    5.  **既往治疗**：是否接受过激素治疗（如“口服避孕药”）及其效果。

**第四层：治疗经过与转归判断**
- **关键提问**：“这次出血前有没有看过医生或做过检查？（如B超、诊刮）”“之前用过什么药？效果怎么样？”“这次来诊最希望解决什么问题？（是止血，还是调周期？）”
- **医案特征提取**：患者有“诊刮术”史以排除恶变，且口服避孕药调治效果不佳。本次就诊首要解决“漏下不止”，血止后进入“调周治疗”阶段。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**冲任、胞宫**（病变所在），涉及**脾、肾、心、肝**四脏功能失调。
- **核心病性**：**本虚标实，虚实夹杂**。
    - **虚**：脾虚（大便稀溏、疲劳）、肾虚（年逾四十、围绝经期、后续见小腹冷、尿频）、心血虚/心神不宁（失眠、焦虑）。
    - **实**：**瘀血内阻**（经血有块、淋漓日久、内膜偏厚）、**肝郁化火/心火偏亢**（经色深红、焦虑烦躁、脉弦、夜寐不安）。
- **推理公式**：
    1.  **[主症：月经淋漓不净2月，色深红] + [体征：量多时有血块、内膜1.4cm偏厚] + [舌脉：舌淡红苔薄白，脉细弦]** → 提示**瘀血内阻，热扰冲任**（瘀热）。
    2.  **[伴随症：大便易稀溏、疲劳] + [舌象：舌淡]** → 提示**脾气虚弱，统血无权**。
    3.  **[伴随症：夜寐欠佳、易醒、焦虑烦躁] + [脉象：弦]** → 提示**心肾不交（心火偏亢，肾水不足），肝郁气滞**。
    4.  **[患者年龄：44岁] + [生理阶段：围绝经期]** → 提示**肾气渐衰，天癸将竭**的生理基础。
    5.  **综合推导**：在**脾肾两虚**（气血生化不足、封藏失职）的基础上，因**肾水不足**不能上济心火、涵养肝木，导致**心肾不交、肝郁化火**，火热扰动冲任；加之久漏必有**瘀**，瘀血内阻，血不归经，共同导致**崩漏（子宫异常出血）**。故证型为：**脾肾两虚、心肾不交、瘀血内阻型**。
- **鉴别要点**：
    1.  **单纯血热证 vs 本案例**：单纯血热常伴舌红苔黄、脉数、口渴等实热象。本案舌淡红苔薄白、脉细，热象不显，且兼有脾虚便溏、肾虚之象，故为**虚中夹实（虚火、郁热）**，非纯实热。
    2.  **单纯脾不统血证 vs 本案例**：单纯脾不统血多见经色淡红、质稀、乏力明显、舌淡胖。本案经色深红、有血块、烦躁失眠，提示**兼有瘀热与心神不安**，病机更复杂。
    3.  **鉴别瘀血为因还是为果**：本案瘀血既是导致出血不止的病理产物（“瘀血内阻，血不归经”），也可能源于肝郁气滞或气虚运血无力，需结合全身证候综合判断。治疗需在健脾补肾、清心安神的同时**化瘀止血**，而非单纯活血或单纯补益。
