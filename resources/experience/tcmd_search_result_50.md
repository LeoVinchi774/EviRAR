### 一、 模拟问诊路径（针对皮肌炎/肌痹场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：
    1.  “请问您这次来看病，最主要、最不舒服的问题是什么？”（引导患者说出主诉：如“脸上起红斑”或“身上没劲、肌肉疼”）。
    2.  “这个问题（红斑/无力/疼痛）出现多久了？最开始是怎么引起的？”（追溯起病诱因，如发热、外感）。
    3.  “在这期间，病情是持续存在，还是时好时坏？有没有什么情况下会加重或减轻？”（了解病情波动规律，如进食寒凉、劳累、再次发热后加重）。
- **医案特征提取**：病程长达9年余（慢性迁延），有明确诱因（幼年发热后起病），病情反复（进食清凉曾消退后复发），近期因发热（T38℃）后出现新症状（肌无力、疼痛）且加重。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    1.  **皮损**：红斑的形态（蝶形、对称性）、颜色（鲜红、紫红、淡红）、范围（是否局限于面部、有无向躯干四肢扩展）、边界是否清晰、有无肿胀、脱屑、萎缩或色素沉着。
    2.  **肌肉**：肌肉有无萎缩（特别是肩胛带、骨盆带、大腿）、有无假性肥大、肌肉有无自发性跳动或震颤。
- **触觉焦点**：
    1.  **皮损**：红斑处皮温是否升高、有无压痛。
    2.  **肌肉**：肌肉有无压痛（对称性近端肌压痛是重点）、压痛的程度和范围。肌肉的硬度（是否僵硬或松软）。
    3.  **肌力**：通过动作评估肌力，如下蹲起立、抬臂、上楼梯、平卧抬头等动作是否困难，是否需要辅助（如上肢支撑、扶栏杆）。
- **医案特征提取**：颜面部对称性蝶形红斑、双大腿肌肉瘦削（萎缩）、四肢肌肉压痛、颈肌疼痛、下蹲起立无力需上肢支撑、上楼困难需双手攀扶。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    1.  **舌象**：舌质（颜色、胖瘦、嫩/老、有无瘀点）、舌苔（颜色、厚薄、润燥、分布）。
    2.  **脉象**：脉的位、数、形、势，重点感受脉的力度（有力/无力）、粗细（洪/细）、速率（数/迟）。
- **关联病史追问**：
    1.  **全身症状**：有无发热（特别是低热）、体重变化（下降）、乏力感、有无吞咽困难、声音嘶哑、胸闷气短、关节疼痛、皮疹有无瘙痒或疼痛。
    2.  **体质与诱因**：平素怕冷还是怕热？容易出汗吗？大小便情况如何？饮食、睡眠如何？近期有无劳累、情绪波动或再次感染？
- **医案特征提取**：低热、体重下降、舌嫩红、苔白厚、脉细稍数无力。

**第四层：治疗经过与转归判断**
- **关键提问**：
    1.  “之前因为这个病，有没有去医院做过检查？比如抽血、拍片、肌电图？”（获取实验室检查结果，如肌酶、自身抗体、血沉、肌电图等）。
    2.  “之前用过什么药治疗？效果怎么样？特别是激素（比如强的松），用了多久，多大剂量，现在还在用吗？用了之后感觉怎么样？”（了解西医诊断、治疗史及疗效，评估病情严重程度和治疗反应）。
    3.  “这次为什么想来看中医？对之前的治疗效果有什么不满意的地方？”（了解患者诉求和转诊原因）。
- **医案特征提取**：曾于外院诊断为“皮肌炎”，予强的松（15mg tid）治疗症状未改善，兼见新发颈肌疼痛，故要求中医治疗。实验室检查提示抗核抗体阳性、血沉增快、肌源性损害。

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：病在**肌肤、肌肉、经络**，与**脾、胃、肝、肾**关系密切，尤以**脾**为主（脾主肌肉、四肢）。久病及肾，耗伤气阴。
- **核心病性**：本虚标实，**虚实夹杂**。
    - **本虚**：**气阴两虚**（气虚则肌肉无力，阴虚则内热、舌嫩红）。
    - **标实**：**湿热郁结**，**痹阻经络**（湿邪内蕴见苔白厚，热郁肌肤见红斑，痹阻经络见肌肉疼痛、压痛）。
- **推理公式**：
    1.  **[主症：肌肉痿软无力、疼痛]** + **[体征：肌肉瘦削、压痛]** + **[舌脉：舌嫩红、脉细无力]** → 推导出 **“气虚不荣，阴虚失濡”** 的本虚基础。
    2.  **[主症：面部蝶形红斑]** + **[病史：发热诱发、进食寒凉曾缓解]** + **[舌脉：苔白厚、脉数]** → 推导出 **“湿热郁结于肌肤”** 的标实病机。
    3.  **[病程：长达9年，反复发作]** + **[治疗：激素未效，症状迁延]** → 支持 **“久病入络，正虚邪恋”** 的慢性、复杂病机判断。
    4.  综合以上：**（气阴两虚）之本** + **（湿热郁结，痹阻经络）之标** = **辨证结论：气阴两虚，湿热郁结肌肤，痹阻经络**。
- **鉴别要点**：
    1.  **与单纯“痿证”鉴别**：痿证多以肌肉无力、萎缩为主，疼痛不显。本案兼有明显肌肉疼痛、压痛及皮肤红斑，属“肌痹”范畴，为**痹痿并存**，病机更复杂。
    2.  **与单纯“热毒炽盛证”鉴别**：急性期皮肌炎多见皮疹紫红肿胀、高热、舌红绛苔黄燥。本案病程长，表现为低热、舌嫩红苔白厚、脉细数无力，属**慢性期虚中夹实**，热象为阴虚内热而非实火，湿象为脾虚生湿而非外感湿浊。
    3.  **湿热与血瘀的侧重**：本案辨证重点在“湿热郁结”与“气阴两虚”，血瘀征象（如舌质紫暗、固定刺痛）不突出。若见皮疹紫暗、舌有瘀斑、脉涩，则需考虑**兼夹血瘀**，治疗需加重活血通络之力。
