### 一、 模拟问诊路径（针对心功能不全/心水证场景）

**第一层：主诉与病程锁定（必问）**
- **核心询问语句**：“您这次主要因为哪里不舒服来看病？这种情况持续多久了？”
- **医案特征提取**：患者主诉为“心悸气促，动则尤甚，伴下肢浮肿”，病程长达20余年（风湿性心脏病史），近期因“上呼吸道感染”诱发加重。

**第二层：局部体征细查（望诊/切诊导向）**
- **视觉焦点**：
    - **面色与口唇**：观察两颧是否色赤（虚阳上浮），口唇是否紫绀（血瘀）。
    - **肢体**：观察下肢有无浮肿（按之凹陷？），肢端有无厥冷、发绀（颜色青紫）。
    - **关节**：观察有无关节肿胀或变形。
- **触觉焦点**：
    - **肢体**：触摸肢端温度（厥冷），按压下肢浮肿处（判断水肿程度，是否为凹陷性）。
    - **心脏**：听诊心音、心率、有无杂音（结合西医诊断）。
- **医案特征提取**：两颧色赤、唇紫、下肢浮肿、肢端厥冷而发绀。

**第三层：伴随体征与体质挖掘（全身与舌脉）**
- **必查舌脉**：
    - 舌象：舌体胖瘦？舌质颜色（暗红）？舌苔颜色与厚薄（薄白）？
    - 脉象：脉位（沉取还是浮取）？脉力（有力无力）？脉形（细、涩）？
- **关联病史追问**：
    1.  “您有风湿性心脏病病史多久了？平时如何控制？”（确认慢性病史）
    2.  “最近一个月有没有感冒、发烧过？当时如何治疗的？”（确认诱因：上呼吸道感染）
    3.  “除了心慌气短，有没有咳嗽、咳痰？痰是什么颜色，带不带血丝？”（确认兼症：咳嗽频发，咳痰带红）
    4.  “精神体力怎么样？胃口好不好？”（确认全身状态：神萎乏力，胃纳不馨）
    5.  “关节有没有酸痛、胀痛的感觉？”（确认风湿活动：关节酸胀）

**第四层：治疗经过与转归判断**
- **关键提问**：
    1.  “这次发病后，是否住过院？用过哪些药（中药/西药）？效果怎么样？”（确认前期治疗：经治发热渐退，但余症未消）
    2.  “您之前有没有类似的心慌、水肿发作？通常是怎么缓解或加重的？”（评估病情稳定性与既往治疗反应）

### 二、 辨证诊断逻辑链（模型内部推理用）
- **核心病位**：**心**（主血脉、主神明），累及**肺**（咳嗽）、**脾**（纳呆）、**肾**（水肿、肢冷）。病在气血，以心阳衰微为本。
- **核心病性**：**本虚标实**。
    - **本虚**：**阳气虚衰**（以心阳虚、肾阳虚为主）。
    - **标实**：**血瘀**、**水饮**内停。
    - **寒热**：整体属**寒**（肢冷、脉沉），局部见虚热上浮之假象（两颧色赤）。

- **推理公式**：
    - **阳虚证据链**：`心悸气促（动则尤甚）` + `神萎乏力` + `下肢浮肿` + `肢端厥冷` + `舌胖` + `脉沉细` → **心肾阳气虚衰，温运无力，水湿内停**。
    - **血瘀证据链**：`唇紫` + `肢端发绀` + `舌质暗红` + `脉涩` → **心阳不振，推动无力，血行瘀滞**。
    - **综合辨证**：`[阳虚证据链]` + `[血瘀证据链]` + `慢性心病史（久病入络）` → **辨证结论：心水证（阳虚血瘀）**。

- **鉴别要点**：
    1.  **与单纯“气虚血瘀”鉴别**：本证“阳虚”症状突出，如**肢冷、脉沉**，是气虚的进一步加重。若仅见乏力、气短、舌暗，而无明显畏寒、肢冷、水肿，则可能尚在“气虚血瘀”阶段。
    2.  **与“痰瘀互结”或“水热互结”鉴别**：本证舌苔**薄白**而非黄腻，提示热象不显，非痰热或湿热。虽有咳嗽、咳痰带红（可能与肺络损伤有关），但整体病机以阳虚寒凝血瘀水停为主导，非实热证。
    3.  **“两颧色赤”的鉴别**：此为虚阳浮越的“戴阳”征象，需与阴虚火旺或实热的面红目赤鉴别。结合**全身一派寒象（肢冷、脉沉）**，可断定为真寒假热之象。
